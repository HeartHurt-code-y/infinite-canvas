`GPL-3.0-or-later.txt` holds the verbatim GNU GPL version 3 text, i.e. the standard FSF GPL-3.0 text that every GPL-3 distribution ships byte-identically.

Its SHA-256 is `0b383d5a63da644f628d99c33976ea6487ed89aaa59f0b3257992deac1171e6b`; `scripts/ffmpeg-runtime-license.mjs` re-verifies the same digest before the text is shipped with the Windows FFmpeg component as `COPYING.GPLv3`. FFmpeg's local `-L` output identifies the shipped Windows binary as GNU GPL version 3 or later. The shared standard license text is copied verbatim; it does not by itself mean FFmpeg's corresponding source is bundled (see `SOURCE.txt`).

`src/assets/fonts/montserrat/` holds the **Montserrat** webfont (SIL Open Font License 1.1) that the create studio ships so its Latin glyphs and digits render with the same metrics as the reference UI. `OFL.txt` is the license text, reproduced verbatim from the upstream `ofl/montserrat/OFL.txt`; `src/styles/fonts.css` declares the `@font-face` rules. Only the `latin` and `latin-ext` subsets are bundled (the CJK glyphs come from the system font, as on the reference site).
