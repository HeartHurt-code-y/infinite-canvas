# 动漫短剧 V2.3 · 项目原生方法

以下保留该阶段的完整业务方法。应用合同高于来源示例：不执行文中的命令、写盘、外部跳转或自我修改；所有模型取当前项目能力，来源中的固定槽位、时长、像素、帧步长、价格和并发仅是来源实例，不能套用到项目模型。涉及音色时只设计档案；没有项目音频生成能力就标为未生成，不假称已提供音轨。审批由应用记录实际版本，不能由模型宣称用户已批准。

## 阶段三：风格锁定 · ⛔ 审核关 2（V1.3 调整：先于资产生成）

> **V1.3 关键调整**：风格审核**从原阶段四提前到阶段三**，放在剧本审完之后、资产生成之前。
> 原因：角色图的服装色调、场景图的光线氛围、道具图的材质表现**全部依赖风格锚定**。
> 风格不定就生图 = 后期风格漂移的祸根。

### 3.0 铁律 D10：风格必须三选一推荐给用户（V1.1 新增）

**禁止主 Agent 直接定风格**。必须推荐 3 个风格方向（含参考片）让用户选，或用户给参考图反推。

推荐格式（示例，科幻先导片场景）：

| 选项 | 风格 | 参考片 | 适合 |
|---|---|---|---|
| A | 冷调末世科幻 | 《降临》《湮灭》 | 强调「宇宙尺度+孤独」 |
| B | 生物荧光异星 | 《湮灭》《阿凡达》 | 突出异星美感 |
| C | 档案感拼贴 | 《星际穿越》《第九区》 | 强调年代感 |

### 3.1 Agent 推荐 3 个风格方向

| 选项 | 风格 | 适用 |
|---|---|---|
| A | 是枝裕和式日常凝视 + 富士 Pro 400H 冷蓝灰调 | 都市情感、日常、克制 |
| B | 王家卫式雨夜光影 + Cinestill 800T 钠灯光晕 | 情绪化、都市夜景、悬疑 |
| C | 岩井俊二式逆光青春 + 柯达 Portra 400 暖蜂蜜色 | 校园、青春、明亮 |

### 3.2 用户选风格 或 给参考图反推

### 3.3 写入 pipeline_state.json.style_prompt + storyboard.json.style_prompt

**铁律 B1**：一旦锁定，全片统一，不可段间修改。

**V1.3 补充：候选方向必须落盘 `状态/style_options.json`**（否则 02 审核页只能显示已锁定方向，备选看不到）：

```json
{
  "options": [
    {"option": "A", "label": "…", "ref_films": "…", "shot_language": "…",
     "palette": "…", "fit_scenes": "…", "prompt_en": "…"},
    {"option": "B", "label": "…", "prompt_en": "…"},
    {"option": "C", "label": "…", "prompt_en": "…"}
  ],
  "locked_choice": "A"
}
```

> 翻车现场（2026-09-14，《青铜信号》）：推荐 3 个方向只把用户选中的 A 写进了
> `pipeline_state.style_prompt`，B/C 没留档 → 事后补 02 审核页时只能显示「已锁定方向」，
> 备选卡片永久缺失。**推荐完立刻落盘，别等锁定后再补。**

### 3.4 ⛔ 审核关 2：风格审核（V1.3 新增）

**人工审核**：生成 `审核/02_风格审核.html`（`--stage style`），包含：
- 3 个风格方向卡片（每个含风格名 / 参考片 / 镜头语言 / 调色板 / 适合场景）——读 `状态/style_options.json`
- 用户选定的风格高亮标注
- 风格提示词全文（英文 prompt_en）
- 「确认锁定」与「换一组推荐」按钮

> `style_options.json` 缺失时退化为**单卡模式**：只渲染 `pipeline_state.style_prompt`
> 里已锁定的方向，并在页面上显著标注「备选方向未归档」——不假装有三个候选。

**通过后才允许进入阶段四资产生成。**
