# 无限画布前端设计

状态：视觉与交互方向 v0.8（提示内容 module 深化）

## 设计对象

- **具体产品**：为影视、动画与故事创作者服务的 AI 图片与视频生成画布。
- **核心用户**：同时管理角色参考、场景素材、生成节点内提示词、生成参数和多个异步任务的创作者。
- **主界面的唯一工作**：让用户在不丢失媒体位置和任务上下文的前提下，把素材组织成一次可检查、可复用的生成请求。

它不是通用白板，也不是参数表单的可视化外壳。主界面应接近“分镜台 + 剪辑台”：素材始终可见，节点之间的媒体流向清楚，运行状态集中出现。图片与视频生成的供应商、模型和实际生成参数都收拢在各自的生成节点卡片内，右侧检查器不再形成第二套设置或生成入口。

## Hallmark 设计选择

- **宏观结构：Workbench**。素材、画布、检查器和任务记录同时围绕当前创作对象工作，不套用营销页或后台仪表盘结构。
- **主题分支：Bloom**。使用浅纸面、深石墨框架和克制的暖铜交互色，保留“银盐工作台”的产品识别。
- **导航原型：N9 Edge-aligned minimal**。顶栏只保留项目上下文、保存状态、侧板入口和应用级动作。
- **底部原型：Ft2 Inline rule**。将其转译为单线任务摘要与可横向检查的任务卡，不添加无关页脚。
- **视觉素材：既有项目素材（Tier C）**。继续使用项目专属的夜车接触表，不新增装饰性生成图。
- **动效：三种原语**。只保留按钮按压、侧板淡入位移和状态变化；不使用持续漂浮、弹跳或滚动驱动装饰。

## UI/UX Pro Max 可用性补强

这轮不替换 Hallmark 视觉系统，只补强高密度创作工具最容易遗漏的操作能力：

- **键盘优先**：首个焦点提供“跳到画布”；`+ / -` 调整缩放、`0` 恢复默认缩放。画布不设选择/平移工具切换：空白处左键拖拽或任意位置中键拖拽直接平移，滚轮以鼠标位置为锚点缩放，全部由鼠标完成。
- **固定区域避让**：任务栏展开状态提升到工作区共享状态；缩放控件跟随任务栏移动。画布本身不再依赖滚动条，通过平移把被聚焦的节点移出任务栏遮挡区。
- **异步反馈**：任务摘要使用单一原子状态播报；运行任务暴露 `aria-busy`，进度条使用原生进度语义，原始响应入口声明展开关系但不改写响应内容。
- **表单清晰度**：素材筛选使用可见且与输入框关联的标签，搜索结果用完整句子播报并提供直接清除动作；图片与视频节点内的供应商、模型和实际生成参数都使用可见标签。图片节点在文生图操作中直接设置尺寸和质量；视频节点直接设置画幅、分辨率、时长、生成音频和模型特有参数。当前端点不支持批量数量，两类节点的生成数量都固定只读为 `1`；其他字段按当前操作和所选模型能力动态展示或限制。
- **供应商模型设置**：全局设置只管理“连接信息 → 模型能力目录”。用户输入供应商名称、Base URL 和 API Key 后拉取真实模型，将每个模型互斥归为图片模型、视频模型或不启用；图片模型再配置文生图与参考图能力。保存后，图片模型和视频模型只出现在对应生成节点卡片。加载、空列表、成功和完整原始错误都在原位反馈。
- **触控与移动端**：粗指针环境把关键控件命中区提升到至少 `44px`；窄屏输入字号为 `16px`，固定任务栏和检查器操作区预留安全区。
- **减少动态效果**：任务列表展开和运行状态图标只表达状态变化；开启减少动态效果后，展开动画和旋转反馈会直接关闭。

## 视觉命题：银盐工作台

使用浅灰色工作台承载节点，深石墨色框架承载素材库、工具与任务状态。工作台像剪辑室里的灯箱，媒体缩略图和连接关系是画面中最有色彩的部分。

第一版明确避开“全黑背景 + 荧光单色”的常见 AI 工具外观，也不采用营销网站式的大渐变、玻璃卡片和超大标题。专业创作工具通常偏暗，但本产品选择浅色画布作为一处有依据的视觉风险：它把画布与周围控制面板清楚分离，也让复杂节点在长时间工作时更容易扫描。

## 设计令牌

全部令牌集中在根目录的 `tokens.css`，组件样式不得重新声明孤立颜色、字体、间距、圆角、层级或动效值。

### 颜色

| 令牌组             | 色彩模型 | 用途                                           |
| ------------------ | -------- | ---------------------------------------------- |
| `--color-paper-*`  | OKLCH    | 节点、检查器、字段与高优先级内容面             |
| `--color-canvas-*` | OKLCH    | 无限画布工作台和抬升画布面                     |
| `--color-chrome-*` | OKLCH    | 顶栏、素材库、任务栏和深色控件                 |
| `--color-accent-*` | OKLCH    | 暖铜主动作、焦点、选中登记标记                 |
| `--color-image-*`  | OKLCH    | 图片端口和图片位置                             |
| `--color-video-*`  | OKLCH    | 视频端口和视频位置                             |
| `--color-audio-*`  | OKLCH    | 音频端口和音频位置                             |
| 状态令牌           | OKLCH    | 成功、警告、失败及其浅色底，不覆盖原始错误文案 |

所有媒体类型都同时使用文字、图形或编号表达，颜色不作为唯一识别方式。

### 字体

- **界面正文与节点标题**：本地打包的 `IBM Plex Sans Variable`，中文回退到 `Microsoft YaHei UI` 与系统无衬线字体。
- **项目标签、参数、任务 ID 和原始返回**：本地打包的 `JetBrains Mono Variable`。
- 字号下限为 `10px`，按钮文字保持单行；不依赖在线字体服务或运行时 CDN。

### 尺寸、形状与动效

- 间距使用 `2 / 4 / 8 / 12 / 16 / 24 / 40 / 64 / 96 / 144px` 的 4pt 主节奏，画布节点坐标不受界面间距令牌约束。
- 节点和浮层只使用 `3 / 6 / 8px` 三档圆角；圆形只用于端口和状态点。
- 层级统一使用 `--z-*` 令牌；阴影只区分轻微抬升与浮层两级。
- 动效使用 `120 / 220 / 420ms`，自定义 `ease-in / ease-out / ease-in-out`；减少动态效果时统一压缩到 `150ms`。

### 形状和层级

- 节点和浮层圆角为 `8px`，工具按钮、输入框和缩略图圆角为 `6px`；状态胶囊只用于短状态，不把每个操作都做成胶囊。
- 工作台通过细网格和场景坐标表达空间，装饰不进入交互命中区。
- 阴影只用于浮在画布上的节点和弹出选择器；固定面板通过明暗和分割线建立层级。
- 选中状态使用实线外框和左上角登记标记，不依赖大面积发光。

## 识别性元素：三轨接片标记

图片生成节点与视频生成节点都显示三条短轨道：图片、视频、音频。连入的媒体使用 `图片 N`、`视频 N`、`音频 N` 标记，三类分别编号。被提示词 `@` 芯片引用的已连线素材实例按芯片首次出现顺序排列且每个实例只占一个位置，其余已连线实例按连线顺序追加。这个元素不是装饰，它把后端已经确定的三套独立媒体顺序变成用户提交前可以直接核对的界面语言。

活动中的生成链路使用虚线与语义色表达。首版不使用持续动画，只保留悬停、按下与侧板开合反馈；系统开启减少动态效果时把过渡时间压缩到接近零。

## 视觉素材

素材库与节点预览只展示真实媒体：有签名预览地址的图片/视频直接展示源媒体；加载中显示中性加载状态，失败或缺失时显示“预览不可用”，不内置任何示例图冒充真实素材。

## 主界面布局

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 项目 / 场景              保存状态                视图、导出、应用级操作    │
├──────────────┬──────────────────────────────────────────────────────────────┤
│ 素材库       │ 场景坐标 / 缩放控制                                          │
│ 节点仓库     │                                                              │
│ 图片 视频 音频│   素材 ───────> 图片生成                                     │
│ 搜索 / 导入  │       │  供应商 / 模型 / 数量 / 尺寸 / 质量                   │
│ 图片/视频生成│       └───────> 视频生成                                     │
│ 缩略图列表   │          供应商 / 模型 / 画幅 / 时长 / 音频                   │
│              ├──────────────────────────────────────────────────────────────┤
│              │ 异步任务抽屉：运行、重试、成功、失败                         │
└──────────────┴──────────────────────────────────────────────────────────────┘
```

- **素材库与节点仓库**共用默认宽 `272px` 的左侧区域。素材库负责搜索、分类、上传和拖拽；节点仓库只提供图片生成、视频生成两个可重复拖拽的模板，不展示供应商参数。
- **画布**占用剩余空间，是唯一可以无限平移和缩放的区域。节点坐标不做边界钳制，可放置在包括负坐标在内的任意位置；网格随平移与缩放同步移动，连线层按节点包围盒动态计算可视范围。
- **新建画布**初始不放置任何节点或素材；素材卡片、提示词节点和两类媒体生成节点均可不限次数拖入，不对相同来源或模板做实例数量限制。
- 主界面不设节点检查器侧板；节点的输入、任务状态、发起错误与本地结果直接在节点卡片上展示（发起失败错误显示在生成节点卡片内，文件大小显示在结果节点卡片的结果信息中）。
- **任务抽屉**停靠在画布底部，可以折叠；不提供取消按钮。它负责展示不限业务并发数的任务、自动重试提醒和完整原始返回入口。

窄窗口优先保住画布：低于 `960px` 时，素材库变成临时侧板，而不是继续压缩节点。图片和视频生成节点卡片都保持能够容纳自身全部参数字段的稳定最小尺寸，参数与生成操作不会因窄屏转移到其他弹层；用户通过画布平移访问节点的完整内容。移动端采用 `320px` 上限的覆盖式侧板；`320 / 375 / 414 / 768px` 都必须保持根页面无横向滚动，只有无限画布和任务卡轨道允许各自横向移动。两类生成节点内字段在粗指针设备上保留完整标签、键盘焦点与至少 `44px` 的触控命中区。

## 画布 state module

画布持久状态通过一个 deep module 管理。外部 interface 只包含稳定读模型、类型化命令、版本化文档往返和撤销/重做；`nodesById`、Zustand、zundo、九类节点投影、连线索引和引用缓存均属于 implementation，不得由调用方读取或改写。

- 节点操作使用 `addNode / patchNode / patchNodes / removeNode`。patch 不能增删节点或改变 key；删除节点会在同一次写入中清理相关连线和失效选择。
- 连线操作使用 `connect / disconnect`。module 统一维护端点存在、禁止自连、提示词单入口和爆款复刻单输入等不变量，调用方不再自行过滤边数组。
- 产物卡片使用 `addOutput`，节点与来源虚线在同一次写入中建立。清空画布也只执行一次原子命令，并保留视图。
- `snapshotV2 / restoreDocument` 隐藏九类节点数组映射、可选字段缺省、会话预览过滤、V1 迁移和历史重置。磁盘 I/O 仍由 `canvasDocumentClient` 调用方负责。
- React Flow 变化通过最小 change adapter 进入画布 module。提示内容以结构化 canonical document 进入 V2；旧 V1 HTML 只由提示内容 adapter 白名单迁移，不能原样恢复。
- 节点与连线进入历史；视图、选择和被动尺寸测量不进入历史。一次原子命令最多产生一步撤销。

这个 seam 把“画布持久状态”与生成任务、临时运行状态、AbortController、DOM 引用和 blob 生命周期分开，提升 locality；常见调用无需理解缓存和历史策略，interface 因而具有较高 depth 与 leverage。

## 提示内容 module

提示内容由节点级 handle 管理；有序 `text / media_reference / pending_reference` 是 canonical document，contentEditable DOM 只是 local-substitutable adapter。`WorkspaceApp` 只调用结构化快照、纯文本准备、生成冻结、文本替换和恢复，不读取 `HTMLElement`、`innerHTML`、dataset、Range 或 chip class。

- `read / snapshot / restore` 统一文本、媒体引用、待确认项和文档往返；相邻文本归并，换行固定为 `\n`，零宽光标锚点不进入 document。
- `preparePlainText` 是提示词优化的唯一读取入口；存在待确认项时返回 typed issue，并由 handle 聚焦对应位置。
- `prepareGeneration` 原子校验待确认、断线和引用来源身份，一次返回冻结的 `PromptSegment[]`、已引用画布实例集合和未引用连线媒体；调用方不再重复解释引用规则。
- 每个媒体引用都直接保存 `canvasNodeKey`。公司素材、本地素材和本地生成结果都同时保存来源身份；相同来源的两个画布实例不会被错误合并。
- DOM adapter 隐藏自动名称识别、最长匹配、同名消歧、learned mapping、chip 创建、caret、IME、纯文本粘贴和 stale 投影。jsdom 通过同一 interface 测试该 implementation，不增加伪造 port。
- 画布 V2 只保存 `PromptContentDocumentV1`；V1 `innerHTML` 经严格白名单转成 canonical document，脚本、样式、事件属性和未知富文本结构不会进入新文档。

## 关键界面对象

### 素材卡片

- 缩略图或音频波形是主体。
- 固定展示素材类型、名称和时长/尺寸等一个最重要的元数据。
- `Pending`、`Processing`、预览刷新和不可用状态覆盖在缩略图内，但不改变素材稳定身份。
- 视频素材卡片静止时展示代表性关键帧截图；指针悬浮后在原缩略图区域内静音播放，移出时停止并恢复关键帧，不创建常驻播放器。
- 拖入画布创建新的素材节点实例；同一素材可反复拖入，每个实例拥有独立画布节点 ID。

### 生成节点内提示词

- 图片和视频生成节点都自带提示词输入框；独立提示词节点可生成或优化文本，并通过输出端连接到图片或视频生成节点。
- 输入 `@` 时只列出已经连入当前生成节点的素材实例；芯片保存目标画布节点 ID，并使用真实素材名称及 `图片 N`、`视频 N` 或 `音频 N` 标签显示。
- 粘贴或手写输入走同一套自动引用解析：粘贴后立即扫描，手写停止片刻后扫描；唯一命中的已连线素材完整名、文件名词干或稳定别名（如 `图片2`）原位转换为结构化 `@` 芯片，粘贴文本已有 `@` 时不重复添加。
- 同名或同词干命中不猜测具体实例，而是原位转换为带问号和“待确认”文字的黄色可聚焦芯片，并立即展示包含素材类型、完整名称、实例短 ID 和 `图片 N` / `视频 N` / `音频 N` 稳定别名的内联选择器。确认一次会解决当前提示内容中全部相同待确认项，并把名称到画布实例的映射保存进 canonical reference；DOM dataset 只是瞬态投影。该节点后续输入同名词自动沿用，目标断线后记忆自动失效。
- 提示词框常驻显示自动识别状态，以图标、文字和颜色共同区分“正在识别、已自动引用、同名待确认、未匹配、未连接素材”；动态结果通过礼貌级 live region 播报，自动替换不移动用户光标。存在待确认引用时，图片/视频生成和提示词优化都必须阻止提交并把焦点送回待确认项。
- 文本编辑状态和只读画布状态使用同一内容结构，不在两者之间重新解析名称。
- 同一来源素材的多个画布实例不能按名称或来源 ID 合并；选择器同时展示缩略图、类型和实例短 ID，保证引用落到用户选择的具体连线实例。
- 同一实例即使出现多个 `@` 芯片，提交时也只占一个媒体输入位置；未被 `@` 引用的连线实例按稳定连线顺序追加。

### 生成节点

- 节点仓库展示提示词生成与优化、图片生成和视频生成三种模板；任一模板都可反复拖入画布并形成相互独立的实例。提示词节点使用已配置的文本模型，输出端可连接到图片或视频节点。
- 提示词节点保留完整多轮上下文，输出框始终支持直接编辑；编辑后的内容继续作为下游图片或视频节点的提示词输入。
- 图片生成节点卡片是图片生成参数与生成操作的唯一入口；卡片内直接设置供应商、模型，并显示只读生成数量 `1`。文生图操作显示尺寸和质量，接入图片后切换为图片参考生成并隐藏这两个不受该接口支持的字段，提交时也不携带它们。节点头部的小型生成图标是唯一图片任务入口，工具栏、全局设置或其他位置不提供同类参数控件或图片生成按钮。
- 视频生成节点卡片是视频生成参数与生成操作的唯一入口；卡片内直接设置供应商、模型、画幅、分辨率、时长和生成音频，并按模型能力显示联网搜索、输出格式和任务类型，生成数量固定只读为 `1`。工具栏、全局设置或其他位置不提供同类参数控件或视频生成按钮。
- 分辨率与时长选项跟随当前模型能力变化；Seedance 2.5 提供输出格式、任务类型与联网搜索（已确认支持 `1080p`），Seedance 2.0 标准版/快速版提供联网搜索。联网搜索仅在没有媒体输入时可启用，接入素材后节点立即关闭并禁用该参数。
- 每个提示词、图片或视频生成节点实例都独立保存自己的配置；重复拖入的节点互不联动，修改一个节点不会改变其他节点或后续新建节点。
- 两类节点的参数字段都使用稳定的紧凑网格、可见标签和明确焦点状态；字段交互不得触发节点拖动，参数内容变化不得造成卡片尺寸跳动。
- 节点主体同时显示输入数量、最新结果和运行状态；全部生成参数直接保持可核对，不另做仅供编辑的弹层。
- 图片、视频、音频输入分别显示自己的位置列表，绝不显示跨类型的“素材 1”。
- 视频生成节点头部固定放置一个小型向右播放图标；点击该图标创建视频生成任务。图标在任务创建后立即恢复可点击，允许继续创建新任务。
- 运行中节点没有取消入口；节点可继续移动、选择和查看历史任务。

### 任务抽屉

- 每个任务显示本地任务 ID、节点名称、供应商/模型、状态、当前尝试次数和创建时间。
- 网络错误或 `5xx` 自动重试时展示“将在 4 秒后进行第 3 次请求”等明确文案。
- 失败任务直接显示原始状态码与返回摘要；详情中完整展示请求参数、每次调用及未经改写的原始返回。
- “复制原始返回”和“导出诊断”是操作；不提供把错误改写成友好摘要的替代视图。

## 首轮原型范围

第一轮只验证信息架构和视觉方向：

1. 空白初始画布、素材类型切换、素材列表与三个生成模板的节点仓库。
2. 素材、提示词生成与优化、图片生成、视频生成和结果节点的重复拖入与画布编排。
3. 节点选择后右侧检查器切换；图片和视频节点都只展示只读输入、任务和结果信息。
4. 提示词节点的生成/优化、文本模型选择、输出编辑，以及到图片/视频节点的提示词连线。
5. 生成节点内提示词、`@` 精确引用与图片、视频、音频三套输入位置预览。
6. 任务抽屉的运行、重试、成功和失败状态。
7. 图片节点内供应商、模型、只读生成数量 `1`、文生图尺寸和质量的独立实例配置，操作随图片输入切换，以及节点头部唯一图片生成入口。
8. 视频节点内供应商、模型、画幅、分辨率、时长、生成音频和模型特有参数的独立实例配置、只读生成数量 `1`，以及头部播放操作。
9. 视频素材关键帧与悬浮静音播放。
10. 桌面宽度下的布局与基础键盘焦点。

第一轮不实现远程请求或任务持久化；这些交互在视觉骨架确认后分别进入可测试的功能切片。

## 后续实现切片

1. 工作区框架与面板尺寸持久化。
2. 真实无限画布、鼠标直接平移、滚轮缩放和节点层级。
3. 素材库与节点仓库拖拽、空画布和不限重复实例。
4. 生成节点内结构化提示词编辑器，以及只引用已连线实例的 `@` 选择器。
5. 类型化端口、稳定连线顺序和三套媒体位置预览。
6. 生成节点参数 Schema 与所有权：图片供应商、模型、操作相关参数只在各自图片节点卡片内编辑；视频供应商、模型、画幅、分辨率、时长、生成音频及模型特有参数只在各自视频节点卡片内编辑。两类节点的生成数量都在卡片内固定显示为 `1`，检查器仅保留只读输入、任务和结果信息。
7. 视频素材关键帧、悬浮静音播放、视频节点头部播放操作，以及异步任务抽屉、原始请求/返回详情和本地结果预览。
8. 键盘操作、减少动态效果、高对比度与长时间使用校准。
