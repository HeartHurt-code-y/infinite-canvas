# 多宫格分镜提示词技能接入

提示词生成与优化节点增加 `multi_grid_storyboard` 模式，界面名称为“多宫格分镜”。在原有文本模型调用中处理创意完善、剧本分析和参考图加剧情，交付位置对应的图片提示词与视频提示词。

## 使用方式

1. 添加“提示词生成与优化”节点，选择项目已有文本模型，将技能模式切换为“多宫格分镜”。
2. 输入创意或剧本，也可连接参考图片、已保存的视频产物作为视觉参考。仅有素材时允许根据可见画面建议剧情，并明确区分观察与创作设定。
3. 在对话中指定宫格数、目标时长和风格，例如：“6 宫格，18 秒，真人电影感。咖啡店里，两位老友多年后重逢，从迟疑到释然，少量对白。”
4. 必要参数缺失时，节点用普通对话合并补问；已提供或历史确认的参数不重复询问。参数完整时展示测算并继续生成。
5. 正常输出包括整体设定、时长与台词预算、逐格图片提示词、图片整体生成指令、逐格视频提示词和视频整体生成指令。剧本分析模式另含角色、场景、道具资产准备清单。
6. 可直接编辑输出，然后切换优化并提交修改要求；留空也能基于当前输出继续优化。请求携带完整对话、当前手改输出和本轮真实素材。
7. 图片或视频节点沿用现有连线接收当前输出全文。需要单一用途时，可先回复“只保留完整的图片整体生成指令”或“只保留完整的视频整体生成指令”，再连接相应节点；不会自动分拆输出或自动执行媒体生成。

没有文字、没有参考素材且没有可优化输出时不提交空请求。模式、对话、输出与连线沿用现有画布保存和恢复机制。

## 应用适配合同

### 宫格与输出

| 宫格数 | 布局      | 阅读顺序                           |
| ------ | --------- | ---------------------------------- |
| 4      | 2 行 2 列 | 第一行 1–2，第二行 3–4             |
| 6      | 2 行 3 列 | 第一行 1–3，第二行 4–6             |
| 9      | 3 行 3 列 | 第一行 1–3，第二行 4–6，第三行 7–9 |

位置称呼以主技能 Step 2 的实际布局为准；6/9 宫格的位置 2 为“中上”，不照抄 Step 6 通用示例中的“右上”。正常输出以主技能的双输出合同为准，原始参考模板中的固定六宫格、纯视频输出或每格必须有台词要求不能覆盖它。用户明确选择单一交付内容时尊重该要求。

### 时长与台词预算

文本模型按本轮目标时长 `T`、宫格数 `N` 和语速 `r` 估算，默认 `r = 3.5 字/秒`、每格最低留白 `0.5 秒`；慢速抒情和快嘴等设置采用本轮实际选择的同一个 `r`。

- 单格计划时长：`T / N`。
- 单格台词预算：`max(0, floor((T / N - 0.5) × r))`。
- 台词和最低留白占用：`实际台词总字数 / r + N × 0.5`。

公式优先于来源速查表；检查单格 1.2 倍容差后仍须复核总占用不超过用户选择的 `T`，某格多用的时间需由其他格节省抵消。只增加宫格数不能减少总对白耗时，反而增加最低留白时间。

目标/计划时长与对白占用估算分开展示。无台词镜头可通过动作、停顿和环境声延展至计划时长，不把对白少当作成片时长不足。这些是文本规划估算，并非实测配音或视频长度。12–30 秒为来源建议范围；用户明确选择范围外时说明影响并尊重选择，实际生成能力仍以媒体节点模型为准。

### 素材与工具

- `AskUserQuestion` 适配为节点自然语言对话，不要求文本供应商提供工具调用能力，也不输出伪造工具调用。
- 素材及历史作为参考，不覆盖用户当前要求和内置运行合同。无图时明确依据文字，不编造人物外观或读图结论。
- 视频由现有联系表链路提供真实画面证据。采样联系表的格数、边框和时间码不代表用户选定的故事板宫格；不能据此宣称原视频包含同样布局或已经听到声音。
- 本模式只有文字交付能力，不直接生成故事板图片、视频、定妆图或写入资产库。资产准备清单中的提示词只是后续制作输入。
- 完整结果保留多个代码块、测算、资产清单和双输出，不只提取第一段正文。供应商明确报告长度截断时记录失败并保留当前输出，提示精简每格描述或减少宫格数后重试；不自动删格或扩大通用模型输出额度。
