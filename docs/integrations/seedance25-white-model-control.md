# Seedance 2.5 专业级白模控制

来源：[Seedance 2.5 使用手册](https://bytedance.larkoffice.com/wiki/RXh5ww6EqighMdkVTMccm2d4n7e)，2026-09-13 经 Firecrawl 重新读取。依据为「（7）白模怎么写？」和「专业级白模控制」。抓取记录位于本机忽略目录 `.firecrawl/lark-white-model-control.json`。

## 使用

1. 在视频生成节点选择项目内已启用的 Seedance 2.5 模型，任务选择「全参考 / 自动判断」或「参考生视频」。
2. 通过已有素材入口导入 Maya、Blender 等软件导出的白模动画视频，并连接到视频节点。角色、道具和场景参考图也通过普通素材连线输入。
3. 展开「专业级白模控制」并启用，明确选择白模视频。粗颗粒度用于几何体预演的动作与镜头参考；细颗粒度用于完整模型动画的材质、风格和光影渲染。
4. 选择需参考的运镜、站位、动作动线、空间构图、光影、节奏或音频。逐项描述白模中对象的颜色、形状或位置，以及对应角色、道具的参考图或文字设定；相同对象不重复映射。
5. 填写剧情动作或分段渲染要求、场景参考和整体材质风格。粗颗粒度模型有四肢或翅膀时，写清完整动作序列；细颗粒度视频导出前关闭轨迹线、坐标轴和相机辅助线。
6. 检查白模提示词预览，按需在原提示词输入框填写补充要求，点击节点的「生成」。生成任务详情保留实际提交的完整提示词和素材快照，生成结果复用现有视频产物卡片。

## 实现契约

- `VideoNodeConfig.whiteModelControl` 保存开关、粒度、约束、映射与渲染要求，随画布保存、恢复和撤销。关闭后保留设置但不参与生成。
- 映射同时绑定画布素材实例 key 和来源身份；重排输入只改变媒体编号，不改变角色归属。重命名刷新展示名。断开、替换来源或删除参考后显示错误并拒绝生成，需要用户重新选择。
- 预览和实际提交共用 `resolveWhiteModelControl`。执行时把控制要求转换为 `PromptContentDocumentV1`，与当前输入框文档合并，经统一提示词校验生成 `PromptSegment[]` 和 `explicitMedia`；不覆盖输入框已有编辑，也不在反复生成时累积重复控制段落。
- 白模表单文字仅描述剧情、特征和渲染要求；素材通过对应选择器绑定。需要在任意位置插入 `@` 引用时使用节点原有提示词编辑器。表单中的引用写法会显示校验错误，避免把未保存为规范引用的 `@图片1` 在素材重排后绑定到其他对象。
- 全部连线媒体仍按项目现有顺序送出，未用于白模映射的参考仍保留。供应商素材读取、上传、模型能力校验、任务历史及视频保存复用现有链路。
- 白模控制使用文档描述的参考视频与提示词方式，没有新增 `white_model`、轨迹、骨骼或相机专用 API 字段。普通任务仍遵守所选供应商已开放的 schema。

## 边界

白模本地渲染曾由内置 Blender 组件提供：可在本地工作室搭建立方体、球体、圆柱与简易人形，设置颜色、路径关键帧、朝向与镜头，固定 Blender Python 脚本生成工程与 PNG 帧，FFmpeg 编码 MP4。该组件连同动画渲染（Remotion）与视频动作捕捉（MediaPipe）已整体删除，对应的 `white-model-render`、`animation-render`、`browser-download`、`motion-capture` 功能不再提供；白模导演台、站位图导出与 `whiteModelStudio` 节点配置一并移除。

「专业级白模控制」本身不依赖任何本地渲染组件，继续保留：参考视频由用户从画布上已有的视频节点选择，角色／道具参考图来自普通素材连线，节点只负责把两者编译成冻结提示词。用户可以自行使用 Maya、Blender 等外部软件制作白模动画后导入，再在此处消费。

模型对运镜、走位、遮挡和渲染要求的最终遵循程度取决于输入素材与供应商模型。自动化验证覆盖配置、稳定身份、实际请求与存档；不等同于真实模型成片质量验收。
