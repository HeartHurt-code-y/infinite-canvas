# 火山引擎 TOS 暂存上传设计

状态：MVP 设计草案 v0.9（直连 TOS）

## 目的

公司素材库和部分远程生成输入只接受公网可访问 URL，而桌面端拥有用户选择的本地文件以及已经保存到本机的图片和视频生成结果。TOS 暂存模块负责把这些媒体短期转换成目标远程接口可抓取的 URL。

暂存对象不是业务素材。导入用户文件时，最终素材身份来自公司素材库的 `id` 和 `asset://...`；本地图片或视频结果作为远程生成输入时，最终身份仍是本地生成结果，TOS 只提供一次短期可读地址。

TOS 解决的是“目标远程接口需要公网 URL”这一处边界，不是生成结果的保存层。图生图 `POST /v1/images/edits` 本身接受 multipart 图片文件：应用从已有图片素材或本地图片结果读取字节后直接提交，不先上传 TOS。

图片和视频生成结果都不使用 TOS 保存，也不导入公司素材库；它们在生成成功后直接保存到本机 Downloads 目录。只有用户以后把某个本地结果作为只接受公网 URL 的远程生成输入时，才允许按需使用 TOS 取得短期公网 URL，并且该中转不创建公司素材记录。

TOS 暂存 URL不承担画布长期预览职责。导入期间使用本地 Blob 或处理中占位；素材进入 `Active` 后，画布只根据素材 ID向公司素材接口解析可刷新的预览地址。TOS URL过期或暂存对象清理不能让已经入库的素材节点破图。

## 推荐架构

```text
桌面 WebView
    │ 选择文件、显示进度
    ▼
Tauri Rust 暂存模块
    │ 1. 读取系统凭据管理器中的 AK/SK，本地派生 TOS V4 预签名 URL
    ▼
火山引擎 TOS（直连，桶名 + 地域 + Endpoint）
    │ 2. 通过预签名 PUT URL 上传对象（15 分钟有效期）
    │ 3. 生成预签名 GET / DELETE URL（1 小时有效期）
    ▼
公司素材接口 /v1/assets/async
    │ 4. Pending → Active
    ▼
asset://... 业务素材
    │
    ├─ 5. 通过预签名 DELETE URL 主动删除 TOS 暂存对象
    └─ 删除失败时由生命周期规则兜底

本地图片/视频结果 ─> 私有 TOS 暂存对象 ─> 短期 GET URL ─> 远程生成输入
                                               │
                                               └─ 请求结束后清理，不创建素材
```

桌面端按官方《签名机制》文档在本地实现 TOS 签名版本 4（[URL 中包含签名](https://www.volcengine.com/docs/6349/129226)、[单分块上传的签名机制](https://www.volcengine.com/docs/6349/74839)），签名实现以官方文档的签名示例作为单元测试向量。预签名 URL 均使用 `UNSIGNED-PAYLOAD` 且仅签名 `host` 头域，因此上传时的 `Content-Type` 头不影响签名。签名实现见 `src-tauri/src/backend/tos_sign.rs`，暂存流程见 `staging.rs`。

曾经评估过的方案：官方 Rust SDK `ve-tos-rust-sdk`（依赖 reqwest 0.11 / hyper 0.14，与项目现有 reqwest 0.12 形成双版本依赖）与公司预签名 Broker 服务（需要额外部署内部服务）。均已拒绝：本地签名约 150 行，仅依赖项目已有的 `sha2`/`hmac`，测试向量可字节级对齐官方文档。

## 预签名请求与重定向约束

TOS 预签名 URL 的签名绑定到请求 `Host`（CanonicalRequest 中 `host` 头域参与签名，且 `X-Tos-SignedHeaders=host`）。火山引擎在「桶域名或预签名的 URL 访问限制变更」后，会对预签名请求返回 `301/307` 重定向到规范化 `Host`。若 HTTP 客户端自动跟随重定向，会把同一套签名查询串重放到不同 `Host`，TOS 用新 `Host` 重算签名即报 `SignatureDoesNotMatch`（AK 合法仍被原样回显，极易被误判为密钥错误）。

因此 **TOS 预签名请求专用客户端必须禁用自动重定向**（`reqwest::redirect::Policy::none()`），原样发往签名时的 `Host`。约定：

- `staging.rs` 中的 `build_presign_http_client()` 构造专用客户端，所有预签名 GET/PUT/DELETE 请求均走此客户端，不复用 `ProviderRuntime` 共享客户端（其默认 `redirect::Policy::limited(10)` 会跟随重定向）。
- 连通性测试探针 GET 返回 `3xx` 时归类为 `Redirected`（机器可读 reason `redirected`），提示用户确认 Endpoint、地域与桶名是否与火山引擎控制台完全一致，而非归因为鉴权失败。
- 回归测试 `presign_client_does_not_follow_redirects` 用一个会 `307` 到捕获服务器的本地服务，断言专用客户端直接返回 `307` 且捕获服务器从未被访问。

## 职责划分

### Tauri Rust 暂存模块

- 读取用户选择的本地文件，或读取需要作为远程 URL 输入的本地生成结果。
- 识别 MIME 类型和扩展名，不只信任用户文件名。
- 确认文件可读取并识别基本 MIME，用于构造上传请求；不复制供应商的格式、尺寸、时长和大小业务规则。
- 从系统凭据管理器读取 AK/SK，本地生成预签名 PUT / GET / DELETE URL。
- 通过普通 HTTPS PUT 上传，并报告字节进度。
- 保存对象键和暂存状态，以便应用重启后继续入库或清理。
- 在素材入库完成后通过预签名 DELETE URL 删除暂存对象。

### 凭据管理

- AK/SK 以 JSON 形态（`{"accessKey":"...","secretKey":"..."}`）保存在系统凭据管理器（Windows 凭据管理器），引用名固定为 `tos-ak-sk`。
- 桶名、地域（默认 `cn-beijing`）、Endpoint（默认 `tos-cn-beijing.volces.com`）、对象前缀和启用状态保存在本地 SQLite `application_settings` 表。
- 旧版本保存的 Broker 配置无法映射到直连字段，读取时视为未配置，用户需重新填写。

### 前端

- 显示选择、上传、素材审核和完成状态，只拦截文件不存在、无法读取或缺少必要配置等明显问题。
- 设置面板提供桶名、地域、Endpoint、对象前缀、AccessKey ID 和 Secret Access Key 输入；AK/SK 成对填写，两者留空表示沿用已保存凭据。
- 文件格式、大小、尺寸、时长和内容是否合法由 TOS 或素材服务权威校验；前端完整展示原始错误，不改写消息，并允许用户原地重试。
- 文件仍在待上传列表、暂存流程尚未创建时可以移除；流程开始后不提供取消、停止或暂停，也不因为关闭面板或切换画布而终止后台流程。运行中记录不能删除，终态后才允许清理历史展示。
- AK/SK 明文不写入数据库、画布、任务日志或任何持久化文件。

## 对象键

推荐格式：

```text
staging/{credential-scope-hash}/{yyyy}/{MM}/{dd}/{uuid}.{ext}
```

- `credential-scope-hash` 用不可逆散列区分作用域，不直接暴露令牌、用户 ID 或邮箱。
- `uuid` 防止重名和覆盖。
- `ext` 来自实际媒体类型检测，不直接采用用户提供的扩展名。
- 原始文件名只作为本地展示元数据，不进入对象键。

## 状态模型

| 状态          | 含义                                                     |
| ------------- | -------------------------------------------------------- |
| `validating`  | 校验本地文件或 Base64 字节                               |
| `authorizing` | 申请预签名 URL                                           |
| `uploading`   | 上传到 TOS 并显示进度；不提供取消、停止或暂停            |
| `staged`      | TOS 对象已存在，等待导入素材库或一次远程生成请求         |
| `importing`   | 公司素材库正在处理 `Pending/Processing`                  |
| `active`      | 已取得 `asset://...`，可以创建素材节点                   |
| `in_use`      | 短期 GET URL 正被一次远程生成请求使用；不创建素材记录    |
| `failed`      | 上传或导入明确失败，可按阶段重试                         |
| `interrupted` | 应用退出或进程异常中断了尚未完成的本地步骤；不是用户取消 |
| `cleaning`    | 正在删除 TOS 暂存对象                                    |
| `cleaned`     | 暂存对象已删除，或已交给生命周期规则兜底                 |

状态模型不包含 `cancelling`、`cancelled`、`paused` 或 `stopped`。

上表的 `importing` 和 `active` 只适用于用户文件导入素材库。生成结果按需中转在 `staged` 后进入一次远程请求的 `in_use`，请求结束后直接进入 `cleaning`；它不会进入 `importing`、`active`，也不会取得 `asset://` 身份。

## 不支持取消、停止或暂停

TOS 暂存流程成功创建后，只能自然进入 `active`、`failed`、`interrupted` 或清理相关终态。前端和 Tauri 暂存模块的 Interface 都不提供用户可调用的 `cancelUpload`、`stopUpload`、`pauseUpload` 或 AbortSignal。

以下行为不能终止已经开始的暂存流程：

- 关闭上传面板。
- 切换画布。
- 文件卡片离开视口。
- 相关生成节点或素材节点被删除。
- 其他上传、生成或素材导入失败。

用户只能在暂存流程创建前，从待上传选择列表移除文件。流程创建后，运行中的记录不能从任务列表删除；关闭面板、列表虚拟化或切换画布不影响后台继续上传、申请 GET URL、导入素材库和清理暂存对象。进入终态后可以清理历史展示，但不会删除已经入库的业务素材。

关闭整个应用会终止桌面端进程，这是进程生命周期事件，不是产品取消操作。重启后，已进入 `staged`、`importing` 或 `cleaning` 的记录按持久化状态恢复；简单 PUT 正在传输但尚未完成时标记为 `interrupted`，之后由用户显式重试或安全恢复逻辑重新申请 URL，不能标记为 `cancelled`。

## 有效期和清理

建议的 MVP 默认值：

- 预签名 PUT URL：15 分钟。
- 预签名 GET URL：1 小时，必须覆盖素材服务下载、审核和短期重试。
- `staging/` 生命周期删除：上传后 1 天或公司选定的最短安全窗口。
- 未完成分片：配置独立的过期清理规则。

素材进入 `Active` 后立即尝试删除 TOS 对象。生命周期不是主清理路径，因为规则加载和执行可能存在延迟；它只保证崩溃、断网或删除失败时不会永久积累暂存数据。

## 重试规则

- PUT URL 过期但对象尚未上传完成：申请新的 PUT URL并重新上传。
- 对象已上传但 GET URL 过期：只刷新 GET URL，不重复上传。
- 素材导入失败且 TOS 对象仍存在：刷新 GET URL并重试 `/v1/assets/async`。
- 素材已经 `Active` 但主动清理失败：不影响业务素材成功状态，记录待清理并依赖生命周期兜底。
- 应用重启：从本地暂存记录恢复 `staged`、`importing` 和 `cleaning` 状态。
- 应用退出中断尚未完成的简单 PUT：标记 `interrupted`；不自动声称已取消，也不把未确认完整的对象当作 `staged`。

## 生成结果的按需中转

文生图或图生图返回 `b64_json` 时，结果保存模块先在 Rust 侧解码、识别真实格式并原子保存到 Downloads 目录；这一过程不进入 TOS。以后只有目标远程接口必须接收公网 URL 时，TOS 暂存模块才读取已经保存的本地文件：

1. 校验本地结果仍存在、可读，并核对任务保存记录中的内容哈希。
2. 根据文件魔数识别 PNG、JPEG、WebP 等真实格式；无法识别时不上传未知二进制。
3. 上传 TOS 并取得签名 GET URL，只用于这次远程输入。
4. 远程请求完成或安全窗口结束后清理暂存对象，不调用素材导入接口。

视频本地结果采用相同边界。TOS 对象和签名 URL 都不能替代本地文件成为结果主副本。

提示词中的 `@` 媒体引用只保存公司素材或本地结果的稳定身份，不保存 TOS URL。任务提交时，如果目标 Adapter 必须取得公网 URL，媒体引用模块先验证本地文件和内容哈希，再调用本模块创建一次暂存；任务快照保存引用身份、对象键的非敏感标识和内容哈希，签名查询串仍不持久化。

图片、视频和音频分别拥有独立位置。多个 TOS 暂存可以并行执行，但每次暂存开始前都必须携带冻结的 `(mediaType, typePosition)`，取得 URL 后只能回填原位置。上传完成先后、URL 颁发先后或重试完成先后都不能重排任何类型的输入；某一位置失败时，整次远程生成输入解析失败，不删除该位置或压缩后续编号。

## 安全不变量

- 桶必须保持私有。
- 长期 AK/SK 只存在于系统凭据管理器，不能进入桌面安装包、配置文件、日志或画布数据。
- 预签名 URL 只授权单个对象和单个操作，并设置短有效期。
- 上传必须使用 HTTPS，并固定预期的 Content-Type。
- 应用日志不得记录完整预签名 URL；查询参数包含有效签名（现有 `redact_url_string` 会整体脱敏 `X-Tos-*` 查询参数）。
- TOS 暂存对象不能直接成为画布素材节点。
- TOS 暂存 URL不能写入画布数据或成为图片组件的长期 `src`。
- 只有公司素材明确进入 `Active` 且可由素材 ID重新解析预览时，才允许主动删除暂存对象。

## 验收场景

1. 本地图片、视频和音频能上传到私有 TOS 桶并显示进度。
2. 桌面端仅凭桶名、地域、Endpoint 和保存在系统凭据管理器的 AK/SK 即可完成本地签名与上传，无需任何中间服务。
3. 公司素材服务可以通过短期 GET URL 抓取对象并进入 `Active`。
4. `Active` 后画布只保存 `asset://...`，TOS URL 不成为素材主键。
5. PUT 或 GET URL过期后可以按阶段刷新，不重复已完成步骤。
6. 主动删除失败时，生命周期规则最终删除 `staging/` 对象。
7. 只返回 Base64 的图片结果直接保存到本地，不触发 TOS；以后作为只接受公网 URL 的远程输入时才按需暂存，且不创建素材记录。
8. 日志和持久化文件中不存在长期 AK/SK 或完整预签名 URL。
9. TOS URL过期或暂存对象删除后，`Active` 素材仍可通过素材 ID刷新预览，本地生成结果仍从本地文件预览，不出现由暂存 URL 过期造成的永久破图。
10. 暂存流程开始后没有取消、停止或暂停入口；关闭面板和切换画布不终止后台执行，运行中记录不能删除。
11. 应用退出中断简单 PUT 后，记录进入 `interrupted` 而不是 `cancelled`；重试时重新确认对象状态并按阶段申请新 URL。
12. 提示词 `@` 引用本地结果并提交到只接受公网 URL 的生成端点时，先校验稳定身份和内容哈希再暂存；任务和画布不持久化签名 URL，暂存结束后不产生素材记录。
13. 图片、视频和音频暂存并行完成且返回顺序与开始顺序相反时，验证每个 URL 仍按冻结的 `(mediaType, typePosition)` 回填；任一位置失败时不压缩同类型后续编号，也不发送部分生成请求。

## 实现前需要提供

- TOS 桶名（必须为私有桶）、地域（默认 `cn-beijing`）与 Endpoint（默认 `tos-cn-beijing.volces.com`）。
- 一对火山引擎 TOS 的长期 AK/SK（建议使用仅授权该桶的 IAM 子账号）。
- PUT 和 GET URL 的有效期策略（当前默认：PUT 15 分钟，GET/DELETE 1 小时）。
- `staging/` 前缀的生命周期删除规则（建议上传后 1 天）。
- 各媒体类型允许的最大文件大小和 MIME 类型。
