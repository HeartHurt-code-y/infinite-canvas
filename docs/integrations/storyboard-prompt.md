# 故事板提示词技能接入

“提示词生成与优化”节点的 `storyboard_prompt` 模式，界面名称为“故事板”。把创意、剧本、真实产品资料或参考画面整理成一张故事板图片的完整生成提示词，覆盖影视、广告、动画、漫画、游戏、教学、体育、品牌、社交短视频与 MV。

## 使用

1. 添加“提示词生成与优化”节点，选择项目已有的文本模型，把模式切换为“故事板”。
2. 输入用途、主题和需要保留的事实，可同时说明风格、镜头数量、时长或版式；也可连接真实图片及已保存的图片/视频结果作为视觉参考。例如：“把这段剧本整理成 15 秒九镜故事板，国漫水墨风，保持人物服装和剧情顺序。”
3. 普通构图、配色和节奏由模型合理补全。真实产品卖点、关键人物事实或相互冲突的核心要求无法可靠确定时，节点合并补问；已经提供或确认的内容不重复询问。
4. 默认输出一份完整中文提示词，包含整图版式、主体一致性、各区或逐格画面、必要文字与排除约束。输出通常放在一个可复制的代码块中，必要补问或假设说明保留在块外。
5. 可直接编辑输出，再提交继续优化要求；本轮使用当前编辑稿、完整对话与实际参考素材，输出完整替换稿。既有事实和未要求修改的内容继续保留。
6. 通过现有提示词连线把当前输出交给图片生成节点，或自行复制提示词。此模式只交付文字，不创建图片、视频或资产。实际出图效果、文字清晰程度和媒体规格由后续生成模型决定。

模式、输出与对话沿用提示词节点现有画布保存机制。视频联系表只作为可见画面证据，不把采样格数、边框和时间码当成用户要求的故事板版式，不声称根据静态联系表听到了声音。

## 适配合同

### 用户要求与示例

先遵守用户本轮明确要求及已确认事实，再遵守应用主技能，最后应用相关原始模板。当前编辑输出是优化基线，不能被历史旧稿覆盖。角色姓名、品牌、地点、产品功能和台词等示例内容不会自动成为用户事实；奔驰 AMG、LUMO、东京街头、固定人物或 Seedance 2.0 等不是默认内容或指定供应商。体育示例的 16 格篮球也不强制用于其他训练。

短剧、广告、MV、漫画、教程等各取适合的结构。真实产品以用户资料和实际可见图片为依据，不编造功能、规格、认证、功效、价格、销量或用户反馈；新广告文案属于创作建议，不能伪装成已有品牌口号。无产品图时可以按文字制作概念提示词，但不声称已验证产品外观。

### 画幅和视觉风格

整图、内部镜头和教程展示图的外层海报比例分别处理。修仙原文前半部分要求 16:9 影视开发板，末段要求 3:4 教程图；用户要求开发板时采用 16:9 六模块，明确要求教程展示图时才采用 3:4 外层并在其中展示开发板示例。同一整图不会同时要求两种冲突比例。

短剧原文中的 UE5 超写实及“卡通化 / 二次元”负面词仅适用于写实路线。用户选择国漫、卡通、动画或漫画时采用用户风格并移除冲突负面词。避免重复镜头指避免无叙事增量的构图；连续同场景、正反打和景别变化可以保留，不为“场景不重复”擅自换地点或改写剧情。

### 镜数、时长与图中文字

短剧默认 9 镜 15 秒，源文件的 `1.5、1.5、2、1.5、2、1.5、2、1.5、1.5` 合计确为 15 秒。用户指定其他时长或镜数时遵从用户，重新分配并检查逐镜总和、镜数和版面标签一致。修仙来源的 30 秒只是其示例设定，各用途不共享同一个固定时长；这些数值是拍摄规划，并非视频模型接口限制或实测视频长度。

制作板需要说明文字时压缩为清晰标签；短剧每镜说明保持 1–2 行，四栏广告避免大段文字。按行列核对格数，明确编号和阅读顺序；漫画页允许大小不等分格。源文档中的空编号、占位符和多余引号不进入最终提示词。清晰中文是目标，不把提示词描述当作零乱码保证。

## 验证边界

原始目录和应用内 `references/` 的 14 个文件逐一比较字节数与 SHA-256，来源清单可据上表复核。主技能入口独立校验名称、前言与引用路径。节点接入沿用现有文本任务、对话、素材和输出机制；本次不向付费媒体接口提交图片或视频生成请求。

前端用例覆盖模式选择、空请求拦截、纯文字与仅素材生成、必要补问、完整输出、手改稿继续优化、下游图片/视频连线和 JSON 画布恢复。后端覆盖模式序列化、15 份文档完整编译加载、三个文本 API 档案的技能与历史透传、图片/视频证据、完整正文提取及供应商明确报告的长度截断。长度截断进入现有失败流程，保留当前输出并提示精简描述后重试。

验证命令包括 `pnpm build`、改动前端文件的 ESLint/Prettier、定向 Vitest、`cargo test --manifest-path src-tauri/Cargo.toml --locked backend::prompt_optimize::tests`、`cargo fmt --manifest-path src-tauri/Cargo.toml --check` 和 `git diff --check`。独立技能试用另检查二维国漫同场景短剧、无参考图的四栏产品广告及 3:4 教程海报内嵌 16:9 开发板；这是文本合同验证，不是实际出图效果验收。
