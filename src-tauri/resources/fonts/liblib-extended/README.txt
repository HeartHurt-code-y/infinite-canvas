LibTV extension fonts: 136 catalog entries

originals/ contains the byte-for-byte source files (content-addressed and deduplicated).
source.json maps each original public catalog entry to its original URL.
PROVENANCE.json retains source hashes, copyright, license metadata and embedding flags.
manifest.json maps entries to static font files used by both preview and export.
instances/ contains static instances only when a source font was variable.
The ZIP includes one named original font file for each of the 136 catalog entries.
