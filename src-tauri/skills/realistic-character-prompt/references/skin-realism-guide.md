# 真实皮肤质感方法论速查

## 为什么AI人物会"假"
- 视频模型会放大参考图缺陷：原图脸糊，进视频更糊。
- 空泛词（8K、超高清、真人皮肤、完美无瑕）让模型把"精致"理解成更润、更亮、更干净 → 油腻磨皮假脸。
- 模型不知道"这张脸为什么像真人"，必须具体写出皮肤物理规律。

## 人物资产图
- 不垫低分辨率、低细节参考图。
- 真人感角色优先用对"光线-材质-皮肤纹理"关系处理稳定的模型（如 Seedream 5.0 Pro），分辨率首选 4K 保面部细节。

## 六段式皮肤提示词公式
1. **物理状态**：一次只选一组（自然半哑光 / 运动出汗 / 风尘擦伤 / 淋雨 / 精致底妆），不要混合。
2. **区域纹理**：皮肤不是统一色块。额头毛孔细、鼻翼略明显、面颊纹理大小不一、眼下细薄纹理（非粗毛孔）、唇有纵向唇纹（中心略湿、唇缘偏干）。
3. **克制瑕疵**：轻微肤色不匀、鼻翼泛红、眼下细纹、淡色斑。禁写"完美无瑕"。
4. **高光分布**：小而破碎，只在鼻梁、颧骨、下唇中央、下巴；下颌低反射。高光是光在骨骼曲面上的局部反应，不是全脸油。
5. **光线/表情驱动**：说明什么光或表情触发了皮肤反应。
6. **时间连续性**：镜头间皮肤状态保持一致。

## 人像质感调节推荐参数（平台功能）
纹理：颗粒质感；肤质：自然肤质；光影融合：氛围强化；人景融合：自然融合；锐度：标准清晰。
修图顺序：先脸 → 再肤质 → 再光线 → 最后情绪（克制/警惕/疲惫/压怒等）。

## 视频提示词三层写法
1. **身份锁定**：人物模板是最强视觉锚点，视频提示词不要重复写"漂亮女生、真实皮肤、8K"——会把已做好的脸冲掉。
2. **光线触发**：写光如何经过皮肤（如"窗光左扫，颧骨留下移动光斑"）。
3. **表演动作**：只写镜头能看见的动作，前一句规定表演，后一句规定光线。

## 景别决定细节密度
- 全身：只写整体肤色、裸露皮肤与衣服反光差异。写毛孔睫毛会让模型注意力错堆到脸。
- 近景：可写毛孔、细软绒毛、眼下纹理、唇纹、局部高光。
- 微距特写：一次只抓一个重点。

## 反面案例
❌ "8K超高清真人皮肤，完美无瑕，电影质感，害羞地看着镜头"
✅ "自然半哑光皮肤，鼻翼毛孔略明显、眼下细薄纹理，轻微肤色不匀，鼻梁一点破碎高光；窗光从左扫过面颊，她眨了一下眼"
