# 真实感AI人物提示词生成技能

## 用途

根据用户的创意需求，生成具有真实皮肤质感、避免"伪人/模型脸"效果的AI人物提示词（适用于文生图人物模板、图生视频、文生视频等场景）。**以提供多选项的方式与用户协作**，围绕用户的想法定制提示词，而不是一次性输出固定结果。

## 核心原则

- 避免空泛词汇（"8K""超高清""真人皮肤""完美无瑕"），这些词会让模型生成油腻磨皮脸。
- 所有描述必须具体、可视化、符合真实皮肤的物理规律。
- 按"物理状态→区域纹理→克制瑕疵→高光分布→光线/表情驱动→时间连续性"六段式组织皮肤描述。
- 视频提示词需遵守"身份锁定→光线触发→表演动作"三层结构，并按景别调整细节密度。

## 交互流程

### 1. 理解用户需求并提问

收到用户的创意后，**不要直接生成最终提示词**。先提出关键选择项，让用户决定方向。每个选择项给出2-4个具体选项，并说明每个选项的视觉差异。

**必须确认的选择项：**

**① 人物基础设定**

- 性别 / 年龄段（少年 / 青年 / 中年 / 老年，皮肤状态差异极大）
- 角色气质（温柔 / 硬朗 / 疲惫 / 野性 / 精致 / 沧桑等）

**② 皮肤物理状态（六段式第1段，一次只选一组）**

- 自然半哑光（日常、干净但不假）
- 运动出汗（额头、鼻尖、颈侧有细汗，毛孔微张）
- 风尘 / 擦伤（带灰尘、细小伤口，适合战损、旅途角色）
- 淋雨 / 湿润（皮肤表面有水膜，高光连成线）
- 精致底妆（均匀、控油，适合时尚、广告风）

**③ 瑕疵程度（六段式第3段，克制是关键）**

- 轻度（肤色微不匀、鼻翼泛红，几乎无斑）
- 中度（可见色斑、眼下细纹、轻微痘印）
- 重度（明显皱纹、晒斑、疤痕，适合老年或饱经风霜的角色）

**④ 光线环境（决定高光与阴影逻辑）**

- 自然光（窗光 / 户外，柔和过渡）
- 电影光（单侧硬光，强调骨骼结构）
- 夜景 / 霓虹（彩色反光，皮肤染环境色）
- 逆光 / 轮廓光（边缘发光，面部细节弱化）

**⑤ 使用场景（决定提示词写法）**

- 文生图人物模板（重点：皮肤质感本身）
- 图生视频 / 文生视频（重点：三层结构 + 景别适配）

### 2. 生成提示词

**人物模板提示词（文生图）结构：**

```
[人物身份] + [物理状态] + [区域纹理] + [克制瑕疵] + [高光分布] + [光线/表情驱动] + [时间连续性]
```

- 区域纹理：分区描述额头、鼻翼、面颊、眼下、嘴唇的纹理差异（如"额头毛孔细密，鼻翼毛孔略明显，眼下是细薄纹理而非粗大毛孔，嘴唇有纵向唇纹，中心略湿唇缘偏干"）。
- 高光分布：仅写鼻梁、颧骨、下唇中央、下巴等骨骼凸点的局部破碎高光，下颌保持低反射。
- 不要写"完美无瑕""精致五官"，要写"轻微肤色不匀""鼻翼泛红""眼下微细纹"等真实瑕疵。

**视频提示词（图生视频 / 文生视频）结构：**

```
第一层：身份锁定（"她/他"或角色名，不重复描述皮肤）
第二层：光线如何经过皮肤（如"窗光从左侧扫过，在颧骨留下移动的光斑"）
第三层：镜头能看见的表演动作（不写"害羞""真实"，写"她眨了一下眼，睫毛在光里投下阴影"）
```

- **景别适配**：全身镜头只写整体肤色与衣服反光差异；近景才写毛孔、绒毛、唇纹；微距特写一次只抓一个重点（如仅写"鼻翼毛孔在光下张开"）。

### 3. 提供变体选项

生成提示词后，**至少提供2-3个不同方向的完整提示词变体**，让用户选择或组合：

- 变体A：更自然日常
- 变体B：更电影感 / 戏剧性
- 变体C：更强情绪 / 更特殊状态（如疲惫、受伤、愤怒）

每个变体附一句说明其视觉差异（如"变体B的高光更硬，阴影更重，适合悬疑氛围"）。

### 4. 迭代调整

用户选择后，可继续询问是否需要调整细节（如"要不要把汗改成雨水？""瑕疵再少一点？"），并快速输出修改版。

## 输出格式

每次输出完整提示词（中英文均可，根据用户使用的平台），并附上简短说明该提示词的设计逻辑（为什么这样写能避免假脸）。
