# MiniMax H3 引擎（英文六段式 · 多参一致性最强）

## 时间码优化（统一管线的第9步在此落地）
- 时间码首尾相接（00:00.00-00:02.40 → 00:02.40-…），单条提示词只用这一种格式
- 标准版：15s=4-5镜；极速版：镜头数略增、每镜起止时间码更短，微动作+30-40%，起手0.15s内，动作特写压到0.4-0.8s，默认不用慢动作（决定性命中最多一次0.15-0.3s）
- 一次命中短促停顿后恢复实时速度的写法可用于强调，不等于慢动作滥用

## 模式判定
T2VA 文生 / I2VA 图生（首帧起）/ FL2VA 首尾帧 / L2VA 尾帧 / Ref2VA 全参考。
打斗输出统一走 Ref2VA 六段式（纯文生时也用该结构，图片引用标注 N/A）。

## 六段式（英文，顺序与字段名固定）
```
subject_definitions: 每个主体一段；图片只定义角色/场景时写 "whose appearance/costume comes from <Picture N>"，不单列 Picture 行
summary: 以方括号任务前缀开头，如 [reference generation]
retention_analysis: 每个引用标 fully_preserved / partially_preserved / attribute_transfer / weak_reference，并写出现位置
detailed_description: 350-500词；先一句风格开场（The target video uses a [STYLE] set in [ENVIRONMENT], with [LIGHTING] and [MOOD].）→ [Shot 1]（无时间码）→ [Shot N] At MM:SS.mmm …；只写可见可听，不写meta、不写 do not/must 指令
overall_soundscape: 环境音与物理音总结
non_diegetic_music: 观众向配乐（无则 N/A）
```

## 成龙式一打多调度（嵌入画面，不得写成指令）
1 主角是绝对中心（镜头跟主角）2 攻击重量重叠不排队（禁"第一波结束第二波开始"）3 同一时刻只有1-2名活跃攻击者，其余从画框边缘/背景/障碍物进入（常以手/肩/腿/半剪影出现）4 先设计主角10-12s移动路线再放敌人入路线 5 环境压缩攻击线路（柱子/桌沿/门口把1对4变局部1对1）6 环境交互=身体借过不玩道具 7 允许主角挨打/失衡/失手并影响下一动作 8 不必每人都击倒，打退/挤开/逼偏也算结果；倒下者成为新空间条件 9 留呼吸拍（短暂调整/喘息/重读威胁）10 镜头服务可读性（中景为主，重击才推近）11 每招因果链 12 声音同步且剧情内，无超英音效。

## 打斗写作工艺
- A 参考图身份锁定（图生/多参必用）："`<Subject 1>` is the [ROLE] whose [face/hair/eyes/build] come from `<Picture 1>`. She is recast as [combat role] in [costume+weapon], [one-line stance]." retention里外貌 fully_preserved、服装武器 partially_preserved
- B 命名招式链：中线刺/反握后刺/低位扫/翻越滑铲/绕柱变向/前臂格转肘反；禁止 "she kicks him"
- C 逐秒空间位移 + 重击反馈（踉跄/撞环境/碎屑；风格化才加接触点环状冲击波）
- D 能力只从接触点爆发；写实街战零能量
- G 跨镜状态连续：上一镜的败者状态是下一镜起点，无静默复位
- H 0秒硬启动：首帧即威胁在动，无慢入场

## 镜头数按时长
10s=3镜(0-3/3-6/6-10) | 12s=3-4镜 | 15s=4-5镜(0-3/3-6/6-10/10-13/13-15) | 20s=5-6镜（切在空间状态变化处）。一打多保持中/中远景可读，决定性命中才推近。

## 图生/参考生附加产出
- 角色图提示词×2：①半身正面照（面部肩部特写、白底、写实高细节）②四视图转身（白底单张：左1/3脸部大特写 + 右2/3同角色正面/左侧/背面三张全身，服装发型武器逐字一致）
- 场景图提示词：定场全景+时间光线+空间结构+4-6可互动元素
- 三处角色描述（四视图/半身/subject_definitions）必须逐字一致

## 输出规则
六段正文英文；对白/歌词/画面文字保留原文；时间码与请求时长一致；可选中文调性补丁放在六段之外作为独立辅助（严禁西式铠甲错调性 / 严禁原地互殴 / 严禁对峙空镜）。
默认：12s / 4-5镜 / 多参模式优先。
