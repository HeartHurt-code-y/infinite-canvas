# 失败诊断与验收（单变量排错法）

生成结果出问题时，先找到**最影响可读性的一个症状**。每轮只修改动作、镜头或参考素材中的一类变量，改完复测再定下一步。连续两轮无改善 → 重查问题是否分错变量。不要同时重写全部提示词。

## 三类变量
- **动作变量**：方向、目标部位、接触结果、身体回应、位移、速度、距离、资源、下一拍接口
- **镜头变量**：景别、机位、轴线、速度、切点、跟随对象、遮挡、镜头职责
- **参考素材变量**：首帧姿势、人物轮廓、武器可见性、角色与场景职责、素材顺序、首尾帧差异

## 症状 → 首选修正

| 症状 | 变量 | 首选修正 |
|---|---|---|
| 双方各打各的 | 动作 | 补全发起、接触、回应、位移和下一拍接口 |
| 接触点看不清 | 镜头 | 改侧向中景或短促接触特写 |
| 人物左右互换 | 镜头 | 固定轴线和屏幕方向，切镜前记录站位 |
| 动作自动减少 | 动作 | 减装饰描述，保留关键动作与结果 |
| 身体融合 | 素材 | 换轮廓分离、肢体完整的首帧 |
| 武器复制或变形 | 素材 | 用完整武器图，写明数量/长度/材质/握法 |
| 远程攻击凭空出现 | 动作 | 补取用、装填或充能，交代路径和落点 |
| 远程角色突然近战 | 动作 | 增加后撤、侧移、掩体或副武器反制 |
| 受击没有力量 | 动作 | 写清接触部位、受力方向、位移、材质反馈 |
| 场景损伤恢复 | 动作 | 在后续时间段重复记录损伤状态 |
| 镜头随机跳切 | 镜头 | 减机位数量，每镜只承担一个职责 |
| 首尾帧过渡扭曲 | 素材 | 缩小姿势和机位差异，必要时加中间落点 |
| 参考视频被完整复刻 | 素材 | 明确只继承动作轨迹或摄影机路径 |
| 特效没有来源 | 动作 | 删除特效或绑定到武器/装置/能力/接触点 |
| 画面平淡被简化 | 动作 | 「打斗得更激烈」/「更高密度」；15秒微动作提到16-22个 |

## 交付前验收清单
- **角色与道具**：角色数量符合要求；外观锚点全程一致；武器关键道具数量固定；多角度设定图未生成额外分身
- **动作因果**：每次攻击有目标和回应；接触/格挡/落空清楚可见；受力方向与位移一致；下一拍从上一拍状态自然发生；不同角色距离/移动/反制方式区别明显
- **远程连续性**：投射物或能量有可见来源；路径、命中或落点清楚；弹药装填充能连续；被贴身反制符合角色武器特点
- **空间与镜头**：开场建立人物路线障碍位置；屏幕方向稳定；镜头职责清楚没有遮动作；切镜继承姿态速度武器环境状态
- **环境与声音**：破坏从接触点沿受力方向扩散；损伤碎片余波在后续镜头继续存在；同步声与画面动作同序；持续声场与场景相符
- **格式**：时间段首尾连续覆盖完整时长；单条提示词只用一种时间格式；生成说明在代码块外；默认无字幕无水印

## 修正记录模板
```
本轮主要症状：〔只写一个〕
归属变量：〔动作 / 镜头 / 参考素材〕
本轮唯一修改：〔具体改动〕
保持不变：〔其余条件〕
复测观察：〔修正后结果〕
```

## 只诊断模式（用户提供自己的提示词时）
只出问题清单+建议不改写：0.3s有效动作？1.5s首接触？一攻一应完整？中段攻防转换？预兆/线路/接触点/受力/位移？武器持有稳定？能力有来源？破坏不复原？胜负明确？时间格式与模型匹配？负向约束齐？用户确认后再按单变量法修改。
