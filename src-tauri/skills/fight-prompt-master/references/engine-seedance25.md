# Seedance 2.5 引擎（时间戳精准 · 单段4-30s · 超长180s）

## 时间块优化（统一管线的第9步在此落地）
- 标准版：15秒约4段、每段3-4s；19-30s 五到七段、中段一次有效反转
- 极速版：5-6段、每段2-3s（如0-2/2-5/5-8/8-11/11-13/13-15），首尾相接；微动作+30-40%；起手0.15s内；特写0.4-0.8s；默认不用慢动作（决定性命中最多一次0.15-0.3s）
- 时间戳必须首尾相接覆盖完整时长，不靠留白或重复动作补齐

## 能力边界（与2.0差异，避免用错）
单段 [4,30]s（打斗建议12-30s）；超长视频 30-180s 一次生成；视频延长 4-30s/次套娃至60s；**文本时间戳钉死每拍**；图片≤30/视频≤10/音频≤10；@音频音色复刻；多角色同框分别 @图片 锁脸防双胞胎；@视频白模动作迁移；智能编辑改已生成视频；负向默认补「不要字幕、不要BGM」。

## 输出格式（2.5融合版）
```
【整体风格】同2.0（"整体风格:"开头）
【素材描述】@图片1=…；@视频2=…；@音频3=…，按上传顺序编号并逐个写用途；无素材写「无」
【一句话概述】主体+地点+事件+风格+运镜，单段X秒
【时间戳剧本分镜】（核心，必须有，不用=没发挥2.5能力）
0-2秒：起幅 + 第一威胁，建立空间关系和压力方向
2-7秒：节点1（动作→对手反应→环境反馈→镜头反馈→衔接）
7-12秒 / 12-18秒 / 18-24秒：节点2-4
24-30秒：结尾，终段动作+结果爆发+空间位置，不写慢收势；可加末帧钩子
【特效细节】纯写实(T1/T3)可省
【音效】10-14个，只取本题材声音
【全局补充】机位+环境+声音氛围+光影；负向：不要字幕、不要BGM、不要水印、不要Logo
【强制声明】无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

## 2.5 专属动作增强
- 慢镜局部：只慢关键命中帧（"第7秒命中瞬间40%速度0.5秒后恢复正常"）
- 多速度层次：快攻+慢镜+突停交替
- 镜头速度变化：跟拍加速 / 命中前0.2秒骤停+机位微晃
- 环境余波链：上一拍碎屑未落地卷入下一拍拳风
- 时间戳断点：3-5秒三次换位；5-7秒贴身缠斗

## 时长测算（必输出测算表）
台词：普通3-4字/秒（÷3.5）、情绪/古风÷2.5、气声÷1.8、停顿0.5-1s、打斗嘶吼0.5s/次（台词极简1-2句）。
动作：交手2-3回合3-5s / 冲刺5-10米1.5-2s / 倒地坠落1.5-3s / 变身1.5-3s / 环境破坏1.5-3s / 走位3-5步2-4s。
超限处理：延长到30s → 超长视频模式 → 视频延长 → 减次要反应镜；用户原文绝不删改。

## 多模态模块（按需加载）
- 白模粗颗粒：参考声明+对应关系映射+打斗详述+场景处理+整体收束
- 白模细颗粒：渲染指令+分段渲染描述+场景处理+整体收束
- 智能编辑：修改对象+动作变化+生效时序（"3-8秒把木棍换成长剑"）
- 视频延长：必写"向前/向后延长/延续/续写"+一镜到底约束+切镜设定
- 超长打斗：全局参数（分钟数/画幅/分辨率）+每5-8s一个节拍；群战合并用代表性击倒+余波带倒

## 硬规则
字数1100-1800（目标1200-1500，超长可2200）；时间戳必须有；末帧钩子；案例归档；双版本+TXT。
默认：打斗15s / 16:9 / 4-6节点（30s可6-8）。
