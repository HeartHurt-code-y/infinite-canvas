# 动作摄影机指南

摄影机服务动作可读性，不能代替动作本身。

## 镜头句式（每条运镜写全6项）
〔景别或焦段〕+〔机位高度与角度〕+〔运动速度〕+〔摄影机方向〕+〔跟随对象〕+〔本镜职责〕
示例格式：〔焦段〕低机位中景，摄影机以〔速度〕沿〔方向〕跟随〔角色或物体〕，让〔接触、距离或结果〕保持清楚。

## 镜头职责表（四镜以上尽量覆盖不同职责）

| 职责 | 画面要回答的问题 | 可选方式 |
|---|---|---|
| 建立空间 | 人物、出口、障碍在哪里 | 大全景/俯拍/侧向全身景 |
| 追随位移 | 谁朝哪里移动，速度怎样变 | 平行/侧后/贴地跟拍 |
| 看清接触 | 是否命中，接触点在哪 | 侧向中景/短促特写/动作匹配切 |
| 表达反制 | 主动权怎样变化 | 反应近景/轴线同侧切入/回接双人景 |
| 表达失衡 | 受力方向与身体姿态改变 | 倾斜/短幅翻滚/沿受力方向追随 |
| 展示弹道 | 释放者、路径、目标关联 | 过肩景/长焦压缩/高位距离景 |
| 揭示结果 | 谁获得优势，环境变了什么 | 快速后拉/升镜/遮挡物移开 |
| 稳定收尾 | 结果清楚后保留哪些运动 | 固定构图/稳定跟随/慢速轨道 |

## 按动作阶段选镜
- **起动**：全景或中景同时建立角色/路线/第一步；要速度沿主角前进方向移动；要空间判断用高位或侧向；开场镜头内已有有效动作
- **距离变化**：横向用平行跟拍保留间距；折线逼近用高位交代掩体路线；高度变化低机位起跳+高位落点承接；改机位保持屏幕方向和左右关系
- **接触与格挡**：接触前用能看见双方身体的景别；瞬间可短促推近/轻微震动/侧向特写；接触后立即承接受力位移环境结果；不在接触即将发生时遮挡或过近藏动作
- **远程攻击**：释放前交代来源；过肩/长焦同时建立射手路径目标；关键投射物短暂追随，普通投射物直接切落点；命中后回释放者交代换位装填资源
- **反制**：反应镜头保留上一镜视线方向与动作状态；切对手侧维持轴线，回接双人景确认接触；特写只拍正在变化的状态（握力/重心/视线/武器角度）
- **受击与结果**：沿受力方向承接失败方移动；先拍接触部位再拍墙面地面道具反馈；结果明确后拉开景别保留余波

## 三档强度镜头搭配

| 阶段 | 高强度 | 中间型 | 慢节奏 |
|---|---|---|---|
| 起动 | 低机位快速跟随 | 中景定向后切入 | 长镜建立路线 |
| 位移 | 贴地或侧后跟拍 | 平行跟拍 | 轨道移动 |
| 接触 | 动作匹配切、短促推近 | 接触特写+双人回接 | 侧向全身景 |
| 反制 | 轴线同侧快速切入 | 反应近景 | 长镜内改构图 |
| 远攻 | 落点切回、短暂弹道追随 | 过肩景、高位距离景 | 长焦保持路径关系 |
| 受击 | 沿受力方向快速追随 | 中景承接位移 | 长镜看完整结果 |
| 收尾 | 快速拉开后稳定 | 中景转全景 | 稳定轨道离开 |

极速版补充：三档都优先快速跟随和摇甩衔接；慢节奏不用慢速轨道开场；特写改0.4-0.8秒短推近；默认不用慢动作。

## 连续性记录（每次切镜前过一遍）
人物左右位置 / 面朝方向与身体姿态 / 运动方向与速度 / 武器所在手、角度、完整状态 / 弹药能量道具数量 / 对手是否还能行动 / 场景损伤与移动物 / 仍在持续的尘土火花液体光效。
**切镜只改变观看位置，已发生的事件不能因机位变化被重置。**

## 声音配合
普通镜头1-3个与动作同序的同步声；长镜头可加脚步/衣料/武器/环境层次；极短镜头只保留一个最重要的接触重音；风雨机器底噪和音乐放全局声场；所有音效都要在画面或场景中找到来源。

## 常见误用
连续快速切镜致左右互换 / 运镜过多遮住身体动作 / 每次命中都震动失去层次 / 普通投射物全程跟随压缩反应时间 / 慢动作覆盖完整倒地拖散节奏 / 收尾只剩静止姿势无环境运动。
