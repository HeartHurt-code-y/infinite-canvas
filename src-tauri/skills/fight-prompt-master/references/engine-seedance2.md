# Seedance 2.0 引擎（10-15s 单段 · 11字段格式）

适用：模型选 SD2.0；通用性好，其他兼容 Seedance 提示词格式的模型也可直接用本引擎输出。

## 时间块优化（统一管线的第9步在此落地）
- 标准版：15秒约4段、每段3-4s（如0-4/4-8/8-11/11-15），首尾相接覆盖完整时长
- 极速版：5-6段、每段2-3s（如0-2/2-5/5-8/8-11/11-13/13-15），微动作+30-40%，起手0.15s内
- 使用连续整秒粗时间段；单条提示词只用这一种时间格式

## 输入等级
- L1创意 → 补全题材/场景/角色/2-3核心动作节点
- L2剧本 → 直接生成，补全外观锚点、武器、场景、动作链和结尾
- L3小说 → 抽骨架（胜负与转折）/ 去修辞（删不可拍的心理描写）/ 建奇观（选2-3个最具视觉冲击的画面做节点）
- L4锁定分镜 → 硬约束：动作结果、顺序、视觉锚点、出口不变，只补衔接与物理反馈

## 结构与题材
结构：A 对打（4-6个攻防节点）/ B 形态演化（起态→触发→分层覆盖→终态）/ C 单人武学演绎（起势→招式用"——"分隔→收势）。
题材 T1-T7：T1现代街战 / T2凡躯超英 / T3低魔武侠 / T4玄幻仙侠 / T5机甲变身 / T6邪典恐怖 / T7极速者。混合题材以画面最强视觉元素为准；T1/T2边界：有装备/能量/仿生→T2，只有物理夸张→T1。

## 压力曲线（选1）
压迫递增 / 反制失败 / 诱敌反打 / 波峰波谷 / 蓄力爆点。把曲线节拍映射进【过程】各节点。

## 输出格式（11字段，字段名与顺序固定）
```
【整体风格】"整体风格:"开头；调性词×3 + 特效/速度/力量通过具体物理现象呈现 + 排除跨题材污染词；主体清晰可读优先于特效，动作不断流，命中不定格
【角色卡】"- @图片1作为[主角]: 外观锚点+武器/能力+动作倾向+本段攻守位置"（无图也占位；不写外貌作文）
【场景设定】地点+光线+空间结构+4-6个可被动作影响的环境元素
【画面坐标】开场主体位置+威胁进入方向+纵深/退路
【起幅】开场画面+第一威胁
【过程】4-6个攻防节点，每节点：动作→对手反应→环境反馈→镜头反馈→衔接
【结尾】终段动作+结果爆发+空间位置；不写慢收势/能量渐熄/定格摆姿态
【特效细节】T2/T4/T5/T6/T7用；能量只沿武器/碰撞点/攻击轨迹，粒子不遮主体
【音效】10-14个，逗号分隔，只取本题材声音
【禁止项】文字/UI/水印/Logo/角标/可读文字/真实UI
【强制声明】无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

## 硬规则
- 每个命中点写满6变量因果链：打击者+载体 → 命中位置 → 受击反应 → 环境响应 → 镜头反馈 → 下一招衔接
- 连招编排四步（内部完成不输出）：方向链 / 每拍因果 / 镜头贴附动作 / 装饰词物理化
- 镜头策略选1：压迫贴身 / 兵刃核心 / 重量仰拍 / 高速追踪 / 恐怖遮挡 / 大场面调度
- 字数 1100-1500（目标1200-1400）；压缩删修辞→删重复运镜→删低价值环境细节，不删因果链与末尾固定项
- 双版本输出：多模态版（@图片占位）+ 纯文字版（可直接复制）

## 默认设置
15s / 16:9 / 4-6节点 / 1场景 / 2-3角色 / 输出双版本+TXT
