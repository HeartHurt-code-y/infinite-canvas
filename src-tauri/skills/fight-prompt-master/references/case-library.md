# 案例库

每次完成打斗提示词任务后，追加一张案例卡片：

```yaml
案例编号: C-[日期]-[序号]
输入类型: [创意/剧本/小说/分镜]
生成方式: [文生/图生/参考生]
模型: [SD2.0/SD2.5/H3]
输入原文: "[用户原始输入摘要，≤100字]"
题材/骨架: [T1-T7 + 骨架类型]
时长: [X秒]
输出数量: [N方案]
用户反馈: [修改意见或表扬点]
可复用模式: [本次发现的通用动作组合或特效写法]
```

案例库用于：新任务检索相似案例、积累各题材成熟打斗范式、识别用户偏好。
每累计10个案例做一次反思，改进点写入 evolution-log.md。
