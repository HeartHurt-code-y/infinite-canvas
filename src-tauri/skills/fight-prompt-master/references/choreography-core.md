# 导演核心 · 统一方法论（所有引擎通用）

## 通用动作设计表（写任何类型前先填完8项）

| 项目 | 需要回答的问题 |
|---|---|
| 完成条件 | 怎样才算结束这场动作戏（击倒/逼退/脱离/抵达/保护/拖延/撑到结束） |
| 角色差异 | 每名角色擅长什么距离和动作方式 |
| 空间轴线 | 谁从哪里开始，朝哪个方向移动 |
| 资源 | 武器、弹药、能量或可用环境介质有哪些 |
| 主动权变化 | 谁在什么时刻取得或失去优势 |
| 连续状态 | 位置、朝向、速度、武器和损伤怎样继承 |
| 结束画面 | 结果如何被镜头明确看见 |
| 速度档位 | 本次是标准版还是极速版 |

## 角色动作档案（每名参战角色8项，缺一不可）

1 优势距离 2 起手姿态 3 移动方式 4 主要攻击方式 5 防守与反制习惯 6 武器/弹药/能量资源 7 力量节奏 8 结束战斗的方式。
不同角色至少在距离、移动和反制方式上形成明显区别；远程角色需管理视线弹道资源，近战角色需说明怎样缩短距离；体型差异反映在速度、受力与环境反馈上。动物/机械按真实结构（猫=蹬壁摆尾控失重；机器人=磁吸轮/钳臂/卷轴）。

## 第一层 战斗目标
先写可见的完成条件，再写各方怎样实现、对方怎样阻止。目标决定攻防选择、移动方向和结束画面。用户指定的胜负、对白、关键招式、结尾完整保留。

## 第二层 一攻一应（最重要）
每轮交锋6项：**谁发起 → 动作指向哪里 → 接触/格挡/落空 → 对方怎样回应 → 双方位置怎样变化 → 什么状态支持下一拍**。
下一拍可由距离变化、失衡、遮挡、资源消耗、场景损伤或暴露空当触发；避免双方同时执行互不关联的动作。

## 第三层 组合拳公式（力量呈现）
**预兆 → 加速方向 → 接触位置 → 材质变化 → 受力方向 → 位移结果 → 环境反馈**
- 坏写法："重重一拳"
- 好写法："拳头撞上前臂，镜头在接触点短震一次，对方肩膀向右后方偏转，鞋底擦过积水滑出半步"

## 第四层 时间与节奏
- 标准版：0.3s 内有效动作，1.5s 前首次接触；极速版：0.15s 内起手；禁止对峙/蓄势/慢入场
- 时长分配：4-8s 一个动作闭环最多一次明显转折；9-18s 起动/争夺/反制/结果四五阶段；19-30s 五到七段，中段一次有效反转；精确接触过多拆短片段并记录状态
- 中段至少一次攻防转换；结尾默认决出胜负
- Seedance 用连续整秒时间段；H3 用首尾衔接精确时间码；**单条提示词只用一种时间格式**

## 第五层 三套强度 × 两档速度
- **高强度**：交锋密集，快速跟拍+动作匹配切为主，特写只服务关键接触
- **慢节奏**：动作少而完整发力，长镜头/轨道移动/明确环境声，过程最完整的一套
- **中间型**：连续交锋与1-2个动作特写交替，特写中仍有手部/眼神/武器/身体状态变化
- 三套共享角色身份、武器数量、能力边界、场景规则；攻防顺序与结束路径分别设计
- 速度档位独立于强度，同时作用于三套（详见 SKILL.md 极速版硬规则）

## 第六层 连续性锁定
角色/服装/武器/道具/位置/运动方向/弹药资源/场景损伤跨镜一致。武器唯一、数量不增减、破坏不复原（墙面裂纹留到最后一帧）。切镜只改变观看位置，已发生的事件不因机位变化重置。

## 镜头要点（详见 camera-guide.md）
每个镜头只承担一个主要职责，运镜写全6项：景别/机位高度角度/运动速度/摄影机方向/跟随对象/本镜职责。四镜以上覆盖不同职责。

## 武器与能力铁律
- 参考图没武器+用户没指定 → 全程徒手；称号≠装备事实；用户写"挥剑/拔刀"才算指定
- 能力三来源：用户指定 / 参考图可见 / 已确认角色当前版本具备；能力从真实部位或武器产生，双方视觉规律不互换
- 载体路由：刃器斩刺滑刃 / 长柄中线横扫回马 / 钝器砸压撞震 / 远程管弹道装填 / 徒手拳肘膝摔擒拿 / 能力型牵引压缩束缚 / 飞行振翼俯冲 / 四足扑咬甩尾 / 机械按真实结构
- 攻防适配：持械vs徒手→踢腕控臂贴身不接锋刃；双徒手→无剑气无金属音；双能力→近中距接触攻防不对轰

## 强度调节（交付后）
「打斗得更激烈」→ 提高交锋频率、减少呼吸拍；「提示词更高密度」→ 微动作 +30-40%（15秒约16-22个，一次交锋3-5个微动作）。

## 全局禁止项
开场对峙 / 原地互殴 / 攻击无接触点 / 重复招式构图 / 切镜复位换手 / 无依据瞬移飞行 / 凭空补武器 / 能量互换 / 特效遮主体 / 纯特效对轰 / 慢动作定格 / 新增第三人 / 无要求字幕Logo / 最后一秒新能力 / 无来源闪切堆密度。
