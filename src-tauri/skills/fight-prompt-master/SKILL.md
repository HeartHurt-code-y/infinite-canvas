# 全能打斗提示词导演 Fight Prompt Master V0.2

> **一句话定位**：一个统一导演方法论，前面用固定选择卡收齐参数，中间按导演管线编排动作，最后按所选模型（SD2.0 / SD2.5 / H3）做提示词格式优化。
> **集成来源**：seedance-fight-prompter(2.0) + seedance-2.5-fight-prompter + h3-prompt-writing + h3-jackie-chan-fight-director + 电影级动作导演高密度模板 + fight-prompt-director（三套强度×两档速度、8项角色档案、7类结构、镜头语法、单变量排错）。**原 skill 全部保留不动。**

---

## 一、固定选择卡（前期选项已固化，不自由发挥）

用户已提供的参数**不重复询问**；只补问会显著改变结构的缺失项。

| # | 选择项 | 选项 | 默认值 | 询问规则 |
|---|-------|------|--------|---------|
| 1 | 输入素材 | 纯文字 / 角色图 / 场景图 / 首帧图 / 首尾帧 / 分镜图 / 动作参考视频 / 运镜参考视频 | 自动判断 | 从素材判断，不问 |
| 2 | 生成方式 | 文生 / 图生 / 参考生 | 有图→参考生；无图→文生 | 不问，自动 |
| 3 | 模型 | SD2.0 / **SD2.5** / H3 | SD2.5 | 未提时问一次（说明默认SD2.5） |
| 4 | 时长 | 4-30s（2.5）/ 10-15s（2.0）/ 10-20s（H3） | 15秒 | 未提时问一次 |
| 5 | **速度档位** | 标准版 / 极速版（独立于强度的一轴） | 标准版 | 未提时补问一次，说明极速版让三套方案整体变快 |
| 6 | 强度方案 | 高强度 / 中间型 / 慢节奏 | **默认输出三套**供三选一 | 用户指定单一强度则只出该版 |
| 7 | 胜负结果 | 决出胜者 / 指定赢家 / 平局 | 决出胜者 | 用户没提就走默认 |
| 8 | 画幅 | 16:9 / 9:16 / 1:1 | 16:9 | 从素材或用途判断 |

**极速版硬规则**（以15秒为基准，作用于三套强度方案，不新增第四套）：
- 时间颗粒更短：Seedance 从约4段（每段3-4s）改为 **5-6段（每段2-3s）**，首尾相接；H3 缩短时间码，镜头数略增
- 微动作 +30-40%：高强度7-9次交锋/16-22微动作/6-9镜头；中间型6-8次/12-16/5-7；慢节奏5-7次/10-14/3-4镜或高密度一镜到底
- 起手0.15s内（标准0.3s）；纯恢复动作≤0.3s；动作特写0.4-0.8s；默认不用慢动作（决定性命中最多一次0.15-0.3s）
- 不用无来源闪切堆密度；因果链照常成立

## 二、统一导演管线（9 步）

```
①选择卡 → ②素材职责拆分 → ③动作设计表+角色档案 → ④结构骨架
→ ⑤因果交锋编排 → ⑥时长分配 → ⑦三套强度×速度档 → ⑧镜头设计
→ ⑨模型引擎封装输出（SD2.0/2.5/H3 各自优化）
```

1. **选择卡**：按上表收齐参数
2. **素材职责拆分**：每份素材单一职责——角色图锁身份、场景图锁空间、首帧锁起点、首尾帧写因果衔接、分镜按序读取忽略边框标注、动作参考视频只继承身体轨迹、运镜参考视频只继承机位路径
3. **设计表+档案**：读 `references/choreography-core.md`——通用动作设计表8项（完成条件/角色差异/空间轴线/资源/主动权变化/连续状态/结束画面/速度档位）+ 角色动作档案8项
4. **结构骨架**：读 `references/fight-structures.md`，7类结构选1：单人突围/双人攻防/远程能量对抗/一人对多人/人兽对决/单人演武/风格化材质动作
5. **因果编排**：一攻一应6项 + 组合拳公式（预兆→加速→接触点→材质变化→受力方向→位移→余波）
6. **时长分配**：4-8s一个动作闭环 / 9-18s起动-争夺-反制-结果四五阶段 / 19-30s五到七段中段一次反转
7. **三套强度×速度档**：高强度/中间型/慢节奏各设计一套，共享角色身份、武器数量、能力边界、场景规则；攻防顺序与结束路径分别设计
8. **镜头设计**：读 `references/camera-guide.md`——镜头句式6项、8职责表、按阶段选镜、三档强度搭配、连续性记录8项
9. **模型引擎封装**：读对应引擎文件做格式优化——
   - SD2.0 → `engine-seedance2.md`（11字段，粗时间段约4段）
   - SD2.5 → `engine-seedance25.md`（时间戳钉死每拍，极速版5-6段2-3s，多模态/超长/延长）
   - H3 → `engine-h3.md`（英文六段式，首尾相接精确时间码）
   - 最高密度需求 → 加载 `director-template-A.md`+`B.md`

## 三、输出格式规范（所有模型通用）

每个方案 = 标题 + 生成说明 + 一句设计说明 + 完整提示词代码块：

```
## 方案一｜高强度：〔动作方式与空间特点〕
说明：〔模型〕，〔时长〕，〔比例〕，〔标准版或极速版〕
〔一句设计说明：看点与发展方向〕
```text
〔可直接复制的视频提示词〕
```
```

提示词结尾写明：角色数量、武器数量、外观锚点、空间方向、资源状态、场景损伤、字幕与水印要求。三套方案默认全出，带标题与看点注释供三选一；选定后可用「打斗得更激烈」（提高交锋频率）或「提示词更高密度」（微动作+30-40%）加强。

## 四、失败诊断（单变量排错）
用户提供失败结果或要求验收 → 读 `references/failure-diagnostics.md`。**每轮只调整动作/镜头/参考素材中的一类变量**，改完复测再定下一步；连续两轮无改善→重查变量归属。同时支持"只诊断不改写"模式（体检10项）。

## 五、内容边界
- 不复制外部提示词的完整句子、固定动作链、具体角色场景组合；不调用知名影视动漫游戏角色
- 不用空泛强度词替代可见动作、方向和结果
- 武器/投射物/角色数量/场景损伤不因切镜重置
- 默认无字幕、无水印，不加用户未要求的旁白
- 参考图没武器+用户没指定=全程徒手；能力三来源才可用（用户指定/参考图可见/已确认角色具备）

## 六、输出前自检

[ ] 每份参考素材单一职责；多角度设定图未生成额外分身
[ ] 每轮交锋6项完整（发起/指向/接触或落空/回应/位置变化/下一拍接口）
[ ] 三套方案共享身份武器能力边界；极速版密度在上表范围内
[ ] 时间段首尾连续覆盖完整时长；单条提示词只用一种时间格式
[ ] 结尾写明数量/锚点/方向/资源/损伤/字幕水印
