# 方法论

持续依据的三本书。

---

## 罗伯特·麦基 —《故事》

### 控制理念（Controlling Idea）
一句话，形式为「当主角做了Y，因为Z，生活变为X」。这是电影的控制理念。每一场戏必须服务于它。

如果你不能用一句话表述控制理念 — 电影没有脊梁。先有理念，后有场景。

### 场景价值（Scene value — 价值变动）
任何一场戏中，**某些东西在变化** — 从 + 到 – 或反之。价值以某种状态入场，以另一种状态出场。

**没有价值转向的戏 = 不是戏。** 那只是描述。

在写一场戏之前，回答：
- 什么价值入场？（例如：信任。）
- 处于什么状态？（例如：团队信任领导者。）
- 以什么状态出场？（例如：团队怀疑领导者。）
- 这是如何发生的？（什么行为翻转了价值。）

典型价值对：
- 控制 ↔ 无助
- 信任 ↔ 背叛
- 爱 ↔ 执念
- 生 ↔ 死
- 自由 ↔ 囚禁
- 纪律 ↔ 混乱
- 团队 ↔ 工具
- 希望 ↔ 绝望
- 知识 ↔ 无知

### 激励事件（Inciting Incident）
将主角的生活从平衡中击出的事件。必须在电影的**第一个四分之一**内发生（对90分钟片长 — 在22分钟前）。

没有这个事件，情节无法启动。主角在此事件之前和之后的生活 — 是两个不同的世界。

### 渐进式复杂化（Progressive Complications）
每一个后续冲突都比前一个更强。主角的期望与其行为结果之间的鸿沟 — 在扩大。

如果你的第三幕冲突比第一幕弱 — 结构已损坏。

### 危机 → 高潮 → 结局（Crisis → Climax → Resolution）
- **危机：** 主角的终极两难。在两个不可兼得的价值之间抉择。最艰难的节点。
- **高潮：** 回应两难的行为。电影中最具物理性和最响亮的部分。
- **结局：** 高潮之后新世界的简短坐标。

### "+" 与 "–" 的钟摆
主角不能一直做得好或一直做得差。交替。每次迭代振幅都在增大。

在坠落弧线中 "+" 是地方性的（小胜利），"–" 是系统性的（大损失）。
在上升弧线中反之。

### 展示，不讲述（Show, don't tell）
用行为和物体替代内心独白。画面中的物体比台词更有力。

验孕棒 替代 台词「她怀孕了」。
撕碎的信 替代 台词「他和她分手了」。
空椅子 替代 台词「他很孤独」。

## 约瑟夫·坎贝尔 —《千面英雄》

将坎贝尔用作**诊断工具**，而非教条。并非每个故事都是纯粹的英雄之旅。尤其在写反英雄或悲剧时（此时起作用的是镜像旅程 — *katabasis* 无归途，如俄耳甫斯追欧律狄刻）。

### 12个阶段

1. **平常世界** — 主角处于平衡中。展示已有的，让观众明白将失去什么。
2. **冒险的召唤** — 要求主角离开家园的事件。
3. **拒绝召唤** — 主角犹豫、恐惧。没有这个阶段，主角不是主角，而是功能。
4. **遇见导师** — 有人给予工具、技能或知识。可能是假导师 = 阴影。
5. **跨越门槛** — 主角穿越世界之间的边界。
6. **试炼、盟友、敌人** — 在新世界中安顿。
7. **接近洞穴** — 为主要试炼做准备。
8. **主要试炼** — 与死亡或阴影相遇。
9. **奖赏** — 主角获得了为之而来的东西。
10. **回归之路** — 回到平常世界（或在反英雄中 — 无法回归）。
11. **复活** — 终极试炼。主角死去并重生。
12. **携灵药归来** — 主角为世界带来新的东西。

### 原型
- **英雄：** 情节的主动推动者。
- **阴影：** 反英雄，英雄黑暗面的映照。
- **导师：** 给予工具。
- **门槛守卫：** 进入新世界的障碍。
- **信使：** 宣告召唤。
- **变形者：** 改变立场。
- **捣蛋鬼：** 打破规则的喜剧角色。

在反英雄悲剧中 **导师常常 = 阴影**。主角不明白他的老师就是他的敌人。

## 亚里士多德 —《诗学》

### Ἁμαρτία（hamartia — 悲剧性缺陷）— 主角的致命缺陷
不是道德意义上的「罪」，而是性格中的错误，启动悲剧。一个好主角有一个弱点，在正常生活中是美德，在特殊情境中变成灾难。

「我爱得太深」— 这就是浪漫悲剧中的 hamartia。
「我信任每个人」— 政治剧中的。
「我无法原谅」— 家庭剧中的。

Hamartia 必须**从第一场戏就可见**，并在**高潮中引爆**。

### Περιπέτεια（peripeteia — 突转）— 行为向相反方向转变
本应导致 X 的行为，导致了 -X。

想要拯救，却杀死。想要保护，却毁灭。想要打开，却永远关闭。

一部强片有 2-3 次突转，力度递增。

### Ἀναγνώρισις（anagnorisis — 发现/认出）
主角（或观众）理解了之前隐藏的东西的时刻。

最好的 anagnorisis 是**与 peripeteia 重合的**。双重打击：主角在行为反转为相反方向的同一时刻发现了真相。

### Κάθαρσις（katharsis — 净化）— 通过恐惧和怜悯获得净化
结局必须让观众产生对主角的同情和对自己命运的恐惧（「我本可能是他」）的混合情感。

### 行动的统一
亚里士多德要求悲剧中的一切都指向一个点。每一个行为、每一个物品、每一句台词都必须服务于终局点。

**如果一场戏不服务于终局点 — 它就是多余的。** 测试很简单：移除这场戏，电影会变吗？如果不会 — 剪掉。

## 如何使用

在写每一场戏之前：
1. 控制理念是什么（来自麦基）？
2. 什么价值进入这场戏，什么价值离开？
3. 处于坎贝尔的哪个阶段？（如果适用。）
4. 这场戏如何服务于主角的 hamartia？
5. 这是突转戏还是铺垫戏？

如果答案是空的 — 这场戏要么不需要，要么需要重新思考。
