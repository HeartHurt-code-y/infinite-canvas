- [ ] 本集信息头部完整，核心冲突一句话说清

## 格式符号速查

| 符号 | 含义 | 用法 |
|------|------|------|
| `**角色名**` | 加粗角色名 | 每句台词开头，后接括号标注情绪/动作 |
| `（…）` | 情绪/动作/语气指导 | 紧跟角色名后，括号内写表演指导词 |
| `△` | 台词标记 | 三角形符号开头，标记人物台词行 |
| `【…】` | 环境/音效/调度说明 | 场景开头或需要氛围切换时使用 |
| `【特效：…】` | 打斗VFX特效描写 | 独立成行，三段式，**不计入总字数** |
| `---` | 场景分隔线 | 每个场景之间用三条横线分隔 |

**常用镜头类型**（方括号内只写景别，不写剪辑/后期指令）：
`面部特写` / `中景` / `全景` / `俯拍` / `仰拍` / `手持晃动` / `推` / `拉` / `快速剪辑` / `慢动作` / `近景` / `远景` / `空镜`
