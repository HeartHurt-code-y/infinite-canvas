# 打斗场景 VFX 特效描写参考手册

> 版本：v1.0 | 用途：短剧打斗/动作场景的特效细节描写 | 不计入剧本总字数

## 一、特效标注格式（强制）

所有特效描写**不占用剧本正文字数**，统一使用以下格式嵌入剧本：

```
【特效：XXXXX】
```

**格式规则**：
- `【特效：` 为固定开头，不可省略或替换
- 内容写完后以 `】` 结尾
- 可插入在台词前、镜头指示后、或独立成行
- **字数不计入单集总字数限制**，可充分展开细节

## 二、三段式特效描写结构

每个完整的打击/受击动作，按以下三段顺序描写：

```
[行动段] → [攻击段] → [受击段]
```

| 段落 | 内容 | 特效焦点 | 参考时长 |
|------|------|----------|---------|
| **行动段** | 攻击方蓄势/移动/出手 | 环境互动、能量积聚、预备动作的视觉化 | 0.5-1.5秒 |
| **攻击段** | 攻击命中瞬间 | 轨迹残留、命中特效、能量释放 | 0.2-0.5秒 |
| **受击段** | 被攻击方受力反应 | 形变、粒子迸发、创伤表现 | 0.5-2秒 |

## 三、行动段：角色行动特效

### 3.1 蓄力类

**物理层面**：肌肉紧绷产生的视觉外化

| 元素 | 描写方向 | 示例词汇 |
|------|----------|---------|
| 地面 | 压力传导导致的裂纹/塌陷 | 蛛网裂纹、碎石弹跳、地面下沉 |
| 气流 | 能量积聚导致的气压变化 | 气浪翻涌、尘土呈螺旋状升起、衣摆猎猎作响 |
| 粒子 | 能量溢出的微观表现 | 电火花噼啪跳跃、皮肤表面浮现金色光纹 |
| 环境 | 大范围环境响应 | 灯光明灭不定、玻璃轻微共振、水面向外荡开同心圆涟漪 |

### 3.2 位移类

**速度感表现**：通过环境破坏和残留轨迹展现实时速度

| 速度等级 | 环境破坏程度 | 残留轨迹 | 参考词汇 |
|----------|-------------|----------|---------|
| 常人极限 | 蹬踏处轻微磨损 | 短暂残影 | 身影一闪、劲风扑面 |
| 超人类 | 地面龟裂/凹陷 | 持续1-2帧的清晰残影 | 音爆云、地面炸开 |
| 极致速度 | 路面崩塌/建筑结构受损 | 多段连续残影如真人定格 | 真空通道、身后建筑玻璃连环爆裂 |

### 3.3 武器出鞘/能量释放类

按角色背景选择对应能量形态：

| 能量类型 | 视觉特征 | 环境互动 | 代表风格 |
|----------|---------|----------|---------|
| 刚猛/火焰 | 橙红-白炽色、高亮度、热浪扭曲 | 可燃物点燃、金属发红 | 武者/战士 |
| 阴冷/冰霜 | 青白-幽蓝色、低饱和度、霜晶蔓延 | 水面结冰、呼吸成雾 | 刺客/术士 |
| 迅疾/雷电 | 银白-紫蓝色、高频闪烁 | 电子设备干扰、金属磁化 | 异能者/科技 |
| 厚重/土岩 | 赭石-深棕色、缓慢厚重、颗粒质感 | 地面隆起、尘土飞扬 | 重装/古武 |
| 锋利/金刃 | 银白-淡金色、细线状、锐利边缘光 | 无接触切割、金属共鸣 | 剑客/杀手 |

## 四、攻击段：角色攻击特效

### 4.1 徒手打击

拳击描写要点：拳峰前方空气压缩、肘关节后方气浪、目标面部皮肤已受气压影响开始凹陷变形。

踢击描写要点：腿如鞭子传导力量、裤管在高压气浪下撕裂、脚背绷直如刀，轨迹上留下半月形白色气刃残像。

投技/摔技描写要点：双手如铁钳扣住对方、旋转身躯搅成小型龙卷、砸向地面时冲击波呈环形炸开。

### 4.2 武器攻击

刀剑斩击：刀身从鞘中滑出迸出火花流，刀刃并非纯粹金属光泽而是流动的液态光纹，挥斩轨迹留下"真空裂痕"。

长枪突刺：枪身在气浪中炸开，枪尖前方空气压缩至临界状态形成高压球体，双层打击的视觉效果。

能量/气功波：掌缝间泄露光芒，能量球表面是不断起伏翻涌的等离子体，内部可见闪电状分支结构疯狂游走。

## 五、受击段：受力点特效描写

### 5.1 受力点分类与描写

| 受击部位 | 即时形变 | 粒子迸发 | 连锁反应 |
|----------|---------|----------|---------|
| **面部/头部** | 皮肤凹陷呈拳印/靴形 | 汗水扇形飞散，牙齿或血滴飞出 | 头部后仰带动全身重心后移 |
| **胸腹** | 肌肉/护甲向内凹陷 | 口中喷出血雾圆锥形扩散 | 双膝本能弯曲缓冲 |
| **背部** | 脊柱轮廓在衣物下短暂凸显 | 衣物背部大面积撕裂 | 冲击波沿脊柱向上传递至后脑 |
| **四肢** | 关节反方向扭曲 | 骨骼断裂骨茬刺破皮肤 | 肢体失去支撑功能 |

### 5.2 受击反应深度分级

**一级：轻微打击** — 面部皮肤从正常肤色转为潮红，皮下毛细血管网短暂显现。

**二级：中度打击** — 嘴角崩裂鲜血喷射，瞳孔放大至极限，虹膜边缘出现细小出血点。

**三级：重度打击** — 腹腔瞬间凹陷出深坑，口中喷出血雾混杂胃酸和唾液的粉红色气溶胶云，身体呈"V"字形向后飞出。

## 六、角色背景与特效风格映射

### 6.1 根据角色类型选择特效风格

| 角色类型 | 核心视觉语言 | 特效关键词 | 禁止使用 |
|----------|------------|-----------|---------|
| **古武/内功** | 气韵流动、含蓄内敛 | 气浪、罡风、内劲外放、残影、音爆 | 光污染、科技感元素 |
| **现代格斗** | 写实物理、肌肉动力学 | 汗水飞散、肌肉震颤、骨节脆响、地面龟裂 | 能量光束、飞行 |
| **异能/超能力** | 能量具象化、规则扭曲 | 磁场偏转、重力异常、空间褶皱、时间凝滞 | 过于写实的物理限制 |
| **修仙/玄幻** | 天地异象、法则显现 | 剑气纵横、雷劫降世、虚空破碎、法宝灵光 | 现代科技词汇 |
| **科幻/机甲** | 机械美学、能量计量 | HUD界面、充能百分比、推进器尾焰、液压传动 | 魔法元素、玄学描述 |
| **暗杀/刺客** | 极简致命、一击必杀 | 细线状刀光、血雾瞬间凝固、影子分身 | 大范围爆炸 |

### 6.2 角色专属特效指纹

每个主要角色的特效应有**辨识度**：
- **古武世家角色**：金色罡气为主，龙形虚影缠绕手臂，金属共鸣般的低频龙吟，地面留下焦黑龙爪印记
- **科技改造角色**：钴蓝能量管线 + 橙色警告灯，机械关节处液压光纹，电子合成充能音

## 七、物理细节库

### 7.1 粒子系统

| 场景 | 粒子类型 | 密度 | 初速度 | 持续时间 |
|------|---------|------|--------|---------|
| 拳击命中面部 | 汗水+血滴 | 20-50颗 | 3-8 m/s | 0.5-1.5秒 |
| 刀剑劈砍 | 金属碎屑 | 10-30颗 | 5-15 m/s | 1-3秒 |
| 地面塌陷 | 碎石+尘土 | 100-500颗 | 2-20 m/s | 2-5秒 |
| 能量爆炸 | 火花+光粒 | 200-1000+ | 0.5-50 m/s | 3-10秒 |
| 衣物撕裂 | 纤维碎屑 | 50-200颗 | 1-5 m/s | 2-4秒 |

### 7.2 流体模拟

```
血液描写公式：
- 喷射型（动脉）：抛物线轨迹，飞行中分裂为大中小三滴，落地后呈放射状溅开
- 渗出型（毛细血管）：沿皮肤表面流淌，受重力影响向下弯曲
- 雾化型（肺部/口腔）：锥形扩散，密度随距离衰减

火焰描写公式：
- 核心温度区：白炽色，亮度最高，空气严重扭曲
- 中温燃烧区：橙黄色，主体体积，产生黑烟上升
- 外焰舔舐区：暗红色，不规则跳动，偶尔脱离主体形成飘浮火球
```

## 八、检查清单

- [ ] 每个打击动作是否包含完整的【行动段→攻击段→受击段】三段结构
- [ ] 特效是否符合角色的背景设定（古武/科技/异能/修仙等）
- [ ] 受力点是否有具体的形变、粒子迸发、连锁反应描写
- [ ] 是否使用了具体的物理参数（速度、温度、距离、时间）
- [ ] 是否避免了不同风格元素的混用
- [ ] 特效标注格式是否为【特效：…】，而非 [特效] 或其他格式
- [ ] 特效字数是否未计入单集总字数限制
- [ ] 同一角色的特效是否有辨识度

## 九、禁止清单

- [ ] 禁止将特效内容写入 `[ ]` 方括号内（方括号仅限景别词）
- [ ] 禁止用模糊的"发出光芒""产生冲击波"代替具体物理细节
- [ ] 禁止角色风格混用——古武角色不能有科技充能特效
- [ ] 禁止忽略受击方的受力点反应
- [ ] 禁止连续三段以上特效不插入台词或镜头指示
- [ ] 禁止过度使用慢动作标注——只有关键一击才能用慢动作
