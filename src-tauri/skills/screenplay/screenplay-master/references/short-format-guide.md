# 短格式剧本创作指南（1-5 分钟）

> 本指南是 AI agent 创作 1-5 分钟微短剧剧本的核心参考文件，覆盖极速模式与弧光模式两种核心创作方法论。

## 一、极速模式（1-3 分钟）完整流程

### 1.1 核心公式
```
Hook(3s) → 冲突(15s) → 反转(60s) → CTA/爽点(15s)
```

### 1.2 基本参数
| 参数 | 标准 |
|------|------|
| 单集字数 | 200-720字 |
| 场景数 | ≤ 2个 |
| 单句台词 | ≤ 15字 |
| 钩子密度 | 每10秒至少1个 |
| 催化剂 | 第1秒出现（即第一帧必须有动作/冲突/情绪） |

### 1.3 台词节奏标准
- 每10秒一个信息点（台词或动作）
- 对话如格斗：一句一招，不接无意义的废话
- 禁止内心独白，全部外化为动作或对话

### 1.4 极速模式节拍表模板

| 时间 | 节拍 | 动作/内容 | 情绪曲线 | 钩子 |
|------|------|----------|---------|------|
| 0-3s | Hook | 主角被打/被骂/发现秘密 | 震惊/愤怒 | 视觉暴击 |
| 3-15s | 冲突升级 | 反派出招，主角隐忍 | 憋屈↑ | 每10s一句狠话 |
| 15-45s | 压抑叠加 | 连续羞辱，主角握紧拳 | 压抑峰值 | "你算什么东西" |
| 45-75s | 反转爆发 | 主角亮底牌，局势逆转 | 爽感↑↑ | 身份/能力揭露 |
| 75-90s | 释放+CTA | 反派跪地/众人震惊 | 极致爽 | 未完待续钩子 |

## 二、弧光模式（4-6 分钟）完整流程

### 2.1 核心公式
```
建置(1min) → 对抗(2-3min) → 危机(1min) → 结局(1min)
```

### 2.2 基本参数
| 参数 | 标准 |
|------|------|
| 单集字数 | 800-1200字 |
| 场景数 | ≤ 3个 |
| 台词功能 | 对话推动冲突，允许独白用于情感爆发 |
| 钩子密度 | 每15秒至少1个 |
| 催化剂 | 30秒内出现 |
| 核心要求 | 开场画面与结尾形成对比，证明角色改变 |

### 2.3 弧光模式节拍表模板

| 时间 | 节拍 | 动作/内容 | 情绪曲线 |
|------|------|----------|---------|
| 0-30s | 开场画面 | 展示主角日常/缺陷状态 | 平静/略压抑 |
| 30-60s | 催化剂 | 事件打破平衡（接到电话/被人找上） | 紧张↑ |
| 60-120s | 对抗A | 主角尝试用旧方式解决，失败 | 挫折↑ |
| 120-180s | 对抗B | 被迫改变策略，遇到关键盟友/真相 | 希望↑ |
| 180-240s | 危机 | 最大打击：失去最重要的人或物 | 绝望峰值 |
| 240-270s | 领悟 | 独白/对话触发内在转变 | 觉醒↑ |
| 270-300s | 结局画面 | 与开场画面对比，展示成长 | 释然/燃 |

### 2.4 弧光模式关键规则
- **开场与结尾必须形成镜像**：开场逃避的，结尾面对；开场软弱的，结尾强硬
- 独白仅允许在"领悟"阶段使用，字数控制在80字以内
- 危机必须是"灵魂黑夜"：主角失去一切，被迫直面真我

## 三、开场 6 种钩子模式

### 3.1 情绪暴击型
第一秒就呈现极致情绪画面，让观众来不及思考就被卷入。

### 3.2 悬念抛钩型
抛出一个违反常识的核心悬念，迫使观众追问"为什么"。

### 3.3 身份反差型
角色的外在身份与行为形成巨大反差，制造认知冲突。

### 3.4 冲突开局型
不铺垫，直接进入最激烈的对抗现场。

### 3.5 价值展示型
展示极致的生活方式、能力或价值，制造欲望。

### 3.6 喊话挑衅型
直接对观众或角色喊话，建立亲密感和挑衅感。

## 四、反转 5 种模式

### 4.1 身份反转（假身份揭露）
### 4.2 立场反转（盟友变敌人/敌人变盟友）

### 4.4 感情反转（爱恨瞬间转换）

## 六、核心创作规则

### 6.1 台词铁律
- 单句台词 **≤ 15字**
- 极速模式：每10秒一个信息点
- 弧光模式：每15秒一个钩子
- 禁止"你好吗"/"吃了吗"等无意义寒暄
- 一句一招，不接废话

### 6.2 场景铁律
- 极速模式场景 **≤ 2个**
- 弧光模式场景 **≤ 3个**
- 换场景必有叙事理由，不为换而换

### 6.3 打脸四步法（必走完）
```
羞辱 → 隐忍 → 反击 → 释放
```
- **羞辱**：反派嚣张到让观众生气
- **隐忍**：主角越忍，观众越急（不超过总时长40%）
- **反击**：主角亮出底牌，局势180°逆转
- **释放**：反派崩溃/众人震惊/观众爽透

### 6.4 AI 创作自检 prompt
```
写完剧本后，逐条检查：
1. 第一秒有没有动作/冲突/情绪？（催化剂是否到位）
2. 每10秒（极速）/15秒（弧光）有没有一个钩子？
3. 打脸四步法是否完整走完？
4. 单句台词是否≤15字？
5. 场景数是否超标？
6. 开场与结尾是否有对比（弧光模式）？
7. 最后一秒是否留钩子引导下一集/付费？
```
