# 短剧剧本质量门与快速诊断手册

> 用途：AI agent 对剧本逐集进行质量检查时的核心参考指南。所有检查项未通过则该集不得交付。

## 一、每集质量门（7 项必检，全部通过方可交付）

| # | 检查项 | 判定标准 | 验证方法 |
|---|--------|---------|---------|
| 1 | **钩子检查** | 前5秒有强钩子，观众必须被吸引住 | 遮住后面内容，只看前5秒是否想知道后续？ |
| 2 | **反转检查** | 每集至少一个反转/打脸/真相揭露/情绪转折 | 梳理全集是否有"以为A结果是B"的时刻 |
| 3 | **结尾检查** | 每集结尾有悬念/情绪爆发点/"未完待续"卡点 | 结尾是否让人"欲罢不能"？ |
| 4 | **OOC检查** | 台词符合人物卡，每句台词都能对应到人设四件套 | 遮住角色名，能否根据台词猜出是谁说的 |
| 5 | **字数检查** | 单集字数在标准范围内 | 统计字数并核对 |
| 6 | **场景检查** | 每集独立场景数 <= 3 个；超出必须有明确创作理由 | 统计独立场景数量 |
| 7 | **制作检查** | 所有场景和道具在预算范围内可拍摄 | 逐条检查场景描述的可实现性 |

**交付规则**：以上7项全部打勾（Pass）方可交付；任一Fail需返修后重检。

## 二、剧本快速诊断（4 维度速查）

### 2.1 观众看不下去？

| 诊断项 | 检查方法 |
|--------|---------|
| 钩子 | 每集前5秒够不够吸引？ |
| 节奏 | 是否连续2集没有反转？ |
| 悬念 | 每集结尾有没有"非看不可"的钩子？ |
| 信息密度 | 是否有超过30秒的无意义对话？ |

### 2.2 角色不讨喜？

| 诊断项 | 检查方法 |
|--------|---------|
| 主动性 | 主角是否在推动剧情（而不是被推动）？ |
| 共鸣 | 主角的困境是否能让观众代入？ |
| 魅力 | 主角是否有让观众"想成为TA"的特质？ |
| 成长 | 角色是否有明显的变化轨迹？ |

### 2.3 打脸不够爽？

| 诊断项 | 检查方法 |
|--------|---------|
| 前置羞辱 | 反派欺负主角的力度够不够？ |
| 等待时间 | 从羞辱到反击间隔是否太短？ |
| 揭露方式 | 身份/真相揭露的场景够不够震撼？ |
| 围观群众 | 是否有"众人震惊"的场面？ |

### 2.4 感情线不磕？

| 诊断项 | 检查方法 |
|--------|---------|
| CP化学反应 | 两人在一起时有没有火花？ |
| 反差萌 | 是否有"在外人面前A面，在TA面前B面"的设计？ |
| 互动密度 | 是否每2-3集有一次甜蜜互动？ |
| 障碍设置 | 是否有合理的阻碍让感情不能一帆风顺？ |

## 三、常见创作陷阱与解决方案

### 3.1 节奏类陷阱

| 陷阱 | 表现 | 解决方案 |
|------|------|---------|
| 开局拖沓 | 第1集在铺垫背景 | 第1集直接进入冲突，背景后面补 |
| 中段注水 | 20-40集重复相似的误会 | 每5集必须引入新变量 |
| 高潮疲软 | 大反转力度不够 | 反转前要有更深的误导，落差越大越震撼 |
| 结局仓促 | 最后3集赶进度收尾 | 从Ep 80开始收束 |

### 3.2 角色类陷阱

| 陷阱 | 表现 | 解决方案 |
|------|------|---------|
| 女主圣母 | 被欺负不反抗，等男主来救 | 每3集给女主一次主动反击的机会 |
| 男主工具人 | 只有霸道/深情两个模式 | 给男主一个独立的成长线或弱点 |
| 反派降智 | 反派后期突然变蠢 | 反派能力始终在线，最后输在信息差上 |
| 配角遗忘 | 写着写着配角消失了 | 配角出场计划表：每隔N集必须出现 |

### 3.3 逻辑类陷阱

| 陷阱 | 表现 | 解决方案 |
|------|------|---------|
| 信息不对称滥用 | 角色不沟通制造误会 | 误会必须有"无法沟通"的合理阻碍 |
| 巧合驱动 | 关键剧情靠巧合推进 | 关键转折必须是角色主动行为的结果 |
| 设定前后矛盾 | 前面说的设定后面忘了 | 维护设定文档，每10集回查一次 |
| 时间线混乱 | 事件发生顺序不合理 | 使用时间线表格追踪所有事件 |

## 四、质量检查速查口诀

> **"钩反悬、字数场制"** —— 七门全过才交付
>
> **"看角爽感"** —— 四维诊断定位病灶
>
> **"冲突第一集、变量每五集、收束八十起"** —— 节奏底线
>
> **"人设遮名猜、主动给女主、反派不降智"** —— 角色底线
>
> **"巧合不推主线、误会要有阻碍、设定十集回查"** —— 逻辑底线
