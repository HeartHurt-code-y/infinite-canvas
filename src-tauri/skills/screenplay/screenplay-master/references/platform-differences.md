# 短剧平台差异指南

> 本文件为 screenplay-master SKILL 的平台适配参考，AI agent 在生成/改写剧本时需根据目标平台特征进行适配。

## 一、抖音

| 维度 | 特征 |
|------|------|
| 画幅 | 9:16 竖屏，1080x1920 |
| 时长 | 单集 1-2 分钟为主 |
| 分发机制 | 算法推荐，**前3秒完播率**决定推荐量级 |
| 付费设计 | 信息流广告为主；付费短剧通过小程序跳转 |

### 剧本适配
- 开场必须极强（3秒完播率压力），**前3秒必须有冲突/反转/悬念**
- 信息密度更高，压缩一切冗余
- 节奏更快，**每10秒一个钩子**
- 台词精简，避免长篇独白

### 特殊要求
- 开场画面**禁止黑屏/慢镜头/空镜**，直接切入冲突
- 标题和封面图决定点击率，需单独优化
- 评论区互动量直接影响推荐权重，可埋互动梗

## 二、快手

| 维度 | 特征 |
|------|------|
| 画幅 | 9:16 竖屏 |
| 时长 | 单集 1-3 分钟 |
| 分发机制 | 关注+推荐双驱动，**私域流量占比高** |
| 付费设计 | 快手小剧场付费解锁 |

### 剧本适配
- 增强粉丝互动感，台词可带称呼感（"兄弟们""家人们"）
- 结尾可增加引导评论的钩子（"你们遇到过这种事吗？"）
- 接地气的台词风格更受欢迎，减少书面语

### 特殊要求
- **老铁文化**：强调亲近感、真实感、烟火气
- 评论区互动是重要的分发因素，需设计互动点
- 人设真实感比精致感更重要

## 三、微信小程序

| 维度 | 特征 |
|------|------|
| 画幅 | 9:16 竖屏 |
| 时长 | 单集 1-2 分钟 |
| 分发机制 | **私域传播**为主（微信群/朋友圈分享） |
| 付费设计 | 付费墙设计，连续付费解锁后续集数 |

### 剧本适配
- **付费卡点设计是最核心任务**，每集结尾必须制造强烈"欲知后事"的冲动
- 前 5 集免费引流，第 6 集起付费
- 每集结尾必须有悬念 cliffhanger
- 可设计"付费预告"字幕/旁白："下一集更精彩"

### 特殊要求
- 标题和封面图比内容更重要，直接决定点击率
- **付费转化率**是核心指标，一切围绕转化设计
- 前5集质量必须最高，是付费转化的关键漏斗

## 四、跨平台通用规则

### 4.1 内容结构定律
- **前十集定律**：前10集决定全剧生死，必须全剧精华
- **前5秒Hook**：所有平台都遵循前5秒定生死
- **单集结尾必须有悬念**，不可平淡收尾

### 4.2 视觉规范
- 9:16 竖屏是所有平台的统一标准
- 竖屏构图：人物占画面 **60%以上**，减少全景/大场面
- 特写和近景为主，强调人物表情和情绪

### 4.3 台词风格
- 口语化、接地气，避免书面语和长句
- 一句话一个信息点，不要堆叠
- 方言/网络梗需结合目标用户群体判断

### 4.4 钩子节奏
- 每集至少 3 个情绪转折点
- 每 10-15 秒一个小钩子，每集结尾一个大钩子
- 钩子类型：反转、悬念、冲突、情感爆发、信息揭示
