# 角色工程参考手册

> 短剧角色设计与爽点编排核心指南。所有角色必须通过四件套定义，所有剧情必须通过密度曲线和节奏表检验。

## 一、人设四件套模板

每个角色必填四项，缺一项即人设不完整。

| 维度 | 定义 | 写作要点 |
|------|------|----------|
| **欲望** | 角色最想要什么 | 分表层（观众可见）+深层（角色自己未必察觉） |
| **雷点** | 触碰即爆发的禁忌 | 需具体、可触发剧情冲突，忌模糊表述 |
| **反差** | A面（对外）vs B面（真实） | 反差越大角色越立体，B面需在关键时刻揭露 |
| **语言标识** | 口头禅、语气词、风格 | 三句台词内能认出角色 |

### 填写模板

```
角色名：[姓名]
标签：[3秒可识别标签，如"赘婿龙主""替嫁毒妃"]

欲望表层：[看得见的追求，如"夺回公司""找出凶手"]
欲望深层：[隐藏渴望，如"被父亲认可""不再被抛弃"]

雷点：[具体触发条件，如"被说靠女人""家人被碰"]

反差A面：[对外形象，如"懦弱赘婿"]
反差B面：[真实面目，如"龙殿之主"]

语言标识：[标志性表达，如"你配吗？"每句带"呵"]
```

## 二、人物弧光轨迹图

弧光结构：**起点（缺陷态）→中点（裂变点）→终点（完成态）**

| 阶段 | 功能 | 短剧写法 |
|------|------|----------|
| **起点** | 建立缺陷与渴望 | 第1集开场即暴露最大缺陷，同步埋入深层欲望 |
| **中点** | 重大转变/觉醒 | 第10集附近必须有一个性格拐点，不可拖延 |
| **终点** | 成长完成/使命达成 | 大结局时角色状态与开场形成鲜明对比 |

**短剧铁律：极速变化**
- 每10集一个性格转折点
- 每3集至少一次情绪强度升级
- 转折点必须有具体事件驱动，忌内心独白式转变

## 三、三角关系网设计

核心结构：**主角 → 盟友 → 反派**（三点互相关联）

每条关系线必须同时包含三要素：

| 要素 | 作用 |
|------|------|
| **利益绑定** | 让两人不得不产生交集 |
| **情感冲突** | 制造张力与看点 |
| **信息差** | 一方知道另一方不知道的，驱动反转 |

**关系线检查公式**：`(主角,盟友) = 利益绑定 + 情感冲突 + 信息差`

## 四、角色一致性检查表

每集完稿后逐项核对：

- [ ] **台词检查**：是否符合语言标识？换个人说这句还成立吗？
- [ ] **欲望检查**：行为是否指向表层或深层欲望？
- [ ] **雷点检查**：触发场景是否合理？反应强度是否匹配？
- [ ] **情绪检查**：情绪反应与处境是否逻辑自洽？
- [ ] **人设边界**：是否出现了四件套中未定义的"新性格"？

> 红线：禁止为服务剧情临时给角色添加未预设的性格特征。

## 五、爽点密度曲线

### 分频策略

| 类型 | 核心爽感来源 | 爽点公式 |
|------|-------------|----------|
| **男频** | 身份反转 + 实力碾压 | 被低估 → 揭露身份 → 全场震惊 |
| **女频** | 情感逆袭 + 男主独宠 | 被欺负 → 男主护短 → 众人艳羡 |

### 密度要求

- **频率**：每5集至少2个爽点事件
- **强度**：波峰波谷交替上升，后一个波峰必须高于前一个
- **节奏**：爽 → 压 → 更爽 → 大压 → 最爽（finale 释放）

## 六、打脸四步法标准

| 步骤 | 内容 | 时长控制 | 关键要点 |
|------|------|----------|----------|
| **1.羞辱** | 反派嚣张挑衅，主角被看低 | 1集内完成 | 反派态度越嚣张，后续爽感越强 |
| **2.隐忍** | 主角积蓄力量，观众积累期待 | 2-3集 | **核心步骤**，太短则爽感不足，太长则流失 |
| **3.反击** | 主角以压倒性优势回击 | 1集内完成 | 反击必须碾压式，不能势均力敌 |
| **4.释放** | 反派震惊 + 众人态度转变 | 集末收尾 | 多视角展示反应，最大化爽感 |

> 隐忍期是成败关键：需给观众"再忍一集就能打脸"的明确预期。

## 七、反转类型库

| 类型 | 定义 | 执行要点 |
|------|------|----------|
| **身份反转** | 隐藏/假身份揭露 | 前期埋3个以上身份线索，揭露时信息密度要炸 |
| **情感反转** | 爱恨立场瞬间转换 | 转换必须有情感依据，忌生硬反转 |
| **命运反转** | 绝境中突然翻盘 | 翻盘手段必须在前面有暗示 |
| **认知反转** | 真相完全颠倒 | 新真相需覆盖旧认知，形成"原来如此"震撼 |

**反转铁律**：每个反转必须在前面有至少1处伏笔，禁止无铺垫硬转。

## 八、情绪波峰波谷节奏控制

### 情绪曲线公式
```
高 → 低 → 更高 → 低 → 最高（大结局）
```

### 三条铁律

1. **禁止连续3集同方向情绪**：不能连虐3集（观众弃剧），不能连爽3集（爽感麻木），必须在第3集前插入反向情绪
2. **每集至少1个情绪转折点**：可以是微转折（语气变化、眼神变化），也可以是大转折（身份揭露、关系破裂）
3. **情绪锚点设定**：
   - 第1集：强钩子情绪（震惊/悬念/冲突）
   - 第10集：第一个情绪波峰
   - 第20集：情绪谷底（最大危机）
   - 第30集：第二个波峰（高于第一个）
   - finale：最高波峰（全剧释放）

> **使用方式**：角色设计阶段用一、二、三完成定义；完稿阶段用四、五、六、七、八逐项检验。
