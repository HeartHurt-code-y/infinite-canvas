# 短剧剧本格式规范参考手册

> screenplay-master SKILL 参考文件，用于指导 AI Agent 格式化中文短剧剧本。

## 一、单集剧本模板结构

```markdown
# 《剧名》第X集剧本

## 本集信息
- 核心冲突：[一句话概括本集核心矛盾]
- 钩子类型：[身份反转/误会揭穿/致命危机/情感极限/秘密曝光/打脸预备]
- 反转类型：[身份/立场/真相/感情/命运/无]
- 情绪标签：[虐/甜/燃/泪/惊/气愤，选1-2个]
- 场景数：[1-3个，超过3个需注明原因]
- 预估字数：[XXX字]
- 预估时长：[X分XX秒]
- 主要角色：[列出本集出场角色名]

## 场景1：[地点]/[子地点]-[时段]

【环境音效/氛围描写/人物着装等调度说明】

△ **角色A**（情绪/动作细节）：台词正文第一句。
△ **角色B**（情绪/动作细节）：台词正文回应。

[镜头类型]：[画面呈现描述，独立成段]

## 场景2：[地点]/[子地点]-[时段]
...

## 本集悬念结尾

[描述下集钩子，1-3句话，制造"必须看下一集"的期待感]
```

### 场景要素格式速查

| 要素 | 格式 | 示例 |
|------|------|------|
| 场景编号 | `## 场景N` | `## 场景1` |
| 地点/时段 | 编号后紧跟，`-`连接 | `总裁办公室/落地窗前-夜` |
| 调度说明 | `【】` 包裹 | 【暴雨声，窗外电闪雷鸣】 |
| 角色台词 | `**角色名**（情绪）：台词` | **苏婉婉**（冷笑）：你以为这样就能威胁我？ |
| 台词标记 | `△` 前缀，接角色台词 | △ **角色名**（情绪）：台词正文 |
| 特效标注 | `【特效：…】` 独立成行 | 【特效：拳峰前方空气被压缩成透明碟状】 |

### 镜头类型速查

| 标记 | 含义 | 使用场景 |
|------|------|----------|
| 特写 | 面部/细节放大 | 情绪爆发、关键道具 |
| 近景 | 胸部以上 | 对话戏、微表情 |
| 中景 | 膝盖以上 | 双人对话、动作互动 |
| 全景 | 完整人物+环境 | 入场、关系建立 |
| 远景 | 大环境 | 氛围渲染、转场 |
| 空镜 | 无人物画面 | 时间流逝、情绪留白 |
| 快速剪辑 | 多画面快速切换 | 回忆闪回、信息轰炸 |
| 慢动作 | 降格镜头 | 关键动作、情感瞬间 |
| 俯拍 | 从上方拍摄 | 压迫感、全局展示 |
| 仰拍 | 从下方拍摄 | 威严、气势、威胁感 |
| 手持晃动 | 模拟手持摄影 | 紧张、纪实、混乱场面 |
| 推 | 镜头前推 | 情绪升级、聚焦关键 |
| 拉 | 镜头后拉 | 揭示环境、疏离感 |

**方括号 `[ ]` 内禁止词汇（黑名单）**：【特效】【切至】【切换】【转场】【淡入】【淡出】【叠化】【划入】【划出】【后期】【字幕】【配乐】【音效】。这些属于剪辑指令或后期制作标注，**绝对不可**出现在 `[镜头类型]` 位置。如确实需要标注特效需求，写在画面描述文字中而非方括号内。

### 悬念结尾公式
**新信息/反转揭示 + 主角处境急转 + 观众想知道结果**

## 二、Fountain 格式说明（可选）

当用户明确要求时使用，默认采用 Markdown 格式。

| Fountain 标记 | 含义 | 示例 |
|---------------|------|------|
| `INT./EXT. 地点 - 时段` | 场景标题 | `INT. 咖啡厅 - 日` |
| 大写居中 + 空行 | 角色名 | `\n林墨\n` |
| 角色名下一行 | 对话内容 | `这不可能是真的。` |
| `(情绪描述)` | 括号标注 | `(颤抖着声音)` |
| `> 过渡指令` | 镜头过渡 | `> 切至:` |
| `[[注释]]` | 制作注释 | `[[此处需补拍反应镜头]]` |
| `Title:` / `Author:` | 标题/署名 | `Title: 《剧名》` |

## 三、场次编号规则

### 编号体系

| 层级 | 格式 | 示例 |
|------|------|------|
| 集编号 | 第X集 | 第5集 |
| 集副标题 | `[主题]` | `[身份揭穿]` |
| 场景编号 | 场景N | 场景2 |
| 完整标题 | 《剧名》第X集 - [副标题] | 《闪婚总裁》第5集 - [身份揭穿] |

### 编号规范
- 集内场景从 **1** 开始顺序递增，不可跳号
- 同一地点不同时段视为不同场景，分别编号
- 新增场景接续现有最大编号，删除后不重新编号

## 四、制作可行性检查项

### 场景与场地
- [ ] 所有场景在实际拍摄地点可实现
- [ ] 转场逻辑合理，不跨越不合理地理距离

### 人员与预算
- [ ] 单集主要出场演员 <= 5 人
- [ ] 群演人数、服化道需求明确标注

### 技术与特效
- [ ] 特殊效果/后期特效需求写在画面描述文字中，方括号内只写景别
- [ ] 打斗场景的【特效：…】标注格式正确，三段式完整
- [ ] 特效风格与角色背景一致
- [ ] 夜景戏数量合理

### 字数统计规则
- [ ] 单集总字数 = 所有角色台词字数 + 调度说明字数 + 镜头指示字数
- [ ] **【特效：…】标注内容完全不计入总字数**，可充分展开描写

## 五、格式快速参考卡片

```
场景头：     ## 场景N：地点/子地点-时段
调度说明：   【音效/氛围/服化道】
台词标记：   △ **角色名**（情绪/动作）：台词正文。
镜头指示：   [景别]：[画面描述]
特效标注：   【特效：…】独立成行，三段式，不计入总字数
悬念结尾：   ## 本集悬念结尾 + 下集钩子描述
```
