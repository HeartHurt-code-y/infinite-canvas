# 竖屏短剧：场景与台词写作参考手册

> 版本：v1.0 | 用途：AI Agent 编写分镜与台词时的核心引用文档

## 一、竖屏 9:16 构图要点

竖屏画面宽度仅为横屏的 56%，构图逻辑完全不同：

- **人物占比 >= 60%**：头部到胸部占画面中央主体，不可被裁切。
- **景别限制**：避免全景（信息过载），优先中景/近景/特写交替。
- **背景极简化**：虚化处理，仅用 1-2 个视觉锚点交代环境。
- **三分法**：上区（20%）放信息/氛围；中区（60%）放人物表情；下区（20%）放手部动作或道具。
- **视线引导**：人物视线朝向画面留白较多的一侧，制造呼吸感。
- **安全区**：关键表情和字幕避开顶部 10% 和底部 15%（防遮挡）。

## 二、运镜指示词汇库

| 符号 | 运镜 | 画面呈现描述 |
|------|------|--------------|
| `推` | 推镜头 | 景别由远及近，强调情绪升级 |
| `拉` | 拉镜头 | 景别由近及远，揭示环境或孤立人物 |
| `摇` | 摇镜头 | 机位固定，镜头水平或垂直转动 |
| `移` | 移镜头 | 机位平行移动，跟随角色走位 |
| `跟` | 跟镜头 | 镜头紧随角色运动 |
| `升` | 升镜头 | 机位垂直上升，制造俯瞰或抽离感 |
| `降` | 降镜头 | 机位垂直下降，用于出场亮相或压迫感 |
| `环` | 环绕镜头 | 360° 围绕主体旋转，用于情绪高潮 |

> **镜头标注格式**：`[运镜]：[起始景别] → [终止景别]，[情绪/动作描述]`

## 三、微表情动作库

每种情绪提供 3 组「面部 + 肢体」组合：

| 情绪 | 面部微表情 | 肢体动作 |
|------|-----------|---------|
| **愤怒** | 咬肌凸起、瞳孔收缩、嘴角单侧抽动 | 指关节发白握拳、拇指按压桌面、颈部青筋微凸 |
| **悲伤** | 眼眶泛红但无泪、嘴角下压成一条线、眼神失焦 | 手指绞动衣角、肩膀微缩、头微低下巴轻颤 |
| **得意** | 嘴角单侧微扬、眼神从对方脸上扫过、缓慢眨眼 | 手指轻敲桌面、整理袖口、身体后仰 |
| **紧张** | 眼神快速闪烁、频繁舔嘴唇、眉毛微挑 | 手指绞动、脚尖点地、喉结滚动 |
| **惊喜** | 瞳孔瞬间放大、嘴角上扬、眉毛抬高 | 身体前倾、双手悬空、小步后退 |
| **恐惧** | 眼白增多、嘴唇微张、眉毛八字 | 双手护胸、脚尖朝向逃跑方向、肩膀耸起 |
| **轻蔑** | 单侧嘴角上扬、眼神从下到上扫视、缓慢闭眼睁开 | 鼻腔轻哼、转身侧对、手指弹开灰尘 |
| **爱慕** | 眼神柔和瞳孔放大、嘴角自然微翘、目光在唇眼间移动 | 身体前倾、手指轻触锁骨、脚尖指向对方 |

> **使用规则**：每次只选 1 面部 + 1 肢体，组合使用，不可全写。

## 四、场景最小化原则

- **单集场景数 <= 3**，超过则拆分集数。
- **每个场景必须通过一个测试**：删除它，剧情是否断裂？人物是否扁平？不通过则删除。
- **场景转换三要素**：时间（天色/时钟）、空间（门/走廊/车）、情绪（沉默/音乐/呼吸）。
- **一景多功能**：同一空间通过灯光/道具/人物站位变化承载多场戏。

## 五、分镜脚本标准格式

```markdown
## 场景N：[地点]/[子地点]-[时段]

【环境音效/氛围描写，1-2句】

△ **角色A**（情绪/动作）：台词正文（不超过15字）
△ **角色B**（情绪/动作）：台词正文

[景别]：[画面描述，含景别变化]
```

**格式规则**：
- 每句台词后紧跟运镜标注，不另起大段。
- 情绪/动作标注在括号内，用 `/` 分隔多元素。
- 环境音效用 `【】` 包裹，置于场景开头。
- 潜台词用 `〔〕` 在台词后标注实际含义。

## 六、短句控制（8-15 字/句）

- **核心规则**：单句台词 <= 15 字，理想区间 8-12 字。
- **长对白拆分**：超过 15 字必须拆为两句，中间插入对方反应或动作。
- **轮替原则**：A 说一句 → B 反应 → A 再补一句，禁止一人连续说超过 2 句。
- **允许例外**：① 情感爆发独白（需提前铺垫 3 句以上短句积累情绪）② 重要宣言（需配合推镜头至特写）

## 七、潜台词写作技巧

### 核心方法
- **表面说 A，实际意思 B**：用具体事物代替抽象情感。
- **沉默替代回答**：用动作停顿或移开视线表达拒绝/心虚。
- **反问替代陈述**：把情绪包装成问题，避免直白。

### 示例对比

| 直白版 | 潜台词版 |
|--------|---------|
| "我很伤心。" | "（低头，手指绞动）这灯，太亮了。" |
| "我不会原谅你。" | "（转身整理袖口）你回去吧，外面冷。" |
| "我爱你。" | "（停顿两秒，喉结滚动）你吃了吗？" |

> **检测标准**：如果删除括号内的动作描写，台词意思完全相反或模糊 → 潜台词合格。

## 八、金句 / 方言 / 反套路模板

### 金句公式
```
金句 = 反差设定 + 情绪极端 + 短句押韵
```

### 方言使用

| 方言 | 适用角色 | 示例词汇 |
|------|---------|----------|
| 东北话 | 豪爽/喜剧角色 | "整事儿"、"必须的"、"咋地" |
| 四川话 | 市井/精明角色 | "要得"、"搞啥子"、"巴适" |
| 粤语 | 商界/江湖角色 | "冇问题"、"抵死"、"讲数" |
| 北京话 | 老炮儿/体制内 | "甭"、"今儿个"、"凑合" |

> **用量控制**：每集方言词汇 <= 3 个，过多影响全国观众理解。

## 九、对话节奏

### 标准节奏链
```
短句铺垫 → 反问施压 → 留白（2-3秒停顿/动作） → 致命一击
```

### 速度变化图谱

| 阶段 | 速度 | 句长 | 景别 | 功能 |
|------|------|------|------|------|
| 铺垫 | 快 | 8-10 字 | 中景→近景 | 信息交换 |
| 转折 | 慢 | 停顿/沉默 | 特写 | 情感沉淀 |
| 爆发 | 极快 | 4-8 字 | 特写交替 | 冲突顶点 |
| 收尾 | 慢 | 1 句留白 | 特写定格 | 情绪余韵 |

## 十、禁止模式清单

- [ ] 禁止连续 3 句超过 15 字
- [ ] 禁止废话开头 — "你知道吗"/"其实"/"说实话"等
- [ ] 禁止双长对白 — 两个角色不可同时连续说长句
- [ ] 禁止解释性对白 — 不对白重复观众已通过画面知道的剧情
- [ ] 禁止 OOC 台词 — 必须符合人物卡设定
- [ ] 禁止标签化情绪 — 不用"愤怒地说"，改用微表情动作替代
- [ ] 禁止静态对话 — 每 3 句台词间必须至少 1 个动作或运镜变化
- [ ] 禁止说教台词 — 道理藏进冲突和选择里
- [ ] 禁止过度方言 — 单集同一方言词汇不超过 3 处
- [ ] 禁止无意义寒暄 — 每句台词必须推动剧情、揭示人物、或制造冲突

> **写作流程**：角色卡确认 → 场景清单（<=3）→ 分镜粗写 → 短句压缩 → 潜台词替换 → 微表情植入 → 禁止清单自检 → 输出

## 十一、特效描写规范（打斗场景激活）

当剧本出现打斗/动作场景时：

- 格式：`【特效：XXXXX】`（独立成行，不写在 `[ ]` 方括号内）
- 三段式结构：行动段（蓄力/位移/出招）→ 攻击段（命中瞬间）→ 受击段（受力点反应）
- **字数完全不计入单集总字数限制**，可充分展开物理细节
- 特效风格必须与角色背景一致（详见 vfx-fight-scene.md）

## 十二、景别规范（强制）

### 方括号 `[ ]` 内合法词汇（白名单）

| 类别 | 合法词汇 |
|------|----------|
| 基础景别 | 特写、近景、中景、全景、远景、空镜 |
| 角度 | 俯拍、仰拍 |
| 运镜 | 推、拉、手持晃动 |
| 特殊速率 | 快速剪辑、慢动作 |

### 方括号 `[ ]` 内禁止词汇（黑名单）

以下词汇**绝对不可**出现在 `[ ]` 内：
【特效】【切至】【切换】【转场】【淡入】【淡出】【叠化】【划入】【划出】【硬切】【交叉淡化】【后期】【字幕】【配乐】【音效】【CG】【合成】
