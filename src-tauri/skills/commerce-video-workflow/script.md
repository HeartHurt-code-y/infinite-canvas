# 带货剧情编剧方法

把已选创意写成完整可拍摄脚本。保持研究底稿的产品事实和创意阶段的人物关系、主冲突、产品介入机制，不另造功效与剧情事实。

## 时间与表演

- 输出总时长和按顺序编号的 SEG-01 等时间段。每段时间码连续、不重叠，总时长与制作要求和实际模型能力相容。
- 每段列画面与具体动作、对白或旁白原句、声音、产品作用和事实依据。全句台词必须直接出现在交付正文，不用“此处补对白”等占位符。
- 开头 1–3 秒即出现悬念或冲突。中段每 5–10 秒出现新信息、关系改变或动作结果，避免平铺直叙。
- 保留至少两次改变观众判断的有效转折。升级依靠因果与行动，而非单纯喊叫或无意义的误会。
- 产品首次出现前有需求或伏笔；首次出现承担剧情动作，不先摆成正面硬广告。
- 卖点通过可见动作和已知结果演出来，再以短台词点明。演员能自然说完全部对白，超时优先删字，不要求机械加速或不可能的口型精度。
- 结尾回扣开头的动作、悬念或台词，并让 CTA 与角色结果连贯。未知品牌或优惠不补造，使用中性产品称谓和可核实的 CTA。

## 自检与自动修订

逐项检查总时长、前三秒钩子、两次转折、产品伏笔、产品推动性、结尾回扣、完整台词、事实依据和使用逻辑。删除产品后故事仍成立、卖点全靠口播、人物目的不清、动作无法连续执行或需要未知事实才能成立时，先修订再交付。

保留人物身份、服装、场景布局和产品外观的连续性锚点，标出后续分镜必须遵守的关键动作、产品特写及不能裁掉的台词。完整脚本、自检结论与采用依据均写入正文。完成后自动进入分镜；仅无法可靠决定的事实冲突才请求决定。
