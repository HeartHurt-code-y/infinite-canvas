# 剧情创意方法

只使用权威研究底稿中的可用事实，生成三版机制不同的剧情创意并自动选出一版进入制作。不能通过更换姓名或地点伪装成不同创意，也不重复发菜单让用户选择。

## 类型选择

用户指定的剧情类型优先；智能推荐根据产品、目标人群、可视化卖点与可生成性决定。可选机制包括现代闺蜜反差、古装宫斗、古装宅斗、穿越反转、魔幻漫剧、国风仙侠、职场救场、情侣误会、家庭轻喜剧、宿舍日常、悬疑揭秘、挑战测评、身份反转、赛博未来、无对白视觉流。

美妆适合造型反差、身份反转；家清适合家庭冲突、揭秘、现场挑战；食品适合宿舍、家庭与视觉展示；数码工具适合职场救场、效率挑战；服饰首饰适合关系与身份变化。创意中的虚构能力只能作为清楚的故事设定，不能把真实产品包装成不存在的超自然功效。未实际检索时不宣称某种类型是当前平台趋势。

## 每版必须闭合的剧情链

1. 前 1–3 秒立即用异常行为、迫近危机、关系冲突、损失风险、身份悬念、反常台词或视觉反差抓住观众。禁止人物介绍、无信息空镜或直接产品讲解开场。
2. 钩子 → 冲突建立 → 第一次升级 → 产品伏笔或需求 → 第二次转折 → 产品行动介入 → 结果或反转 → 回扣式 CTA。
3. 至少两次有效转折。转折要改变对人物、问题或结果的判断，不能只有尖叫、摔东西和无意义误会。
4. 产品通过场景布置、人物习惯、赠予、任务或证据提前出现；角色主动拿取、寻找、递出或使用，不能突然从画面外变出来。
5. 产品介入必须改变行动结果：阻止损失、揭开误会、推进关系、完成任务或促成新决定。做删除测试：删去产品仍能完整成立的故事必须重写。
6. 可证实卖点由行动和可见结果呈现，再补一句简短台词。不得堆叠未经证实的对比、效果与购买承诺。
7. 结尾回扣开头的动作、台词、误会或悬念，自然转入 CTA，不硬接无关广告。

## 完整交付

A、B、C 各自给出一句话故事、前 3 秒钩子、人物关系、主冲突、两次转折、产品伏笔、介入动作、改变的剧情结果、结尾回扣、CTA、建议时长、事实依据、风险和评分。

评分至少覆盖钩子强度、因果闭合、产品推动性、事实可靠性、可视化证明、台词时长和模型可实现性。自动选出综合最合适的一版，说明选中版本及理由，并在后续只沿用该版。已有用户明确选择时遵守该选择。只有用户要求相互冲突或事实底稿有不能回避的关键缺口时才请求一个决定；普通审美选择由你完成。
