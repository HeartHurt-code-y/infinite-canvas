# 带货分镜与视频提示词方法

只依据当前有效脚本拆镜头并组织视频生成单元。提示词逐句、逐动作关联原脚本，不能新增产品事实、改变人物关系或重写已确定对白。

## 镜头与单元

1. 先列 S01 等逐镜表：关联 SEG 段、时长、景别、机位、运动、人物动作、产品位置、声音、对白和连续性。
2. 再按动作连续性组合成 V-01 等生成单元。单元时长、画幅、参考图数量与输入类型必须使用请求明确给出的项目模型能力；不得沿用某个平台固定上限。能力限制较小时拆成更短的连续单元，不能裁断关键台词。
3. 每个生成单元包含关联 SEG 与镜头 ID、引用的稳定人物/场景/产品/道具资产 ID、起始状态、结束状态、分秒时间轴、完整对白、音效、镜头运动、连续性和禁止项。
4. 上一单元结束与下一单元起始在人物站位、持物手、服装、产品朝向、空间和情绪上衔接；必要时明确承接动作。
5. 真实产品原图由程序注入 product-01 等 ID，成片模式每个视频单元必须引用至少一个实际提供的产品图 ID。文档模式允许只有文字资料，不要求补充原图或选择媒体模型；无图时不得编造 product- 引用，时长按合理的剧本计划安排。人物、场景、虚构道具先在正文规划稳定 ID 与外观，下阶段必须按同一 ID 产出资产。不能引用未提供的产品图，不能让文字资产 ID 替代实际图片引用；进入媒体生成前全部引用必须闭合。

## 提示词结构

每段都明确：生成时长与画幅、风格、引用资产角色、起始状态、逐秒动作/对白、光线/镜头、环境音与音乐、结束状态、连续性锚点、不得新增人物/产品事实/台词等约束。对白保留原文、标注说话者，不输出省略号替代整句。

质量描述是目标而非能力承诺。不要硬写未选模型不支持的分辨率、固定品牌参数或绝对精度保证。未知包装文字、标识与功效均不得重造。

交付逐镜摘要及全部可直接生成的视频提示词，并提供完整引用闭合检查。普通镜头安排与单元拆分自动完成，不要求用户逐镜审批。
