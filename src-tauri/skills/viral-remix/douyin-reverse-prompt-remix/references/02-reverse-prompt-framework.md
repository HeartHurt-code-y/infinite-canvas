# 反推提示词 · 十维提取法

## 核心原则

先真看画面，再下笔。必须覆盖开头、四分之一、中段、四分之三、结尾；联系表已经包含全部抽帧时，应逐格观察。绝不允许只凭标题或话题标签编造画面内容。

## 十维清单

| #   | 维度      | 观察内容                                                         |
| --- | --------- | ---------------------------------------------------------------- |
| 1   | 主体      | 人物、动物或物体的数量、年龄、性别、姿态与动作状态               |
| 2   | 造型/道具 | 服装分件、配色、材质、配饰、手持物与手持关系                     |
| 3   | 场景      | 地点、环境、前中后景、材质与年代感                               |
| 4   | 光线      | 光源方向、软硬、色温、时段与阴影变化                             |
| 5   | 色调      | 主色、辅助色、强调色、饱和度、对比度与影调                       |
| 6   | 运镜      | 推、拉、摇、移、跟、升降、环绕及速度；不确定时基于相邻帧保守判断 |
| 7   | 景别/构图 | 远景、全景、中景、近景、特写，主体位置与构图法则                 |
| 8   | 情绪氛围  | 3～5 个有画面证据的观感关键词                                    |
| 9   | 内容类型  | 旅拍、Vlog、剧情、广告、教程、卡点等                             |
| 10  | 爆点钩子  | 前 3 秒靠视觉奇观、悬念、反差、情绪或信息增量中的什么留人        |

## 中文通用提示词结构

```text
[主体与逐件造型]，[正在做的动作]，位于[分层场景描述]。
[光线方向与软硬]，[主/辅/强调色与影调]，[材质细节]。
[摄影机运动]，[景别与构图]，[动作节奏与时间码]。
整体氛围：[情绪关键词]。[画幅]构图，电影质感。
```

## 分镜规则

- 超过 10 秒必须拆分镜头；每个分镜给独立、可直接粘贴的提示词。
- 时间段按动作节拍划分，不平均切段。
- 每段同时写人物/物体动作、摄影机行为、构图变化、光影与声音状态。
- 竖屏素材明确写 `9:16 竖屏构图`。
- 静态联系表无法证明的对白、音乐、镜头速度或帧间动作必须标记待确认。

## 常见错误

1. 凭标题脑补画面。
2. 用“镜头感强”等空泛词代替标准运镜术语。
3. 堆叠互相冲突的风格词。
4. 忽略画幅、主体动作或最后一秒的定格状态。
5. 把联系表时间码、播放器控件或节点界面当作原视频内容。
