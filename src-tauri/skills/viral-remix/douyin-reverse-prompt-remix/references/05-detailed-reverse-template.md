# 详细反推模板（短视频深度拆解）

## 何时使用

满足任一条件必须使用：视频不超过 30 秒、单镜头/一镜到底，或用户要求详细、完整、逐秒、保持一致、复刻或二创。最后 5 秒必须单独核对。

## 四段式输出

### 一、视频结构摘要

写明总时长、画幅、类型、主要人物、场景数、镜头数与核心事件。分别描述开端、发展、转折/高潮、结尾；情绪转折必须指向具体动作、构图或光影证据。

### 二、全片设定

1. 角色固定锚点：性别/体型、上衣、下装、鞋、配饰、头发/帽子、道具、气质与动作风格。
2. 场景固定锚点：地点、前景、中景、背景、光源方向、阴影与人物活动范围。
3. 视觉风格锚点：写实/动画、材质、光影、主色/辅助色/强调色、景深与动作呈现。
4. 声音锚点：对白、旁白、字幕、标题、标识、音乐、环境声与动作音效；联系表无法证明的部分标记待听觉确认。

### 三、分场设定

```text
【场景0X：场景名｜00:00.0—00:XX.X｜总时长XX.X秒】
地点为……出场人物为……起始状态为……核心事件为……
情绪作用为……进入方式为……与下一场景通过……连接/视频在此结束。
```

时间码使用 `00:00.0—00:18.3` 格式。

### 四、分镜生成稿

```text
【镜头0X｜00:00.0—00:18.3｜18.3秒】
18.3秒，9:16竖屏，[风格与情绪]。[完整人物描述]在[场景描述]。

0.0—12.0秒：[动作 + 摄影机运动 + 构图位置 + 光影细节 + 声音]。
12.0—14.0秒：[动作推进 + 摄影机变化 + 尺度关系 + 声音变化]。
14.0—16.0秒：[关键转折动作 + 摄影机停止/变化 + 音效]。
16.0—18.3秒：[收尾定格动作 + 摄影机微调 + 光线 + 音乐状态 + 最终画面]。

全程保持同一人物面容、发型、服装、道具形状、手持关系和场景方位，
不新增人物、道具、文字、标识或水印，人体结构自然，动作连续无跳变。
```

## 硬性规则

- 按动作节拍分段，不能按等分时长机械切割。
- 每段只承载一个清晰动作阶段，并写清摄影机行为与声音状态。
- 结尾写最终定格画面；最后 5 秒加密帧中的停下、转身、抬手、合十、回眸等动作必须逐段核对。
- 服饰逐件写，不用“古装”“废土风”等笼统词代替。
- 固定连续性约束句不可省略。
