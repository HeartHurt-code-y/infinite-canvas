# 爆款二创 Playbook

## 爆点诊断五问

| 问题                   | 观察点                                     |
| ---------------------- | ------------------------------------------ |
| 前 3 秒靠什么留人？    | 视觉奇观、悬念、反差、情绪或信息增量       |
| 核心情绪是什么？       | 爽、治愈、震撼、孤独、燃、猎奇、共鸣等     |
| 强记忆点是什么？       | 一个强记忆点优先于多个弱记忆点             |
| 可复制的部分是什么？   | 场景公式、运镜公式、节奏公式、叙事公式     |
| 不可复制的部分是什么？ | 真人 IP、版权音乐、特定地点/事件、品牌资产 |

只复用可复制的结构；不可复制部分必须替换。

## 三条二创路线

### 路线 A · 换皮

保留运镜、节奏、构图与叙事结构，替换主体、场景、造型和色调中的至少两个维度。

### 路线 B · 换视角

保留核心场景或视觉风格，替换主角身份、观察位置、时间线或情绪走向中的至少两个维度。

### 路线 C · 换叙事

保留合法可用的画面公式，替换开头钩子、事件顺序、信息揭示方式和结尾中的至少两个维度。

## 每条路线输出格式

```markdown
### 路线 X · 一句话概念

**保留**：原视频中被验证的结构公式
**替换**：至少两个明确维度
**提示词**：可直接复制的完整提示词
**预期效果**：开头、过程与结尾的观感
**风险**：可能失败的生成点与版权/同质化风险
```

## 避坑与质量门禁

- 不复用原 BGM、真人肖像、品牌 Logo 或平台水印。
- 不做像素级搬运；每条路线至少替换两个维度。
- 前 3 秒有明确钩子，提示词无需二次补全即可运行。
- 三条路线不能只是换同义词，必须在结构或视觉变量上有实质差异。
- 高赞不等于自然爆款；缺少互动数据时，把爆点判断表述为“基于画面的推断”。
