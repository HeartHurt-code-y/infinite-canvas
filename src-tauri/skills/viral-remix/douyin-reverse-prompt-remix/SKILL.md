# 爆款视频复刻 · 纯复刻适配版

本技能由 `douyin-reverse-prompt` V1.1 裁剪而来，只保留视频视觉复刻能力。

## 运行边界

- 输入是应用已经准备好的、带精确时间码的视频联系表图片。
- 不下载视频，不解析网络链接，不调用浏览器、yt-dlp、ffmpeg 或下载脚本。
- 不创建案例文件，不写案例库，不声称执行任何本地脚本。
- 必须真实观察全部联系表，禁止根据标题、文件名或用户描述脑补画面。

## 抽帧合同

应用侧遵循原 V1.1 规则生成联系表：

- 时长不超过 30 秒：全片每 0.5 秒一帧。
- 时长超过 30 秒：全片约 12 帧均分。
- 任何时长：最后 5 秒额外按每秒 6 帧加密；这些帧会明确标记为“结尾加密”。
- 每一格都带时间码。输出中的动作时间必须引用这些证据，不能伪造帧间细节。

## 标准流程

1. 按联系表编号和时间码逐格观察，先建立全片印象，再单独核对全部结尾加密帧。
2. 按 `references/02-reverse-prompt-framework.md` 完成十维分析。
3. 短视频、单镜头或用户要求复刻时，按 `references/05-detailed-reverse-template.md` 输出四段式详细复刻稿。
4. 按 `references/03-viral-remix-playbook.md` 完成爆点诊断与三条二创路线。
5. 用 `references/learned-patterns.md` 作为低权重先验；它不能覆盖本次联系表中的直接视觉证据。

## 输出合同

只输出一份完整 Markdown 文档，至少包含：

1. 视频结构摘要：时长、画幅、场景/镜头数、四阶段结构、情绪转折与视觉证据。
2. 十维视觉分析：主体、造型/道具、场景、光线、色调、运镜、景别/构图、情绪、类型、爆点钩子。
3. 全片设定：角色、场景、视觉风格、声音四个固定锚点。
4. 分场设定与逐镜生成稿：按动作节拍分段，每段包含摄影机行为与声音状态。
5. 结尾精确动作：逐段写清最后 5 秒发生了什么，并给出最终定格画面。
6. 爆点诊断与三条路线：换皮、换视角、换叙事；每条至少替换两个维度并给出可直接粘贴的完整提示词。
7. 风险与自检：版权音乐、真人肖像、品牌/水印、同质化与过度还原。

逐镜稿末尾必须包含：

> 全程保持同一人物面容、发型、服装、道具形状、手持关系和场景方位，不新增人物、道具、文字、标识或水印，人体结构自然，动作连续无跳变。

若声音无法从静态联系表可靠判断，明确标记“声音待听觉确认”，不要假装听过原视频。
