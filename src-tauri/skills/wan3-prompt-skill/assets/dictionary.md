## 4. 声音取词

- **人声六要素**（缺一项模型就自由发挥一项）：`"内容"` + 情绪 + 语调 + 语速 + 音色 + 口音。类目：单人说话、多人对话、音色指定、方言（地道京腔）、唱歌。
- **音效三段**：音源材质 + 行为 + 环境音。类目：脚步声、敲门声、物体坠地、撞击声、火焰燃烧、8-bit 游戏音效、电子故障声、ASMR、动物叫声、键盘声；环境音分自然 / 城市 / 特定空间。
- **BGM 两段**：配乐 + 风格（情绪音乐 / 卡点音乐 / 轻音乐）。速度、乐器、情绪曲线属扩展写法，官方未验证。
- **拟声词对照**（音效跟着动作节点写）：物体/色块滑入「嗖」whoosh、按键与数字跳动「咔嗒」、关键信息弹出清脆「叮」、指腹摩擦包装「沙沙」、气泡破裂「嘶嘶」、玻璃小球落地「砰」、液体注入低沉「咕咚」。
- **旁白写法**：语言 + 语气 + 语速 + 重音位置，如「英文，明快自信，语速约每秒 2.5 个词，关键数字处微微加重」。
