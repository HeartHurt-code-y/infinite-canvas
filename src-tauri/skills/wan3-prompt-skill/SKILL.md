## §0 官方锚点（必读，最高优先级）

### 0.1 模型与模式

- **模型名（固定）**：`wan3.0-video`。
- **两种模式**：
  - **全能参考模式（All-in-One）**：自由输入文本/图片/视频/音频/文件/网页，做参考生成与视频编辑，覆盖绝大多数创作任务。**本技能默认与首选路径。**
  - **首尾帧模式**：输入首帧 `first_frame` 与/或尾帧 `last_frame`，严格遵循首尾帧生成，适合需要精确控制起止画面的场景。
- **原生 30 秒**：单次最长生成 30 秒；支持**智能时长**（duration 传 `-1`，由模型推荐）与**智能比例**（`ratio=adaptive`）。

### 0.2 这些是 API 参数，不写进提示词正文

| 参数 | 取值（默认） | 说明 |
|---|---|---|
| `resolution` | 480P / 720P / **1080P** | 清晰度档位 |
| `ratio` | **adaptive**（默认）/ 16:9 / 9:16 / 4:3 / 3:4 / 1:1 | 画幅；首尾帧模式自动用首帧比例 |
| `duration` | 整数 [2,30]；**-1 = 智能时长** | 无视频输入时 2–30s；有视频输入时 输入+输出 ≤30s |
| `audio` | **true**（默认，含音轨）/ false | false 则输出无音轨 |
| `seed` | [0, 2147483647] | 随机种子 |
| `prompt_extend` | **true**（默认，智能改写）/ false | 关闭后不自动扩写 |
| `watermark` | **false**（默认）/ true | 水印开关 |

> **分辨率口径校准**：官方《Wan3.0 视频创作者手册》明确列出 `480P / 720P / 1080P`，本技能据此收录；个别 API 参考页当前仅示例 `1080P`，实际可选值以你所调用端点的文档为准（默认均为 1080P）。

> 你**只优化提示词，不改这些参数，也不调整视频输出时长**。时长偏短/偏长只能靠调节奏、提语速消化（见 §3.3 节奏与语速消化）。

### 0.3 媒体输入上限与互斥（全能参考模式）

| type | 最大数量 | 时长/其他限制 |
|---|---|---|
| `reference_image` | **10 张** | JPEG/JPG/PNG/BMP/WEBP，单边 [240,8000]px，长宽比 ≤8:1，≤20MB |
| `reference_video` | **5 段** | 单段 [1,15]s，总时长 ≤15s；mp4/mov；≤100MB |
| `reference_audio` | **5 段** | 单段 [1,15]s，总时长 ≤15s；wav/mp3；≤15MB |
| `file` | **1 个** | docx/doc/xlsx/xls/pptx/ppt/pdf/txt/md（API 额外支持 key/pages/numbers），≤100MB，≤50 页 |
| `link` | **1 个** | 公网 HTTP/HTTPS；与 `file` 二选一 |
| `first_frame` | 1 张 | 严格作为第一帧；与参考类互斥 |
| `last_frame` | 1 张 | 严格作为最后一帧；与参考类互斥 |

> **关键互斥（官方硬约束）**：`reference_image / reference_video / reference_audio / file / link` 与 `first_frame / last_frame` **不能同时出现在同一个请求**。`file` 与 `link` 也互斥。首尾帧模式下不再支持参考输入。

### 0.4 提示词规模

- `prompt` 最大 **20000 字符**（每个汉字/字母占 1 字符，超出自动截断）。
- 支持中英文；在参考模式下用 `@图片N / @视频N / @音频N` 指代 media 数组中对应顺序素材。

### 0.5 文档/PPT 转视频（"万物皆视频"）

`file` 或 `link` 可承载产品 PPT、培训 deck、表格、报告等；提示词只需定**风格与方向**，不必重复文档内容。示例（官方）：上传咖啡品牌介绍文档 + "把它变成一支暖色调品牌 TVC，让人想来坐坐"。

## §1 输出纪律（最高优先级，违反即失败）

1. **你的回复只有提示词本体**，放在一个 `text` 代码块里。不写前言、不写"改了什么"、不写逐层说明、不写参数建议、不写风险提示、不写自检结论。
2. 用户**明确追问**时才补充解释；用户没问就一个字都不加。
3. 不提交生成任务、不调用生成工具，除非用户明确说"跑一下 / 生成看看"。
4. `duration`、`resolution`、`ratio`、`audio`、`seed` 是 API 参数：你只优化提示词，**不能改这些参数，也不能调整视频输出时长**；它们不写进提示词正文（时间戳除外）。时长偏短/偏长只能靠调节奏解决。

## §2 公式族（官方，按原文收录）

万相3.0 针对不同需求提供多种典型公式。四段式（§3）是这些公式的**统一工程封装**，默认覆盖绝大部分场景；下表用于理解"为什么这么写"与特殊模式（文生/首尾帧/视频编辑）。

| # | 公式 | 提示词 = | 适用 |
|---|---|---|---|
| 1 | 基础（文生） | **主体 + 场景 + 运动**（谁在哪里干什么） | 初次尝试、想象力优先 |
| 2 | 进阶（文生） | 主体 + 场景 + 运动 + **美学控制** + **风格化** + **音效** | 提质感/故事性 |
| 3 | 图生 / 首尾帧 | **运动 + 运镜** | 首帧/尾帧已定主体场景风格，只写动态 |
| 4 | 参考生视频 | **@参考对象 + 动作 + 台词** | 多素材参考生成 |
| 5 | 多镜头 | **总体描述 + 镜头序号 + 时间戳 + 分镜内容** | 连贯叙事、控结构/机位/时间 |
| 6 | 视频编辑 | **编辑对象 + 编辑行为** | 改已有视频局部 |
| 7 | 声音 | **人声 + 音效 + 背景音乐（BGM）** | 原生音频控制 |

**公式 4 拆解（官方）**：
- **@参考对象**：通过 @ 引用素材，多个按顺序排列（@图片1、@视频2、@音频1），可在不同位置多次 @ 精准控制意图。
- **动作**：参考对象的运动状态——静止、表情情绪变化、肢体动作、外力动作、位移变化。
- **台词**：说话内容，支持单主角/多主角对话；音色可参考 `@音频1`。
- **视频时序参考**：参考 `@视频1` 的运镜方式。
- **白膜参考**：输入白膜参考视频，提示词可把 3D 预览转化为正式成片。

**公式 5 拆解（官方）**：总体描述（全局叙事方向）+ 镜头序号（第N个镜头）+ 时间戳（[0-3秒]）+ 分镜内容（动作/语言/表情/姿态，可参考一般单镜头写法）。

**公式 6 拆解（官方）**：
- 元素编辑："把猫换成狗""男人戴上红色帽子""视频中男人的衣服换为 @图片 中的红色外套"。
- 全局编辑："视频修改为阴天""修改为暖色调""把视频改为图中的 2D 卡通风格"，可补"其他保持不变"。
- 时序编辑："让视频里的男人拿起水杯喝下一口"；改台词时强调"保持人物音色和语气，将女生说话内容改为：Hello World"。
- 视频延长：画面/风格/布局已定，只描述后续动态变化，如"男人继续往前走，突然摔倒"。

**其他控制（官方）**：
- 分镜控制：想强控一镜到底，写 **"生成单镜头" / "一镜到底"**；否则模型自行发挥单镜或多镜。
- 台词控制：`xx说："xxx"` 保持台词不变；不写则模型自由发挥；不要台词写 **"全片无台词"**。
- 背景音乐控制：不写则模型自行配乐；不要 BGM 写 **"无背景音乐"**。

## §3 输出结构（唯一格式：四段式）

```text
【主体】@参考指代 逐个声明素材职责 + 背景设定
【风格】美学控制词串 + 氛围 + 画风 + 色调光线 + 镜头基调
【时间线】
镜头1[0-3秒]（转场/机位/景别）+ @指代与主体状态 + 动作 + 场景 + 台词（可选）+ 声音（可选）
镜头2[3-6秒]……
【限制】无字幕 + 3—8 条本条提示词真实会踩的风险
```

### 3.1 【主体】

**@ 指代纪律**：写 `@图片1` / `@视频1` / `@音频1` —— **带 @、用全称"图片"**，图片/视频/音频各自分开计数，序号与上传顺序一致（= media 数组顺序）。同一对象在正文里可多次 @（官方推荐的提高命中率手法）。

> **特殊模式的指代例外**：① 首尾帧模式**不写任何 @ 指代**——首帧/尾帧本身就是画面约束，且按 §0.3 与参考类互斥，提示词只写「运动 + 运镜」。② 视频编辑模式里 **`视频1` 指被编辑的源视频（故意不加 @，它不在 reference 数组里）**；新增的参考图仍写 `@图片1`（如「视频1 中…新增 @图片1 中的花瓶」）。

逐个素材写**四要素 = 素材编号 + 正向职责 + 生效时段 + 禁止迁移项**，一个素材超过两项职责就拆两句：

```text
@图片1 锁定人物五官、发型与服装，全片生效；图中背景与文字不参与生成。
@图片2 锁定商品外形、材质、部件数量与比例结构，全片生效；棚拍白底、影子方向与附带文字不参与生成。
@视频1 只参考运镜方式与动作节奏，全片生效；其中的人物、场景、品牌标识与声音均不迁移。
@音频1 只作为音色参考，引用写在台词同句内。
```

**有参考图就不复述外观**：@图片N 后面只跟"做什么动、往哪走、镜头怎么移"，外观一律"以 @图片N 为准"。禁止写"严格还原参考图中的纹理"——参考图本身就是约束。**但状态类（液位、开合、数量、干湿、朝向）参考图承载不了，必须显式写锁。**

背景写地点、时间、天气、关键空间关系；人物或商品重复出现写明"全片同一"。

### 3.2 【风格】

写法是**一串美学词 + 一句氛围定调**（取词见 §8）：

```text
柔光，侧光，中近景，中心构图，平拍，浅景深，暖色调，固定镜头。写实广告质感，安静克制的高级感基调。
```

不要同时要求互斥项（"固定机位"+"持续环绕"）。互斥表见 §7.4。

### 3.3 【时间线】（你的核心工作）

格式固定为 `镜头N[a-b秒]`，对齐官方多镜头公式（镜头序号 + 时间戳 + 分镜内容）。

**每个分镜内部语序固定为五位**，缺项跳过、**不许换序**：

| 位次 | 写什么 |
|---|---|
| ① 拍法 | 转场方式（硬切转场）+ 机位/景别/运镜，短句，一段只给一个主运镜 |
| ② 指代与状态 | 本镜出现的 `@图片N/@视频N` + 起始状态 |
| ③ 动作 | 可拍摄的具体动词 + **幅度 + 速率 + 作用效果** + 结束状态 |
| ④ 场景 | 本镜环境或环境变化 |
| ⑤ 声音 | 台词 `@图片1 用<情绪>的声音说："<原文>"` + 人声六要素；音效；BGM 变化 |

硬规则：

- 时间从 0 秒起连续覆盖到结尾，**不重叠、不留空，各段之和 = `duration`**（官方硬要求，对不上会被裁）。
- **单段 ≥ 2 秒**；一段一主动作、一主运镜。
- **上段的结束状态 = 下段的起始状态**。第 2 段接不上第 1 段结尾，说明中间缺一个动作，补上或合并。
- 段数卡尺：`5s → 1 段`（写「生成单镜头」）、`8—10s → 2—3 段`、`15s → 3—4 段`、`20—30s → 4 段封顶`，镜头偏多时合并相邻动作压到 4 段以内。**首尾帧模式不受此卡尺约束**——首/尾帧已锚定起止，段数服务于叙事，动作复杂时可酌情增加到 4 段以上。
- 台词字数 ≈ 时长 × 4 字；**每句台词所在镜头预留 ≥「字数÷4」秒**。窗口不够时**不能加时长**，只能压紧其他镜头动作腾出时间；仍读不完就对台词/旁白提速，写明"以较高语速清晰念出，在镜头结束前读完"。
- 一镜到底：写「生成单镜头」，时间段只代表动作阶段，结尾补"全片为一个连续镜头，不硬切、不瞬移，机位运动连续"。

### 3.4 【限制】

**第一条默认"无字幕"**（用户要字幕时除外），再挑 2—7 条**本条提示词真实会踩**的风险（合计 3—8 条，与 §10 自检一致）。堆到二三十条会稀释每一条的注意力。

- 官方显式声明词照原样写：**无字幕、无台词 / 全片无台词、无背景音乐**。
- 其余风险项**优先写成正向目标状态**：写"轮廓与比例全程保持稳定"而不是"不要变形"；写"画面背景与图中文字不参与生成"而不是"不要参考背景"。
- **先消矛盾，再写限制**。正文里"固定机位"和"环绕运镜"打架时，加十句约束也没用，回去改正文。
- 挑选优先级：身份/商品稳定 → 物理正确 → 摄影正确（机位轴线）→ 文字与品牌 → 声音边界。
- 下笔前过**商品连续性八查**：形状比例 / 材料颜色 / 部件数量位置 / 物体精确数量 / 朝向尺度 / 液位 / 开合状态 / 干湿破损。

## §4 工作流路由

| 输入长相 | 走哪条 |
|---|---|
| 只有商品/需求一句话、只有参考素材、脚本三五行 —— **信息量少，缺分镜** | **§5 生成工作流** |
| 已有成篇原稿、已有分镜或时间戳、已有台词 —— **信息量多，要规整** | **§6 优化工作流** |

判不准就看**有没有可复用的分镜与动作序列**：有 → 优化（不许重写）；没有 → 生成。

缺参考图、是否出镜/出声、时长与比例等信息时，按电商默认合理推断（见 §5 第 4 步），**不向用户提问**。

有参考素材先看素材：图片直接读；视频/音频如果读不到就只按能确认的信息处理，**读不到的内容不虚构**。

## §5 生成工作流（输入少）

1. 读素材，定每个素材的职责（人物 / 商品 / 场景 / 动作节奏 / 音色）。
2. 只用**全能参考**形态（首尾帧模式除外，见本节末尾路径）：所有素材（人物 / 商品 / 场景 / 动作节奏 / 音色）都作为参考输入；有参考图就不复述外观，只写动作 + 运镜。
3. 判场景，去 §9（及 references/03、assets/templates.md）挑模板套结构；品类取词去 §8。
4. 定时长与段数（用户没说：口播 8—10s，静展 5s，种草/试穿 8—10s，TVC 按客户要求），按 §3.3 卡尺切段。
5. 无脚本时按**节奏骨架**设计一个连贯事件，不编造与素材无关的剧情：
   - 15s：0—2 钩子（主体/商品立刻出现）→ 2—5 第一动作或卖点 → 5—9 推进 → 9—12 效果证明 → 12—15 落点
   - 30s：0—3 钩子 → 3—8 第一阶段 → 8—13 升级 → 13—18 变化 → 18—24 高潮 → 24—28 结果 → 28—30 收尾
6. 前 1—2 秒必须出钩子，结尾必须有落点（商品正面定格 / 人物定格表情）。
7. 按 §3 写四段式，过 §7.2 加固锁与 §10 自检，只交提示词。

**首尾帧路径（用户提供首帧/尾帧图，或明确要求"首尾帧"）**：不进全能参考，直接走 references/03 #9 模板——提示词只写「运动 + 运镜」，不 @ 任何参考、不复述外观，时间线仍用 `镜头N[a-b秒]`；风格与起止画面由所传首/尾帧决定。

## §6 优化工作流（输入多）

**第一原则：优化 = 结构规整 + 语序调整 + 取词替换，不是二次创作。** 原稿是需求本身，不是草稿。

### 6.1 允许做的四件事

1. **归位**：把原稿内容搬进四段式 —— 素材职责与背景进【主体】，全局氛围光影进【风格】，逐镜内容按时间戳进【时间线】，风险项进【限制】并补"无字幕"。
2. **调序**：把每个分镜内部的句子按 §3.3 五位次重排（拍法 → 指代与状态 → 动作 → 场景 → 声音），**只搬位置，不改语义**。
3. **替换**：模糊/泛化表述换成 §8 词典里的可执行词、§9 模板里的成熟句式。一次替换只换一个词组，不整句重写。
4. **补技术层**：@ 指代、时间戳、素材职责声明、人声六要素、正向排除层、§7.2 加固锁。**与原稿冲突时一律以原稿为准。**

### 6.2 禁止做的五件事

1. **不删动作**。原稿动作序列全部保留，只允许合并表述。动作密度超时长时通过合并相邻动作、压紧节奏消化，**不能加时长、不能把提示词拆分提交**，也绝不擅自删减。
2. **台词一字不改**。引号内容原文照抄，不删除、不降级为旁白、不改写措辞，只允许补情绪/语速/音色/口音。
3. **指名信息逐字保留**。原稿点名的场景、地点、品牌、规格、机型原样写进对应段落并锁定。
4. **不换场景、不换风格、不改叙事顺序**。镜头顺序以原稿为准，即便你觉得别的顺序更好。
5. **情绪与节奏词逐字锚到镜号**（如"镜头1—2 快节奏，镜头3 起反转温柔"），不许泛化成全局一句话。

### 6.3 替换对照（最常用）

| 原稿这样写 | 换成 |
|---|---|
| 高级感、有质感 | 柔光，侧光，浅景深，低饱和度，长焦镜头 |
| 电影级大片、高质量、精美 | 删掉，改为具体光影/材质描述 |
| 科技感 | 冷色调，硬光，低饱和度，高对比度，黑镜反射 |
| 食欲感 | 暖色调，硬光点缀，微距，高饱和度，边缘光 |
| 伤心 / 开心 | 眼眶泛红、嘴角微微下压 / 眼角上扬、露齿轻笑 |
| 精彩地展示、酷炫地转身 | 换成可拍摄动词 + 幅度速率（"缓慢转身约 90 度"） |
| 第一幕、擦除切换、转场特效 | 改为「硬切转场」或连续视觉变化 |
| 一个颈部按摩仪 | 白色 U 型颈部按摩仪，两端弯曲贴合颈部，内侧两枚银色金属触点 |
| 慢跑 | 慢跑，双脚交替蹬地有短暂腾空，步频与摆臂幅度明显大于走路，身体微前倾 |
| 图1 / 视频1（旧写法） | @图片1 / @视频1 |
| 不要出现水印 | 画面保持洁净，无叠加图形与标识（正向化） |

### 6.4 定向优化

用户点了具体问题就只修对应段落，其余原文保留：

| 用户抱怨 | 改哪里 |
|---|---|
| 人物/商品前后不一致、变脸、变形 | 【主体】锁死 + 【限制】+ §7.2 加固锁 |
| 画风、氛围、光线不对 | 【风格】 |
| 节奏乱、不知道怎么切镜、动作没做完 | 【时间线】重切时间戳与段数 |
| 台词被吞、没说完 | 【时间线】扩台词时间窗 + §7.3 可听性锁 |
| 乱码文字、水印、多余元素、多出一个人 | 【限制】+ 对应镜头正向覆盖 |

## §7 强弱项与应对策略

### 7.1 能力清单（官方能力边界 + practitioner 经验）

| 能力 | 表现 | 提示词应对 |
|---|---|---|
| 商品/主体一致性 | **强** | 敢在全能参考里给复杂商品、多图并用，配 §7.2 一致性锁兜底 |
| 常规口播指令遵循 | **强** | 台词直接内嵌引号给完整句子，音色引用紧贴台词同句 |
| 动作表现力 | **强** | 敢写幅度大的动作，明确幅度 + 速率 + 结束状态 |
| 文字 / logo 稳定性 | 较稳（参考图承载） | 敢让参考图里的 logo 出镜，写"文字保持清晰完整"；**绝不要求模型新生成文字** |
| **像素级一致性** | **强（官方亮点）** | 人物千人千面、多图/多视频参考稳定；正向写死外观与状态锁 |
| 原生 30s 叙事 | **强（官方亮点）** | 敢做多镜头连贯叙事、一镜到底、连续运镜 |
| 文档/网页解析 | **强（官方亮点）** | 上传 PPT/PDF，提示词只定风格方向 |
| 特效 / 动效指令 | **弱** | 降低预期，用连续视觉变化替代花哨特效 |
| **物理交互** | **弱**：开罐、倾倒、冰块、剥开易穿帮 | 走 §7.5 换视角规避 |
| **空间逻辑** | **弱**：躺卧朝向错、人物与物体比例失衡 | 显式写朝向锚点与相对比例 |
| **美妆上妆特写** | **弱**：左右侧互换、前后对比被抹平、双头产品被拆件复制 | 双眼 + 鼻梁同框、禁单侧特写；用"画面左右"下锚；加跨镜头对比全局锁 |
| 精确卡点 / 输出时长 | **不可控**：改不了 duration，卡点精度不保证 | 时长偏差只靠调节奏、提语速消化，不承诺卡点精度 |

### 7.2 一致性加固锁（多镜头必加，高频打回点）

写"全片一致"模型不会照做，命中就上对应锁：

1. **单人锁**（打回：冒出第二个人）：在【主体】、每个人物镜头、【限制】**三处**都写"画面仅一人出镜，始终只有本人，背景无路人"。
2. **服装逐镜复述**（打回：切镜换装）：每个人物镜头内用短句复述核心服装（颜色 + 单品名），全局造型锁只兜底。
3. **多 SKU 对应表**（打回：口味/颜色错配）：给"名称 → 包装色/内容物色"对应表，展示某 SKU 时当场复述其颜色。
4. **小件相对尺寸锚**（打回：大小漂移）：饰品小件写相对锚（佩戴时约耳垂的几倍、入盒时占盒内几分之一），并写"商品物理尺寸全片恒定"。
5. **全身造型计数**（打回：多出一双鞋）：全身镜头写"头上仅一顶帽、上身仅一件、下身仅一件、脚上仅一双鞋"。
6. **头部入画**（打回：开头无人头）：人物镜头写"头部完整入画、面部清晰、头顶不被画框裁切"，第一镜尤其要写。
7. **道具物理尺寸锚**（打回：道具比例失真）：网/桌/椅/车/器械用与人的相对关系表达（"网宽明显大于人物身高、约 3 米"）。
8. **品类先验防幻觉**（打回：奶茶自己长出珍珠）：锁细容器 + 内容物 + 状态，用正向目标状态挤掉先验元素（"杯中仅为纯色饮品本体，液体均匀，无固体颗粒，无顶部配料"）。

### 7.3 声音与时间线加固

1. **默认有声**：不写台词模型自编台词，不写 BGM 模型自行配乐。不要就显式写"全片无台词""无背景音乐"。
2. **音色引用必须与台词同句、紧贴台词**：`@图片1 用亲切的声音说："<台词>"，音色参考 @音频1`。前置的"提取 @音频1 的音色特征…"式声明**实测不生效**。
3. **台词可听性硬锁**：台词清单与镜号一一映射；带台词的镜头写"本镜台词完整念出，不被环境音或动作音替代"；再加"每镜只读本镜分配的那一句，不串镜、不加字"防幻觉加字。
4. **读音锚**：英文品牌名写"按标准英文原音读"，**禁止写 IPA 音标**（实测干扰语音生成）；中文写"标准普通话，字正腔圆"；收尾长 CTA 拆两个短句慢读，读完留 ≥0.5 秒气口。
5. **道具出场时间线锁**（打回：道具被提前到开头）："从第 N 镜才出现"的道具，出场前每镜显式写"未戴/未出现"，出场镜写"首次出现"。
6. **音效跟着物理衰减写**：✅"以清脆的敲击声撞击桌面，伴随逐渐变弱的撞击声，每次弹跳精确同步" ❌"有弹跳的声音"。

### 7.4 互斥组合（下笔前扫一遍）

| 互斥 A | 互斥 B |
|---|---|
| 固定镜头 | 持续环绕 / 持续推进 |
| 一镜到底 / 生成单镜头 | 硬切转场 |
| 自然纪录质感 | 每秒强转场 |
| 浅景深近景特写 | 交代全景空间关系 |
| 商品正面 logo 全程朝向镜头 | 360 度环绕展示 |

### 7.5 高危动作

**清单**：开罐/拉环、倾倒液体、冰块与融化、剥开撕开包装、液体挂杯、泡沫涌起、切开多汁物体、快速多手交接。

命中时**不要中断输出去讲风险**（违反输出纪律），直接在提示词里执行规避：

- **换视角规避**：用微距特写只拍局部，穿帮面积小；或分别拍高危瞬间前的张力（指腹搭在拉环边缘、包装轻微受力形变）与已完成状态（液面波纹、气泡上升），跳过高危瞬间本身。
- 必须一镜完成时，在动作句后补物理约束："沿固定轨迹被向上提起约 30 度后停止，罐体轮廓与拉环形状全程保持完整，金属边缘连续无断裂，液体流线连续，手指数量与位置稳定。"

**复杂动作五要素**（只在打斗、追逐、抛接、液体喷射、多人换位时追加）：谁发起 + 从哪出发 + 沿什么路径 + 作用于谁 + 落在哪里。飞行物从发起者身边出现、不凭空出现在画面中央；多人换位用一个双人广角交代，别在特写里换位。

## §10 交付前自检（自己在心里过，不要输出）

- [ ] 回复里**只有一个 text 代码块**，没有任何说明文字
- [ ] 只有【主体】【风格】【时间线】【限制】四个一级段落
- [ ] 指代全部为 `@图片N / @视频N / @音频N`，带 @、用全称、分类型计数
- [ ] 有参考图的外观没被文本复述；状态类（液位/开合/数量/朝向）有显式锁
- [ ] 时间线为 `镜头N[a-b秒]`，从 0 连续覆盖、单段 ≥2s、各段之和 = duration
- [ ] 每个分镜内部按「拍法 → 指代与状态 → 动作 → 场景 → 声音」五位次排列
- [ ] 每段一主动作一主运镜，上段结束状态接得上下段起始状态
- [ ] 优化场景：原稿动作数量、顺序、台词原文、指名信息**零删改**
- [ ] 台词每句预留 ≥ 字数÷4 秒；声音层存在（要么写清，要么显式写无台词/无背景音乐）
- [ ] 【限制】首条"无字幕"，总数 3—8 条，除官方声明词外均为正向表述
- [ ] 正文无 §7.4 互斥组合；命中高危动作已按 §7.5 规避而非口头提醒
- [ ] 未改 duration/resolution/ratio/audio/seed 等参数、未调视频时长；时长偏差只靠调节奏/提语速消化
- [ ] 未把提示词拆分提交；形态优先全能参考（首尾帧/文生为官方支持的备选模式，见 §0/§2）

> 可用脚本自动体检：`python scripts/validate_prompt.py <prompt_file.txt>`（检查四段式结构、@ 指代、时间戳连续、五位次、互斥组合、参数未写进提示词等）。
