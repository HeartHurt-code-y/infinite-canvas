## 9. 首尾帧模式模板（与全能参考互斥）

> 首尾帧模式通过 `first_frame` / `last_frame` 传入（可只传首帧，或首+尾帧），**不能再传任何 reference_xx / file / link**（见 references/01-official-api.md §4）。提示词只写「运动 + 运镜」，不 @ 任何参考图、不复述外观——首/尾帧本身就是画面约束。时间线仍用统一的 `镜头N[a-b秒]` 封装，便于自检脚本校验。

```text
【主体】画面起始即所传首帧：水墨竹林、浓雾环绕、竹影婆娑的中心，头戴斗笠、身着墨色长袍的刀客伫立；如有尾帧，结尾定格为<尾帧内容>。
【风格】黑白、水墨画风格，动作须带毛笔触感，速度要快、细节要足（墨滴、火花、墨痕裂口）；水墨晕染的颗粒感清晰可见。
【时间线】
镜头1[0-3秒]中景，刀客左手轻按刀柄，竹叶随风飘落；氛围寂静、压抑。
镜头2[3-8秒]特写，镜头快速推进至斗笠下的眼部特写，斗笠边缘露出一双凌厉的眼睛；刀客右手缓缓握紧刀柄，指关节泛白。
镜头3[8-13秒]快速环绕，两名水墨剪影刺客从竹林深处杀出；镜头快速掠过刺客身影，强调速度感。
镜头4[13-18秒]手持感、高速捕捉，刀客猛然拔刀，刀光是一道纯白色的水墨裂痕。
镜头5[18-20秒]慢镜头至定格，刀停在刺客颈侧，竹林归于平静。
【限制】无字幕；保持首帧图的水墨黑白风格全程不漂移；动作连贯、无跳帧；不生成新文字；首尾帧模式下不引用任何参考素材。
```
