# references/02-formula-families.md — 官方提示词公式族（含示例）

> 来源：阿里云《Wan3.0 视频创作者手册》第五章"提示词指南"与 API 参考示例。按原文收录，不改写。SKILL.md §2 为索引，此处给完整拆解与可抄示例。

## 0. 总纲

> "提示词用来描述视频中所包含的内容和运动过程……描述越完整、精确和丰富，生成品质越高。我们针对不同的使用需求提供了几种典型公式。"

---

## 1. 基础公式（文生视频）

**提示词 = 主体 + 场景 + 运动（谁在哪里干什么）**

- **主体**：主要表现对象——人、动物、植物、物品或非物理真实存在的想象物体。
- **场景**：主体所处环境，含背景、前景，真实或虚构。
- **运动**：主体具体运动 + 非主体运动状态——静止、小幅度、大幅度、局部、整体动势。

> 适用：初次尝试 AI 视频、想象力优先。

---

## 2. 进阶公式（文生视频）

**提示词 = 主体 + 场景 + 运动 + 美学控制 + 风格化 + 音效**

- **主体描述**：外观细节，形容词或短句列举。例："一位身着少数民族服饰的黑发苗族少女""一位来自异世界的飞天仙子，身着破旧却华丽的服饰，背后展开一对由废墟碎片构成的奇异翅膀"。
- **场景描述**：环境特征细节。
- **运动描述**：幅度、速率、作用效果。例："猛烈地摇摆""缓慢地移动""打碎了玻璃"。
- **美学控制**：光源、光线环境、景别、视角、镜头、运镜。
- **风格化**：画面风格语言，如"赛博朋克""勾线插画""废土风格"。
- **音效**：见公式 7。

---

## 3. 图生 / 首尾帧生视频公式

**提示词 = 运动 + 运镜**

- 首帧或首尾帧图像已确定主体、场景与风格，提示词主要描述**动态过程及运镜需求**。
- 首尾帧模式下不要复述外观，只写动作与镜头运动。

---

## 4. 参考生视频公式

**提示词 = @参考对象 + 动作 + 台词**

- **@参考对象**：通过 @ 引用素材，多个按顺序排列（@图片1、@视频2、@音频1）；可在提示词不同位置**多次 @** 精准控制参考意图。
- **动作**：参考对象的运动状态——静止、表情情绪变化、肢体动作、外力动作、位移变化。
- **台词**：说话内容，支持单主角/多主角对话；音色可参考 @音频1。
- **视频时序参考**：参考 @视频1 的运镜方式。
- **白膜参考**：输入白膜参考视频，提示词可把 3D 预览转化为正式成片（"把预览视频中...换成...角色"）。

**官方示例**：
> 这是一个充满童趣的童话场景。@图片1 在草地上蹦跳着玩耍，@图片2 在旁边的一颗苹果树下弹奏钢琴，一颗苹果掉到了@图片2 的头上，@图片1 参考@音频1的音色，开心地指着@图片2 说："你要变成科学家了！"

**多主角对话 + 音色（官方示例）**：
> 将图片1中的女人定义为主体1，将图片2中的女人定义为主体2，主体1台词音色参考音频1，主体2台词音色参考音频2，在健身房内，主体1和主体2并排站在跑步机旁，主体1转头微笑对主体2说{今天练哪个部位}，主体2一边用毛巾擦汗一边回应{练背吧，昨天腿还酸着呢}……

## 5. 多镜头公式

**提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容**

- **总体描述**：概述整个视频内容——故事主题、叙述风格、主要情感或核心事件。
- **镜头序号**：每个镜头分配编号。
- **时间戳**：标明每个镜头在视频中的具体时间范围（如 [0-3秒]）。
- **分镜内容**：每个镜头中角色/物体的具体行为——动作、语言、表情、姿态；可参考一般单镜头写法。

**官方示例**：
> 这个故事以第三人称视角，讲述了一个关于放弃与重拾希望的短剧。
> 第1个镜头[0-3秒]一个男孩在操场的角落独自坐着，低头望着手中的信纸，随后轻轻叹气，眼神中透露出迷茫。
> 第2个镜头[4-6秒]硬切转场，固定机位，聚焦于男孩的眼睛，泪光闪烁，带着失落和无助。
> 第3个镜头[7-10秒]硬切转场，场景转至一间简朴的教室。一个女孩眼神温和而坚定，穿着朴素的衣着，面带温和而坚定的笑容，走到男孩的身边安慰他。

> 本技能的四段式【时间线】即对该公式的工程化封装（镜头N[a-b秒] + 五位次语序）。

## 6. 视频编辑公式

**提示词 = 编辑对象 + 编辑行为**

- **元素编辑**："男人戴上红色的帽子""把猫换成狗""去除草地上的猫"；有图参考时"把视频中男人的衣服换为 @图片 中的红色外套""让视频中的男人穿上@图片中的衣服和@图片2中的裤子"。
- **风格/光线/色调全局编辑**："视频修改为阴天""修改为暖色调""把视频改为图中的 2D 卡通风格"；可补"其他保持不变"。
- **时序编辑**："让视频里的男人拿起水杯，喝下一口水"；改台词强调"保持人物音色和语气，将女生说话内容改为：Hello World"。
- **视频延长**：画面/风格/布局已定，只描述后续动态，如"男人继续往前走，突然摔倒在地上"。

**官方示例**：
> 将视频1中泳池水面上的蓝色和黄色游泳圈全部去掉，池边石板地上的画纸、颜料罐、画笔和黑色收纳箱也全部去掉，用周围泳池水面和石板地面自然填充。仅保留女人漂浮在泳池中，女人的姿态动作和泳池背景保持不变。
> 编辑视频，视频1中女人右侧桌面空位处新增图片1中的花瓶，花瓶光影与窗户自然光方向一致，自然融入木桌场景。女人的动作和画面其余部分保持不变。

---

## 7. 声音公式

**提示词 = 人声 + 音效 + 背景音乐（BGM）**

- **人声**：`xx说："<原文>"`，配套情绪/语调/语速/音色/口音。例："一个男人在讲脱口秀，他说道：\"好好学习，天天向上\"，语气轻松，语速适中，声音清亮，美式英文。"
- **音效**：`<行为发声>`。例："一个玻璃小球从桌面掉在木质地面上，发出\"砰\"的声音，室内安静环境。"
- **背景音乐**：`(风格)`。例："雨夜，阴森窄小的走廊，尽头有一扇窗户，配有悬疑风格背景音乐。"

> 排除式控制直接写：`无背景音乐，只保留人物对白、环境声和动作音效。` / `不要字幕。` / `不要任何声音。` / `全片无台词。`

---

## 8. 其他控制（官方）

- **分镜控制**：想强控多镜头个数/时间戳，写"镜头1 xxxx，镜头2 xxxx"或"镜头1[0-3秒]xxxx"；强控一镜到底写**"生成单镜头""一镜到底"**。
- **台词控制**：`xx说："xxx"` 保持台词不变；不写则模型自由发挥；不要台词写**"全片无台词"**。
- **背景音乐控制**：不写则模型自行发挥；不要 BGM 写**"无背景音乐"**。
