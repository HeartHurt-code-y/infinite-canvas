## V1.3.1 · 《青铜信号》（2026-09-14）

**一句话**：把之前只写在文档里的规则真正落到代码——修掉 4 个「文档写了但代码没有」的坑。

- **坑 1「怎么没有自动合成？」** `batch_run_drama.py` 拼接用 `os.path.dirname(out_dir)` 把 `视频` 层剥掉，成片落到 `<项目根>/final/`，而审核页读 `视频/final/`。铁律 D20 上一版**只有描述没有 diff**。→ 拼接目标显式取 `视频/final/final.mp4`，成片审核页改权威路径优先
- **坑 2「审核页面要齐全，不要漏」** `audit_html_builder.py` 还是 V1.2 的 6 页编号、`02_风格审核` 不存在、资产页缺道具卡片墙。→ 新增 `build_style_review()`；编号整体后移（资产 03 / 分镜 04 / 提示词 05 / 视频 06 / 成片 07）；补道具墙
- **坑 3 徽章不反映真实状态** → 新增 `_stage_state()` 读 `pipeline_state.json` / `prompt_review.json`
- **坑 4「一致性审核其实一次都没跑」** `consistency_auditor` 只认 `speaker_char_id`；本片全片 V.O. 旁白 → 该字段全 null → 人脸审核被整体跳过。→ 新增 `audit_faces_onscreen()`，按 **`on_screen_char_ids`** 逐角色抽帧判图
- **坑 5「不适用」与「未审」混为一谈** → `audit_result.json` 加 `face.applicable`，徽章升级四态（✅/❌/`人脸— 不适用`/`人脸⏸ 未判`），文件缺失显式渲染「未审」
- **坑 6 成片页分段汇总表一片红色 fail** → 加「人脸一致性」列，`applicable=false` 显示「不适用」
- **坑 7「final 的文件时间怎么还是旧的？」** Windows 上原地覆盖**不刷新创建时间**，成片创建时间停在第一次拼接那一刻。→ `concat_segments()` 改「写 tmp + `os.replace`」；成片审核页新增**元信息行**（大小 / 时长 / 更新时间）

- 补上此前只在文档里承诺的 `backup_existing_video()`（重抽前自动备份旧片）
- **新增「版本进化与回退」机制**：`VERSION` + `CHANGELOG.md` + `tools/snapshot.py` + `tools/rollback.py` + `tools/checks.txt` + git tag
