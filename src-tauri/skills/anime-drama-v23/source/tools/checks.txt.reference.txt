# ==== V2.2.9 · 非台词字段会「渗漏」（铁律 D2-s）====
# 来源：2026-09-19 用户看完成片逐条报 12 类问题。定位后发现两类同源：
#   **非台词字段（overall_soundscape / 动作行 / action_zh / camera_lock_zh）里的内容，
#     H3 会当成「要生成的内容」，而不是「元信息」。**
#   机制一 语音性的会被**念**：多出来的台词全部命中非台词字段 ——
#     段2 soundscape 里引号内的「让一下」；段6/14/18/19 的动作行
#     （不说话 / 声音是抖的 / 后话被堵回去 / 那句话是她自己说的）。
#   机制二 物件会被**画**：段7「拿瓶盖喝水」← soundscape 里写着「瓶盖拧开的脆响」。
#   机制三 关键关系缺排除会被**并**：段3「坐在病床上」← 分镜写的是「床边的小凳」。
# 判据：
#   ① 非台词字段只写「看得见的」，不写「听得见的」（声音抖→下唇抖了一下）；
#   ② overall_soundscape 只写音色与音源类别，不写画面里不该出现的具体物件细节；
#   ③ 关键接触关系要「正向 + 排除」双写（坐在床边的小凳上（不是床上））；
#   ④ 三层判别且每层都要有判别器：拟声不算泄漏 / 台词原文重复引用=警告 / 新增人声=硬拦；
#   ⑤ 检查对象必须与实际生效的那份一致（中文项目不查英文 soundscape）；
#   ⑥ **字段的「语义」和模型的「理解」是两件事** —— 交给生成模型的文本，
#      都要问一句「它会不会把这段当成要生成的东西」。
#   ⑦ 机检抓不全（段15「停了一拍，没有收回来」无高置信词）→ **机检替代不了关 6 人眼复核**。
