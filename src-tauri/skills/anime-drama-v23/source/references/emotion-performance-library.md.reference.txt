# 情绪表演库（精简内置版）

> drama-auto-pipeline 阶段四专用。连续无对白镜头靠表演推进时，为主情绪人物选 2~3 个连续状态，每个近景只取 1~2 个可见动作/姿态/呼吸，**翻译成白话**——禁止复制术语、编号、"颧大肌"这类解剖词进交付文本。
>
> 取材纪律：只取部位动作与视觉结果；评价性措辞、情绪标签、阶段标记不进正文。

## 用法速查

1. 先定人物此刻的**主情绪**（对照下表大类），再定**强度档**（轻/中/重）
2. 每条只取：1 个面部动作 + 1 个手/身姿态（+ 激动情绪加 1 个呼吸细节）
3. 相似情绪靠"肌肉主导"区分：悲伤=眉头向内聚（八字眉）；恐惧/惊讶=眉毛整体上挑
4. 强忍/克制 = 两组对抗动作同时出现（咬紧牙关 + 嘴唇抿直）
5. 情绪转换必须写"哪个动作先退、哪个动作接管"，不能写"从A变到B"

## 喜悦类

- **自然微笑**：嘴角微微上扬、双唇自然闭合不露齿；眼神柔和略有微光；面部肌肉放松、苹果肌微显；头中立或微侧
- **欣慰浅笑**：嘴角缓慢浮现一丝弧度；目光微微低垂温柔、眼眶略湿润但泪不落；肩膀随一次缓慢呼气下沉；头轻微点头
- **娇羞窃喜**：用力抿唇掩饰上扬的嘴角；眼神躲闪不敢直视、眨眼变快；脸颊泛起粉红；头低垂微侧
- **释然微笑**：长舒一口气后嘴角放松地勾起；眼神从紧绷转为清澈；眉头彻底舒展；头微微仰望或轻摇
- **得意洋洋**：单侧嘴角斜向上扬呈戏谑斜笑；一侧眉毛高挑；下巴前凸；头高昂、视线向下俯视

## 愤怒类

- **隐忍怒意**：双唇紧闭成一条直线、咬牙切齿；目光死死盯住目标、眉头压低；两侧咬肌凸起、面部微微抽搐；头僵硬不动
- **恼羞成怒**：嘴唇气愤得发抖、嘴角用力下撇；眼神慌乱闪躲后转为凶狠；脸庞涨红；头急促转向一侧后猛地回头对峙
- **高傲鄙视**：单侧嘴角轻蔑下撇；眼皮半垂、斜视对方；表情冷漠僵硬；头高高仰起、用鼻孔看人
- **嗔怒娇嗔**：微微嘟起嘴唇、嘴角假装下垂；瞪大双眼但毫无杀伤力、眼波流转；双颊微鼓；头带傲娇节奏快速扭向一侧
- **憋屈闷气**：双唇紧闭向内抿、频繁吞咽；眼神极度向下压、眼眶发红带泪；鼻翼剧烈翕动；头深深耷拉拒绝对视

## 悲伤类

- **无声落泪**：嘴角剧烈颤抖着向下压；泪水夺眶而出滑落；眼神空洞失去高光；面容憔悴苍白、泪痕清晰；头微微无力下垂
- **抽泣哽咽**：嘴唇剧烈哆嗦、不停倒吸凉气；眼睑红肿、泪水在眼眶打转；下巴规律性颤抖；头随抽泣节奏一顿一顿抽动
- **忧郁惆怅**：嘴角无力松弛地自然下垂；眼神迷茫忧伤、失神望向远方；双眉微蹙；头轻微偏向一侧显得孤独无依
- **委屈巴巴**：下嘴唇明显向前委屈突起；由下往上仰视、眼睛水汪汪；鼻尖发红、脸颊气鼓鼓微凸；头瑟缩微向后退缩
- **无奈苦笑**：单侧嘴角带自嘲意味上扬扯动；眼神充满悲伤宿命感；面部一半似笑一半似哭；头微偏、伴随一口叹气沉重摇动

## 惊恐类

- **极度惊恐**：嘴巴不受控张大到极限；眼球几乎凸出、瞳孔极度放大；面庞惨白、额头冷汗直流；头剧烈向后躲闪退缩
- **目瞪口呆**：下巴因震惊掉落、嘴巴半张；双眼暴睁、视线死死锁在一点；面部肌肉瞬间定格硬化；头停止一切运动呆若木鸡
- **惶恐不安**：频繁艰难地吞咽口水、嘴唇发干微张；眼珠像受惊的兔子疯狂左右转动；眉头深锁、额头布满细密冷汗；头神经质地四处惶恐张望
- **警惕防备**：双唇紧闭、嘴角两侧用力拉扯锁死；微微眯起双眼、目光死死盯紧暗处；咬肌紧绷、下颌棱角分明；头微微下沉、下巴收紧
- **恍然大悟**：嘴巴瞬间微张、发出轻微舒畅的短促轻叹；原本迷茫的眼睛瞬间睁大增亮；双眉高挑、整张脸豁然开朗；头随思绪顿开微微后仰

## 三条通用法则

1. **正文只说白话**：上面每一条已经是白话状态，再落到镜头里继续往"部位+动词+视觉结果"收——"眉心聚拢，挤出两道浅浅竖纹"是白话，"她露出伤心的表情"是废话。
2. **留一处没完成**：全片保留若干处中断或压抑——没掉下来的泪、没说完的话、启动后骤停的动作、只有半弧的笑。
3. **双人不同步换挡**：两人相邻反应必须有可见先后。A 的台词/动作先完整发生，B 看见听见后用眼神、呼吸、手部接住；B 的反应再改变 A 的下一步。禁止同帧无因同步换脸。
