# 扩展风格建议库

本文件提供多宫格分镜提示词导演技能的扩展风格库。当默认 9 种风格不满足需求，或需要为特定题材匹配更精准的风格时，可加载此文件。

---

## 风格选择原则

1. 风格必须服务于故事情绪，不喧宾夺主
2. 全宫格必须使用同一套视觉风格，保持连续性
3. 风格关键词需注入到每个宫格的提示词中
4. 即使用户指定风格，仍保持动作克制、画面自然

## 自定义风格指引

若用户提出自定义风格，按以下原则处理：

1. 提取用户描述中的视觉关键词
2. 补充该风格典型的光影、色彩、材质特征
3. 确认风格是否兼容"动作克制、画面自然"的基本要求
4. 若风格天然包含激烈动态（如热血漫画），仍按本技能规则将激烈内容转化为克制片段
5. 将最终风格关键词注入到每个宫格提示词中
