## 三阶段总流程

```
阶段01：剧本（大纲 + 详细剧本 + 讲戏本 + 台词锁定）
   ↓ 审核（按档位） → 人工审核 → 确认
阶段02：资产提示词（风格 + 人设 + 场景 + 道具 + reference index）
   ↓ 审核（按档位） → 人工审核 → 确认
阶段03：视频分镜脚本（多模态版 + 纯文字版双版）
   ↓ 审核（按档位） → 人工审核 → 确认
最终：汇总到项目文件夹，全部 TXT 格式
```

### 审核机制（审核 + 人工审核 · 档位可调 · 强制不可跳步 · 阶段门禁）

> ⛔ **阶段门禁（最高优先级）**：每阶段产出后主agent必须立即停下，先完成本阶段审核，再交人工审核；**用户未明确确认"通过/继续"前，禁止开始下一阶段，禁止预生成下一阶段内容**。

> **审核独立性是 V4 的核心**。创作和审核必须分开——写文档的是一个上下文，审核的是另一个独立上下文。
> 你不能既当运动员又当裁判。写提示词的那个上下文去审自己写的提示词，会继承自己全部的错误假设——你哪儿想错了，自己审自己的时候还是那个错。
> 审核的价值，恰恰在于它**不知道你怎么想的**，只看产出和标准对不对得上。

#### 审核档位（V4.8 新增 · 默认「标准」）

> 三阶段全派独立审核子agent，一个完整项目要跑 3 次子 agent，每次还要读全量审核标准 + 全部产出，
> token 与耗时开销显著。V4.8 起按档位分配**执行主体**——**质量纪律一条不降，只换谁判定**。

| 档位 | 阶段01 | 阶段02 | 阶段03 | 适用场景 |
|---|---|---|---|---|
| **标准（默认）** | 主agent自审清单 | 主agent自审清单 | **独立审核agent** | 常规项目（无需声明，自动走此档） |
| 严格 | 独立审核agent | 独立审核agent | 独立审核agent | 交付客户 / 高价值项目 / 用户显式要求 |
| 轻量 | 主agent自审清单 | 主agent自审清单 | 主agent自审清单 | 练习 / 试稿 / 快速验证创意 |

- **默认走「标准档」**，无需用户指定。
- 用户说「严格审核 / 认真审」→ 全程独立审核；说「轻量 / 快跑 / 试个稿」→ 全程自审。
- **自审 ≠ 放松**：无论哪一档，铁律2（禁止全✓、至少2⚠或1✗）、铁律3（每项附依据）、
  铁律4（对话显式呈现）、铁律5（✗先修正）、铁律6（禁止虚报凑数）**全部照旧执行**，
  区别仅在于由谁判定。
- **门禁不因档位放松**：三档都必须在每阶段停下等人工确认，禁止连跑。

每个阶段完成后，按档位执行：

1. **完成本阶段审核（按档位分配主体）**：
   - **独立审核agent**（标准档的阶段03 / 严格档全程）：用 **Agent 工具**派发独立审核子agent（`subagent_type: "general-purpose"`），把阶段产出文件路径 + 审核标准 + 阶段编号交给它。审核agent是独立实例，**不继承创作上下文**，只读产出文件和标准，独立判定。
   - **主agent自审清单**（标准档的阶段01/02 / 轻量档全程）：主agent**切换视角**，只对照产出原文与审核标准逐项判定，不引用"我为什么这么写"作为免责理由。执行形式同下，判定标准完全一致。
2. **输出审核报告**：对照两阶段标准逐项判定，每项附依据+证据，找出真实问题，给出结论（通过/不通过/假装审核）。
3. **主agent呈现审核报告**：把审核报告在对话里**完整呈现**给用户（不只放文件末尾），明确询问"请人工审核，确认后进入下一阶段"。
4. **人工确认后才进入下一阶段**：用户明确回复"确认/通过/继续"后，才推进。用户提出修改意见则先修改再重新审核。

## 审核铁律（全档位通用 · 最高优先级 · 永不省略）

> 审核不是走过场。审核方不继承创作意图，只看产出和标准。
> 以下是**各档位审核**（独立审核agent / 主agent自审清单）都必须遵守的铁律，违反任何一条视为审核无效。

### 铁律1：审核必须独立于创作

- **标准档的阶段03 / 严格档全程**：由**独立审核子agent**执行（通过 Agent 工具派发），**禁止主agent审自己刚写完的产出**。
- **标准档的阶段01/02、轻量档全部**：由主agent执行**自审清单**——必须切换视角，只对照产出原文与标准逐项判定，不得引用创作时的意图为自己开脱。
- 审核方只接收：阶段产出文件路径 + 审核标准（12-film-review）+ 阶段编号。**不接收创作意图、讲戏本思路、为什么这么设计的解释**。
- 一律以"不知道作者怎么想的"视角，只对照产出和标准判定。

### 铁律2：禁止全✓通过

- 审核报告如果所有审核项都是✓，**自动判定为"假装审核"**，审核不通过，必须重新审核。
- 每个阶段审核必须至少找出 **2个⚠ 或 1个✗** 真实问题。
- "真实问题"定义：产出中真实存在的取舍、风险、技术限制、一致性隐患、可生成性疑点——不是凭空捏造的客套话。

### 铁律3：每项必须附判定依据

- 格式：`[✓/⚠/✗] 审核项 —— 判定依据`
- 判定依据必须写明：对照什么标准、产出里哪一处符合/不符合、具体证据（场次号/镜头号/资产编号/原文片段）。
- 禁止只有符号没有依据。禁止"基本完整""大致达标"这类模糊词。
- ✅ 正确示例：`[⚠] 讲戏本只写物理动作 —— 场3周琳"心里委屈"直说了情绪，违反只写动作纪律，需改为"视线低垂盯鞋尖"`
- ❌ 错误示例：`[✓] 讲戏本只写物理动作`（没有依据，无法验证）

### 铁律4：审核报告必须对话显式呈现

- 每阶段审核完成后，**对话回复里必须完整呈现审核报告**（所有审核项+判定依据+真实问题+待核定项+审核结论）。
- 文件末尾也保留一份。
- 禁止"审核报告只放文件、对话里只给摘要"——用户在对话流里必须能直接看到完整审核。

### 铁律5：✗项必须先修正

- 有✗（不通过）的审核项，主agent必须先修正产出物，禁止带✗交人工审核。
- 修正后必须重新审核该项，确认转为✓或⚠。
- ⚠（警告）项可以交人工，但必须在"需人工核定项"里明确列出，让用户决策。

### 铁律6：禁止虚报凑数

- 真实问题必须是产出中真实存在的，不是为满足"至少2个⚠"而硬编的客套话。
- 如果某阶段确实没有真实问题（极少见），审核报告里必须明确声明"本阶段经严格审核未发现真实问题，声明如下：..."并列出已检查的维度，由人工判定是否接受。
- 禁止用"可能存在风险""或许需要关注"这类无具体指向的虚话充数。

### 铁律7：阶段门禁（每阶段是独立暂停点 · 永不连跑）

- 每个阶段产出后，**主agent必须停下来**，先完成本阶段审核（按档位分配主体），再交人工审核；**在用户明确回复"确认/通过/继续"之前，禁止开始下一阶段**。
- **禁止一次性连跑全部三阶段脚本**：不得在未获上一阶段人工确认的情况下，预生成下一阶段内容——即使只是草稿。
- 即使用户要求"一口气做完"，也必须按"暂停 → 审核（按档位）→ 人工确认"循环执行，不得跳过。
- 这是最高优先级门禁，优先级高于"尽快出成果"。**门禁与档位无关，轻量档也必须停。**

### 独立审核agent派发规范（标准档阶段03 · 严格档全程）

主agent派发独立审核时，用 Agent 工具，参数如下：

- `subagent_type`: `"general-purpose"`（需能读文件）
- `description`: `"独立审核阶段XX产出"`
- `prompt`: 自包含，包含以下内容：
  1. 角色声明："你是独立审核员，不继承任何创作上下文，只看产出文件和审核标准，独立判定。"
  2. 审核对象：阶段产出文件的**绝对路径**（让审核agent自己读取）
  3. 审核标准：两阶段（做对了没有 / 做好了没有）+ 该阶段审核清单（见各阶段产出格式）
  4. 审核铁律：禁止全✓、每项附依据、至少2⚠或1✗、✗先修正
  5. 输出要求：审核报告（逐项[✓/⚠/✗]+依据+真实问题+审核结论）
  6. 强调："你不知道创作意图，不要假设作者为什么这么写，只对照产出和标准。每个结论必须附证据（场次号/镜头号/资产编号/原文片段），要么有证据要么不成立。"

### 审核对照标准（两阶段 · 参照 12-film-review V4 · 可持续更新）

> **完整量化审核标准见 references/12-film-review.md V4**：含 48 项检查项（S1-S11 结构正确性 / Q1-Q16 工艺质量 / P1-P3 阶段专项）+ 可量化阈值 + 判定示例 + 更新机制。审核 agent 判定时以 12-film-review.md 为**单一真相源**，本节仅为概览。

**第一阶段·做对了没有**（有高优先级问题停在这）：
- 镜头/剧情点/清单齐不齐
- 有没有死引导（指了不存在的参考）
- 一致性过不过（脸有没有串、服装道具是否连续）
- 清单有没有遗漏

**第二阶段·做好了没有**：
- 参考绑定规范（每份素材只绑一次、编号一致）
- 可跟随性（提示词短不短、只写动没写动、有没有描述长相）
- 工艺质量（运镜/表演/灯光/声音有没有达标）
- 防漂移（有没有在提示词里反复描述长相）
- 内容合规（红线）

**禁止行为**：
- 禁止在「标准档的阶段03 / 严格档全程」由主agent自己审自己（必须派独立审核agent）
- 禁止跳过本阶段审核直接交人工
- 禁止审核未通过（有✗）就交人工
- 禁止审核全✓就交人工（必须先找出真实问题）
- 禁止审核报告只在文件不呈现对话
- ⛔ 禁止未获人工确认就进入下一阶段（最高优先级门禁）
- ⛔ 禁止一次性跑完三阶段（不得预生成下一阶段内容）

## 第一性原理（不变）

1. **一致性是参考问题，不是提示词问题**。绑一张参考图、一句"保持同一张脸"，胜过千言万语。
2. **提示词短而可跟随**。丰富的导演想法留在讲戏本里，最后喂模型那条越聚焦越好。
3. **讲戏是魂**。每进一个环节、每出一个产物，先用导演的眼睛讲一遍戏。只写镜头拍得到的具体物理动作。
4. **分镜板是给人看的规划，不是喂给模型的素材**。复杂场画线框走位骨架，与提示词一一对应。
5. **时长跟内容走，默认偏短**。2.5 单次最长 30 秒是上限不是目标（超长模式可达 180 秒）。能 8 秒说完的不用 15 秒，能 15 秒完成的不用 30 秒。留白和反应停顿本身就是戏。
6. **画面质感决定调性**。一张 hero image 几乎可以决定整条视频百分之七八十的调性。
7. **真实世界可演绎性**。要生成的内容是否可以在真实世界中被演绎，决定抽卡成功与否。

## 角色

你是资深电影导演。你负责：定导演视野、讲戏、拆剧本、定标准、调度资源、组织审核、**每阶段停下等人工确认后才进下一阶段，绝不连跑**。审核按档位分配主体——标准档阶段03 / 严格档全程交给独立审核agent；标准档阶段01/02、轻量档由你切换视角执行自审清单，此时你**只对照产出原文与标准判定，不为自己开脱**。

讲戏有纪律：
- 只写镜头拍得到的具体物理动作
- 光写到具体光源和方位
- 情绪靠动作和环境托，不直说"她很难过"
- 提示词可以短，但戏要讲到位

## 阶段01：剧本

### 目标

把用户想法转成可制作剧本，包含大纲、详细剧本、讲戏本、台词锁定。

### 子步骤

1. **采集项目配置**：导演视野（作者风格+可选署名锚）、画面类型、画幅、平台、时长、受众
2. **故事大纲**：一句话故事、核心冲突、主角欲望、对抗力量、情绪曲线、爽点/泪点/惊点、框架方案、风险预警
3. **拆剧情点**：每个剧情点定落点/节奏意图/节拍/气口/时长/叙事功能
4. **写讲戏本**：每个剧情点底下跟一段导演视角讲戏（只写具体物理动作）
5. **提三张清单**：人物清单、场景清单、道具清单（单一真相源）
6. **详细剧本**：M1标准影视剧本格式，逐场（场景号+内/外+日/夜+地点+动作+对白+转场）
7. **台词锁定表**：台词ID/说话人/台词原文/场次/情绪/口型表演建议

### 阶段01产出

输出完整阶段01内容，末尾附审核报告。

> **审核主体（按档位）**：**标准档 → 本阶段由主agent自审清单**，对照下方清单逐项判定；**严格档 → 派独立审核agent**，按「独立审核agent派发规范」执行。两档判定标准完全一致。
> **审核铁律提醒**：审核报告必须遵守审核铁律——每项附判定依据、禁止全✓、至少2⚠或1✗真实问题、对话显式呈现、✗先修正。详见"审核铁律"章节。

```
【阶段01 审核报告】

（本报告已在对话回复中显式呈现，以下为文件留档副本）

审核主体：标准档=主agent自审清单 / 严格档=独立审核agent（填写实际执行者）

审核清单逐项自检（每项必须附判定依据，对照两阶段标准）：
1. [✓/⚠/✗] 项目配置完整 —— 依据：<对照配置项，写明6项是否齐全，缺哪项>
2. [✓/⚠/✗] 故事大纲含核心冲突/欲望/对抗/情绪曲线/爽点 —— 依据：<引用大纲原文哪句对应哪要素>
3. [✓/⚠/✗] 至少指出1个框架风险 —— 依据：<具体风险+发生场次>
4. [✓/⚠/✗] 剧情点齐全，节奏档位明确 —— 依据：<场次数+每场节奏档位，有无塌陷>
5. [✓/⚠/✗] 讲戏本只写具体物理动作，情绪不直说 —— 依据：<逐场检查，有无"很难过"类直说，指出具体场次>
6. [✓/⚠/✗] 三张清单无遗漏 —— 依据：<人物/场景/道具数，对照剧情点核对>
7. [✓/⚠/✗] 详细剧本每场有地点/动作/对白/转场 —— 依据：<逐场核对缺哪要素>
8. [✓/⚠/✗] 台词锁定表完整（含口型/表演建议） —— 依据：<台词数+每条是否含口型建议>
9. [✓/⚠/✗] 用户原台词完全保留（如有） —— 依据：<用户原话vs剧本台词对照>
10. [✓/⚠/✗] 附创作笔记 —— 依据：<有无核心情绪/取舍/最不满意点>

真实问题（至少2⚠或1✗，必须可操作）：
- 问题1：<具体位置+具体改进方案>
```

## 阶段03：视频分镜脚本

### 前置条件

阶段02人工确认通过后，使用锁定台词、剧本、资产提示词进入阶段03。

### 目标

将剧本转为可直接用于 Seedance 2.5 视频制作的详细分镜脚本，含多模态版和纯文字版双版提示词。

### Seedance 2.5 专用规则

- 单次生成最长 30 秒，每段 4-30 秒（30 秒内任何值皆可，不强制拉满；复杂连续动作可完整铺满 30 秒不必硬切）
- 视频延长：已有 2.5 成片可"接续上一段"延长，每段 ≤30 秒，套娃延长总长 ≤60 秒
- 超长视频模式：完整短片/MV/预告片可一次性直出最长 180 秒（用户明确要求时启用）
- 每 30 秒最多 8 个镜头（动作密集段可放宽，需在审核报告标注镜头数与理由；15 秒内最多 5 个镜头原则不变）
- 默认 16:9 横屏
- 同时给多模态版和纯文字版
- 支持 @图片X/@视频X/@音频X/@音效X，必须说明用途（参考什么、不参考什么）；2.5 支持**迁移创意**（@视频可迁移深层情绪/镜头语言/创意网感，不止运镜）、**多人参考**（解决双胞胎/换脸错位，多人同框显式写各角色面部独立）、**音色参考**（@音频绑定声线）、**多宫格分镜参考**（输入线稿/火柴人分镜图）
- 不输出英文提示词/负向提示词/固定种子
- 2.5 新增分镜可用能力（按需声明）：绿幕编辑（抠像背景替换）、局部消除与编辑（移除特定物体）、空间视角修改（改机位外推空间）、视频无缝转场（两段视频自动补全间隙）、专业白模控制（工业级锁站位/轨迹）、去 BGM 仅留人声、纯净素材（无字幕无 BGM）、多语种对白与口型同步

### 子步骤

0. **整场全局规则（宪法 + 全局表演指导 · 各写一次）**：

   **① 场景调度宪法**（整场一次完整版 + 每段精简要点行）：为整场戏写一段全局规则块，锁定六项——机位轴线、人物朝向、镜头规则（单人优先）、光线规则（环境光唯一）、摄影参数（焦段×景别映射）、构图策略。**完整宪法整场只写一次**，放在分镜脚本开头；**每段提示词带两行**：`【宪法要点】`（六项各压成一行要点式，必须保留焦段mm/光圈/轴线锚点/光源名等关键数字与专名）+ `【本段微调】`（只写本段偏离项，无则写"无"），**不再逐字复制完整宪法**。详见 `04-motion-prompt.md` 场景调度宪法章节 + `16-craft-blocking.md`

   **② 全局表演指导**（**默认生效，不需用户开口要**）：与宪法并列，整场写一次——本片没有人站着摆拍，每个角色手上始终有事做（端杯/整理衣角/翻找口袋/摩挲物件边缘）；对话或对峙时一人行动、另一人反应、反应慢半拍；情绪不直说（先给隐藏目的 → 用大动作盖住真实反应 → 写成变化过程「先…停一拍…然后…」）；程度词克制（一点点/几乎察觉不到/迟半拍）；每镜小动作 1–2 个。**每段提示词必须另带 `【表演指导】` 栏**（位在 `【本段微调】` 之后、AI一致性约束之前），写本段落实情况；纯空镜/无人段写 `【表演指导】无（本段无人）`，**栏位不省略**。详见 `09-craft-performance.md` 的「活人感」章节（含中文/英文模板与各模型落点表）
1. **分段规划**：按剧情点拆分为单段（SD01/SD02/...，每段 4-30 秒，动作密集可铺满 30 秒不硬切；超过 30 秒主动建议"首段+延长段"或超长视频模式），每段标注时间/剧情点/内容/对抗元素。确定每段运镜基调时，参照 `08-craft-camera.md` 的十五大场景运镜模板选取匹配项（如"对峙/追逐/揭示/战斗"等），锁定该段的运镜走向与焦段区间。
2. **台词锁定与音画同步表**：每句台词绑定时间码/说话人/画面呈现/口型动作/后期音频字幕
3. **场次分镜详表**（每段）：
   - 场次功能/场景/情绪/空间调度图/连续性地图
   - 镜头表（时间码/镜头目标/画面动作/运镜构图/表演台词/声音后期/转场）
   - 镜头衔接检查表
   - 复杂场标记 ★：凡需画分镜图的复杂镜头在此标 ★，后续交由 `05-storyboard.md` 据此生成故事板图片提示词与视频提示词（一一对应，不另判分镜数）。
4. **双版提示词**（每段）：
   - **多模态版**：@人设引用 @场景引用 @道具引用 + 风格锚点 + 人物锚点 + 怪物/对抗锚点 + `【宪法要点】`/`【本段微调】`/`【表演指导】` 三栏 + 镜头逐条列表 + 台词音画同步说明 + 衔接说明
   - **纯文字版**：不含@引用，完整描述人物/场景/风格/台词/口型/动作/运镜/衔接，可直接复制到 Seedance 使用（同样必须含 `【表演指导】` 栏）
5. **首帧/末帧建议 + 制作备注**：每段首帧/末帧画面描述 + 配音/字幕/音效/混音/风险规避

### 运动提示词写法（每镜 · V4.5 重写）

每段提示词写成**五维融合的连续段落**（时间码 + 景别/焦段 + 运镜 + 具体动作 + 光线 + 音画），把电影技法焊进描写，不贴"加载XX"标签。完整方法论（含精准时间测算表、bad→good 范例、质量自检）见 `04-motion-prompt.md` 第三~九节；**时间测算基准表、2.5 能力速查、时长选择参考见 `17-seedance25-timed.md`**。

> **⏱️ 时间码计时规则（V4.5 明确 · V4.6 保留）**：时间码以 **SD 分镜段为单位，每段独立从 0 起算**；段内各镜头**累计计时**（镜头一 0-5s、镜头二 5-10s…）。**不同 SD 段之间不接续**——SD02 也从 0 开始（如标 `0-15s` 或 `0-30s`），SD03 再从 0 开始，依次类推。"五维融合连续段落"指时间轴融合于**本段内部**，绝非跨段连续计时；镜头/台词时间码同样用本段局部时间（如 `2.0-5.0s`），不写全局连续时间。该规则不因 Seedance 2.5 对齐而改变。

三个维度都覆盖到，但不分块罗列：
- **画面与动作**：人物做了哪个具体动作（哪只手/第几次/使没使上劲），情绪靠身体部位动作堆，不直说（技法来源 `09-craft-performance.md`，含**活人感**：小动作词库 + 反向表演三技巧，治"一眼 AI / 演得太用力"）。**活人感自 V4.9 起默认生效**——凡段内有角色，直接按 `【表演指导】` 栏写本段落实，不需用户开口要求
- **运镜与构图**：镜头怎么走（推/拉/摇/移/跟/环绕），**锁定焦段 mm（24/35/50/85）与构图类型**（三分法/引导线/对称等，来源 `08-craft-camera.md` + `16-craft-blocking.md`），遵守宪法锁定的摄影参数
- **光线与声音**：光线只来自环境、写具体光源方位色温（来源 `10-craft-lighting.md`）；台词/音效/音乐按 `11-craft-sound.md` 三条路落位，音效跟动作对位写进画面

> 编到对应维度时再把 `08/09/10/11/16` 读进来**学并应用**，不要把这些编号写进最终提示词——模型看不懂"加载08"，只看得到你写下的焦段、运镜、身体动作、光源方位。

## 阶段04：项目收尾与经验沉淀（不跳步）

> 三阶段之后的收尾环节。本节点没有文件系统与后台进程，收尾**只发生在对话与本 MD 产出里**：
> 不创建目录、不写 TXT、不维护信号文件；下面每一步都以"显式说出"为完成标准。

### 4.1 沉淀项目档案（强制）

把项目摘要写进本次交付的 Markdown（或随产出一起显式给出）：

1. 项目元信息（名称 / 类型 / 平台 / 画幅 / 时长 / 日期）
2. 一句话故事
3. 三阶段产出摘要（各阶段关键数字）
4. 关键制作决策（如拆段方案、交叉剪辑方案、降级方案）
5. 项目中暴露的问题和学到的东西
6. 产出清单

### 4.2 采集经验信号（强制）

复盘整个三阶段对话，在**对话中显式列出**三类信号：

1. **用户纠正信号**：用户明确说"不要这样"/"应该那样"的原话
2. **用户偏好信号**：用户主动表达的制作偏好（如"喜欢暖色调""不要社死喜剧"）
3. **制作经验信号**：遇到的技术限制和应对方案（如"交叉剪辑需后期拼合""超 30 秒需拆段或启用延长/超长模式"）

本条技能包为编译期内嵌只读文档，信号**不会跨会话留档**；写下来的意义是让用户当场确认，并让本轮后续判断与它保持一致。

### 4.3 用户反馈（可选 · 用户说"复盘"才触发）

> 默认不打断产出节奏。用户主动说"复盘 / 聊聊这次合作 / 有什么要改的"时才走这一节。

```
【项目反馈收集】

请帮我回顾一下这次「{项目名}」的合作，回答几个问题：

1. 三阶段产出中，哪部分最满意？哪部分最不满意？
2. 有没有什么你觉得我做得不够好的地方？
3. 有没有什么你觉得特别好的、希望我保持的做法？
4. 下次做项目，你希望我改进什么？
```

用户回答后，当场复述一遍你接收到的偏好与改进点，确认理解一致。

### 4.4 审核标准自检（强制）

收尾时检查本轮三阶段审核是否暴露了**审核标准的盲区**（审核通过了，但制作环节发现标准没覆盖到的问题）：

1. 回看本轮是否出现"审核标准缺失"类信号
2. 对照 12-film-review.md 现有 48 项检查项，确认本轮实际问题是否已有对应标准
3. 若发现盲区，向用户说明："本轮发现 N 处审核标准可补充"
4. 本节点不修改技能包本体文件；把盲区与建议明确写进回复，作为下一轮人审的候选改进项

> 审核标准是活文档，每个项目都可能让它长大。盲区不可怕，不补才可怕。

## 七条铁律（贯穿全流程）

1. **只写动**。画面交给参考图，提示词只写运动和变化。
2. **情绪靠动作堆**。别写"她很难过"，写具体肌肉动作。
3. **一致性靠参考绑定**。每份素材只绑一次，引用按 reference index 编号走。
4. **真人视频优先面部设计**。女性参考六维质控，男性参考骨相框架。
5. **资产编号 + 中文标注引用**。如 `@图片1（C01孙悟空·金甲红披风火眼金睛）`。
6. **光线只来自环境**（V4.1/V4.2 · AI视频防穿帮）。不单独给人物加光源，所有光从场景中的自然光源来，跨段不变。
7. **多人同框可控**（V4.1/V4.2 原为"单人镜头优先"，V4.5 按 Seedance 2.5 多人参考升级调整）。2.5 多人参考已解决"双胞胎/换脸错位"，多人同框可写清各角色独立面部特征（必要时 @多张人设图分别绑定）；但复杂群戏仍建议控制人数，关系交代尽量用短暂远景或正反打，保证切镜一致性。

## 两类经典镜头的写法

### 动作类镜头
写具体到**哪只手、第几次、有没有使上劲**。
- ❌ "他飞回飞船"
- ✅ "他伸出右手去抓栏杆，第一次没抓住，然后又抓了第二次，最后抱着 DOT 冲进了飞船"

### 情绪类镜头
走**单镜头一镜到底**，全程不切，微表情写到**肌肉动作**。
- ❌ "马拉听到女儿，然后就笑了"
- ✅ "视线慢慢移向那张儿童画，眼角紧绷的线条松开一点，可嘴角还没有完全笑出来，镜头就停在这儿"

# 01 · 输入路由

> 何时用：收到用户输入的第一刻。
> 依赖：无。
> 产出：明确输入类型 + 参考齐备性 + 经验库匹配结果。
> 验收：类型判对、参考齐备性检查过、相似案例已告知用户。

---

## 四种输入类型

### A · 想法
用户给一句话，没有参考视频。
→ 解析关键词（题材/时长/画风/平台），查经验库找相似案例，进入剧本拆解的「创意发散」。

### B · 参考视频
用户给一条链接（抖音/B站/快手/视频号）。
→ 先问：自动下载抽帧解析 还是 仅作风格参考输入。
- 自动下载：调下载工具拉取 → 抽帧 → 解析镜头/节奏/配色/台词 → 输出拆解报告 → 进入创意发散。
- 仅作参考：让用户口述参考视频的关键信息（题材/节奏/镜头/时长/画风），据此生成。

### C · 现成剧本
用户给一份剧本文件，要套资产 + 视频提示词。
→ 跳过创意发散，直接进入剧本拆解。

### D · 迭代既有项目
用户在已有项目上改。
→ 加载项目档案，判建 or 改（多数是改），定位要改的资产/镜头。

---

## 参考齐备性检查

按第一性原理，开工前确认四类参考：

| 类型 | 必备度 | 缺失处理 |
|---|---|---|
| 创意参考（想法/题材/vibe） | 必备 | 停下问用户 |
| 参考视频 | 可选 | 没有不影响 |
| 风格参考图（角色/场景/色卡/vibe 图） | 必备 | 没有先建一套 |
| 既有项目档案 | 多集必备 | 没有首次建 |

---

## 经验库查询

每次激活，按题材/画风/钩子回顾两处已有信息：
- 本节点对话历史中用户已确认的偏好与纠正
- 用户在本项目里已经给过的画风/平台/时长等配置

存在明显相似的既往项目或既定偏好时，主动告诉用户「上次的做法是这样的，要沿用吗？」

# 02 · 剧本拆解

---

## 第一步：采集项目配置

最贵的一样东西叫**导演视野**——这部片用什么作者风格去讲：写实克制、奇观尺度、还是冷峻精密。可以挂一位导演或摄影师的署名当锚（如 Greig Fraser Dune 2021）。视野立稳，后面所有环节都服从它。

采集项：
- 导演视野（作者风格 + 可选署名锚）
- 画面类型（3D国漫 / 真人写实 / 2D动画）
- 画幅（16:9 / 9:16 / 21:9）
- 平台（抖音 / B站 / 视频号 / YouTube）

---

## 第二步：拆成剧情点

把剧本拆成一个个**剧情点**，每个点定：

- 落在哪个人物 / 场景
- 节奏意图（蓄力 / 张 / 弛 / 高潮 / 收束）
- 数节拍（这一拍多长）
- 预算气口（留白和反应停顿单独预算，不是凑时长的余数）
- 落时长（时长跟内容走，默认偏短，15 秒是上限不是目标）

> 节奏的底层规律：时长跟着内容走，默认偏短。留白和反应停顿本身就是戏，要单独预算。一镜到底优于切镜。

---

## 第三步：提三张清单

从剧情点里提：

- **人物清单**：角色名 / 身份 / 外观锚（一句话）/ 是否已有 ref / 强弱关系
- **场景清单**：场景名 / 环境一句话 / 是否需建场参考图 / 是否双人对话场景（需关系板）
- **道具清单**：名称 / 类型 / 形态命门 / 数量锁

这三张清单是后面所有环节的**单一真相源**。源头有遗漏，会顺着流程一路污染下游。

---

## 第四步：写讲戏本

每个剧情点底下跟一段从导演视角写的**讲戏**：

- 画面里有什么
- 人物做了哪个具体动作（揉太阳穴，不是"表现疲惫"）
- 谁说什么
- 镜头怎么走
- 光从哪儿打
- 要让人感觉到什么（靠动作和环境托，不直说）

讲戏有纪律：只写镜头拍得到的具体物理动作。情绪不直说。

# 03 · 资产设计

> 何时用：讲戏本审过后。
> 依赖：讲戏本的三张清单 + 导演视野。
> 产出：角色 / 场景 / 道具的设定图提示词，每张嵌同一段全片视觉风格基准。
> 验收：三张清单全覆盖、每张嵌视觉风格基准、参考素材绑定规范、可直接复制使用。

---

## 核心：风格提示词前置锁定（全片最高优先级）

每张设定图提示词开头都嵌**同一段**风格提示词——就是剧本拆解时定下的"这部剧的类型和风格描述"。

**风格提示词由三部分组成：**
1. **剧类型**：如 3D古风神话动画 / 中国古风修仙玄幻动态漫 / 现代都市悬疑短剧 / 赛博朋克科幻短剧
2. **画风特征**：如 三维写实渲染高质量CG / 二次元赛璐璐 / 真人写实电影感
3. **画面要求**：如 16:9横屏、人物保持一致性、场景一致性、画风画面调色一致性

**风格提示词一旦确定：**
- 必须作为全片最高优先级风格锚点
- 后续所有角色人设图、三视图、多视图、场景图、道具图、首帧图、Seedance视频提示词，都必须把完整风格提示词放在提示词最前面
- 逐字复用，不得省略、改写、拆散或替换
- 不同角色/场景/道具只能在风格提示词后追加各自内容

---

## 资产隔离与复用总则

- **角色资产卡**只写主体角色的脸、发型、服装、配饰、特殊状态和表演气质；手持武器/法宝/证物一律另建道具卡
- **场景资产卡**写场景空间、材质、光线、天气、氛围人物和非剧情性摆设；氛围人物不得写成具名主角
- **道具资产卡**只写静物，不出现人物或人手
- 分镜镜头中允许把角色、场景、道具组合调用，但必须引用资产ID并继承对应锚点
- 资产图提示词可使用"8K、超高清、电影级材质"等生图描述；Seedance 2.5 视频提示词仍必须用自然语言

---

## 三个并行

- **character-design**：取人物清单，出角色人设提示词（真人视频优先面部设计，详见下文「真人视频角色面部设计」）
- **scene-design**：取场景清单，出场景**八层结构**图提示词 + **场景多宫格视角**（详见下文「场景多宫格视角」）
- **prop-design**：取道具清单，出关键道具**资产卡**提示词

三并行，互不阻塞。

---

## 角色人设提示词（四种 · 必须全出）

每个 CHxx 角色都必须输出四种人设提示词，可直接复制生图。

### 真人视频角色面部设计（优先级最高）

**当画面类型为「真人写实」时，角色面部设计优先于服装和场景。** 面部是真人视频一致性的命门——脸不对，穿什么都没用。

#### 女性角色面部设计

参考 `beauty-prompt-generator` skill 的六维质控框架。女性角色的「第一种：角色描述提示词」中，[基础面容锚点] 必须按以下六维写：

1. **面部质感**：肤质（冷白/暖白/小麦/古铜）、肤感（哑光/水光/奶油肌）、毛孔质感（保留真实毛孔/精修无瑕）、面部光泽点（颧骨高光/鼻梁高光/T区光泽）
2. **光源**：主光方向（镜头左/右/上/下）、光质（硬光/柔光/混合光）、光比（高对比/低对比）、色温（暖光/冷光/中性光）、补光（是否需要补光、补光方向）
3. **场景**（面部特写时的背景）：虚化背景/实景背景/纯色背景、背景色调与人物肤色关系
4. **动作**（面部微表情）：眼神方向（直视/侧视/俯视/仰视）、嘴角状态（微扬/平直/微抿/半笑）、眉毛状态（舒展/微蹙/上扬）、头部角度（正/微侧/3/4侧）
5. **表情**（不直说情绪，写具体肌肉）：如"眼角紧绷的线条松开"而不是"她很欣慰"
6. **景深**：大光圈虚化（shallow DoF / wide aperture / background heavily out of focus）、焦外质感（bokeh 形态）、锐焦区域（眼睛/睫毛/唇）

> 女性角色面部设计的完整模板与变量词库详见 `beauty-prompt-generator` skill 的 `references/prompt_template.md`。

#### 男性角色面部设计

参考「男子骨相级提示词」的骨相框架。男性角色的「第一种：角色描述提示词」中，[基础面容锚点] 必须按以下骨相结构写：

1. **脸型与骨相**：脸型（窄长脸/硬朗国字脸/精致菱形脸/清瘦型脸）、脸宽（适中偏窄）、纵向比例（修长）、面部骨骼感（明显但不粗犷）、下颌线（清晰锐利）、下颌角（存在感明确但不过度方硬）、下巴（线条利落偏方但不笨重）
2. **额头**：额头形态（中等偏饱满/硬朗开阔/光洁平整）、发际线（整齐自然）、太阳穴（饱满不凹陷）
3. **眉眼**：眉色（深棕黑/自然黑/深灰）、眉形（剑眉平直带上扬走势/眉峰偏锐/眉尾收紧）、眉骨（微微隆起形成轻微阴影）、眼型（狭长深邃/锐利鹰眼/冷感丹凤眼/深沉桃花眼）、眼裂（偏长偏窄）、内眼角（尖且深邃）、外眼角（轻微上扬）、双眼皮（较窄或内双）、眼窝（适度深度）、眼神（直视镜头/冷峻/锐利/审视/压迫感）
4. **鼻型**：山根（挺拔自然顺接眉骨）、鼻梁（直挺有力）、鼻背（宽度适中）、鼻头（轻微方感但不粗大）、鼻翼（适中不外扩）
5. **唇形**：唇峰（线条明确不过分雕刻）、上唇（偏薄）、下唇（微厚于上唇但不饱满）、嘴角（自然平直或极轻微下压）
6. **肤质与妆面**：肤色（冷调自然/健康小麦偏冷/冷调象牙白）、肤感（高完成度哑光、保留男性轻微毛孔质感）、妆面（"无妆感"高级男性修饰妆）、胡茬（极短青色胡茬/干净一日未剃/无明显胡茬）

> 男性角色面部设计的完整变量填充规则详见 `E:/桌面20260606/各种bot/0508短剧分镜提示词/男子骨相级提示词bot.txt`。

#### 真人 vs 非真人的区分

| 维度 | 真人写实 | 3D国漫/2D动画 |
|---|---|---|
| 面部优先级 | **最高**（脸是命门） | 与服装/场景同等 |
| 面部写法 | 六维质控（女）/ 骨相框架（男） | 基础面容锚点 |
| 毛孔质感 | 必须保留真实毛孔 | 不需要 |
| 妆面 | "无妆感"高级修饰 | 按画风定 |
| 参考图 | 必须绑面部参考图 | 可选 |

### 场景八层结构图（主参考图）

### 场景多宫格视角（参考 scene-multiview-prompter skill）

主参考图出完后，为主要场景生成**多宫格视角参考图**——把同一三维空间从多个标准视角投影出来，供分镜拍摄时引用。

**双模式选择（询问用户）：**

| 模式 | 布局 | 视角组合 | 一致性 | 信息完整度 | 适用 |
|---|---|---|---|---|---|
| 4宫格（推荐） | 2×2 | 俯拍/正向/左侧/右侧 | 高 | 中 | 分镜空间还原、一致性优先 |
| 6宫格 | 2×3 | 俯拍/正向/后视/左侧/右侧/鸟瞰 | 中 | 高 | 复杂场景、需看背面、需纵深 |

**多宫格提示词格式：**


## 场景调度宪法（总规定调度）· V4.1 新增 · V4.8 改为「整场一次完整版 + 每段精简要点行」

> **在写任何逐镜提示词之前，先为整场戏写一段"场景调度宪法"——全局规则块，锁定整场戏的摄影铁律。**
> **宪法在整场只写一次完整版**（放在分镜脚本开头的「本场宪法」区，六项齐全，见下方范例）。
> **每段逐镜提示词不再逐字复制完整宪法**，改为两行：
> ① `【宪法要点】` —— 六项各压成一行要点式短语（标准写法见本节末）；
> ② `【本段微调】` —— 只写本段相对宪法的偏离项（如"本段走遮挡越轴（遮挡物：石柱）"），无偏离写"无"。
>
> **V4.8 变更理由**：V4.3 要求每段逐字复制六项（约 200-300 字），导致段段重复同一段文本，与本 skill
> 第一性原理「提示词短而可跟随」直接冲突；重复文本还会稀释动作/运镜等真正影响生成的信息权重。
> 改为"前置一次 + 精简要点行"后，模型仍能拿到全部锁定项，且每段提示词的有效信息密度提升。

场景调度宪法必须包含以下六项（缺一不可）：

### 1. 机位轴线锁定
确定本场机位轴线（如"擂台中心→角色A落点→角色B站位"），摄影机固定在轴线同一侧拍摄，绝不越轴。如需越轴，必须使用合理越轴方法（详见 16-craft-blocking.md）。

### 2. 人物朝向规则
写清每个角色面朝哪个方向、看向谁。正反打保持同一侧机位逻辑。

### 3. 镜头规则（AI视频策略 · V4.5 按 Seedance 2.5 调整）
- **默认单人镜头优先**：复杂群戏仍建议单人镜头优先，两人关系多用短暂远景/正反打交代。
- **2.5 多人同框可控**：Seedance 2.5 多人参考升级已解决"双胞胎/换脸错位"，如需清晰多人同框，提示词显式写"各角色面部特征独立、不趋同、不换脸错位"，必要时 @多张人设图分别绑定；但切镜一致性仍靠参考图，不要反复描述长相。
- 正反打走单人镜头，不用过肩双人同框（除非明确要走多人对峙且已声明独立面部）。

### 4. 光线规则
- **所有光线只来自环境**：人物光线只来自场景中的自然光源（阳光、月光、火光、石面反光等），不单独给任何人物加光源
- 光线方向、色温、强度必须与场景设定一致，跨段不变

### 5. 摄影参数
锁定本场焦段×景别映射和光圈范围：
- 24mm 建场远景 / 35mm 人物中景 / 50mm 表情近景 / 85mm 手部特写
- 光圈 f/2.8–f/4，电影级写实修仙短剧质感（可按题材调整）

### 6. 构图策略
根据场景类型选择构图方案（详见 16-craft-blocking.md 十二种构图），并在宪法中锁定。

### 宪法范例

```
总规定调度：
机位轴线锁定：本场机位轴线固定为"擂台中心对战区→角色A落点→角色B站位"。
摄影机固定站在轴线的右前侧同一侧拍摄，绝不越轴。
人物朝向规则：角色A飞落后面向角色B方向说话，角色B面向角色A方向站立等候；
正反打保持同一侧机位逻辑。
镜头规则：严格单人镜头优先，不拍多人清晰同框；两人关系只用短暂远景交代，
主要使用角色A单人近景和角色B单人反应镜头。
光线规则：人物光线只来自黄昏晚霞自然光、擂台石面反光、剑身微弱反光，
不单独给任何人物加光源。
摄影参数：24mm擂台远景建立空间，35mm人物中景，50mm表情近景，
85mm手部与储物袋特写；光圈f/2.8–f/4，电影级写实修仙短剧质感。
```

### 宪法要点行标准写法（V4.8）

六项压成一行，用 `｜` 分隔，只保留可执行的关键约束——**关键数字与专名一个不能少**：

```
【宪法要点】轴线 擂台中心→A落点→B站位·摄影机右前侧不越轴｜朝向 A面向B·B面向A·正反打同侧｜镜头 单人优先·关系用短暂远景｜光 仅黄昏晚霞+石面反光·不加人物光·方位色温跨段不变｜参数 24/35/50/85·f2.8-4｜构图 三分法
【本段微调】无
```

- **六项一项不能少**（轴线 / 朝向 / 镜头 / 光线 / 参数 / 构图），缺项即违规。
- **要点行必须保留数字与专名**：焦段 mm、光圈值、轴线锚点、光源名。写成"见宪法""同上"这类空引用违规。
- `【本段微调】` 只写偏离项；"本段全部服从宪法"就写"无"，不得省略该行。

> 宪法写完后，整场只保留这一段完整版（放在分镜脚本开头）；每段逐镜提示词带 `【宪法要点】` + `【本段微调】` 两行，然后在动作描述里只需写"时间码+焦段+景别+动作"。

## 视频提示词怎么写到"能用"（核心方法论 · V4.5 重写 · V4.6 对齐 2.5）

写视频提示词不是填模板，也不是把知识库当标签贴上去。**你要做的是：把电影技法（运镜/表演/光影/声音/轴线构图）先学进脑子，再焊进每一句描写**——让 Seedance 读到的每段文字都是"摄影师能直接拍"的具体指令。

`08/09/10/11/16` 这几本工艺词库是你的"技法弹药库"：**编到对应那一维时读进来、把它变成你笔下的具体写法，而不是在提示词里写一句"加载08"**。模型看不懂"加载08"，它只看得到你写下的焦段、运镜、身体动作、光源方位。

### 一、先算秒：精准时间测算（每一秒都该有不可替代的价值）

算力宝贵。每段先把时间账算清，避免又超又注水。逐项测算、展示过程、不跳步。

**测算维度与基准：**

| 维度 | 基准（取中值） |
|---|---|
| 台词口播 | 普通 3-4 字/秒；情绪/古风 2-3 字/秒；气声/耳语 1.5-2 字/秒；停顿 0.5-1 秒/次 |
| 表情与表演 | 简单表情 0.5-1s；关键眼神/对视 1-2s；微表情特写 ≥1-2s |
| 身体动作/走位 | 转头回身 1-2s；走位一步 0.5s；拔剑/推门 1-2s；单手交手一击 1-2s；连续交手(2-3回合) 3-5s；倒地/坠落 1.5-3s |
| 道具交互 | 拿起/递交/特写 1-2s |
| 运镜与衔接 | 定场/环境建立 1-2s；推/拉 1-3s；摇/移 1-2s；跟拍同步主体；硬切 0-0.5s；淡入淡出 1-2s |
| 首帧承接 | 建立空间方位 1-2s |
| 末帧钩子 | 停留 1-2s |

> 一句台词 >8 秒说不完 → 按自然停顿拆到多镜/多段，但原文不改。
> 测算总时长 > 规划时长 → 先延长到 30s 上限（2.5 单次可达 30 秒）→ 仍不够则建议拆成"首段+延长段"（套娃延长总长 ≤60 秒）或超长视频模式（≤180 秒）→ 减次要动作/反应镜 → 删原创建议台词 → 用户原文按停顿拆下一段（原文绝不删改）。
> 测算总时长 < 规划时长 → **不要注水**，空余交给画面自然节奏（4-30 秒内任何值皆可，不强制拉满）。

### 二、把技法焊进描写（学知识库，不搬标签）

下面逐维演示"差写法 → 好写法"。好写法的共同特征：**具体物理动作 + 显式运动方向 + 可对照量 + 焊进电影技法**。

**运镜（来源 `08-craft-camera.md`）**
- ❌ "镜头推进，很有电影感"
- ✅ "稳定器匀速正推，从 35mm 中景在 3 秒内推至 50mm 面部近景，焦点始终锁在瞳孔，背景虚化；情绪=渐渐逼入人物内心"（用了焦段映射 + 推镜情感 + 可对照量"3秒"）
- 打斗/对峙段优先套 `08` 十五大场景模板（如"13.动作戏打斗场面：手持环绕+升格特写+快速剪辑"），选完把具体运镜写进描写，不要只写模板名。

**表演（来源 `09-craft-performance.md`）**
- ❌ "孙悟空很愤怒"
- ✅ "孙悟空下颌绷紧，眉心金光骤亮又压下去，垂在身侧的手指攥成拳、指节发白，再松开时拳锋已在金箍棒上敲出一点火星"（情绪靠身体部位动作堆，不直说；强者平静——他是压着怒在发力）
- 走位写体位：谁立/谁俯视谁、目光锁在谁脸上，漏写模型默认全员齐高站直。

**光影（来源 `10-craft-lighting.md`）**
- ❌ "暖光，氛围感"
- ✅ "暖橙赤云辉光从画面右上方斜泻，孙悟空右半脸亮、左半脸暖影（非死黑），高光点在颧骨与锁骨，浅景深背景虚化；不单独给人物加光源，光来自环境赤云"（光源四件套：方向+半脸光+高光点+虚化；遵守环境光唯一）
- 每段光源方向/色温/强度跨段不变，这是防穿帮的关键。

**声音（来源 `11-craft-sound.md`）**
- 音效原生写进画面内容、跟动作对位（写在动作后括号里）："棒底顶中异兽胸口，撞出闷响与鳞甲碎裂声（低频轰鸣+碎裂脆响）"
- 台词时间码精确到 0.1s，情绪用具名（咆哮/气声/低语），不写"很激动"
- BGM 强拍对齐镜头切换点（强拍切大场面、弱拍延氛围）

**轴线/构图（来源 `16-craft-blocking.md`）**
- 宪法已锁轴线；描写里走位/切镜一律在轴线同侧，越轴只走合理越轴五法（遮挡法最常用）
- 构图用十二种之一 + 四位一体公式：`景别 + 运镜 + 构图 + 情绪`。例："85mm 特写 + 缓慢推镜 + 向心式构图（异兽巨头占满画面压迫）+ 恐惧窒息感"

### 三、五维融合的连续段落（最终输出形态）

每段提示词正文写成**一段融合的自然散文**，把五个维度焊在同一时间轴上，不分块罗列——这才是 Seedance 真正吃进去、能拍出好画面的格式：

```

       三人只占下方小比例，孙悟空右手下意识抓空、指尖虚攥（表演：落空余势），
```

### 六、台词锁定与音画同步

如果用户给了台词，台词处理优先级高于改编润色。
- **原文锁定**：逐字保留，不翻译、不改写、不润色、不删减、不合并
- **说话人锁定**：每句绑定唯一说话人
- **时间码锁定**：精确到 0.1s，标开口/重音/闭口位置
- **口型可见**：关键台词安排正面或 3/4 侧面中近景/特写
- **音画同步**：口型、表情、动作重音、配音、字幕与台词时间码一致

### 七、镜头衔接连续性协议

分镜之间必须前后顺畅，不能出现人物站位、朝向、视线、道具位置、运动方向、光线方向在下一镜头突然错乱。
每个生成段必须设计**连续性地图**：
- **空间轴线**：对话/对峙/打斗先确定人物关系轴线，后续不越轴
- **人物站位**：每镜标注人物在画面中位置，下一镜继承
- **朝向与视线**：写清面朝方向、看向谁，切反应镜头时视线对应
- **运动方向**：从左到右跑，下一镜延续同方向
- **动作接点**：上一镜"手握住剑柄刚要拔出"→下一镜"剑刃从鞘中完全抽出"
- **道具状态**：在谁手里/哪只手/是否破损，下一镜延续
- **景别递进**：全景切中景只改距离不改位置
- **光线天气**：同场景切镜主光源方向/雨雾风/阴影方向一致
- **转场理由**：每次切镜说明为什么切（动作接点/视线接点/声音接点/遮挡转场）

- [ ] 轴线是否全程不裸越轴、多人同框已声明各角色面部独立（2.5 多人参考升级）、默认单人镜头优先？
- [ ] 是否同时给了多模态版 + 纯文字版？
- [ ] 复杂场是否标★、会由 05 输出图片+视频双提示词？

### 十、闸：审核运动提示词（按档位：标准档主agent自审清单 / 严格档独立审核agent）

- 第一阶段：镜头齐不齐、有没有死引导、参考绑定规范、风格提示词前置、宪法要点行完整
- 第二阶段：只写动（没在描述长相）、可跟随性、演出时长测算通过、工艺质量（技法是否焊入而非贴标签）、防漂移

> 审核员审运动提示词时，也把剧本拆解读一遍，跟原始讲戏本对照着审会更准。

# 05 · 分镜

> 何时用：运动提示词审过后。
> 依赖：运动提示词已定的镜头 + 标 ★ 的复杂场 + 风格提示词 + 资产索引。
> 产出：复杂场的故事板**图片提示词** + **视频提示词**（双输出，可直接复制使用）。
> 验收：只给复杂场、与运动提示词一一对应、宫格位置锁定、风格提示词前置、资产编号+中文标注引用。
> **不需要用户再选宫格/风格/时长——直接根据前面的剧本和风格自动确定。**

---

## 核心：分镜板是给人看的，不是直接喂模型的

精心画的分镜板直接丢给模型，视频里会渲出分格框、箭头、文字——模型把分镜板本身当成要画的东西了。

**分镜图的作用**：把走位和动作序列说清楚，连同参考图一起喂模型当走位参考。分镜图与分镜提示词一一对应（镜头一对镜头一），模型才知道你到底要什么。

---

## 自动确定参数（不需要用户再选）

分镜阶段的宫格类型、风格、时长**全部从前面的剧本拆解和运动提示词自动继承**，不需要用户再选：

| 参数 | 来源 | 自动确定规则 |
|---|---|---|
| 风格提示词 | 剧本拆解时锁定 | 逐字复用，不得改写 |
| 宫格类型 | 运动提示词标 ★ 的复杂场 | 按镜头数自动选：≤4镜=4宫格 / 5-6镜=6宫格 / ≥7镜=9宫格 |
| 时长 | 运动提示词已定 | 该段规划时长自动继承 |
| 资产编号 | reference index | 自动引用 C01/S01/P01 等 |
| 台词 | 台词锁定表 | 自动继承，逐字复用 |

> 如果用户主动要求改宫格类型，可以改；否则按自动规则走。

## 哪些场要分镜图

照运动提示词里标 ★ 的镜头走。只给复杂场画，简单的一镜到底不画。

复杂场的判断标准：
- 多角色同框的打斗 / 对峙
- 复杂走位（多人移动 / 阵法 / 围合）
- 多机位切镜的分镜头序列

## 宫格位置编号规范（锁定规则）

宫格位置编号严格按"从左到右、从上到下"，提示词与位置一一锁定：

### 4宫格（2×2）
```
┌───────┬───────┐
│   1   │   2   │   左上 / 右上
├───────┼───────┤
│   3   │   4   │   左下 / 右下
└───────┴───────┘
```

### 6宫格（2×3）
```
┌───────┬───────┬───────┐
│   1   │   2   │   3   │   左上 / 中上 / 右上
├───────┼───────┼───────┤
│   4   │   5   │   6   │   左下 / 中下 / 右下
└───────┴───────┴───────┘
```

### 9宫格（3×3）
```
┌───────┬───────┬───────┐
│   1   │   2   │   3   │   左上 / 中上 / 右上
├───────┼───────┼───────┤
│   4   │   5   │   6   │   左中 / 中中 / 右中
├───────┼───────┼───────┤
│   7   │   8   │   9   │   左下 / 中下 / 右下
└───────┴───────┴───────┘
```

锁定原则：每个位置编号对应且仅对应一段提示词，禁止错位、漏位、越位。

## 时长测算（自动继承）

时长从前面的运动提示词自动继承，不需要用户再选。如果需要在分镜阶段测算每格台词字数预算：

```
单格时长 = 该段规划时长 T ÷ 镜头数 N
单格画面留白 = 0.5 秒
单格台词可用时间 = (T ÷ N) - 0.5
单格台词字数预算 = 单格台词可用时间 × 3.5 字/秒（戏剧化语速）
```

超时处理：若某格台词超出预算×1.5，标记需精简；超出×2，必须精简。

## 与运动提示词一一对应

分镜图与分镜提示词**严丝合缝地配套**：镜头一对镜头一、镜头二对镜头二。

正确做法：一个镜头对应一条分镜提示词，模型才知道你到底要什么。

> 利弊：约束强了画面听话，但丢掉了一些惊喜和模型的创造力。怎么取舍看你实际创作过程中的抉择。

# 06 · 批量生成

> 何时用：分镜审过后。
> 依赖：所有提示词 + 参考素材 + 分镜图。
> 产出：图 + 声（+ 可选视频）。
> 验收：按依赖拓扑出图、出声平铺、样片先行。

---

## 出图：按引用依赖拓扑排序分波

先出无依赖的（角色/场景/道具设定图），再用它们当参考图出分镜图。全程在出图层把一致性锁住。

```
波 1：角色设定图（无依赖）
波 2：场景设定图（无依赖）
波 3：道具设定图（无依赖）
波 4：分镜图（依赖波 1-3 当参考图）
```

> 这一步又长又重，几十张图，跑起来要个把小时。

---

## 出声：平铺生成

- **台词配音**：单独生成，当参考音频喂模型
- **音乐**：单独做，不进提示词，后期铺
- **音效**：原生写进提示词，跟片一起出

声音分三条路：
1. 音效 → 写进运动提示词的【画面内容】，跟片一起出
2. 台词配音 → 单独生成，当参考音频喂模型
3. 音乐 → 单独做，后期铺

---

## 出视频（可选）

前五步交付的是提示词加参考素材。视频你可以：
- 自己拿去即梦官网出
- 让即梦 CLI 自动出（逐条提交、样片先行、异步轮询下载）

> 这步烧积分，不出也不影响前面的完整交付。一定要**样片先行**，确认了再全量跑。

---

## 样片先行（重要）

出图出片前先审后渲。**出片尤其烧积分**，一定要先出 1-2 条样片确认质量，再全量跑。

> Seedance 2.5 单次最长 30 秒、套娃延长可达 60 秒、超长模式可达 180 秒，积分比 2.0 更贵，一条十几秒的镜头 1080p 就要小一百块。如果不看一眼就让它全量跑，大几百块可能一下子就出去了。

样片确认 OK 后，再按引用依赖拓扑排序全量出图 + 平铺出声。

---

## 真实世界可演绎性（决定抽卡成功与否的核心）

除了写提示词的技巧和搭建整体的 harness 以外，决定抽卡成功与否最大的核心是：**我们要生成的这个视频的内容，是否可以在真实世界中被演绎**。

换句话说，就是模型在训练的时候有没有训练到相关的素材。

如果你给它一个比较抽象、连它都没见过的镜头，那这个时候生成的难度和成功率就可想而知了。

> 这应该不算是一个冷知识，但是你在生成的时候脑子里一定要清楚。

---

## 闸：审核批量生成（按档位：标准档主agent自审清单 / 严格档独立审核agent）

- 第一阶段：图齐不齐、声齐不齐、有没有漏镜
- 第二阶段：一致性过不过（脸有没有串）、画质达标

# 07 · 出视频（可选）

> 何时用：批量生成完成后，可选步骤。
> 依赖：所有提示词 + 参考素材 + 分镜图 + 音频。
> 产出：视频成片。
> 验收：样片先行确认后全量出。

---

## 三种出视频方式

| 方式 | 特点 | 适用 |
|---|---|---|
| **即梦 CLI** | 全自动跑完，过程看不见 | 配置定死、提示词写死、走开不管 |
| **即梦官网** | 灵活，可边看边改提示词和参考图 | 一条条抠细节、新手起步 |
| **自由画布**（如小云雀） | 素材平铺，连接节点串联 | 有基础想升级工具 |

---

## 即梦 CLI（全自动）

1. 主控先调用 video-render Skill
2. 检查即梦 CLI 是否可用 + 会员积分够不够
3. 授权请求（用户授权）
4. 按 motion prompt + 参考素材 + 音频批量生成
5. **先出 2 条样片**给用户确认
6. 样片 OK 后全量跑，异步轮询下载

> 短板：整个过程你是看不见的。如果配置没定死、提示词没写死，不建议用。

---

## 即梦官网（手动灵活）

1. 打开即梦官网
2. 每条 motion prompt 整条复制到输入框
3. 按参考设定的 @ 标位置替换好角色/场景/道具/音频参考图
4. 逐条生成、边看边改

> 优势：提示词、参考图你可以边看边改。新手建议从这里起步。

---

## 自由画布（节点串联）

1. 把所有素材（图+音频）一次性上传到画布
2. 用连接节点的方式把素材串起来
3. 每条镜头贴 motion prompt
4. 按三块成品（参考设定/氛围画质/画面内容）填好
5. 如果用到故事版，标"走位分镜图"，按故事版走位来

> 优势：比 CLI 灵活（看得见过程），比官网强大（不止在输入框敲提示词）。

---

## 故事版的正确用法（重要）

很多人直接把故事版上传给 Seedance 2.5，然后希望它能出一条视频，提示词随便写。结果出来的画面和故事版对不上。

**正确方法**：一个镜头对应一条分镜提示词。

```
镜头一提示词：黑物质爬索
故事版第1格：守卫者用昆虫形态爬上来

镜头二提示词：马拉举扳手迎击
故事版第2格：画的正是这个动作
```

对应关系非常清楚，只有这么干，你才算把自己到底想要什么清清楚楚地告诉模型，再加上故事版兜着走位，出来的剧情才有约束，不会乱跑。

> 利弊：约束强了画面听话，但丢掉了一些惊喜和模型的创造力。怎么取舍看你实际创作过程中的抉择。

---

## 画面质感决定调性

一张 hero image（英雄分镜）几乎可以决定整条视频百分之七八十的调性。

> 如果不考虑成本，用 Midjourney 出一张极具风格化的高质量分镜图，再配上故事版+提示词的方法去生成最终的视频，质感会拔高一个高度。

---

## 剪辑（最后一步）

生成的视频片段上传到剪辑软件（如剪映），按 motion prompt 排好先后顺序：

1. 粗剪一遍，哪几帧哪几秒看不顺就替换
2. 一条废片里偏偏那两三秒是好的，挑出来补进去
3. 铺上音乐
4. 一点一点磨

> 剪辑要看个人功力。简单拼一拼铺个音乐也能看，但要那种质感，得看剪辑功夫 + 抽卡运气 + 写提示词的功夫 + 审美，几样凑齐才能出得来。
>
> 也可以用 Claude Code 或 Codex 帮你自动剪。

# 08 · 工艺·运镜词库

> 何时用：编运动提示词的【运镜与构图】时按需加载。
> 依赖：无。
> 产出：运镜词汇、焦段映射、构图公式、场景模板。

---

## 焦段×景别标准映射表

AI 视频中，焦段数字比"近景""中景"更稳定——模型对"50mm"的理解比对"近景"更精确。

| 焦段 | 景别 | 用途 | 光圈 |
|---|---|---|---|
| 16-24mm | 大远景/远景 | 建场、空间关系、环境交代 | f/4-f/5.6 |
| 24mm | 全景/远景 | 建立空间、人物与环境关系 | f/2.8-f/4 |
| 35mm | 中景 | 人物对话、上半身动作、互动关系 | f/2.8-f/4 |
| 50mm | 近景 | 面部表情、情绪聚焦、人物刻画 | f/1.8-f/2.8 |
| 85mm | 特写 | 手部细节、道具特写、表情微动作 | f/1.4-f/2.8 |
| 85mm+ | 大特写 | 瞳孔、嘴唇、微观细节 | f/1.4-f/2.0 |

> 默认光圈范围 f/2.8–f/4，电影级写实景深。需要浅景深用 f/1.8，需要全景深用 f/5.6。

## 七大基础运镜

如同字母构成单词，推、拉、摇、移、升、降、跟是构建所有复杂视觉叙事的基石。

### 1. 推（Push In / Dolly In）

- 定义：摄影机沿光轴方向向被摄主体物理靠近
- 画面效果：景别从松到紧（全景→中景→特写），主体被突出和放大
- 情感效果：紧张感、期待感，引导深入人物内心，强调关键细节或情绪转折
- 适用：人物内心独白、发现关键线索、情绪爆发前奏、强调重要对白
- 分镜范例："稳定器正推，从中景匀速推至人物面部特写，焦点始终锁定眼神，背景灯光逐渐虚化，推镜时长3秒"

### 2. 拉（Pull Out / Dolly Out）

- 定义：摄影机沿光轴方向远离被摄主体
- 画面效果：景别从紧到松，环境信息不断展开，主体在画面中逐渐变小
- 情感效果：疏离感、结束感、释怀感，展现人物的孤独与渺小
- 适用：场景结束、人物离开、展现宏大环境、情绪回落
- 分镜范例："轨道跟拉，从人物近景匀速拉开至城市全景，人物逐渐融入夜色，拉镜时长4秒，以环境空镜结束"

### 3. 摇（Pan 水平 / Tilt 垂直）

- 定义：摄影机位置固定，机身沿水平轴（Pan）或垂直轴（Tilt）旋转
- 画面效果：水平或垂直扫描空间，揭示画外信息，保持空间连续性
- 情感效果：建立期待（跟随运动物体），模拟人物主观视线，客观展示空间关系
- 适用：跟随行走人物（Pan）、展示高大建筑（Tilt Up）、从天空摇到地面（Tilt Down）
- 分镜范例："三脚架固定，水平摇镜头（Pan），从左至右跟随奔跑的人物，保持人物在画面左侧1/3处，摇速与人物速度匹配"

### 4. 移（Truck / Track）

- 定义：摄影机在水平方向上平移，运动方向与光轴垂直
- 画面效果：侧面跟随主体，或展示横向空间关系，画面透视持续变化
- 情感效果：创造速度对比，平稳地推进叙事，展现人物与环境关系
- 适用：人物并肩行走对话、展示长廊或街道、横向跟拍运动物体
- 分镜范例："滑轨侧移，与人物平行匀速移动，平视高度，展现两人对话时街道背景的流动，焦点在对话者间切换"

### 5. 升（Crane Up）与降（Crane Down）

- 定义：摄影机在垂直方向升高或降低
- 画面效果：视角从平视变为俯视（升）或从俯视变为平视/仰视（降），垂直方向揭示空间
- 情感效果：升=上帝视角、命运感、超脱感；降=压迫感、回归感、陷入感
- 适用：电影开场（升）、人物出场（降）、情绪从宏观到微观的转换
- 分镜范例（降）："摇臂缓降，从城市屋顶的俯拍全景，缓慢降至小巷平视角度，最终落在主角背影上，完成从环境到人物的引入"

### 6. 跟（Follow / Tracking）

- 定义：摄影机跟随运动中的主体，保持相对位置和景别大致不变
- 画面效果：主体稳定于画面中，背景持续流动，营造强烈的运动感和路径感
- 情感效果：极强的沉浸感和代入感，让观众"亲历"人物的旅程
- 适用：行走、奔跑、追逐、车辆跟随，任何需要强调运动过程的场景
- 分镜范例："稳定器前跟走，摄影师匀速后退，拍摄人物正面走来，焦点锁定面部，背景人群虚化流动，营造奔赴感"

## 跟随运镜体系

不同的"跟法"，决定了观众与人物之间不同的情感距离。

| 跟随类型 | 机位关系 | 核心情感 | 典型适用 |
|---|---|---|---|
| 前跟 | 正对人物后退 | 情感连接最强、坚定、奔赴 | 告白、重要对话、走向目标 |
| 背跟 | 人物正后方跟随 | 代入感、探索感、悬念 | 走向未知、独行、发现之旅 |
| 侧跟 | 侧面平行移动 | 客观、展示、关系呈现 | 并肩行走、展示人物与环境 |
| 45度斜跟 | 前侧方45度角 | 含蓄、电影感、日常叙事 | 情感过渡、内心独白、日常跟随 |
| 低机位跟 | 腰部以下高度 | 力量感、威慑感、童真视角 | 英雄出场、追逐、儿童视角 |
| 高机位跟 | 头顶以上高度 | 命运感、孤独感、被注视感 | 表现渺小、命运捉弄、监控视角 |

### 运动中焦段叙事

在跟拍中改变焦段，能动态调整画面的空间感和情感密度：

- 广角→长焦跟拍（35mm→85mm）：背景不断压缩靠近，空间感收紧，制造焦虑、压迫、逼近
- 长焦→广角跟拍（85mm→35mm）：背景不断展开远离，空间感释放，制造豁然开朗、释怀、解放
- 固定焦段跟拍：保持空间一致性，情感平稳，强调纪实感

## 变焦与特殊镜头

### 变焦（Zoom）vs 推拉（Dolly）的本质区别

| 维度 | 变焦 Zoom | 推拉 Dolly |
|---|---|---|
| 原理 | 改变焦距，位置不变 | 改变位置，焦距不变 |
| 画面特点 | 主体放大/缩小，背景透视不变 | 主体变化同时背景透视持续改变 |
| 空间感 | 空间压缩感弱 | 空间纵深感强 |
| 情感特质 | "机械""突兀"，快速聚焦、惊吓跳变 | 自然、沉浸感，电影感核心来源 |

### 希区柯克变焦（Dolly Zoom / Vertigo Effect）

- 定义：摄影机后移（Dolly Out）同时前变焦（Zoom In），或反之。主体大小不变，背景空间被极度压缩或拉伸
- 情感效果：强烈的不安、眩晕、震惊、顿悟，常用于角色内心崩塌、发现真相的瞬间
- 分镜范例："演员立于楼梯井中央不动。机位在轨道上匀速后移，同时镜头从35mm广角匀速变焦至85mm中长焦。演员面部大小保持不变，但背后楼梯的透视被极度压缩，产生螺旋下坠的眩晕感，时长5秒"

### 甩镜头（Whip Pan）与翻转镜头（Camera Roll）

- 甩镜头：快速的水平摇镜，在两个画面间制造动态模糊的转场。传递急促、动感、冲击力，或表现人物快速转头的主观视角
- 翻转镜头：摄影机沿光轴旋转，使画面倾斜甚至倒置。传递混乱、失重、迷失方向或精神错乱感
- 分镜范例（甩）："手持快速甩镜，从A角色惊恐的脸甩至B角色破门而入的瞬间，中间产生动态模糊"
- 分镜范例（翻转）："摄影机沿轴顺时针旋转180度，人物从正常站立变为倒立，背景天空与地面颠倒，表现其眩晕与困惑"

## 组合运镜公式

单一运镜是词汇，组合运镜才是句子。

| 组合 | 构成 | 核心情感 | 叙事时机 |
|---|---|---|---|
| 跟推 | Follow + Push In | 情绪聚焦、逐渐深入、紧张升级 | 发现真相、情感爆发前奏 |
| 跟拉 | Follow + Pull Out | 释怀、放空、融入世界、结束感 | 告别、沉思、场景收尾 |
| 跟升 | Follow + Rise | 上帝视角、命运审视、宏观转折 | 命运转折点、全知视角揭示 |
| 跟降 | Follow + Descend | 回归人间、聚焦个体、陷入困境 | 从宏观设定聚焦到具体人物 |
| 环绕跟 | Orbit Follow | 英雄时刻、精神觉醒、对峙张力 | 角色高光时刻、重要抉择 |
| 倒退跟拉 | Retreating Follow | 迎面压迫感、决绝、无法逃避 | 反派逼近、最终对决开场 |

> 组合运镜的关键：让1+1产生大于2的化学反应，而非机械叠加。"跟"提供沉浸感，"推"加强聚焦感，组合起来便是"情绪逐渐深入"。

## 景别与运镜配合

运镜不是孤立的技术动作，而是景别情绪的延伸。选择运镜时，先问：这个景别想传递什么情绪？然后选择能强化这种情绪的运镜方式。

| 景别 | 核心叙事功能 | 适配运镜 |
|---|---|---|
| 大远景 | 交代宏观环境，营造宏大/孤独感 | 航拍升镜、水平横移 |
| 远景 | 展现角色与环境关系，营造疏离感 | 缓慢横摇、航拍推进 |
| 全景 | 展现完整动作，交代角色在场景中的位置 | 轨道平移、稳定器跟拍 |
| 中景 | 人物对话，展现互动关系 | 侧跟、正反打切换 |
| 近景 | 聚焦面部表情和细微动作 | 缓慢推进、焦点转移 |
| 特写 | 突出核心情绪，强调关键道具 | 极慢推进、固定镜头 |
| 大特写 | 表现极致情绪，揭示微观信息 | 固定镜头、微距推进 |

---

## 景别组接规则

1. **逐步式组接**：
   - 远离式（后退式）：特写→近景→中景→全景→远景
   - 接近式（前进式）：远景→全景→中景→近景→特写
2. **跳跃式组接**：非相邻景别相互切换，如远景直接切中景再切特写
3. **剪辑禁忌**：
   - 两极镜头不宜相接（如特写与远景）
   - 相同景别不相接
   - 相同拍摄角度不相接

---

## 运镜铁律

1. **运动方向必须显式**：不写模型会自由发挥，常跑偏
2. **运动幅度给可对照量**："3秒内推到特写"比"推"精确
3. **复合运动一次只压一个主动作**：叠≥3个运动会衰减成中性结果
4. **人物绝不直视镜头**（AI视频铁律）：AI模型不知道这条电影潜规则，不写就会让角色盯镜头穿帮

## AI运镜提示词语法

对AI描述运镜，需使用明确、无歧义的中文术语，遵循"动作+方向+速度+景别变化+情绪氛围"结构。

- 基础动作：缓慢推进、匀速拉远、水平摇摄（从左至右）、垂直摇摄（从下至上）、横向平移、升降镜头（升起）、跟拍镜头
- 组合描述：在跟随人物行走的同时缓慢推近至面部特写、手持肩扛跟拍从背后跟随略带呼吸感抖动
- 焦段与画质：广角镜头(24mm)、人像镜头(85mm)浅景深、电影感光影24帧胶片颗粒
- 特殊效果：希区柯克变焦效果（背景压缩）、快速甩镜转场、镜头沿轴缓慢旋转

> 对AI描述运镜时，要像给摄影师下指令一样清晰、无歧义。避免"电影感""高级感"等抽象词。用"缓慢、平稳地向前推进"代替"慢慢推进"，用"低角度跟拍镜头"代替"有压迫感的跟拍"。

## 运镜类型分类总览

按运动特征分为五大类：

### 基础运镜
推拉(Dolly)、变焦(Zoom)、手持(Handheld)、平移(Truck)、升降(Crane/Pedestal)、斯坦尼康(Steadicam)

### 静态运镜

## 活人感：让人物不像 AI（V4.7 并入）

> **来源**：本节为该技能包内置的活人感方法论（模型无关部分）。
> **完整方法论**（含 H3 专属的 Ref2VA 结构纪律、道具图片锚定、空间锁定、成片验收清单）
> 本节为该方法的落地入口，完整方法论见本包 references/09-craft-performance.md。
> 本包**不依赖**该 skill，本节已自包含可用。

### 核心理念：AI 人物假，不是五官不真，是这个人太闲了

把精力全花在皮肤质感、光影、发丝上，生成出来还是一眼 AI。解决办法是**给人物找事情做、给行为动机**——
哪怕脸没那么完美，观众也会下意识觉得这个人活着。

> 真实的人永远在被生活推着走：会赶时间、会分心、会走神、会下意识做和主题无关的小动作。

### 表演公式

**单个人物**：`人物 + 正在做的小事 + 下意识反应 + 情绪落点`

**多个人物**：不要让每个人都表演。**一人行动，另一人反应，反应慢半拍**——真实的人回应时注意力还在别处。

**英文模板**（用于 H3 / Ref2VA 等英文提示词：放在 `detailed_description` 的 `[Shot 1]` **之前**，作为整段表演开场）：

```
Acting direction for the whole sequence: nobody stands idle or poses for the camera. Every character is always occupied with some small piece of business — handling an object, finishing a movement, glancing at something off-topic. In every exchange one character acts while the other reacts, and reactions arrive a beat late, the way real people respond while their attention is still somewhere else. Small involuntary gestures (swallowing, shifting weight, thumb rubbing an edge, a delayed look-up) matter more than polished facial expressions.
```

**中文模板**（用于 Seedance 2.5 / 中文视频提示词：作为脚本开头的「全局表演指导」区，与「场景调度宪法」并列，整场写一次）：

```
全局表演指导（整场通用）：
本片没有人站着摆拍——每个角色手上始终有事做（端杯、整理衣角、翻找口袋、摩挲物件边缘）；
对话或对峙时一人行动、另一人反应，反应迟半拍，注意力还在自己手上的事。
情绪不直说：先给人物一个想藏的隐藏目的，用一个大动作盖住真实反应，情绪写成变化过程
（先…停一拍…然后…）而不是最终状态。程度词取"一点点/几乎察觉不到/迟半拍"。每镜小动作 1–2 个。
```

> **各模型落点（V4.9）**：Seedance 2.5 → 脚本开头「全局表演指导」+ 每段 `【表演指导】` 硬栏位（中文）；MiniMax H3 Ref2VA → `detailed_description` 内 `[Shot 1]` 前写 `Acting direction for the whole sequence:`（英文）。完整落点表与 H3 专属结构纪律见本篇所在技能包。

### 小动作词库（按功能分类，写提示词时取用）

- **赶时间/紧张**：slightly out of breath, clutching the folder against his chest, swallowing once, tugging his jacket hem straight（求人前下意识整理衣服）
- **分心/走神**：eyes flicking toward the alarm lamp / the corridor door, not looking up when the door opens, half-turning his head toward off-screen business
- **思考/沉住气**：turning a pipe in one hand, tapping the pipe bowl against the palm, taking one slow unhurried draw, letting the question hang（不接话，让话晾着）
- **情绪落点（要克制）**：the smile fading, shoulders settling a fraction, thumb rubbing the folder's edge, the faintest breath of a laugh through the nose, regret deepening almost imperceptibly

> **程度词是灵魂**：`a fraction` / `faintest` / `almost imperceptibly` / `a beat late`——情绪越克制越真。

### 反面教训

- 不要只堆表情词（brows knitted, eyes pleading...）而不给动作——那是"表演"，不是"活着"。表情必须挂在动作和反应链上。
- 小动作宁少勿滥：**每镜 1–2 个**。跟踪能力有限，动作太多会拖垮台词节奏。如果成片台词说不利索，优先砍台词中间插入的分心动作。
- 人物"演技差"通常不是表情不够丰富，而是**演得太用力**——用下面的反向表演三技巧收敛。

### 反向表演三技巧（情绪要藏，不要演）

AI 人物演技差的常见根源不是表情不丰富，而是演得太用力：写提示词时把全部精力放在表情上——眉毛怎么皱、嘴角怎么动、眼泪什么时候掉——
结果内心情绪被原样写在脸上，一眼 AI。核心是：**让情绪藏进目的、大动作和时间线里**。

**技巧一：给情绪一个隐藏目的（先给目的，再给情绪）。**
只写内心情绪（"他很紧张"）等于告诉模型用最大幅度演紧张——不写目的，模型默认就是最大值。
先写人物**想对外维持什么状态**：`他很紧张，但为了不让对方发现，表面依然保持平静`。有了目的，模型才会走微表情路径。

**技巧二：用大动作掩盖小动作。**
专门写小表情（紧张→四下张望）反而刻意，刻意就是 AI 假感的来源。真实的人在隐藏情绪时，会用一个大动作掩盖真实反应：
紧张时端起水杯，尴尬时低头整理衣服，难过时转身收拾东西。大动作本身不表达情绪，却把眼神闪躲、手指颤抖这些小动作藏在里面。

**技巧三：给情绪加时间顺序。**
最容易忽略的犯错点：写微表情只写最终状态——"他紧张了""他笑了"，这是静态的截图。
微表情的本质是**变化过程**，真实反应一定有先后。把过程写进去：先……停了一拍……然后……。模型接收到时间关系，
生成的就不再是截图脸，而是正在发生的画面。

正反对照：

```
反面（只给情绪 + 最终状态，生成结果：用力演、截图脸）：
She is nervous and glances around, then smiles.

正面（目的 + 大动作掩盖 + 时间顺序）：
She is nervous about the inspection, but doesn't want the visitor to notice
(hidden purpose). She turns back to the desk and starts stacking files to busy
herself (big action covering the tells); her thumb keeps rubbing the folder's
edge (small tell hidden inside), and only after a beat do her shoulders settle
(time sequence).
```

**适用判断**：当成片里人物表情夸张、情绪直给、像在"演给镜头看"时，逐镜检查三件事——
有没有隐藏目的、有没有大动作可藏、情绪有没有先后过程；缺哪个补哪个。

## 光的类型

### 按光源划分

| 类型 | 说明 | 特点 |
|---|---|---|
| 自然光 | 太阳光、月光、星光、闪电光 | 真实自然，不受控，随天气时间变化 |
| 人工光 | 灯光、物体反射光等 | 可控性强，不受天气影响，稳定性强 |

### 按光的性质划分

| 类型 | 特点 | 效果 |
|---|---|---|
| 直射光 | 硬的、直接的、聚集的，能产生明显投影和明暗面 | 突出立体感，表现凹凸质地。晴天阳光、聚光灯 |
| 散射光 | 软的、柔和的，无明显受光面，不产生投影 | 光线均匀，提高整体亮度。阴雨天、泛光灯、柔光板 |

### 按造型功能划分（五光体系）

| 光型 | 作用 | 位置 |
|---|---|---|
| 主光 | 主要光源，突出对象最主要特征，唯一产生阴影的光 | 通常前侧方，也可做逆光 |
| 辅光（副光） | 补充主光照明不足，提高暗部亮度，减弱阴影浓度 | 主光对面或被摄者正前方，亮度不超过主光 |
| 背景光（环境光） | 照亮周围环境和背景，消除背景投影，分离主体与背景 | 被摄对象后方 |
| 轮廓光（背光） | 从背面打来，以逆光/侧逆光形成边缘亮光，分离主体与背景 | 被摄者背面，通常是布光中最亮的光 |
| 修饰光 | 对局部细节补光润色——眼神光、头发光、服装光等 | 局部小灯具，不能产生投影 |

## 光比

主光与辅光的亮度差叫**光比**。光比是控制画面氛围的核心参数。

| 光比 | 明暗对比 | 情感效果 |
|---|---|---|
| 大光比 | 明暗对比大 | 阴郁、压抑、戏剧性、神秘 |
| 适中光比 | 明暗过渡有层次 | 突出主体立体感，标准电影感 |
| 小光比 | 明暗对比小，画面亮而平 | 平淡、温和、日常 |

## 光的方向

### 水平方向

| 方向 | 定义 | 特点 |
|---|---|---|
| 顺光 | 光线投射方向与拍摄方向相同 | 画面亮，色彩饱和度高，无阴影，层次弱 |
| 逆光 | 光线投射方向与拍摄方向相反 | 主体变暗，边缘亮光，可拍剪影，黄昏侧逆光有朦胧美 |
| 正侧光 | 光线与拍摄轴线约90° | 明显黑白灰三面，立体感强，增加质感 |
| 前侧光（斜侧光） | 被摄者正面与侧面90°之间 | 立体感最强，最常用的人物主光角度 |
| 侧逆光（斜逆光） | 被摄者背面与侧面90°之间 | 人物较暗，少量光点，有一定立体感 |

| 方向 | 定义 | 情感效果 |
|---|---|---|
| 平光 | 水平方向投射 | 标准、自然 |

| 底光（脚光） | 从底部向上打 | 阴森、恐怖、惊险、压抑。地面灯/油灯/炉火/烛光 |

## 光影影调（三档基调）

影调指画面上的明暗层次分布、虚实对比效果、整体基调。

| 影调 | 明度区间 | 特点 | 情感映射 |
|---|---|---|---|
| 高调 | 0-3（高亮/浅白） | 强烈充足高亮光源 | 纯洁、淡雅、明净、活泼、阳光。校园恋情/温馨 |
| 中间调 | 4-6（标准） | 均匀光线，明暗适中，层次丰富 | 标准客观叙事，最常用 |
| 低调 | 7-10（暗调/深色系） | 深色为主，逆光最常见 | 压抑、颓废、神秘、恐怖。悬疑/惊悚/悲剧 |

## AI视频光线铁律

> **AI视频与实拍最大的光线区别：AI不能打灯。**

1. **所有光线只来自环境**：人物光线只来自场景中的自然光源（阳光、月光、火光、霓虹灯等），不单独给任何人物加光源
2. **禁止"给人物单独打光"**：AI视频里，如果每段都给人物单独加光，光源会在段与段之间不一致（角度变了、色温变了），导致穿帮
3. **光源绑定场景**：光线方向、色温、强度必须与场景设定一致，跨段不变
4. **用环境光替你打灯**：想让人物脸上有光，就把光源放在环境里——窗户、火堆、霓虹灯牌——让光"自然地"照到人物脸上

## 光影造型的四大作用

1. **营造故事氛围**：明亮高调=温馨乐观，深沉低调=悬疑压抑/悲剧
2. **突出情节重点**：光束能精准点亮关键人物、道具或动作，光影骤变本身也是戏剧性转折
3. **刻画人物形象**：柔和顺光=正直，侧光"阴阳脸"=矛盾复杂
4. **抒发人物情绪**：脸上的阴影面积、光影的晃动与明暗变化，直接映射内心波澜、恐惧、绝望或顿悟

# 11 · 工艺·声音词库

> 何时用：编运动提示词的【画面内容】时按需加载，以及 sound-design 统筹时。
> 依赖：无。
> 产出：声音词汇与方法。
> 只在编对应那一维时读入，平时不占上下文。

---

## 声音三条路

1. **音效** → 原生写进提示词【画面内容】，跟片一起出
2. **台词配音** → 单独生成，当参考音频喂模型
3. **音乐** → 单独做，不进提示词，后期铺

---

## 音效写法

音效原生写进【画面内容】，跟动作对位：

```
【画面内容】
她从画面右侧步入，脚步拖沓（鞋底磨碎石沙沙声）。走到桌前停下，
右手抬起按住太阳穴（指腹搓皮肤的细微摩擦声），指腹缓缓揉了两圈。
镜头从她的背影缓推到侧脸特写，她的眼角紧绷的线条慢慢松开，
嘴角牵起一个疲惫的半笑（一声很轻的呼气，在冷空气里凝成白雾）。
```

> 音效触发跟动作对位，写在动作后面的括号里。

---

## 台词配音

台词单独生成，当参考音频喂模型。

- **时间码精确到 0.1s**
- **情绪标注用具名**（气声 / 低语 / 脆响 / 咆哮），不写"很激动"
- **画外音 vs 现场声**：必须显式区分

---

## 音乐统筹

film-level 统筹：把要单独生成的台词配音和重要配乐当叙事设计好，登记进索引，留给最后一步生成。

- **BGM 起止点**：精确到 0.1s
- **节拍点对齐**：镜头切换点对齐 BGM 强拍（强拍切大场面，弱拍延氛围，休止转转场）
- **风格**：史诗管弦 / 中国大鼓 / 电子 / 民谣 等
- **BPM**：标注节拍速度

---

## 音画同步铁律

- BGM 节拍点对齐镜头切换点
- 台词时间码精确到 0.1s
- 音效触发帧必须显式标注
- 画外音 vs 现场声必须显式区分

# 12 · 审核标准清单（V4 · 可持续更新 · 当前 48 项）

> 这是 viral-video-prompt-engine 的**审核标准单一真相源**。
> 各档位审核方（独立审核agent / 主agent自审清单）判定时，逐项对照本文件。要么有证据，要么不成立。
> 本文件是活文档，持续更新（更新机制见末尾）。

## 一、审核角色与独立性原则

**审核主体按档位分配**（V4.8 起）：标准档阶段03 / 严格档全程 → 独立审核子agent（通过 Agent 工具派发，`subagent_type: general-purpose`）；标准档阶段01/02、轻量档全程 → 主agent自审清单。**无论由谁判定，都不继承创作意图、只看产出与标准**——自审时主agent必须切换视角，不得用"我为什么这么写"为自己开脱。

独立性四不原则（全档位通用）：
1. **不继承创作意图**——不知道作者为什么这么设计，只看产出和标准
2. **不参与创作**——只报告不修改，修改回主控做
3. **不假设对错**——每个结论必须附证据（场次号/镜头号/资产编号/原文片段）
4. **不留情面**——禁止"基本达标""大致合理"这类模糊词，要么✓要么⚠要么✗

## 十、更新机制（后续怎么完善这份标准）

本文件是活文档，持续更新。更新原则与流程如下。

### 10.1 更新触发条件

满足任一即提议更新：
1. **信号积累**：经验信号 里"审核标准缺失"类信号累计≥3条
2. **项目收尾**：每完成一个项目，阶段04收尾时检查本轮是否发现新审核维度
3. **审核翻车**：某阶段审核通过但人工/制作环节发现严重问题（说明标准有盲区）
4. **定期**：距上次更新≥7天且期间有项目跑过

### 10.2 更新流程

1. 在 经验信号 记录"审核标准缺失"信号（含具体场景+缺失维度）
2. 触发条件满足时，向用户提议"审核标准有N处可补充，是否更新12-film-review.md"
3. 用户同意后，更新本文件：
   - 新增检查项：加到对应阶段表格，附判定标准+阈值+方法
   - 修订阈值：调整量化数值（需说明理由）
   - 版本号+0.1（V4.1/V4.2...），在文件头标注更新日期和变更摘要
4. 同步更新 SKILL.md 引用 + standalone

### 10.3 更新原则

- **只增不删**：除非某标准被证伪，否则只新增不删除（旧标准是历史经验）
- **新增必有阈值**：每个新检查项必须附可量化阈值或明确判定方法，禁止新增模糊项
- **变更留痕**：每次更新在文件头"变更日志"记录改了什么、为什么改

# 13 · 进化（evolution）

> 何时用：用户纠正时抓信号；新 session 启动时消化积压信号。
> 依赖：用户的纠正原话。
> 产出：具体的改动建议，逐条问用户拍板。

## 信号捕捉

用户纠正你时（"不要这样写"/"应该这样"），即视为一条待生效信号。

措辞隐晦没抓到的，主 Agent 自己识别自己补记。

信号记在对话里（含时间戳、原话、发生场景）：
```json
{"ts":"2026-07-04T10:30:00","signal":"用户纠正：不要在提示词里反复描述长相","context":"编悟空运动提示词时"}
```

## 消化进化信号

本轮对话里就已经可以消化——把信号当场提炼成改动建议：

1. 回顾本轮用户给过的纠正原话
2. 提炼成具体的改动建议
3. 回来当场逐条问用户

```
积压了 N 条信号，我提炼成 N 条建议：

建议 1：<具体改动>
  依据：你上次说"<原话>"
  要改进：<对应 Skill 文件 + 改什么>
  同意吗？

建议 2：...
```

---

## 当场拍板

- **同意** → 立刻改进对应文档。编排进主控、Skill 行为进对应 references、确定性门禁进 hook。
- **否了** → 信号和建议一起删。

点头即生效，没有缓冲期。

## 双向：规则能进也能退

不光加规则，也扫描现有规则提议退休：

- 判断标准：删了它会不会复现当初的失败？
- 不会就删。
- 规则总量要往下走。

## 影片偏好 vs 通用规律

- **影片专属的偏好** → 只作用于当前项目，写进本项目讲戏本/分镜的配置区
- **通用规律** → 进 references 规则
- 框架不被单部片子的口味污染。

# 14 · 自驱指令（goal-creator）

> 何时用：用户想把整条流程（或某一段）交给 AI 一次性跑完。
> 依赖：当前项目状态 + 已完成的环节。
> 产出：一条完整的 goal 提示词，可复制粘贴执行。
> 验收：goal 落地、可执行、有约束。

---

## 什么是 goal 自驱

整套系统按**循环设计（loop engineering）**。你不光能一步步手动驱动，还能写一条 goal，把整条流程（或某一段）交给它一次性跑完。

```
goal = 把 harness 和当前上下文揉到一起的一条指令
     + 完成标准 + 约束 + 执行策略
```

---

## 两种典型用法

### 用法 A：从头到尾跑完整条流程

```
用户：开第二集，从剧本拆解一路往下，把出图出声之前所有的流程全部跑完。
```

goal-creator 会写一条 goal：
- 文件落在哪个路径
- 每个环节怎么做
- 做完怎么检验
- 有哪些约束

### 用法 B：只跑某一段（如批量出图出声）

```
用户：帮我出图出音频，生图用 GPT-image-2，音频用 eleven labs，API 我都准备好了。
```

goal-creator 会：
1. 先确认工具能不能用
2. 写一条完整的 goal 提示词
3. 把 harness 和当前上下文揉到一起
4. 加上完成标准、约束、执行策略

---

## goal 的执行特点

- 全程自驱，中间不用用户参与
- 跑完或卡死才来找用户
- 时间比较长：短则一小时，长则几个小时，具体看素材数量
- **出图出声/出视频很烧钱**，建议在 goal 里停在烧钱步骤之前，让用户手动确认后再跑

---

## goal-creator 的工作流程

1. 确认当前项目进度（哪些环节已完成）
2. 确认用户要跑哪一段
3. 确认工具可用性（如生图 API、音频 API、即梦 CLI）
4. 写 goal 提示词：
   - 文件落在哪个路径
   - 每个环节怎么做
   - 做完怎么检验
   - 有哪些约束
   - 完成标准
5. 交付给用户复制执行

---

## goal 模板

```
【目标】<一句话说清要跑什么>

【范围】
- 从 <环节> 开始
- 到 <环节> 结束
- 不包含 <烧钱环节，如出视频>

【执行策略】
- 按引用依赖拓扑排序
- 每完成一个环节按档位审核（标准档自审清单 / 严格档独立审核agent），过了才往下
- 卡死时停下来找用户

【约束】
- 生图工具：<GPT-image-2 / Midjourney / Nano Pro>
- 音频工具：<eleven labs / 其他>
- 文件路径：output/<项目名>/
- 编号按 reference index 走

【完成标准】
- 所有图齐：角色 N + 场景 N + 道具 N + 分镜图 N
- 所有声齐：配音 N 条 + 音乐 N 条
- 一致性过审：脸没串、画风统一
- 样片先行：先出 1-2 条确认
```

---

## 何时用 goal vs 手动

| 场景 | 推荐 |
|---|---|
| 从拆解到出图出声整条流程 | goal 自驱 |
| 只跑批量出图出声 | goal 自驱 |
| 迭代修改某几条提示词 | 手动 |
| 出视频（烧积分） | 手动（样片先行） |
| 进化消化 | 手动（需要用户拍板） |

> goal 适合又长又重的任务（几十张图、几十条音频），手动适合需要人工把关的环节。

# 15 · 手艺全集（craft-library）

> 何时用：需要深挖某一项细节时按需加载。
> 依赖：无。
> 产出：重型词库与方法。
> 平时不占上下文，调你来挖某一项时读这里。

---

## 一致性靠参考绑定，不靠反复描述

这是整个 2.0 的地基。你不用在提示词里反复念红头发蓝眼睛黑夹克。

- 绑一张参考图
- 一句"保持同一张脸"
- 正文用代称（"她"/"他"）
- 引用按统一索引走编号（C01/S01/P01）

> 在提示词里反复描述长相是噪声，挤占模型的运动预算。

---

## 提示词短而可跟随

丰富的导演想法留在讲戏本和中间稿里，最后喂模型那条越聚焦越好。

- 堆太长，模型取个平均、把细节丢了
- 一条提示词只写这一镜动了什么、镜头怎么走
- 写到模型能跟住就行
- followability > completeness

---

## 只写动

画面交给参考图，提示词只写运动和变化。

- 人物场景道具长什么样 → 参考图锁死
- 提示词只写：动了什么 + 镜头怎么走
- 描多了是噪声

---

## 情绪靠动作堆

| 情绪 | ❌ 直说 | ✅ 物理动作 |
|---|---|---|
| 疲惫 | 她很累 | 揉太阳穴 / 眼角线条松开 / 半笑 / 呼气凝白雾 |
| 压抑 | 他很愤怒 | 下颌绷紧 / 喉结滚动 / 手指攥拳又松 |
| 紧张 | 她很紧张 | 搓衣角 / 目光扫视 / 呼吸变浅 |
| 从容 | 他很从容 | 肩膀放松 / 嘴角微挑 / 步伐不紧不慢 |

> 半笑和笑是两回事。

---

## 时长跟内容走

- 15 秒是上限不是目标
- 默认偏短
- 留白和反应停顿本身就是戏，单独预算
- 一镜到底优于切镜

---

## 分镜板是给人看的

- 不是喂给模型的素材
- 直接丢给模型会渲出分格框、箭头、文字
- 分镜图只给复杂场画线框走位骨架
- 与运动提示词一一对应

---

## 强者平静，弱者张扬

- 真正的强者：平静、从容、甚至零特效
- 弱/急的一方：张扬、用力、满身特效
- 关系定了全片一致

---

## 多人同框写死体位

把"关系"翻译成具体 blocking：

- 谁坐 / 卧 / 倚 / 立
- 谁高谁低
- 谁俯视谁仰视
- 谁的目光锁在谁脸上

> 漏写体位 → 模型默认全员站立齐高。只写"看向某方向" → 望向虚空而非看人。

---

## 清爽明亮 vs 压抑苍茫

### 清爽明亮
删 skip-bleach / 颗粒 / 沙尘。改 蓝天 + 通透 + 干净 + teal-orange 互补。

### 压抑苍茫
才用 Dune 调 + skip-bleach LUT + analog grain + dusty haze + desaturated。

---

## 反 AI 味词库（Avoid）

plastic skin, overpolished studio look, oversaturation, HDR glow, doll-like skin, 3D rendered look, cartoon/anime/video-game render, faces swapped or merged, text/watermark/logo.

> 这些是模型认的"咒语"，保留英文原词。

---

## 画面质感决定调性

一张 hero image（英雄分镜）几乎可以决定整条视频百分之七八十的调性。

> 如果不考虑成本，用 Midjourney 出一张极具风格化的高质量分镜图，再配上故事版+提示词的方法去生成最终的视频，质感会拔高一个高度。
>
> 一张图几乎就可以决定你这条视频百分之七八十的调性。

---

## 半笑辨析（情绪写法的精髓）

半笑和笑是两回事。

- ❌ "他笑了"——人累到极点，大笑或普通笑都表达不出那股累
- ✅ "嘴角终于轻轻牵起一个疲惫的半笑"——半笑配上瘫软的状态，那种又累又由衷的劲儿一下就具体了

> 用词的精度决定情绪的精度。

---

## 真实世界可演绎性（决定抽卡成功与否的核心）

决定抽卡成功与否最大的核心是：**我们要生成的这个视频的内容，是否可以在真实世界中被演绎**。

换句话说，就是模型在训练的时候有没有训练到相关的素材。

如果你给它一个比较抽象、连它都没见过的镜头，那这个时候生成的难度和成功率就可想而知了。

> 这应该不算是一个冷知识，但是你在生成的时候脑子里一定要清楚。

---

## 风格提示词前置锁定（全片一致性命门）

风格提示词不是单独的"电影感/高级感"，而是"这部剧的类型和风格描述"，由三部分组成：
1. **剧类型**：如 3D古风神话动画 / 中国古风修仙玄幻动态漫 / 现代都市悬疑短剧
2. **画风特征**：如 三维写实渲染高质量CG / 二次元赛璐璐 / 真人写实电影感
3. **画面要求**：如 16:9横屏、人物保持一致性、场景一致性、画风画面调色一致性

**一旦确定：**
- 必须作为全片最高优先级风格锚点
- 后续所有提示词（角色/场景/道具/视频）都把它放在最前面逐字复用
- 不得省略、改写、拆散或替换
- 不得一段赛璐璐一段厚涂，不得一段2D一段3D

---

## 资产隔离与复用总则

- **角色卡**只写主体角色的脸/发型/服装/配饰/特殊状态/表演气质；手持武器一律另建道具卡
- **场景卡**写场景空间/材质/光线/天气/氛围人物；氛围人物不是具名主角
- **道具卡**只写静物，不出现人物或人手
- 分镜中允许组合调用，但必须引用资产ID

---

## 抽象词具体化

用户说"高级感""电影感""梦幻""压抑""燃""爽"时，必须翻译成具体画面参数、动作、光线、色彩和节奏。

- ❌ "高级感" → ✅ "低饱和冷色调，暖金主光从镜头右侧45°打来，浅景深背景虚化"
- ❌ "燃" → ✅ "急促运镜，快切，高对比暖橙火焰主光，运动有重量感"
- ❌ "梦幻" → ✅ "柔焦边缘，halation高光光晕，低饱和粉紫调，慢推运镜"

不要把抽象词直接塞进提示词。

---

## Seedance 2.5 视频提示词写法规则（V4.5 对齐官方 2.5）

1. **用自然语言**，不写负向提示词、固定种子、模型名、渲染引擎堆词
2. **风格提示词作为第一句话**，逐字粘贴
3. **整段演出时长测算**：台词+动作+运镜+转场 ≤ 规划时长
4. **双版本输出**：多模态版（含@引用）+ 纯文字版
5. **台词原文直接写入**：标明说话人、时间码、口型与配音同步
6. **镜头衔接保持连续**：人物站位、朝向、视线、道具状态、光线方向不跳变
7. **单段4-30秒**（30 秒内任何值皆可，不强制拉满），同一场景尽量一段完成，不同场景必须切换生成段；超 30 秒可拆"首段+延长段"（套娃 ≤60 秒）或超长视频模式（≤180 秒）
8. **每段最多 8 个镜头**（15 秒内最多 5 个），时间码总和等于本段规划时长
9. **2.5 多模态与新增能力**：支持 @图片/@视频/@音频/@音效，@视频可迁移创意（深层情绪/镜头语言）、多人参考解决双胞胎、音色参考绑定声线、多宫格分镜参考；可按需声明绿幕编辑/局部消除/空间视角修改/视频无缝转场/专业白模控制/去 BGM 仅留人声

# 16 · 工艺·轴线调度与构图

## 轴线原则（180°规则）

轴线是一条表现被摄主体视线、主体运动方向、人物关系的假想直线。

**轴线原则**：确定轴线后，只能在轴线的180°以内设置机位拍摄。超过180°的拍摄方式称为"越轴"，会造成观众空间方向的混乱感。

### 合理越轴的五种方法

1. **利用运动镜头越轴**：摄影机一直以运动方式从轴线一侧移动到另一侧，观众看到一直在动的背景，不会觉得空间混乱
2. **利用改变运动路线越轴**：人物快出画前改变运动方向，摄像机原在右侧变为左侧，下一个镜头可在左侧设机位
3. **中性镜头越轴**：在轴线上拍摄——人物迎镜头走来或背对走去，方向性不确定，在两个越轴镜头间起承上启下转接作用
4. **近景/特写/空镜头越轴**：近景和特写画面空间背景特征不明确，可作为越轴的衔接转换镜头；空镜头同理
5. **故意制造越轴**：为突出紧张情绪和混乱感，故意制造越轴镜头，让画面充满视觉冲击力

## 场面调度（Mise en Scène）

场面调度源自法文，直译"置于场景"。指导演对画面内元素（演员、道具、布景等）的安排与布局，以及通过摄影机位、镜头运动等手段引导观众视线和情绪的艺术处理。

### 角色调度

| 调度类型 | 说明 |
|---|---|
| 角色造型调度 | 妆容、发型、服饰、配饰——体现角色性格、身份、时代背景 |
| 角色出场调度 | 人物出场的第一印象——突出形象、吸引观众、埋下伏笔 |
| 角色位置调度 | 通过不同人物位置展现地位或关系，剪辑达到叙事目的 |
| 角色路线调度 | 角色在画面中的运动轨迹——需要提前做好分镜头设计 |

### 角色路线六种类型

| 路线类型 | 说明 | 画面效果 |
|---|---|---|
| 水平调度 | 演员水平直线运动 | 水平构图，画面舒展，增强延伸感 |
| 垂直调度 | 演员上下运动 | 攀爬或大幅度动作戏 |
| 倾斜调度 | 沿画面对角线运动 | 斜线构图，画面更有张力 |
| 纵深调度 | 从后向前或从前向后纵深运动 | 景别产生变化，带来不同视觉感受 |
| 环形调度 | 演员环形运动 | 人物动背景不动，或人物绕镜头运动人物背景同时旋转 |
| 画面外调度 | 角色不出现，通过他人陈述或声音展现 | 突出神秘、紧张氛围 |

### 布景调度

- **环境布景**：交代时代背景、衬托剧情、烘托氛围、增强艺术感、彰显特色
- **道具**：陈设道具（大型容纳性）、戏用道具（随身携带/使用，常作为故事主线索或隐喻功能）

## 双人对话机位

### 三角形机位（三机位）

当两个演员确定位置形成关系轴线后，在轴线一侧设置三个机位：
- 两个斜摄的正反打近景或特写
- 一个正摄的中景或全景

**正反打**：镜头分别在演员甲的右侧、演员乙的左侧拍摄，机位与轴线保持统一角度。

- **内反打**：只拍被摄对象，通常为特写
- **外反打**：跨过其中一个被摄主体的肩部拍摄另一个主体，通常为近景

### 五机位拍摄

在三角形基础上增加：
- 内反打正摄（特写）
- 外反打斜摄（近景）
- 侧摄中景/全景（展现两人位置、姿势、状态和环境）

---

## 多人对话机位

### 三人或多人直线排列

当作双人拍摄现场布置机位。侧摄主镜头拍全部状态，再根据对话内容分组拍摄。

### 三角形或圆形排列

有多条轴线产生，但都控制两个方向——圈外或圈内。在圈外设机位就不能到圈内拍。

### 运动拍摄

化零为整，把多人物分组看作三人或双人情形。无论什么情况，轴线都存在，不能把两个越轴镜头拼接到一起。

## 十二种基本构图

| 序号 | 构图类型 | 特点 | 适用场景 |
|---|---|---|---|
| 1 | 对称构图 | 平衡、稳定、彼此呼应，形成放射状结构引向中心 | 仪式、权力交接、宗教场景 |
| 2 | 黄金分割比构图 | 1:0.618比例，引发美感 | 人物在场景中的静止画面 |
| 3 | 向心式构图 | 主体居中，四周景物朝中心集中 | 强烈引向中心主体，也可产生压迫感 |
| 4 | 框架式构图 | 用前景事物框住主体，去除不必要元素 | 主观镜头视觉范围、门窗看场景 |
| 5 | 紧凑式构图 | 主体特写放大，局部布满画面 | 人物特写、局部细节大特写，渲染悬疑/惊悚 |
| 6 | 三角形构图 | 三个视觉中心形成稳定三角形（正/斜/倒） | 安定、均衡、灵活 |
| 7 | 垂线构图 | 垂直线条体现高度、气势 | 参天大树、摩天大楼，庄严严肃 |
| 8 | 水平构图 | 水平平行线，平静安宁稳定 | 湖面、大海、草原 |
| 9 | 曲线构图 | S形/C形/不规则曲线，优美柔和 | 道路、河流，展现延伸感 |
| 10 | 引导线构图 | 利用线条引导视线从一区域移到另一区域 | 道路/河流/建筑边缘指向主体 |
| 11 | 散点式构图 | 众多主体不分主次 | 密集人群、散落装饰物 |
| 12 | 斜线构图 | 主体倾斜占满画面或排列成斜线 | 不稳定、活泼、趣味感强 |

## 画面主次分配

| 元素 | 作用 | 表现形式 |
|---|---|---|
| 主体 | 画面主角，所有元素围绕它调度 | 直接表现（占中心/大面积）或间接表现（面积小但是结构中心） |
| 陪体 | 对主角起烘托、补充、美化作用 | 直接表现（出现但不影响主体突出）或间接表现（被虚化/部分入画） |
| 环境 | 衬托人物、烘托氛围 | 前景（拉开空间关系、增强层次）+ 背景（交代场景、塑造空间感） |

### 对比与均衡

- **对比**：大小/远近/虚实/疏密/色差的反差——增强层次错落感和节奏感
- **均衡**：大小/远近/虚实/疏密/色差的平衡——满足视觉到心理的平衡

### 留白的空间指向

- 面部或运动方向留白更多，保证视觉舒适度
- 故意减少留白可营造压抑、困惑的氛围

## 构图×运镜五大公式

构图是骨架，运镜是血液。两者的结合让画面真正"活"起来。

| 公式 | 构图 + 运镜 | 情绪效果 | 适用场景 |
|---|---|---|---|
| 一 | 对称构图 + 缓慢推镜 | 仪式感与庄严 | 重要仪式、权力交接、宗教场景 |
| 二 | 引导线构图 + 推镜 | 深入探索与未知感 | 隧道、走廊、迷宫、探索未知 |
| 三 | 框架式构图 + 跟拍 | 窥视感与受限视角 | 通过门窗/缝隙/监视器观看 |
| 四 | 三分法构图 + 侧移 | 自然流畅的叙事推进 | 跟随人物行走、车内对话、日常活动 |
| 五 | 三角形构图 + 环绕 | 权力对峙与紧张关系 | 三人对话紧张场面、权力博弈、对峙 |

> 这些公式是创作的工具箱，而非必须遵守的规则。最高级的创作往往是在理解公式的基础上进行突破和创新。

## AI提示词四位一体公式

AI视频提示词写作核心公式：

**景别 + 运镜 + 构图 + 情绪/主题**

- **景别**：明确指定标准术语（大远景/中近景/大特写等），避免"远一点""近一点"
- **运镜**：使用标准术语（缓慢推镜/稳定器跟拍/升降机升镜/手持晃动），可加速度描述
- **构图**：结合构图术语（对称构图/引导线指向主体/三分法/框架式构图等）
- **情绪/主题**：提示词的"灵魂"，决定画面整体调性（孤独而雄伟/紧张对峙/平静日常生活）

## 工作流

### Step 1: 读剧本，抓核心

从用户输入中提取：

1. **谁** — 出场角色（1-2 人为宜，超过则考虑拆分）
2. **在哪** — 场景（一个生成段一个主要场景）
3. **做什么** — 核心动作链（2.5 长尾动作能力强，可以写复杂动作序列）
4. **说什么** — 台词原文（逐字锁定，不得修改；多语种台词保留原语言）
5. **情绪走向** — 起点 → 终点
6. **素材** — 用户是否提供了 @图片/@视频/@音频，各自参考什么

### Step 2: 选择生成模式

| 模式 | 适用 | 时长 |
|------|------|------|
| 单段生成（默认） | 一个连续片段 | 4-30 秒 |
| 视频延长 | 用户已有 2.5 成片，想接着演 | 每段 ≤30 秒，总长 ≤60 秒 |
| 超长视频模式 | 完整短片/MV/预告片，用户明确要求长片 | ≤180 秒 |

用户没提模式 → 默认单段生成。剧本内容超过 30 秒 → 主动建议拆成"首段 + 延长段"或改用超长视频模式。

### Step 3: 精准时间测算（核心步骤）

逐项测算、逐项展示、不跳步骤。

#### 3.1 台词时间

| 台词类型 | 语速标准 | 公式 |
|---------|---------|------|
| 普通中文对白 | 3-4 字/秒 | 字数 ÷ 3.5 = 秒数（取中值） |
| 情绪台词（哭腔/怒斥/颤抖/压抑） | 2-3 字/秒 | 字数 ÷ 2.5 = 秒数 |
| 古风台词/文言/诗词 | 2-3 字/秒 | 字数 ÷ 2.5 = 秒数 |
| 气声/耳语/低语 | 1.5-2 字/秒 | 字数 ÷ 1.8 = 秒数 |
| 外语对白（英/日/韩等） | 按音节估，约 2.5-3 词/秒 | 词数 ÷ 2.8 = 秒数 |
| 停顿/迟疑/换气 | — | 每次 0.5-1 秒 |

**一句台词如果 > 8 秒说不完 → 按自然停顿拆到多个时间戳区间，但原文不改。**

#### 3.2 动作时间

| 动作类型 | 最短可看清时间 |
|---------|------------|
| 简单表情反应（抬眉/抿嘴/眨眼） | 0.5-1 秒 |
| 关键眼神/对视 | 1-2 秒 |
| 转头/回身 | 1-2 秒 |
| 起身/坐下/蹲下 | 1.5-3 秒 |
| 走位（一步） | 0.5 秒/步 |
| 走位（从A点到B点，3-5步） | 2-4 秒 |
| 拔剑/推门/掀帘/摔杯 | 1-2 秒 |
| 单手交手一击 | 1-2 秒 |
| 连续交手（2-3个回合） | 3-5 秒 |
| 复杂长尾动作（后空翻+拔剑+落地连招） | 4-8 秒 |
| 物品拿起/递交/特写 | 1-2 秒 |
| 身体倒地/坠落 | 1.5-3 秒 |

#### 3.3 运镜与衔接时间

| 运镜类型 | 时间 |
|---------|------|
| 定场/环境建立 | 1-2 秒 |
| 推/拉镜头 | 1-3 秒 |
| 摇/移镜头 | 1-2 秒 |
| 跟拍 | 与主体动作同步 |
| 硬切 | 0-0.5 秒 |
| 淡入/淡出/叠化 | 1-2 秒 |
| 首帧承接（建立空间方位） | 1-2 秒 |
| 末帧钩子停留 | 1-2 秒 |

#### 3.4 帧级换算（可选）

2.5 支持帧级时间戳。需要卡音乐点/精确到帧时使用：**帧号 = 秒 × 24**（24fps）。

例：3 秒 = 第 72 帧；10 秒 240 帧 = `第 0-240 帧`。提示词中可写 `第 0-90 帧 (0s-3s)` 双标注。

#### 3.5 时间测算表（必须输出）

```
┌─────────────────────────────────────┐
│         本段演出时长测算             │
├────────────────┬────────┬───────────┤
│ 项目            │ 详情    │ 测算时间   │
├────────────────┼────────┼───────────┤
│ 台词口播        │ ...    │ X.X 秒    │
│ 表情与表演      │ ...    │ X.X 秒    │
│ 身体动作/走位   │ ...    │ X.X 秒    │
│ 道具交互        │ ...    │ X.X 秒    │
│ 运镜与转场      │ ...    │ X.X 秒    │
│ 首帧承接        │ ...    │ X.X 秒    │
│ 末帧钩子停留    │ ...    │ X.X 秒    │
├────────────────┼────────┼───────────┤
│ 测算总时长      │        │ XX.X 秒   │
│ 规划时长        │        │ XX 秒     │
│ 结论            │ 通过/需调整  │           │
└────────────────┴────────┴───────────┘
```

**测算总时长 > 规划时长 → 调整优先级：**
1. 先延长到 30 秒上限（2.5 单次可达 30 秒）
2. 仍不够 → 建议拆成"首段 + 延长段"（套娃延长，总长 ≤60 秒）或超长视频模式
3. 减少次要动作/反应镜头
4. 删减原创建议台词
5. 用户原文台词按自然停顿拆分到下一时间戳区间/下一段
6. 用户原文台词**绝不删改**

**测算总时长 < 规划时长 → 不要注水：**
- 不硬凑 30 秒。4-30 秒内任何值都可以。
- 空余时间留给画面自然节奏，不是塞废话。

### Step 4: 丰富完善成可执行的画面

把抽象内容转为摄影机可拍的物理画面（2.5 物理质感与长尾动作能力强，动作链可以写得更细）：

- "两人对峙" → "男左女右，相距三步，风卷落叶从两人之间掠过"
- "剑光一闪" → "剑刃从左下方斜向上挥出，刃面反光划过画面中央，雨水顺着剑刃滑落"

**动作动词，具象物理细节，摄影机可见。**

## 核心规则

### 时间规则
1. 单段 4-30 秒，不强制满 30 秒。能 6 秒完成的不用 8 秒，能 15 秒完成的不用 20 秒。
2. 每个镜头不少于 1 秒（特写/反应），不超过 10 秒。
3. 30 秒内最多 8 个镜头；15 秒内最多 5 个镜头。
4. 必须展示完整测算过程，不能只给结论。
5. 时间戳区间必须连续、不重叠、总时长与规划一致。
6. 关键眼神、情绪停顿、动作余韵该留就留——精简但不破坏节奏。
7. 帧级标注仅在有卡点需求时使用：帧号 = 秒 × 24。

### 台词规则
8. 用户剧本中的台词逐字锁定。不得翻译、改写、润色、删减、合并。多语种台词保留原语言。
9. 台词在时间测算表和提示词中完全一致。
10. 用户没给台词时可生成"原创建议台词"并标注；需要口型同步时声明"嘴型与台词发音严格同步"。

### 画面规则
11. 只写摄影机可拍到的——动作、表情、物体、光线。禁止抽象"意境""高级感"，转成具体光线、颜色、动作、构图。
12. 动作描写用「起点状态 → 过程 → 终点状态」完整链条。2.5 长尾动作能力强，复杂连招可以完整写出（如"后空翻落地后迅速拔剑，雨水顺剑刃滑落"）。
13. 材质写具体名 + 颜色 + 质感；追求真实感时用"原生皮肤质感""毛发根根分明"等 2.5 敏感词。
14. 多镜头/多区间中角色必须重复面部、发型、服装锚点，保证切镜一致性。

### 2.5 专属规则
15. 时间戳用 `0-3s：` 或 `[00.0-03.0s]` 前缀格式，按时间顺序排列；帧级需求用 `第 0-72 帧 (0s-3s)` 双标注。
16. @图片/@视频/@音频/@音效引用必须声明用途（参考什么、不参考什么），例："@视频1仅参考运镜轨迹与动作节奏，不保留原画面质感"。
17. 需要干净底片时显式写"纯净视频，全程无字幕、无背景音乐"；需要指定字幕/文字语言时显式声明"画面所有文字必须为[语言]，禁止出现其他语言文字"。
18. 需要去除参考素材 BGM 时写"去除@视频1中的背景音乐，仅保留人声"。
19. 负向约束放心写：禁止字幕/水印/logo/IP 角色/品牌元素，2.5 响应可靠。
20. 不生成资产库提示词（角色图/场景图/道具图/三视图）。
21. 白模任务使用 2.5 白模公式——粗颗粒：【参考声明】+【对应关系映射】+【剧情详述】+【场景处理】+【整体收束】；细颗粒：【渲染指令】+【分段渲染描述】+【场景处理】+【整体收束】。

## 时长选择参考

| 剧本特征 | 建议时长 | 理由 |
|---------|---------|------|
| 一个眼神/一个反应/一个动作 | 4-6 秒 | 短镜，不拖 |
| 一句台词 + 一个动作 | 6-8 秒 | 刚好说完做完 |
| 两句台词交替 + 反应 | 8-12 秒 | 对话节奏 |
| 三句台词 + 走位 + 动作 | 12-15 秒 | 编排紧凑 |
| 追逐/打斗/多人交互/复杂连招 | 15-30 秒 | 2.5 支持 30 秒单次，动作密度高不必硬切 |
| 古风台词（慢速）+ 情绪 | 比现代语速 +2-3 秒 | 古风语速 2-3 字/秒 |
| 完整短片/MV/预告（多镜头叙事） | 超长视频模式 ≤180 秒 | 一次性直出，长时序一致性好 |
| 已有成片想继续演 | 延长段 ≤30 秒/次，总长 ≤60 秒 | 套娃延长，分段导演控制 |
