# 03 · 资产设计

> 何时用：讲戏本审过后。
> 依赖：讲戏本的三张清单 + 导演视野。
> 产出：角色 / 场景 / 道具的设定图提示词，每张嵌同一段全片视觉风格基准。
> 验收：三张清单全覆盖、每张嵌视觉风格基准、参考素材绑定规范、可直接复制使用。

---

## 核心：风格提示词前置锁定（全片最高优先级）

每张设定图提示词开头都嵌**同一段**风格提示词——就是剧本拆解时定下的"这部剧的类型和风格描述"。

**风格提示词由三部分组成：**
1. **剧类型**：如 3D古风神话动画 / 中国古风修仙玄幻动态漫 / 现代都市悬疑短剧 / 赛博朋克科幻短剧
2. **画风特征**：如 三维写实渲染高质量CG / 二次元赛璐璐 / 真人写实电影感
3. **画面要求**：如 16:9横屏、人物保持一致性、场景一致性、画风画面调色一致性

**风格提示词一旦确定：**
- 必须作为全片最高优先级风格锚点
- 后续所有角色人设图、三视图、多视图、场景图、道具图、首帧图、Seedance视频提示词，都必须把完整风格提示词放在提示词最前面
- 逐字复用，不得省略、改写、拆散或替换
- 不同角色/场景/道具只能在风格提示词后追加各自内容

---

## 资产隔离与复用总则

- **角色资产卡**只写主体角色的脸、发型、服装、配饰、特殊状态和表演气质；手持武器/法宝/证物一律另建道具卡
- **场景资产卡**写场景空间、材质、光线、天气、氛围人物和非剧情性摆设；氛围人物不得写成具名主角
- **道具资产卡**只写静物，不出现人物或人手
- 分镜镜头中允许把角色、场景、道具组合调用，但必须引用资产ID并继承对应锚点
- 资产图提示词可使用"8K、超高清、电影级材质"等生图描述；Seedance 2.5 视频提示词仍必须用自然语言

---

## 三个并行

- **character-design**：取人物清单，出角色人设提示词（真人视频优先面部设计，详见下文「真人视频角色面部设计」）
- **scene-design**：取场景清单，出场景**八层结构**图提示词 + **场景多宫格视角**（详见下文「场景多宫格视角」）
- **prop-design**：取道具清单，出关键道具**资产卡**提示词

三并行，互不阻塞。

## 角色人设提示词（四种 · 必须全出）

每个 CHxx 角色都必须输出四种人设提示词，可直接复制生图。

### 真人视频角色面部设计（优先级最高）

**当画面类型为「真人写实」时，角色面部设计优先于服装和场景。** 面部是真人视频一致性的命门——脸不对，穿什么都没用。

#### 女性角色面部设计

参考 `beauty-prompt-generator` skill 的六维质控框架。女性角色的「第一种：角色描述提示词」中，[基础面容锚点] 必须按以下六维写：

1. **面部质感**：肤质（冷白/暖白/小麦/古铜）、肤感（哑光/水光/奶油肌）、毛孔质感（保留真实毛孔/精修无瑕）、面部光泽点（颧骨高光/鼻梁高光/T区光泽）
2. **光源**：主光方向（镜头左/右/上/下）、光质（硬光/柔光/混合光）、光比（高对比/低对比）、色温（暖光/冷光/中性光）、补光（是否需要补光、补光方向）
3. **场景**（面部特写时的背景）：虚化背景/实景背景/纯色背景、背景色调与人物肤色关系
4. **动作**（面部微表情）：眼神方向（直视/侧视/俯视/仰视）、嘴角状态（微扬/平直/微抿/半笑）、眉毛状态（舒展/微蹙/上扬）、头部角度（正/微侧/3/4侧）
5. **表情**（不直说情绪，写具体肌肉）：如"眼角紧绷的线条松开"而不是"她很欣慰"
6. **景深**：大光圈虚化（shallow DoF / wide aperture / background heavily out of focus）、焦外质感（bokeh 形态）、锐焦区域（眼睛/睫毛/唇）

> 女性角色面部设计的完整模板与变量词库详见 `beauty-prompt-generator` skill 的 `references/prompt_template.md`。

#### 男性角色面部设计

参考「男子骨相级提示词」的骨相框架。男性角色的「第一种：角色描述提示词」中，[基础面容锚点] 必须按以下骨相结构写：

1. **脸型与骨相**：脸型（窄长脸/硬朗国字脸/精致菱形脸/清瘦型脸）、脸宽（适中偏窄）、纵向比例（修长）、面部骨骼感（明显但不粗犷）、下颌线（清晰锐利）、下颌角（存在感明确但不过度方硬）、下巴（线条利落偏方但不笨重）
2. **额头**：额头形态（中等偏饱满/硬朗开阔/光洁平整）、发际线（整齐自然）、太阳穴（饱满不凹陷）
3. **眉眼**：眉色（深棕黑/自然黑/深灰）、眉形（剑眉平直带上扬走势/眉峰偏锐/眉尾收紧）、眉骨（微微隆起形成轻微阴影）、眼型（狭长深邃/锐利鹰眼/冷感丹凤眼/深沉桃花眼）、眼裂（偏长偏窄）、内眼角（尖且深邃）、外眼角（轻微上扬）、双眼皮（较窄或内双）、眼窝（适度深度）、眼神（直视镜头/冷峻/锐利/审视/压迫感）
4. **鼻型**：山根（挺拔自然顺接眉骨）、鼻梁（直挺有力）、鼻背（宽度适中）、鼻头（轻微方感但不粗大）、鼻翼（适中不外扩）
5. **唇形**：唇峰（线条明确不过分雕刻）、上唇（偏薄）、下唇（微厚于上唇但不饱满）、嘴角（自然平直或极轻微下压）
6. **肤质与妆面**：肤色（冷调自然/健康小麦偏冷/冷调象牙白）、肤感（高完成度哑光、保留男性轻微毛孔质感）、妆面（"无妆感"高级男性修饰妆）、胡茬（极短青色胡茬/干净一日未剃/无明显胡茬）

> 男性角色面部设计的完整变量填充规则详见 `E:/桌面20260606/各种bot/0508短剧分镜提示词/男子骨相级提示词bot.txt`。

#### 真人 vs 非真人的区分

| 维度 | 真人写实 | 3D国漫/2D动画 |
|---|---|---|
| 面部优先级 | **最高**（脸是命门） | 与服装/场景同等 |
| 面部写法 | 六维质控（女）/ 骨相框架（男） | 基础面容锚点 |
| 毛孔质感 | 必须保留真实毛孔 | 不需要 |
| 妆面 | "无妆感"高级修饰 | 按画风定 |
| 参考图 | 必须绑面部参考图 | 可选 |

```

[风格提示词逐字粘贴]

[服装六层]：内层、外层、套层、腰部、下肢、足部

[表情与动作气质]：固定眼神、呼吸、站姿、说话习惯
  写可见表演，不写空泛情绪
[一致性声明]：该角色人设必须贯穿整个分镜脚本，所有镜头中身高、体型、面容、
  发型、服装层次、配饰必须与本提示词完全一致
```

### 第四种：角色概念表布局提示词（可选 · 需要更完整人设时用）

在角色提示词正文末尾原样嵌入以下布局段：

```text
----- 角色概念表布局段（固定文本，必须原样嵌入） -----

1. 主视觉区（上方）白底图
以"正面 + 侧面 + 背面"三个核心视角为主体，直观呈现角色的整体身形、服饰搭配和标志性特征，是制作人员对人物"整体造型"的参考基础。

2. 补充信息区（左侧）白底图
拆分出"面部特写（头部正立, 颈部垂直, 下颌线水平, 头顶到下巴在画面垂直中轴上, 不侧倾, 不仰头, 不低头）"和"配色板"（明确毛发、服饰的色值），补充主视角没覆盖的细节与色彩标准。

3. 局部细节区（底部）白底图
用小模块单独展示关键部件的设计（配饰、点缀、关键身份识别元素），把主视角里的"模糊细节"拆分为精准的制作参考，方便导演确认。

4. 半身照比例照（右侧）
生成人物上半身图像，（头部正立, 颈部垂直, 下颌线水平, 头顶到下巴在画面垂直中轴上, 不侧倾, 不仰头, 不低头）

----- 布局段结束 -----

背景统一：纯白底 或 浅灰摄影棚背景。
```

### 角色禁止事项
1. 古装题材禁止现代短发碎发；其他题材发型必须与时代严格匹配
2. 角色提示词中禁止出现武器/法宝/道具/坐骑（须独立建道具卡）
3. 禁止空泛形容词（"帅气""美丽""威严"必须转为具体五官描述）
4. 禁止比喻/拟人（"如寒霜般的眼神"→"眼尾下垂，眼神冷峻"）
5. 同一角色不同形态不得改变面容（仅允许改服装/伤势/年龄/妆造）

## 场景图提示词（八层结构 · 400-600字）+ 场景多宫格视角

### 场景八层结构图（主参考图）

每个主要场景先出一张**八层结构主参考图**（格式见下文），再出**多宫格视角参考图**。

### 场景多宫格视角（参考 scene-multiview-prompter skill）

主参考图出完后，为主要场景生成**多宫格视角参考图**——把同一三维空间从多个标准视角投影出来，供分镜拍摄时引用。

**双模式选择（询问用户）：**

| 模式 | 布局 | 视角组合 | 一致性 | 信息完整度 | 适用 |
|---|---|---|---|---|---|
| 4宫格（推荐） | 2×2 | 俯拍/正向/左侧/右侧 | 高 | 中 | 分镜空间还原、一致性优先 |
| 6宫格 | 2×3 | 俯拍/正向/后视/左侧/右侧/鸟瞰 | 中 | 高 | 复杂场景、需看背面、需纵深 |

**多宫格提示词格式：**

```
AI随风制作，禁止商业售卖

[风格提示词逐字粘贴]

基于 SCxx 主参考图还原同一三维空间，生成{4/6}宫格多视角参考图。

布局：{2×2 / 2×3}，每个视角独立一格，格间细黑边分隔。

4宫格：
- 左上：俯拍（俯视平面图，ground truth，其它视角纵深关系必须与俯拍平面一致）
- 右上：正向（正面视角，与俯拍平面纵深一致）
- 左下：左侧视角
- 右下：右侧视角

6宫格（在4宫格基础上增加）：
- 左下：后视
- 右下：鸟瞰（提供纵深感）

每个视角含四子维度描述：
1. 纵深层次：前景/中景/远景的层次关系
2. 遮挡关系：哪些元素被遮挡、遮挡方向
3. 材质高光：同一材质在不同视角下的高光位置
4. 投影落点：主光源方向、投影落点方向与长度

[主参考图的元素清单、光照条件、投影基准、色调氛围]

[画质尾缀]
```

**多宫格生成后必须执行逻辑可行性审核：**
- 基础八维度：同一场景、元素一致、视角端正、无遮挡、无文字、光照一致、材质一致、比例一致
- 6宫格额外两维度：前后对称性、鸟瞰一致性

> 场景多宫格参考 `scene-multiview-prompter` skill 的完整工作流。


### 场景人物适配规则
- 每个场景默认包含符合场景功能的氛围人物

## Hero Image 技巧（风格抽象原创时用）

用提示词锁定视觉一致性是有用的，但有的时候还是不稳定。如果你的风格比较抽象、比较原创，光靠提示词来描述一致性很容易飘。

**更稳定的做法**：先做一张 hero image（英雄镜头/英雄分镜），拿它当整篇的视觉参考，再用它去生成后面的场景、道具、角色。

光靠提示词锁定一致性八成以上的情况够用，剩下两成用 hero image 兜底。

## 资产索引（reference index · 全片统一编号 · 视频提示词引用依据）

所有资产出后建立**统一索引**，后面写运动提示词要 @ 人物、@ 场景、@ 道具、@ 音频，全片认这一份清单。编号一乱，出片就串。

reference index 管三件事：
1. 把已有的资产登记在册
2. 锁住文件名一致性
3. **视频提示词中准确引用资产编号 + 简短中文标注**（详见 04-motion-prompt）

### 编号规则

| 资产类型 | 编号前缀 | 示例 |
|---|---|---|
| 角色 | C | C01 孙悟空 → images/characters/C01-wukong.png |
| 场景（主参考图） | S | S01 山海经虚空 → images/scenes/S01-void.png |
| 场景（多宫格视角） | S + -MV | S01-MV4 山海经虚空4宫格 → images/scenes/S01-MV4.png |
| 道具 | P | P01 如意金箍棒 → images/props/P01-staff.png |
| 音频 | A | A01 悟空台词 → audio/A01-wukong-line.mp3 |
| 音乐 | M | M01 BGM史诗管弦 → audio/M01-bgm.mp3 |

### 索引格式

```
reference index：

角色索引：
- C01 <角色名>（<一句话标注，如"金甲红披风火眼金睛"）→ images/characters/C01-<文件名>.png
- C02 <角色名>（<一句话标注>）→ images/characters/C02-<文件名>.png
...

场景索引：
- S01 <场景名>（<一句话标注，如"暗金虚空古卷悬浮"）→ images/scenes/S01-<文件名>.png
- S01-MV4 <场景名>4宫格（<一句话标注>）→ images/scenes/S01-MV4.png
- S02 <场景名>（<一句话标注>）→ images/scenes/S02-<文件名>.png
...

道具索引：
- P01 <道具名>（<一句话标注，如"金红双色可变大"）→ images/props/P01-<文件名>.png
...

音频索引：
- A01 <台词/音乐名>（<一句话标注，如"悟空气声"）→ audio/A01-<文件名>.mp3
...
```

> **一句话标注是关键**——视频提示词引用资产时，要写"@图片1（C01孙悟空·金甲红披风火眼金睛）"，让用户一眼知道是哪张参考图。
> 声音设计也跟着同一份编号走，不单独存一份。
