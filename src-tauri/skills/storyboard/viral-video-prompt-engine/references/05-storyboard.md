# 05 · 分镜

> 何时用：运动提示词审过后。
> 依赖：运动提示词已定的镜头 + 标 ★ 的复杂场 + 风格提示词 + 资产索引。
> 产出：复杂场的故事板**图片提示词** + **视频提示词**（双输出，可直接复制使用）。
> 验收：只给复杂场、与运动提示词一一对应、宫格位置锁定、风格提示词前置、资产编号+中文标注引用。
> **不需要用户再选宫格/风格/时长——直接根据前面的剧本和风格自动确定。**

---

## 核心：分镜板是给人看的，不是直接喂模型的

精心画的分镜板直接丢给模型，视频里会渲出分格框、箭头、文字——模型把分镜板本身当成要画的东西了。

**分镜图的作用**：把走位和动作序列说清楚，连同参考图一起喂模型当走位参考。分镜图与分镜提示词一一对应（镜头一对镜头一），模型才知道你到底要什么。

---

## 自动确定参数（不需要用户再选）

分镜阶段的宫格类型、风格、时长**全部从前面的剧本拆解和运动提示词自动继承**，不需要用户再选：

| 参数 | 来源 | 自动确定规则 |
|---|---|---|
| 风格提示词 | 剧本拆解时锁定 | 逐字复用，不得改写 |
| 宫格类型 | 运动提示词标 ★ 的复杂场 | 按镜头数自动选：≤4镜=4宫格 / 5-6镜=6宫格 / ≥7镜=9宫格 |
| 时长 | 运动提示词已定 | 该段规划时长自动继承 |
| 资产编号 | reference index | 自动引用 C01/S01/P01 等 |
| 台词 | 台词锁定表 | 自动继承，逐字复用 |

> 如果用户主动要求改宫格类型，可以改；否则按自动规则走。

---

## 哪些场要分镜图

照运动提示词里标 ★ 的镜头走。只给复杂场画，简单的一镜到底不画。

复杂场的判断标准：
- 多角色同框的打斗 / 对峙
- 复杂走位（多人移动 / 阵法 / 围合）
- 多机位切镜的分镜头序列

---

## 双输出格式（图片提示词 + 视频提示词）

每个复杂场输出两份提示词，都可直接复制使用：

### 输出 1：故事板图片提示词（用于生成故事板参考图）

```
AI随风制作，禁止商业售卖

[风格提示词逐字粘贴]

基于 SDxx 运动提示词生成{4/6/9}宫格故事板参考图。

布局：{2×2 / 2×3 / 3×3}，每格独立一格，格间细黑边分隔。
位置编号从左到右、从上到下。

宫格位置编号：
[根据宫格类型画出布局图，标1-N的位置]

[每格内容，按以下格式：]

位置 N（位置名，如"左上"）：
- 对应镜头：镜头X
- 调用资产：C01（角色名·标注）/ S01（场景·标注）/ P01（道具·标注）
- 画面内容：<具体动作叙述，只写镜头拍得到的物理动作>
- 运镜：<景别 + 机位 + 镜头运动>
- 人物走位：<C01在画面X位置，朝向Y，走位轨迹Z>
- 道具状态：<P01在C01右手/左手/地面/已破损>
- 光线：<主光方向 + 色温>
- 台词（如有）：<说话人 + 完整台词原文 + 时间码>

[画质尾缀]
白色背景或浅灰背景，柔和顶光，{画风}风格，8K超精细，
材质纹理清晰可触，电影级分镜板参考图标准。
```

### 输出 2：故事板视频提示词（用于 Seedance 2.5 生成视频）

> 与 `04-motion-prompt.md` 的视频提示词**同格式（五维融合连续段落）**，只是按故事板逐镜拆分、并引用故事板参考图。技法焊进描写，不贴"加载XX"标签。

```
AI随风制作，禁止商业售卖

[风格提示词逐字粘贴]

本段规划时长X秒，整段演出测算总时长不超过X秒，保持同一角色、同一服装状态、
同一场景光线、同一道具状态和同一画面风格。

本段为复杂分镜头序列，按故事板走位执行。

@图片1（C01角色名·标注）作为角色外貌和服装参考
@图片2（C02角色名·标注）作为角色外貌和服装参考
@图片3（S01场景名·标注）作为场景光线和空间参考
@图片4（S01-MV6场景名6宫格）作为多视角空间走位参考
@图片5（SDxx-STORY故事板参考图）作为本段走位和动作序列参考
@音频1（A01角色名·标注）作为配音和节奏参考

[场景调度宪法·完整逐字复制]（同 04-motion，六项规定完整逐字 + 本段微调）

AI一致性约束：所有光线只来自环境；默认单人镜头优先，多人同框须显式写各角色面部独立、不趋同（2.5 多人参考升级）。

镜头一（0-X秒）：[五维融合段落：时间码 + 景别/焦段 + 运镜(具体术语+可对照量，如"3秒内推至特写") + 人物具体动作(身体部位+起点→过程→终点) + 台词原文(说话人+时间码) + 光线(具体光源/方位/色温) + 音画同步(音效对位)]
镜头二（X-Y秒）：[同上，五维融合]
（注：X/Y 为本段 SD 内部的累计时间码，每段 SD 独立从 0 起算，段间不接续——见 V4.5 计时规则，V4.6 保留）
...
[镜头衔接：上一镜末帧如何接到下一镜首帧，人物位置/朝向/道具状态/光线方向保持连续]

[末帧钩子停留0.5-1秒]

可直接复制到 Seedance 2.5。
```

> 每个镜头一段五维融合描写，参考 `04-motion-prompt.md` 第二~三节的 bad→good 范例与运镜/表演/光影/声音技法写法。

## 宫格位置编号规范（锁定规则）

宫格位置编号严格按"从左到右、从上到下"，提示词与位置一一锁定：

### 4宫格（2×2）
```
┌───────┬───────┐
│   1   │   2   │   左上 / 右上
├───────┼───────┤
│   3   │   4   │   左下 / 右下
└───────┴───────┘
```

### 6宫格（2×3）
```
┌───────┬───────┬───────┐
│   1   │   2   │   3   │   左上 / 中上 / 右上
├───────┼───────┼───────┤
│   4   │   5   │   6   │   左下 / 中下 / 右下
└───────┴───────┴───────┘
```

### 9宫格（3×3）
```
┌───────┬───────┬───────┐
│   1   │   2   │   3   │   左上 / 中上 / 右上
├───────┼───────┼───────┤
│   4   │   5   │   6   │   左中 / 中中 / 右中
├───────┼───────┼───────┤
│   7   │   8   │   9   │   左下 / 中下 / 右下
└───────┴───────┴───────┘
```

锁定原则：每个位置编号对应且仅对应一段提示词，禁止错位、漏位、越位。

## 时长测算（自动继承）

时长从前面的运动提示词自动继承，不需要用户再选。如果需要在分镜阶段测算每格台词字数预算：

```
单格时长 = 该段规划时长 T ÷ 镜头数 N
单格画面留白 = 0.5 秒
单格台词可用时间 = (T ÷ N) - 0.5
单格台词字数预算 = 单格台词可用时间 × 3.5 字/秒（戏剧化语速）
```

超时处理：若某格台词超出预算×1.5，标记需精简；超出×2，必须精简。

---

## 与运动提示词一一对应

分镜图与分镜提示词**严丝合缝地配套**：镜头一对镜头一、镜头二对镜头二。

正确做法：一个镜头对应一条分镜提示词，模型才知道你到底要什么。

> 利弊：约束强了画面听话，但丢掉了一些惊喜和模型的创造力。怎么取舍看你实际创作过程中的抉择。

## 闸：film-reviewer 审分镜

- 第一阶段：只给复杂场、与运动提示词一一对应、宫格位置锁定无错位
- 第二阶段：风格提示词前置、资产编号+中文标注引用规范、走位清晰、台词与锁定表一致、视频提示词为五维融合段落（非占位符）且技法焊入非贴标签

> 审核员审分镜时，也把运动提示词和剧本拆解读一遍，对照着审会更准。
