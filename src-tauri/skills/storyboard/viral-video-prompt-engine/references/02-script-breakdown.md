# 02 · 剧本拆解

> 何时用：输入路由通过后，进入资产设计之前。
> 依赖：输入路由的输出（创意方向 / 参考视频拆解 / 现成剧本）。
> 产出：讲戏本（剧情点 + 节奏 + 三张清单 + 导演视野）。
> 验收：剧情点齐全、节奏档位明确、清单无遗漏、讲戏本可读。

---

## 第一步：采集项目配置

最贵的一样东西叫**导演视野**——这部片用什么作者风格去讲：写实克制、奇观尺度、还是冷峻精密。可以挂一位导演或摄影师的署名当锚（如 Greig Fraser Dune 2021）。视野立稳，后面所有环节都服从它。

采集项：
- 导演视野（作者风格 + 可选署名锚）
- 画面类型（3D国漫 / 真人写实 / 2D动画）
- 画幅（16:9 / 9:16 / 21:9）
- 平台（抖音 / B站 / 视频号 / YouTube）

---

## 第二步：拆成剧情点

把剧本拆成一个个**剧情点**，每个点定：

- 落在哪个人物 / 场景
- 节奏意图（蓄力 / 张 / 弛 / 高潮 / 收束）
- 数节拍（这一拍多长）
- 预算气口（留白和反应停顿单独预算，不是凑时长的余数）
- 落时长（时长跟内容走，默认偏短，15 秒是上限不是目标）

> 节奏的底层规律：时长跟着内容走，默认偏短。留白和反应停顿本身就是戏，要单独预算。一镜到底优于切镜。

---

## 第三步：提三张清单

从剧情点里提：

- **人物清单**：角色名 / 身份 / 外观锚（一句话）/ 是否已有 ref / 强弱关系
- **场景清单**：场景名 / 环境一句话 / 是否需建场参考图 / 是否双人对话场景（需关系板）
- **道具清单**：名称 / 类型 / 形态命门 / 数量锁

这三张清单是后面所有环节的**单一真相源**。源头有遗漏，会顺着流程一路污染下游。

---

## 第四步：写讲戏本

每个剧情点底下跟一段从导演视角写的**讲戏**：

- 画面里有什么
- 人物做了哪个具体动作（揉太阳穴，不是"表现疲惫"）
- 谁说什么
- 镜头怎么走
- 光从哪儿打
- 要让人感觉到什么（靠动作和环境托，不直说）

讲戏有纪律：只写镜头拍得到的具体物理动作。情绪不直说。

---

## 讲戏本格式

```markdown
# 讲戏本 · <项目名>

## 导演视野
- 作者风格：<写实克制 / 奇观尺度 / 冷峻精密>
- 署名锚：<可选 Greig Fraser Dune 2021>
- 画面类型：<3D国漫 / 真人写实 / 2D动画>

## 剧情点

### 剧情点 1 · <名称>
- 落点：<人物 / 场景>
- 节奏意图：<蓄力 / 张 / 弛 / 高潮 / 收束>
- 节拍：<X 拍>
- 气口：<留白 / 反应停顿 单独预算>
- 时长：<X 秒>
- 叙事功能：<这一拍承担什么>

**讲戏**：
<从导演视角写的一段阐述。只写镜头拍得到的具体物理动作。>

### 剧情点 2 · ...
...

## 人物清单
| 角色 | 身份 | 外观锚 | 已有 ref | 强弱关系 |
|---|---|---|---|---|
| ... | ... | ... | ... | ... |

## 场景清单
| 场景 | 环境 | 需建场参考 | 双人对话需关系板 |
|---|---|---|---|
| ... | ... | ... | ... |

```

---

## 闸：film-reviewer 审讲戏本

讲戏本出后自动派 film-reviewer 审：
- 第一阶段：剧情点齐不齐、有没有死引导、清单有没有遗漏
- 第二阶段：讲戏是不是只写具体物理动作、节奏档位合不合理

审不过回本 Skill 修，修完重审，过了才进资产设计。

> 这一步是后面所有环节的单一真相源。源头有遗漏，会顺着流程一路污染下游。这份稿子最值得亲自核一遍。
