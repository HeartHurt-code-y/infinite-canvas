# 05 · 与官方 h3-prompt-writing 逐条对照

对比基准：官方 skill `h3-prompt-writing`（MiniMax 官方），
参考文件 `references/ref-en.txt`（全参考模式）+ `references/base-en.txt`（基础模式）。
官方 skill 未做任何修改，本文件只做差异分析。

| # | 项目 | 官方出处 | 说明 |

## B. 不同点（共 16 项）

### B0. 输出语言策略（**V1.1 新增，最直观的差异**）

| 元素 | 官方 | 本 skill |
|------|------|---------|
| 六个字段名 | 英文 | 英文（一致） |
| `<Subject N>` 等标签 | 英文 | 英文（一致） |
| `fully_preserved` 等保留标记 | 英文 | 英文（一致） |
| **叙述性文本** | **英文** | **中文** |
| **对白** | `<d>[中文] "……"</d>` | `→角色名说"……"` |
| **Negative** | 官方无此字段 | 英文关键词 |

**改动的理由**：官方要求全英文，但中文场景用中文写人物与动作，
描述精度更高、改起来也快；字段名保持英文则不破坏模型对结构的识别。

**代价**：涉及视频编辑 / 音频复用 / 说话人 ID / 精确音画对齐时，
中文叙述会与官方标记体系打架，需整段切回英文（见 B3、B7、B8）。

### B0.5 两种描述模式（**V1.1 新增**）

| | 官方 | 本 skill |
|---|---|---|
| 描述单位 | 只有 `[Shot N] At MM:SS.mmm` | **双模式**：节拍模式 `→` / 时间码模式 `**0–1s：**` |
| 对白密集场景 | 仍是 Shot + 时间戳 | 用 `→` 铺事件流，一行一事件 |
| 表演密集场景 | 仍是 Shot + 时间戳 | 用时间码切到 0.5s |

官方只有 Shot 一种组织方式，对白戏与表演戏用同一套记号。
本 skill 按镜头性质分流，是纯增量。

### B1. 覆盖范围

| | 官方 | 本 skill |
|---|---|---|
| 模式 | 5 种：T2VA / I2VA / FL2VA / L2VA / Ref2VA | 仅 Ref2VA 一种 |
| 影响 | 通用 | 单点击穿，规范更细，但非全参考场景需回退官方 |

### B2. 硬性数值限制

| 限制 | 官方 ref-en.txt | 本 skill |
|------|----------------|---------|
| 输出时长 | 未写明 | 4–15 秒（24 FPS） |
| 提示词长度 | 未写明 | ≤ 7000 字符 |
| 参考素材上限 | 未写明 | 9 图 + 3 视频 + 3 音频，总数 ≤ 12 |
| 参考图分辨率 | 未写明 | 建议 ≤ 1024×1024（过大触发降采样） |
| 参考图数量 | 未写明 | 建议 1–3 张（过多提高失败率） |

> 官方两份 txt 中均无数字上限，这些是平台侧约束的补充。

### B3. summary 的任务类型前缀（**最显著差异**）

官方 ref-en §3 **强制**：summary 必须以方括号任务类型前缀开头，共 6 种，用 ` + ` 组合，不重复：

```
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

| 任务类型 | 使用时机 |
|---------|---------|
| `keyframe completion` | 图作为首帧 / 关键帧 / 尾帧等具体帧锚点 |
| `reference generation` | 素材只提供生成指导，不作具体帧 |
| `video editing` | 直接修改已有源视频 |
| `video continuation` | 从源视频结尾续写 |
| `audio reuse` | 完整或部分复用同一音频信号 |
| `audio reference` | 只引用音色/风格/节奏，不复制信号 |

**本 skill 完全省略此规范**，示例 summary 直接以「8 秒一镜到底，场景是夜晚街头」开头。

> 风险提示：这是本 skill 相对官方的**功能性缺口**。若任务涉及视频编辑/续写/音频复用，
> 建议补回官方前缀；纯角色参考生成场景可省略。

### B4. 时间标注方式

| | 官方 | 本 skill |
|---|---|---|
| 格式 | `[Shot 2] At 00:03.500, ...`（毫秒级切点） | 节拍模式 `→`；时间码模式 `**1–2.5s：**` |
| 粒度 | 以「切镜」为单位 | 节拍 = 一个事件；时间码最细 0.5s |
| 优势 | 多镜头场景切点精确 | 对白戏用节拍更准，表演戏用时间码更细 |

### B5. 镜头组织单位

- 官方：`[Shot 1]` `[Shot 2]` `[Shot 3]` 显式编号，切镜标记 `the camera cuts to`
- 本 skill：`**[一镜到底] 0–8s**` + 时间码段，弱化 Shot 概念
- 影响：本 skill 面向**单镜头长表演**优化；多镜头项目官方更合适

### B6. retention_analysis 书写格式

官方（ref-en §4.1）：
```
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - the exposed brick wall...
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
<Video 1> (cut and pacing structure): weak_reference - ...
```
- 带**出现镜头标注** `(appears in [Shot X])`
- 用 `:` 分隔标签与标记，用 `-` 引出说明

本 skill：
```
- <Subject 1>：fully_preserved 唐糖全套外观，动作：站在马路上 → 背影 → 侧脸 → 微表情变化。
```
- 无镜头标注
- 标记后直接接说明
- **新增「动作链」**：用 `动作：A → B → C` 概括该主体的时间线动作

### B7. 音频关系标记（**官方有、本 skill 缺失**）

官方 ref-en §4.2 为 `<Audio N>` 单独定义了 4 个标记：

| 标记 | 含义 |
|------|------|
| `fully_copy` | 源音频完整作为目标视频最终音轨 |
| `partially_copy` | 只复制部分时间线或图层，或增删替换 |
| `reference` | 不复制信号，只引用音色/节奏/风格/内容/质感 |
| `weak_reference` | 只保留类别或氛围的宽泛相似 |

**本 skill 未涉及音频标记的细化**，音频只在标签定义中一笔带过。
涉及音频复用/音色克隆的任务，须回查官方 ref-en §4.2 与 §5.4。

### B8. 说话人 ID 与语音标记（**官方有、本 skill 缺失**）

| 官方能力 | 出处 |
|---------|------|
| `(S1)` `(S2)` 全局说话人编号 | ref-en §5.4 |
| 复合 ID `(S1,S2)`（多人齐说） | base-en §4 |
| `<Subject N> (Sx)` 组合写法 | ref-en §5.4 |
| `<scenetrans>` 对话跨切镜 | ref-en §5.1 |
| `<cutoff>` 视频结尾截断语音 | ref-en §5.1 |
| `[unclear]` 不可辨语音占位 | ref-en §5.4 |
| BGM 内人声用 `<Audio N>` 而非 `(Sx)` | ref-en §5.4 |

**本 skill 仅在示例 B 中出现一次 `(S1)`，未形成规则。**

### B9. Negative 提示词（**本 skill 独有**）

- 官方两份参考文档中**零次提及** Negative，结构中无此字段
- 本 skill 将 Negative 作为第 7 段，置于提示词末尾，上限 10 词
- 定位为社区实践增强项，非官方规范

### B10. 运镜描述维度

| | 官方（base-en §4.3） | 本 skill V1.2 起 |
|---|---|---|
| 维度 | 3 个：运动类型 + 幅度 + 速度 | **沿用官方 3 个**；弧形/环绕/多主体推拉时**可选**加「轴心点」 |
| Zoom vs Dolly | **明确区分**：`Zoom In/Out` 变焦（机身不动）；`Push In/Pull Out` 推拉（机身移动） | V1.2 起已同步该区分 |
| 幅度/速度省略规则 | 中等幅度、正常速度通常省略 | 与官方一致，不强制写全 |
| 写法 | 自然英文动作句，禁止堆标签 | 与官方一致 |

> **V1.2 修正**：V1.0–V1.1 曾自创「运镜五要素（轨迹/方向/角度/速度/轴心点）」，
> 与官方 §4.3 冲突，且会给出「必须凑齐五要素」的错误建议。已废止。
> 轴心点降为**可选增强**，只保留在弧形/环绕这类确实需要它的场合。

### B10b. 说话人 ID

| | 官方（base-en §4.4 / ref-en §127） | 本 skill |
|---|---|---|
| 稳定 ID | **强制**。说话/演唱/画外人声的角色用 `(S1)`/`(S2)`，放在 `<d>` 之外，跨镜头一致；不发声的角色不给 ID | V1.2 前完全缺失 |
| ID 建立 | 首次出现时用音色/年龄/性别/语速等信息建立身份 | V1.2 起校验但不强制建立 |

确认：官方样例 `the middle-aged baker with a calm, slightly raspy voice (S1) ...`。

### B10c. 切镜时间戳规则

| | 官方（base-en §4.2） | 本 skill |
|---|---|---|
| 首镜 | **不加时间戳** | V1.2 起与官方一致 |
| 后续镜头 | 顺序编号 + 严格递增切点，且不超出视频时长 | V1.2 起校验 |
| 切镜理由 | 每个切点应引入新信息（主体/空间/状态/视点/时间） | 未校验 |
| 转场用语 | 普通切镜用 `the camera cuts to` / `the shot cuts to` 等 | 未区分 |

### B10d. 多镜头时长预算（本 skill 独有，官方无）

官方只约束切点递增，不校验「台词塞不塞得下」。
本 skill 按 **中文 4.5 字/秒** 估算口播时长，逐镜核对：

- 台词耗时 > 该镜可用秒数 → `SHOT-OVER`（错误）
- 余量 < 1.2s（不够做动作/反应）→ `SHOT-TIGHT`（警告）

实测有效：一段 15 秒三镜头短剧，声明 10→15s 给末镜，
但末镜塞了 41 字台词（需 9.1s），严重超时，被该检查直接拦下。

### B11. 抽象词管控范围

| | 官方 | 本 skill |
|---|---|---|
| 管控位置 | **仅** `non_diegetic_music`（base-en §4.4：「do not use abstract mood words」） | 全提示词 |
| 规则强度 | 一条原则性建议 | 14 条铁律 + 禁用词替换表 |
| 具体机制 | 无 | 删内心独白、情绪标签→可观察动作、动作拆因果链（触发→准备→发力→接触→反作用→落定） |

### B12. 去背景污染（本 skill 独有）

官方未提及参考图棚拍背景问题。
本 skill 强制在 Subject 定义中写：
```
完全参照 <Picture 1> 外观。<Picture 1> 不得展示灰色背景，实际场景替换为夜晚街头。
```
这是实战高频坑，官方规范未覆盖。

### B13. 字数与粒度建议

| | 官方 | 本 skill |
|---|---|---|
| 生成任务 | `detailed_description` 350–500 英文词 | 未给字数，改为模式化要求 |
| 视频编辑任务 | 随源视频复杂度缩放，不受该区间约束 | 未区分 |
| 单镜头 | 「不自动缩短描述」 | 时间码模式按 0.5s 切微表情 |
| 对白密集 | 无专门建议 | 节拍模式：10 秒 4–6 句，每句 8–15 字 |

### B14. 纯文字定义的 Subject

- 官方：Subject 主要面向有参考素材的内容
- 本 skill：明确支持「无参考图，由文字描述定义」的 Subject（如场景 Subject 4）
- 影响：场景一致性提升，但会占用 Subject 名额

## C. 结论

### 本 skill 是官方的**垂直增强子集**，不是替代品。

**该用本 skill 的场景**
- 全参考（有参考图/视频/音频）
- 单镜头或少量镜头
- 中文叙述更顺手（本 skill 默认中文，官方强制英文）
- 表演/微表情是核心卖点（MV、情绪短片、人物特写）→ 时间码模式
- 对白密集的短剧分镜 → 节拍模式
- 参考图带棚拍纯色背景
- 需要压住表情失控、镜头不动、乱入路人等常见翻车

**该回退官方 h3-prompt-writing 的场景**
- T2VA / I2VA / FL2VA / L2VA（本 skill 完全不覆盖）
- 视频编辑 / 续写（需要 `[video editing]` 等任务类型前缀）
- 音频复用 / 音色克隆（需要 `fully_copy` 等 4 个音频标记）
- 多人对白需说话人 ID、跨切镜台词、BGM 内人声（需要 `(Sx)` / `<scenetrans>` / `<cutoff>`）
- 台词需精确音画对齐（需要 `<d>[中文] …</d>`）
- 需要 Zoom 变焦语义（官方区分 Zoom / Dolly）

### 建议的合并方向

官方负责「结构正确性 + 音频/语音/任务类型」，
本 skill 负责「表演颗粒度 + 运镜可控性 + 实战避坑 + 中文可读性」。
两者互补，理想做法是在输出前用官方规则做一遍结构校验，
再用本 skill 的 `scripts/validate_ref2va.py` 做一遍实战校验。

**V1.1 起支持「整段切换」**：默认用中文模板（示例 A/B）；
一旦任务涉及上面任何一个回退条件，就把整段切成英文版（示例 C），
不要中英混写——混写最容易让模型搞不清哪个是结构、哪个是内容。
