# 02 · 两种描述模式 + 表演拆解 + 运镜三维度

## 0. 先选模式

`detailed_description` 有两种写法，**按镜头性质选**，不要混着乱用：

| 模式 | 适用 | 记号 | 典型场景 |
|------|------|------|---------|
| **节拍模式** | 对白密集、动作是离散事件 | `→` 起头 | 对话戏、群戏、短剧分镜 |
| **时间码模式** | 表演 / 微表情 / 运镜是卖点 | `**0–1s：**` | MV、情绪特写、一镜到底长表演 |

**判断标准**：这一镜里「说了几句话」比「表情怎么变的」更重要 → 用节拍模式。
反过来，一句话没有、全靠脸演 → 用时间码模式。

两者可在同一段里**混用**：先用 `→` 铺事件流，在需要细写的关键处切时间码。

### 0.1 节拍模式（对白密集）

```
detailed_description:
[一镜到底] 0–10s，场景是夜晚街头。唐糖和林浩并肩在街上行走，镜头从正面跟随拍摄，全程保持和两人的距离。
→林浩看着唐糖。
→林浩说"唐糖，你今天真漂亮！"。
→林浩看着镜头，唐糖笑了，看着林浩。
→唐糖说"林大哥，你今天真会说话！"。
→林浩拍了拍胸部。
→林浩说"那是，做舔狗，我是专业的！"。
→唐糖看着林浩，用手指着林浩。
→唐糖说"舔狗舔狗，一无所有！"。
→俩人看着镜头，继续走路。
```

**写法要点**

| 要点 | 说明 |
|------|------|
| 首行定基准 | `[一镜到底] 0–Ns` + 场景 + 人物状态 + 镜头方式 + 构图距离 |
| 一行一事件 | 一个 `→` = 一个独立动作或一句台词，不合并 |
| 台词格式 | `→角色名说"台词"。` —— 角色名 + 说 + 中文引号 |
| 视线要写 | 「看着谁」是调度核心，每个情绪转折都标视线方向 |
| 动作要具体 | 「用手指着林浩」而不是「指责他」 |

**10 秒对白节奏参考**：10 秒约 4–6 句短台词，每句 8–15 字。
超了会挤，H3 会吞字或加快语速。

## 1. 时间码切片法（表演密集）

官方按 `[Shot N]` 切镜描述；本 skill 用**秒级时间码**逐拍写，粒度细到 0.5s。
单镜头长视频尤其受益——微表情变化在 Shot 级描述里会被整体吞掉。

### 格式
```
detailed_description:

**[一镜到底] 0–8s**

**0–1s：** 远景。夜晚街头（Subject 4）。画面中只有唐糖、宝儿、林浩三人...

**1–2.5s：** 镜头焦点从远景缓慢切换到近景...

**2.5–4.5s：** 镜头开始沿弧线轨迹移动...
```

### 切片密度建议

| 段落性质 | 建议切片 |
|---------|---------|
| 运镜 / 位移 | 1.5–2s 一段 |
| 动作执行 | 0.5–1s 一段 |
| 微表情 / 情绪递进 | 0.5s 一段（最细） |
| 静态停留 | 1s 一段，别再切 |

**8 秒片段建议 5–8 个时间码段。** 少于 4 段说明写粗了。

## 2. 表演拆解：删内心独白，用可观察动作

### 禁用词表（出现即返工）

| 禁用（抽象） | 替换为（可观察） |
|-------------|----------------|
| 悲伤 / 伤心 | 嘴角微微下沉、下颌收紧、目光失焦 |
| 害羞 | 低头、目光落在自己脚上、脸颊泛红 |
| 愤怒 | 鼻翼张开、眉头压低、拳头攥紧、肩膀上抬 |
| 紧张 | 喉结滚动、手指反复摩挲衣角、呼吸变浅 |
| 心动 / 心跳加速 | 瞳孔放大、眨眼频率升高、手指无意识蜷缩 |
| 满脑子都是 | （删掉，改为具体视觉闪回或直接删除） |
| 用力一扔 | 右手向后引臂 → 肘部前送 → 手腕翻转 → 脱手 |

### 情绪递进要拆成节拍

不要写「她哭了」，写：

```
**5–5.5s：** 唐糖眼睛微眯，瞳孔失焦无神，目光空洞地看着前方，眼眶开始微微泛红。
**5.5–6.5s：** 泪水慢慢涌出眼眶，在睫毛处停留，嘴唇微微颤抖。
**6.5–7.5s：** 泪水滑落脸颊，下颌收紧，嘴角微微下沉，整张脸呈现出一种被掏空的伤心。
```

## 2.5 对白写法

### 基础格式（本 skill 默认）

```
→角色名说"台词"。
```

- 角色名用 `subject_definitions` 里定义的名字，全文统一
- 台词用**中文双引号**包裹，句末标点放在引号内
- 一句台词独占一行，不与动作合并

### 台词要配动作和视线

孤立的一句台词，模型往往会让人物"站桩念稿"。**每条台词前后都要挂动作或视线**：

```
→林浩看着唐糖。
→林浩说"唐糖，你今天真漂亮！"。
→唐糖笑了，看着林浩。
→唐糖说"林大哥，你今天真会说话！"。
```

三段式：**谁看谁 → 说什么 → 对方什么反应**。

### 对白七要素（V1.3 新增）

一句台词要成立，光有「谁说」和「说什么」不够。按下面七项检查，
缺项越多，越容易出现「站桩念稿」「口型对不上」「情绪平掉」：

| 要素 | 说明 | 示例 |
|------|------|------|
| 视线 | 说这句话时看着谁/看哪儿 | 林浩转头看着唐糖 |
| 呼吸 | 说话前的吸气、句间的换气 | 他吸一口气，声音发紧 |
| 停顿 | 句内停顿、说之前的沉默 | 顿了半拍才开口 |
| 微表情 | 面部最细微的变化 | 嘴角先动，笑容才慢慢铺开 |
| 音色 | 音质 + 情绪 + 速度 | 低沉男声，语速偏慢，带着笑意 |
| 原话 | 台词原文，一字不改 | "唐糖，你今天真漂亮！" |
| 口型 | 说完嘴唇如何闭合 | 说完抿住下唇 |

**不必七项全写**——按镜头权重挑：

- **主镜/特写**（这镜就是卖这句台词）：七项全写
- **过镜/反应镜**（重点是对方的反应）：视线 + 微表情 + 口型
- **群戏背景台词**：音色 + 原话即可

**口型是硬要求**：官方 base-en §136 明确，画外音（VO）必须在 `<d>` 之后
写明 `lips remain completely closed`。本 skill 把它推广为通用规则——
凡是对白结束，就交代嘴唇状态，否则模型容易让人物张着嘴停住。

> 呼吸/停顿/口型/微表情/音色 五项来自 `minimax-h3-prompt-standardizer` 的
> dialogue 要素清单。官方 ref-en §5.4 有音色与 `<d>` 规范，也有 VO 口型规则，
> 但**没有把呼吸、停顿、微表情列为对白必写项**——本表是增强，不是复述。

### 时长预算

| 片段时长 | 建议台词量 |
|---------|-----------|
| 6 秒 | 2–3 句，每句 8–12 字 |
| 10 秒 | 4–6 句，每句 8–15 字 |
| 15 秒 | 6–8 句，每句 10–18 字 |

**超时后果**：H3 会加快语速、吞字，或干脆砍掉末尾台词。
宁可少写一句，也别挤。

### 什么时候换回官方 `<d>` 语法

以下三种情况，把 `→角色名说"..."` 换成官方写法：

| 场景 | 写法 |
|------|------|
| 需要精确音画对齐 | `<d>[中文] "台词"</d>` |
| 多音色 / 音色克隆 | `<Subject 1> (S1) 说 <d>[中文] "……"</d>` |
| 台词跨切镜 | 配 `<scenetrans>` 标记 |

详见官方 `ref-en §5.4`。

### 物理动作七要素

**触发 → 准备 → 重心 → 发力 → 接触 → 反作用 → 收势**

| 要素 | 问自己 | 例：「他推开门」 |
|------|--------|-----------------|
| 触发 | 什么引起这个动作 | 脚步在门前停住 |
| 准备 | 身体如何蓄势 | 右手抬起，指尖触到门板 |
| **重心** | 重量压在哪只脚 / 哪侧髋 | 重心移到前脚掌，左肩略沉 |
| 发力 | 哪块肌肉主导 | 肩膀前顶，手臂伸直 |
| 接触 | 与物体/环境如何作用 | 掌心压满门板，门轴发出低响 |
| 反作用 | 惯性带来什么连带 | 身体因惯性前倾半步 |
| **收势** | 动作结束时停在什么姿态 | 收回手臂，跨过门槛，站定 |

> **重心** 与 **收势** 是 V1.3 从 `minimax-h3-prompt-standardizer` 合并进来的两个要素。
> 原六要素链完整描述了「动作怎么发生」，但没交代「人站在哪儿」和「停下来什么样」——
> 这两项恰恰是多段生成时**尾帧接得上、接不上**的关键。
> 官方 ref-en §4.4 只要求 describe 动作，未列要素清单，故本表不与官方冲突。

**收势必须显式写出来**，不要停在动作中途。收势即下一段的起始姿态锚点。

## 2.6 多段拆分：切点铁律

一段 4–15 秒装不下时，才拆成多段。**拆点选错，比不拆更糟**——
前后两段接不上，人物会在接缝处"跳"一下。

### 切点必须落在「可见变化」上

只在下面这些位置切：

| 合法切点 | 例子 |
|---------|------|
| 景别变化 | 中景 → 特写 |
| 视点变化 | 正面 → 侧面、第三人称 → 主角视角 |
| 空间变化 | 车内 → 车外、客厅 → 卧室 |
| 时间变化 | 黄昏 → 深夜、"三天后" |
| 主体变化 | 唐糖 → 林浩、人物 → 空镜 |
| **动作完整结束** | 门推开并站定，才切 |

### 严禁在这些位置切

- ❌ 同一个动作做到一半（手抬到一半、门推到一半）
- ❌ 同一个姿势保持中（人物还在走着、还在笑着）
- ❌ 同一次情绪递进的中途（眼泪刚要掉、笑容刚要展开）
- ❌ 同一句台词说到一半（跨切镜台词属例外，须配 `<scenetrans>`）

> **依据**：官方 base-en §4.2 原文——
> *"A cut should introduce new information about the subject, space, state, viewpoint, or time."*
> 官方已规定切点要引入新信息，本 skill 补上了它的反面清单——
> 「什么位置不能切」，以及规范器贡献的第 6 项「动作完整结束」。

### 每段都要写「尾帧状态 + 下一段切点」

多段输出的每一段末尾，额外补两行：

```
【本段尾帧】唐糖站在门内，右手仍搭在门把上，侧脸朝向门外的光，嘴唇微张。
【下段切点】切到林浩的正面特写，景别由中景变特写，视点转到林浩。
```

**为什么必须写**：H3 每段是独立生成的。不写尾帧，下一段的首帧全靠模型猜，
人物姿态、站位、光线方向十有八九对不上。写清楚了，才谈得上跨段连续。

> 这条来自 `minimax-h3-prompt-standardizer` 的多段输出模板。
> 官方六段式是**单段**结构，完全没有跨段锚点的概念——这是本 skill 的净增量。

### 跨段连续性锚点

多段项目在动笔前，先定死这四个东西，全程不改：

| 锚点 | 内容 |
|------|------|
| 角色 | 服装、发型、配饰、特征（疤、痣、伤） |
| 场景 | 空间结构、陈设、光源方向与色温 |
| 声音 | 环境底噪、音色、音乐动机 |
| 时间 | 情节所处的具体时刻与天气 |

## 2.7 转场：禁止空话，必须有可见匹配元素

❌ 不能这么写：

```
→丝滑转场到下一段。
→镜头自然过渡到室内。
→流畅切换。
```

「丝滑」「自然」「流畅」是**观感形容词，不是指令**——模型不知道该做什么动作。

✅ 要这么写：指明**两段之间共有的那个可见元素**，让它成为转场的钩子：

| 转场类型 | 写法 |
|---------|------|
| 视线匹配 | 唐糖看向画右 → 下一段从画左的林浩开始 |
| 动作匹配 | 上一段手伸向门把 → 下一段门把被压下 |
| 形状匹配 | 上一段结尾是圆形车窗 → 下一段开头是圆形挂钟 |
| 色彩匹配 | 上一段收在暖黄灯光 → 下一段从暖黄台灯特写开 |
| 运动匹配 | 上一段镜头右移 → 下一段同方向右移接入 |
| 声音牵引 | 上一段末尾响起电话铃 → 下一段电话铃继续 |

> 官方 base-en §4.2 给了转场的**词汇表**（`the camera cuts to` / `cross-dissolve` /
> `fade` / `wipe`），并规定 dissolve/fade/wipe **仅在用户明确要求时使用**。
> 但官方没有要求「指明匹配元素」。本条是 `minimax-h3-prompt-standardizer` 的贡献，
> 与官方词汇表**不冲突**——用官方的词，再补上匹配元素即可。

## 3. 运镜：官方三维度 + 1 项可选增强

> ⚠️ **V1.2 修正**：本 skill V1.0–V1.1 写的「运镜五要素（轨迹/方向/角度/速度/轴心点）」
> 是自创的，且与**官方 §4.3 冲突**——官方只要求三个维度。已废止，改为下面的口径。

### 基线：官方 §4.3 三维度（写运镜必须覆盖）

| 维度 | 官方写法 | 说明 |
|------|----------|------|
| **运动类型** | `Push In` / `Arc Shot` / `Pan Left` / `Zoom In` … | 相机怎么动 |
| **幅度** | `with small amplitude` / `with large amplitude` | 构图变化范围 |
| **速度** | `at slow speed` / `at fast speed` | 变化节奏 |

官方原话：*"Add amplitude and speed only when they are meaningful;
medium amplitude and normal speed are usually omitted."*
→ **中等幅度、正常速度可省略**，不写不算错。

官方还要求**写成自然英文动作句，不要堆标签**：

```
✅ The camera pushes in with small amplitude at slow speed toward the folded letter.
❌ Camera: push in. Amplitude: small. Speed: slow.
```

**官方运动类型全表**（照抄，别自创）：
`Zoom In/Out`（焦距变、机身不动）、`Push In/Pull Out`（机身后退前进）、
`Pan Left/Right`（原地水平转）、`Truck Left/Right`（水平平移）、
`Tilt Up/Down`（原地垂直转）、`Pedestal Up/Down`（整机上下降）、
`Arc Shot`（绕主体弧线）、`Tracking Shot`（跟随运动主体）、
`Static Shot`（全静止）、`Shake Slightly/Strongly`、`POV`、
`Roll Clockwise/Counterclockwise`

> 注意 **`Zoom` 与 `Push In` 是两回事**：Zoom 是变焦（机身不动），
> Push In 是推镜头（机身前进）。写混了会得到一个"假推镜"。

### 可选增强：轴心点（本 skill 独有，非官方要求）

只在**弧形 / 环绕 / 多主体推拉**这类运镜上加，因为这时"绕谁转"确实会影响结果：

```
The camera arcs 90 degrees with Subject 1 as the pivot,
moving from behind her toward her left side at slow speed.
```

对固定机位、简单跟拍、单主体推近，**不要加**，加了是冗余。

### 完整写法示例（弧形运镜，官方三维度 + 轴心点增强）

```
The camera arcs with large amplitude at slow speed, using Subject 1 as the
pivot, starting from behind her and swinging to her left side through 90
degrees, keeping a constant lens height. Her face turns from back view to
profile while the background rotates in sync.
```

### 运镜关键词表

| 英文 | 中文 | 场景 |
|------|------|------|
| `Static / Fixed` | 固定机位 | 镜头不动，仅画面内元素运动 |
| `Push in / Dolly in` | 推近 | 镜头缓慢向主体推进 |
| `Pull out / Dolly out` | 拉远 | 镜头缓慢从主体拉远 |
| `Orbital / Arc shot` | 环绕 / 弧线 | 沿弧线轨迹围绕主体旋转 |
| `Steadicam / Gimbal` | 稳定器跟随 | 平滑跟随主体运动 |
| `Pan` | 平移 | 镜头水平转动 |
| `Tilt` | 俯仰 | 镜头垂直转动 |
| `Tracking shot` | 跟拍 | 镜头跟随主体移动 |
| `Rack focus` | 焦点切换 | 近景 ↔ 远景焦点互换 |

### 焦点切换（Rack focus）写法
```
镜头焦点从远景缓慢切换到近景 —— 宝儿和林浩逐渐变模糊，
唐糖逐渐变清晰。镜头位置保持不动，仅做焦点推移。
```

**注意**：`Rack focus` 是焦点变化，不是机位移动，两句要分开写清楚，
否则模型容易理解成推镜头。

## 4. 构图占比（可选但强烈建议）

定格画面时写明主体占画幅比例，能显著提升稳定性：

```
定格在唐糖侧面中近景（胸部到头顶），唐糖占画面约 60%，侧脸清晰。
```
