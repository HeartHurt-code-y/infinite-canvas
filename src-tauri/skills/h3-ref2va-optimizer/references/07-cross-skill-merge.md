# 07 · 跨 Skill 合并溯源（V1.3）

V1.3 合并了 `minimax-h3-prompt-standardizer`（小白向 H3 提示词规范器，下称**规范器**）。
本文档记录：**合了什么、从哪来、官方到底有没有**。

## 两份 Skill 的分工差异

| | 规范器 | 本 skill |
|---|---|---|
| 目标用户 | 小白，输入可以很乱 | 已知要写 Ref2VA |
| 输出格式 | 中文 `【任务设定】`/`【主提示词】`/`【防错约束】` | 官方六段式 + 英文标签 |
| 覆盖模式 | 全模式（T2VA/I2VA/FL2VA/Ref2VA） | 只做 Ref2VA |
| 强项 | 输入容错、分段策略、可靠性清单 | 表演粒度、运镜、与官方逐条对齐 |

**结论**：不冲突的两条路线。规范器的价值在**流程层**（怎么接住烂输入、
怎么拆段、怎么防翻车），本 skill 的价值在**表达层**（怎么写准表演和运镜）。
合并方式是：把流程层并入，表达层保持原样。

## B. 看似新增、实际官方已有（合并时须标注，不能邀功）

| # | 规则 | 官方原文 | 处理 |
|---|------|---------|------|
| B1 | 切点必须落在可见变化上 | base-en §4.2：*"A cut should introduce new information about the subject, space, state, viewpoint, or time."* | **沿用官方**，规范器只是补了第 6 项「动作完整结束」+ 反面清单 |
| B2 | 画外音口型 | base-en §136：VO 后必须写 `lips remain completely closed` | 官方只管 VO；本 skill 推广为**所有对白**都交代口型（属增强） |
| B3 | 音色描述 | ref-en §5.4、base-en §132（`quiet, breathy voice (S1)`） | 官方已有，规范器的「音色」= 官方 voice 描述 |

> B1 是本次核验最重要的发现：**差点把官方已有的规则当成规范器的原创**。
> 合并第三方 Skill 时，每一条都必须回官方原文 grep 一遍再定性。

## C. 与官方冲突（不跟随规范器）

| # | 规范器主张 | 官方规定 | 本 skill 取舍 |
|---|-----------|---------|--------------|
| C1 | 「电影感」是要替换的模糊词 | base-en §4.2 把 `Cinematic` 列为**常见风格之一**，示例即 `[Shot 1] Live-action, cinematic, ...` | **不跟随**。按位置区分：首句风格标签 ✅，替代细节描写 ❌ |
| C2 | 输出中文 `【任务设定】` 等自定义块 | 官方规定六段式字段名 | **不跟随**。六段式结构不变，自定义块只放在提示词**之外** |

**C1 的判断依据**：官方是模型厂商自己的规范，`cinematic` 在官方示例里就是合法用法。
规范器从「提示词工程最佳实践」出发禁它，但**与模型实际的训练口径不符**。
冲突时以官方为准——这是本 skill 一贯的原则（V1.2 废掉自创的「运镜五要素」也是同理）。

---

## D. 规范器有、本 skill 明确**不合并**的

| 规则 | 不合并的理由 |
|------|------------|
| 全模式覆盖（T2VA/I2VA/FL2VA） | 本 skill 定位就是 Ref2VA 垂直增强；全模式回退官方 |
| 中文 `【】` 输出块 | 与六段式冲突（见 C2） |
| 「默认无字幕/水印/logo」 | 已由本 skill 的 `Negative` 字段覆盖 |
| 结尾「不许承诺成功」 | 交互话术，非提示词规则，不进规范 |

---

## E. 核验方法（可复用）

合并第三方 Skill 时的三步法：

1. **抽取主张**：把对方 SKILL.md 的每条规则拆成原子条目
2. **回官方 grep**：在 `h3-prompt-writing/references/` 里搜关键词，确认官方是否有
3. **三分法定性**：官方没有 → 新增；官方有 → 标注出处；官方相反 → 以官方为准并说明理由

本次核验命令：

```bash
cd ~/.workbuddy/skills/h3-prompt-writing/references
for kw in transition upload vague weight finishing cinematic segment continuity lip breath pause; do
  printf "%-12s %s\n" "$kw" "$(grep -ic "$kw" ref-en.txt base-en.txt)"
done
```
