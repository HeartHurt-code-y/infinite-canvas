# 06 · 标准输出模板（照抄即可）

> 字段名 / 标签 / 保留标记 / Negative 用**英文**，其余用**中文**。

## 前置块：图片上传顺序（有参考图时必须先写）

**写在提示词之外、提示词之前**，用中文，一行一张：

```text
图片上传顺序：
@图片1：人物主参考，锁定面容、发型、服装和体型
@图片2：场景参考，锁定空间、色彩和光线方向
```

**作用**：H3 只按你上传的先后顺序认图。不写清顺序，
`<Picture 1>` 到底对应哪张全靠猜——这是多图生成最常见的翻车点。

**规则**

- 只列**真实提供**的图，没提供就整块省略，不要编
- 多张参考图冲突时（比如两张都是同一个人），**声明哪张为主**：
  `@图片1：主参考（以这张为准）；@图片2：仅参考服装`
- 源图上的**不良元素要显式声明忽略**：
  `@图片1：忽略原图的水印、界面文字、压缩噪点；姿势不作为参考`
- 顺序必须与正文里的 `<Picture 1>` / `<Picture 2>` 一一对应

> 这条来自 `minimax-h3-prompt-standardizer` 的 Reference rules。
> 官方 ref-en §2 只规定了 `<Picture N>` 的编号与引用方式，
> **没有「在提示词外先声明上传顺序」这个环节**——本 skill 的净增量。

## 前置块：无图模式声明（确认走无图时才写）

**只在用户看完警告并回复确认后使用。** 写在提示词之前：

```text
无图模式（已确认）：本条提示词没有任何参考图，
全部 Subject 由文字描述定义。上线前须补以下参考图后重新生成：
- <Subject 1> 角色A：需补一张正面清晰的人物主参考
- <Subject 4> 场景：需补一张场景参考，锁定空间与光线方向
```

**规则**

- 不写这块 + 正文没有 `<Picture N>` → 校验器报 `IMG-DECL`（警告）
- 写了这块 + 正文还有 `<Picture N>` → 校验器报 `IMG-CONFLICT`（错误，自相矛盾）
- 每个 Subject 末尾都要写「无参考图，由文字描述定义」，否则报 `IMG-TXT-DEF`
- **没图就不许写 `<Picture N>`**，这是硬底线（官方：不许假装看到没给的东西）

## 单段模板

```text
图片上传顺序：
@图片1：角色A主参考，锁定面容、发型、服装和体型
@图片2：角色B主参考，锁定面容、发型、服装和体型

subject_definitions:
<Subject 1>：角色名，年龄/性别/发型/配饰/上装/下装。完全参照 <Picture 1> 外观。
<Subject 2>：角色名，年龄/性别/发型/上装/下装。完全参照 <Picture 2> 外观。
<Subject 3>：场景名，场景元素列举。无参考图，由文字描述定义。

summary:
N 秒一镜到底，场景是 XXX。谁和谁在做什么，镜头从哪个方向拍，全程保持什么构图。

retention_analysis:
<Subject 1>：fully_preserved 角色全套外观，动作：动作 A → 动作 B → 动作 C。
<Subject 2>：fully_preserved 角色全套外观，动作：动作 A → 动作 B。
<Subject 3>：fully_preserved 场景名（场景元素列举）。
画面里只有 XX 和 XX，绝对没有其它人。

detailed_description:
[一镜到底] 0–Ns，场景是 XXX。人物在做什么，镜头怎么拍，保持什么距离。
→事件一。
→事件二。
→角色名说"台词"。
→角色名看着镜头，角色名笑了，看着角色名。

overall_soundscape:
环境音一，环境音二。

non_diegetic_music: N/A

Negative: no other people, no exaggerated expression, no text, no watermark, no camera static,
```

## 逐段写法说明

### subject_definitions

- 一行一个 Subject，用 `<Subject N>：` 起头（**冒号用全角，对齐用全角**）
- 人物：年龄 + 性别 + 发型 + 配饰 + 上装 + 下装，按「从头上到脚下」顺序写
- 末尾一句「完全参照 <Picture N> 外观」
- 若参考图带棚拍纯色背景，**必须**再加一句：
  `<Picture 1> 不得展示灰色背景，实际场景替换为夜晚街头。`
- 场景 Subject 末尾写「无参考图，由文字描述定义」

### summary

固定句式：
```
N 秒一镜到底，场景是 XXX。谁和谁在做什么，镜头从哪个方向拍，全程保持什么构图。
```

### retention_analysis

- 每个 Subject 一行：`保留标记 + 全套外观 + 动作：A → B → C`
- 末尾**可选**加一行防乱入约束：`画面里只有 XX 和 XX，绝对没有其它人。`

> ⚠️ 这行属于画面构成，官方建议放 `detailed_description`。
> 但实战中放在 retention 末尾作为「防乱入」强约束效果更好，本 skill 保留这个写法。

### detailed_description — 两种模式

**节拍模式**（对白密集）：
```
[一镜到底] 0–10s，场景是夜晚街头。唐糖和林浩并肩在街上行走，镜头从正面跟随拍摄，全程保持和两人的距离。
→林浩看着唐糖。
→林浩说"唐糖，你今天真漂亮！"。
```

**时间码模式**（表演密集）：
```
**[一镜到底] 0–8s**

**0–1s：** 远景。夜晚街头（Subject 4）。唐糖背对镜头站在马路中央...
**1–2.5s：** 镜头焦点从远景缓慢切换到近景...
```

首行用 `[一镜到底] 0–Ns` 或 `[Shot 1] 0–Ns` 起头，交代场景 + 人物 + 镜头基准。

### overall_soundscape

中文，两三个环境音，逗号分隔。不要重复 detailed_description 里已有的对白。

### non_diegetic_music

有配乐写「乐器 + 速度 + 动态变化」；没有就写 `N/A`。

### Negative

**必须英文**，≤10 个词，逗号分隔，末尾带逗号。只挑这次最可能翻车的 2–3 类。

## 多段模板（超过 15 秒或内容装不下时用）

```text
【整体设定】
角色：唐糖（蓝白条纹T恤 + 牛仔背带裤，银色船锚耳坠）
场景：夜晚街头，路灯暖黄，从画面左上方打来
声音：远处车流底噪贯穿全片
时间：同一个夜晚，连续时间

【第1段｜8秒｜唐糖在路口停下】
图片上传顺序：@图片1：唐糖主参考
subject_definitions:
...
detailed_description:
[Shot 1] 0–8s，...
【本段尾帧】唐糖站定在路口，右肩微沉，侧脸朝向画右的路灯，嘴唇微张。
【下段切点】切到林浩正面特写，景别由中景变特写，视点转到林浩。

【第2段｜7秒｜林浩转身看见她】
图片上传顺序：@图片1：唐糖主参考；@图片2：林浩主参考
subject_definitions:
...（与第1段保持一致，不要重新描述）
【承上】接续第1段尾帧，唐糖站在路口，右肩微沉。
detailed_description:
[Shot 1] 0–7s，...
【本段尾帧】...
```

**多段三条硬要求**

1. `subject_definitions` 全段复用同一份定义，第二段起**不要重写**（改写就会漂移）
2. 每段开头写【承上】一句，重述上一段尾帧状态
3. 每段结尾写【本段尾帧】+【下段切点】，切点必须落在合法位置（见 02 号文件 §2.6）

## 无图模式模板（用户确认后才用）

```text
无图模式（已确认）：本条提示词没有任何参考图，全部 Subject 由文字描述定义。
上线前须补参考图后重新生成：
- <Subject 1> 角色A：需补正面清晰的人物主参考（锁面容、发型、服装）
- <Subject 2> 场景：需补场景参考（锁空间、色彩、光线方向）

subject_definitions:
<Subject 1>：角色A，28 岁中国男性，黑色短发、深灰羊毛大衣、白色衬衫。无参考图，由文字描述定义。
<Subject 2>：雨夜的咖啡馆内景，木桌、暖光吊灯、窗外雨痕。无参考图，由文字描述定义。

summary:
[reference generation] 8 秒一镜到底，场景是雨夜咖啡馆。角色A坐在窗边，说完一句台词后看向窗外。

retention_analysis:
<Subject 1>：weak_reference 角色A外观（无参考图，外观以本次文字定义为唯一标准），动作：低头看杯 → 抬头 → 说台词 → 收回视线。
<Subject 2>：weak_reference 雨夜咖啡馆（无参考图，空间与光线以本次文字定义为唯一标准）。
画面里只有角色A，绝对没有其它人。

detailed_description:
...

overall_soundscape:
...

non_diegetic_music: N/A

Negative: no other people, no text, no watermark, no camera static,
```

**无图模式三条硬要求**

1. 保留标记一律用 `weak_reference`（没有参考图，就谈不 `fully_preserved`）
2. 每个 Subject 末尾都写「无参考图，由文字描述定义」
3. 交付时附「上线前必须补图」清单，并说明补图后需重新生成哪些片段

## 三个仍然要用官方标记的场景

本模板为了中文可读性做了简化。以下场景**必须补回官方语法**：

| 场景 | 补什么 | 出处 |
|------|--------|------|
| 视频编辑 / 续写 | summary 加任务类型前缀 `[video editing]` 等 | ref-en §3 |
| 音频复用 / 音色克隆 | `<Audio N>` + `fully_copy` / `reference` 等标记 | ref-en §4.2 |
| 多人对白、跨镜台词、精确音画同步 | 对白改 `<d>[中文] "……"</d>`，配 `(S1)` 说话人 ID | ref-en §5.4 |

## 中文版多镜头两处格式坑（实战 2026-09-05）

1. **台词行必须独立成行、行首 `→`**：`→班主任说"大家开始上课。"` 单独占一行。
   写在段落中间（`……开口。→班主任说"……"`）校验器解析不到，报 `DLG-FMT` 警告。
   音色/语气描述放在 `→` 行之前的叙述句里（「她用清亮试探的少女音开口。」）。
2. **切点时间戳统一写 `At 00:03.000`**：中文叙述也保留英文 `At`（`At 00:03.000，镜头切至……`）。
   写成「在 00:03.000」校验器解析不出切点，全部镜头按 0s 起点，报 `SHOT-NOEND`。
