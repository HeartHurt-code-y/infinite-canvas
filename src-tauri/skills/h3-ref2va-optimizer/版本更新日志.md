## V1.5 · 2026-09-05（步骤 0 · 素材门）

**改版主题：把「读图 → 列校准表 → 重写 Subject」定为标准步骤 0，并加无图模式门禁。**

起因：场次58 实测发现剧本文字与参考图有 10 处不一致（含致命项「傍晚 → 夜间」），
**模型只听提示词文字**，校对文字的人看不出错——因为剧本就是那么写的。
一次事故足以毁掉整批素材，所以这个动作必须前移到入口，而不是靠临场想起来。

### 变更 2（重要）：没有一刀切禁「电影感」

### 变更 3（重要）：修掉多段输出导致校验器崩溃的 bug

`scripts/validate_ref2va.py` 第 110 行：

```python
bad = [s for a, s in zip(SECTIONS, order) if a != s]
r.error("SEC-ORDER", f"...`{bad[0]}`")   # ← order 有 12 项时 bad 为空，IndexError 崩溃
```

多段输出时六段会重复出现，`zip` 截断后前 6 项顺序正确 → `bad` 为空 → `bad[0]` 直接崩。

1. 判空 + 只比对前 6 项，不再崩溃
2. 新增 `check_multi()`：按【第N段】切分后**逐段**跑全部校验，再补全局检查
   （`MULTI-SEG` / `TAIL-FRAME` / `ANCHOR-MISS`）
3. 未标段号的多段输入发 `SEC-MULTI` 警告，提示内容类校验只对最后一段生效

## V1.2 · 2026-09-04

**改版主题：拿真实 H3 提示词实测后的纠偏 —— 修掉一处与官方冲突的自创规则，补四个官方强制项检查。**

起因：用户拿一段 15 秒三镜头短剧提示词实测，暴露出本 skill 的四个问题。

### 变更 1（重要）：废止「运镜五要素」，改回官方三维度

**V1.0–V1.1 的「运镜五要素（轨迹/方向/角度/速度/轴心点）」是自创的，且与官方 §4.3 冲突。**

官方 §4.3 只有三个维度：

| 维度 | 官方写法 |
|------|----------|
| 运动类型 | `Push In` / `Arc Shot` / `Pan Left` / `Zoom In` … |
| 幅度 | `with small amplitude` / `with large amplitude` |
| 速度 | `at slow speed` / `at fast speed` |

且官方明确「中等幅度、正常速度通常省略」，并要求**写成自然英文动作句、不要堆标签**。

「轴心点」降为**可选增强**，仅在弧形/环绕/多主体推拉时使用。
原规则会给出「必须凑齐五要素」的错误建议——实测中它确实误报了
`CAM-AXIS 缺失角度/轴心点`，而按官方口径那段只缺**幅度**。

同时补上官方的 **Zoom vs Dolly 区分**（Zoom 变焦机身不动 / Push In 推镜头机身前进）。

### 变更 2：新增多镜头时长预算校验（本 skill 独有）

官方只约束切点递增，不校验「台词塞不塞得下」。新增 `SHOT-OVER` / `SHOT-TIGHT`：
按 **中文 4.5 字/秒** 估算口播时长，逐镜核对，并要求留出 ≥1.2s 给动作/反应。

实测直接拦下致命问题：末镜 `10–15s`（5 秒）塞了 41 字台词（需 9.1s），
必然导致台词被截断或语速失真。

### 变更 3：新增官方强制项检查

| 检查码 | 依据 | 说明 |
|--------|------|------|
| `SPK-ID` | 官方 §4.4 / §127 | 有 `<d>` 对白必须有 `(S1)`/`(S2)` 稳定 ID，跨镜头一致 |

## V1.1 · 2026-09-04

**改版主题：输出格式改为「英文标签 + 中文叙述」，并新增节拍模式。**

### 变更 1：语言策略反转（用户拍板）

V1.0 沿用官方「六段全英文」。V1.1 起改为：

| 元素 | 语言 |
|------|------|

**代价与边界**：涉及视频编辑 / 音频复用 / 说话人 ID / 精确音画对齐时，中文叙述会与官方标记体系打架。
