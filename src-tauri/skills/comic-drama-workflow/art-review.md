# 漫剧服化道业务检查

只检查当前一集的新增和变体美术设计，并以共享资产作为一致性参照。逐项对照已批准剧本与风格中的视觉信息，通过文字排演评估图片提示词可执行性，不假称实际看过尚未生成的图像。内容风险由独立内容检查处理。

## 逐项检查

- 人物与导演清单逐字段比对：年龄、身份锚点、五官发式、肤色、体态、服装款式/颜色/材质、配饰、鞋履。遗漏或矛盾指出具体条目，避免只说“不够精致”。
- 人物之间是否有清晰区别；“清秀”“成熟”等词是否有具体外观补充。人物参考必须是单人半身正面纯白背景，头顶、肩部完整，不出现排版文字或拼版；不能因为未提供三视图而否决符合要求的单人参考。
- 每个场景是否覆盖导演指定的空间布局、时间、光源方向、色调、关键家具与道具；前中后景、门窗与通道是否明确。关键叙事物件不能因提示词过度概括而遗漏。
- 场景总览如采用宫格，应逐格检查覆盖及编号：一至九景三行三列，十至十二景三行四列，十三至十六景四行四列，余格留空，超过十六景分板。总览可以作为文档，但每个用于生成和引用的场景仍须独立资产 ID、独立完整提示词，不能把整张宫格当作一个场景参考。
- 道具外形、尺寸、材质和使用状态应与讲戏及场景一致，关键文字有精确文案与验证点。
- 图片提示词为可直接执行的完整中文叙事段落，不能仅关键词堆叠或写“参考前文”。风格、线条、色系、质感与项目一致，不能引用未经项目配置的模型或外部平台参数。

## 跨集检查

复用资产是否保持同一 ID、原 prompt 与已有生成结果，是否避免重复创建。新增资产是否与已有身份区分；变体是否保留原 ID 关联、清楚列出保留项和变化项，是否没有覆盖原版。新资产风格与旧资产协调，场景改换昼夜不能连空间结构一起漂移。

## 评分与修订

对人物按一致性、辨识度、精确性、细节、风格、布局评分；场景按覆盖、氛围、空间、关键元素、风格、独立引用评分；道具按外形准确性、材质细节、状态连续性评分。各项 1–10 分，总平均至少 8、所有单项至少 6 且无严重错误才能 PASS。

漏掉必须资产、同 ID 偷换身份、覆盖共享原版、变体无来源、整张宫格冒充单景、提示词与结构化资产不一致均为硬失败，即使均分较高仍需 REVISE。每个修改问题写清位置、当前缺陷、预期图像偏差及具体修订动作。仅出现需要用户裁决的身份或风格互斥设定时使用 NEEDS_DECISION。不要因可以自动细化的服装或光影细节中断流程。
