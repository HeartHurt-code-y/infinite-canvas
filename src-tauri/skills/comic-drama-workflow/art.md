# 漫剧服化道设计方法

本阶段根据已通过检查的导演讲戏本、人物清单、场景清单和共享资产，为新增及变体编写完整的中文图片提示词，并建立可复用资产。只使用当前项目配置的图片模型；不选择供应商，不提供外部账号、链接、接口或平台操作说明。

## 共享资产先行

逐项比对导演清单与共享库，核对稳定 ID、类型、名称、外观、创建集数和变体来源。复用项保留原资产及其生成结果，不重新设计，不产生重复 ID。新增项建立新 ID；变体也建立新 ID，记录原资产 ID、保留特征及改变原因，原版仍可被较早集数引用。设计仅覆盖本集需要的新增和变体，不重写其他集数。

同一人物的脸型、五官比例、身形与身份识别点跨集稳定；衣装、年龄、伤情变体须有明确差异边界。相同地点的平面布局、门窗位置、主要家具与动线保持稳定；昼夜、天气或损毁变体不能无理由换掉建筑结构。重要道具在尺寸、材质、纹样、持握方式和完好程度上可追溯。

## 人物设定图

每位需参考图的角色生成独立资产。基础布局为干净白底，左半边面部特写，右半边全身正面、侧面、背面三视图，三个视角为同一个人物、同一套衣装和同一比例。确保鞋子与完整轮廓可见。具体图片画幅和分辨率从所选模型能力取值，不能仅在提示词中写一个模型不支持的参数。

完整叙事段落应覆盖年龄与角色定位、面部轮廓、眉眼鼻唇、肤色、发型发色、神态、身高体态、服装款式颜色材质和扣饰、配饰、鞋子及整体气质。由用户设定决定需要的外观特征，不凭空将姓名推导成族裔。用可见细节区分角色，避免每个人只有同样的“清秀”“英俊”。服装应符合故事年代、气候、身份和行动需求。

人物变体提示词先声明保留的身份特征，再详细描述唯一或明确的一组变化；若应用提供原参考图能力，用实际提供的参考对应身份，不能编造已经存在的图像路径。

## 场景和道具

为每个场景写独立、完整、可直接生成的图片提示词：地点类型、拍摄时间、空间结构、主次通道、门窗方向、主光来源方向与色温、总体色调、家具物件、前中后景层次和叙事氛围。只描写静态空间设计，不把人物表演塞进环境参考图。所有资产共享项目的线条、色彩、材质与光影基准。

需要场景总览文档时保留宫格编排方法：一至九景为三行三列，十至十二景为三行四列，十三至十六景为四行四列，空格留空，超过十六景分板；每格标场景名、空间描述和核心视觉重点。宫格只用于总览排版，工作流内部优先直接生成各场景独立图片。每个场景必须有独立资产 ID 和对应参考文件，绝不能把含多个场景的整张宫格冒充一个场景资产，也不能要求客户逐格人工裁图后继续。

重要道具单独描述整体外形、尺寸参照、材质、色泽、工艺、文字或图案、磨损和接触结构，采用能明确呈现造型的角度。与场景内同一道具保持一致。对于关键可读文字，在文档保留准确文案及验证点，不声称图片模型必然准确渲染。

## 提示词写法

以完整段落从整体到细节叙述。比如先定位白底角色设定图，再描述同一角色脸型和发式，继而服装、鞋履与饰物；场景先建立空间，再交代光源、材质和视觉焦点。摄影术语应连同效果使用，如侧窗冷白光在木地板上投下窄长矩形，而不是关键词列表。每条 prompt 脱离上下文也能执行，不能写“同前”“详见上文”。有实际参考图时简明重申必须稳定的身份锚点，避免与参考矛盾。

## 完整交付

文档包含整体视觉规范、人物提示词、场景提示词与总览编排、道具提示词、复用列表和变体关联。每项标明复用、新增或变体及创建集数。结构化 assets 包含本集实际使用的全部资产，包括复用、新增和变体；复用项的 id、kind、name、prompt 必须逐字保持共享库原值，应用会复用已有生成结果。不要把本集未使用的其他集资产加入。检查导演清单全覆盖、身份区别明确、三视图同一人、场景空间可辨、无重复资产和无未说明的跨集变化。业务检查与内容检查发现的问题合并后一次修订，保留未受影响资产。
