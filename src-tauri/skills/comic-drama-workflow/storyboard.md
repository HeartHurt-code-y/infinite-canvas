# 漫剧分镜与动态提示词方法

把本集已通过检查的导演讲戏本以及服化道资产转成按叙事顺序可执行的视频片段。导演意图决定发生什么，分镜负责把它变成镜头、动作、声音和素材引用。当前项目所选视频模型能力决定允许的时长、画幅和参考输入，不带入外部平台的假设或专属语法。

## 素材对应表与执行引用

1. 列出本集实际使用的稳定资产 ID、类型、名称、来自哪一集及哪个变体、在画面中的用途。人物在前，场景其次，道具随后；文档顺序仅用于阅读，实际任务依赖 referenceAssetIds 的稳定 ID。
2. 只有上游已存在或已规划且可由应用生成的资产能被引用。每个 referenceAssetIds 必须精确匹配可用共享资产，不能使用角色名代替 ID、引用文档编号充当文件、编造图片/音频/视频路径或引用不存在的图片序号。
3. 每个场景独立映射，不能用整张场景宫格作为单景参考。群演和一次性配角用导演提供的具体外观与动作文字描述，无需杜撰对应参考图。
4. 在 prompt 自然语言中明确参考用途：哪个资产固定人物身份、哪个固定场景布局、哪个固定服装或道具。上传顺序和供应商原生引用标记由应用适配，不能假设某种带序号标记通用于所有模型。
5. 单次任务素材数量和格式只根据项目提供的能力验证，全剧总映射不受单片段的引用数量限制。若单段所需参考超出能力，应按连续叙事拆分片段或反馈明确能力缺口，不能悄悄丢掉关键参考。

## 剧情点到片段

每个 P 剧情点是一个完整叙事段落，可有连续多镜头或蒙太奇；每个执行片段有独立镜头 ID、所属剧情点/场景、时长、画面意图、逐字对白、完整 videoPrompt、参考资产 ID 和可观察验收点。一段叙事不能混入无关场景。

若一个剧情点超过模型可用时长，按动作结束、说话人切换、场景转换等自然位置拆为有连续性关联的子片段。保留全部对白和核心动作，不通过加快到不可理解语速、删台词或把 unsupported 时长填入参数来凑单段。片段时长从项目枚举或范围内选择，画幅和生成任务参数交由应用设置。

## 动态提示词四层组织

- 开头说明参考身份和空间用途，以简短稳定锚点绑定正确人物、地点和道具。实际有图时把主要篇幅留给变化；只有文字材料时补足必要静态特征，不能假装模型已见参考图。
- 写开始姿态与环境状态，之后以可连续拍摄的动作链推进到明确结束姿态。用手指收紧、目光避开、肩膀放低等可见行为传达情绪，避免“表现焦虑”等抽象要求。时间顺序清楚，同时发生与先后发生明确。
- 说明景别、机位、运镜方向、速度与视线目标，镜头从哪里到哪里。推近用于聚焦，拉远用于揭示空间或收尾，横移跟随走位，摇摄交代视线，环绕需有空间和叙事理由。固定、跟拍、环绕等不可在同一时段自相矛盾。多镜头明确硬切、叠化或动作匹配的衔接点。
- 融合光影变化、情绪节奏、对白、环境音和配乐意图。原文对白逐字不变，标清说话人及语气，禁止混说、改词、移交给另一角色。声音须与动作匹配；对音频生成能力未知的模型，音频要求作为交付文档的声音设计，不承诺成片已经配音。

十秒以上或含多个子镜头时推荐用连续、不重叠且无间隙的时间区间说明起承转合；短片段可以完整段落叙述。时间区间总长与 durationSeconds 一致。每个连续镜头约每拍 2.5 秒只作排练基准，不是模型硬限制；一句长对白要留呼吸和停顿，复杂移动与运镜不能同时过载。头尾约 0.5 秒留建立与收势余量，关键情节放在可见主体时段。

## 连续性与风格

前后片段核对人物站位与视线、持物手、衣装和损伤、动作终点到起点、主要光源方向、昼夜、空间轴线、情绪强度和声音承接。需要打破连续性时明确闪回、时间跃迁、主观想象或有意跳切，而不是无解释漂移。全片运镜与节奏需有快慢起伏，情绪弧线与导演设计一致。

优先用正向且可视的表述，例如“镜头固定于门口”而不是模糊的禁止语。不能把“模型不理解所有否定句”当作普遍事实；用户明确的约束仍必须保留。视频延长、编辑、融合、首尾帧控制或外部音视频参考仅在项目确实提供相应能力与实际素材时采用，不自行承诺未支持功能。

## 交付与自检

完整文档包含素材对应表、逐剧情点的片段清单、可复制动态提示词、声音设计和连续性备注。逐句对照导演讲戏本检查所有情节、台词、运镜、光影是否保留；检查引用存在、场景独立、每段时长可执行、文字与结构化字段一致。acceptance 为每段给出身份、动作、构图或连续性的具体可观察标准，避免只有“画面精美”。业务和内容检查都通过后交由应用自动生成；只有需要变更原文或互斥创作方向时提出最小人工决定。
