# 面向当前视频模型的提示词

只根据本轮用户指定、项目实际提供的模型能力与素材组织目标格式。不要把某个来源示例的时长、计费、字段或特殊标签当成所有视频模型的规则；未拿到能力数据就不宣称支持某种时长、音色、口型同步或参考模式。

节点下拉框的 `targetFormat` 决定本轮主提示词格式：`generic` 使用自足的通用纯文本结构；`h3` 使用下文的 H3 分区与对白标签。两种格式都要保留场景与人物一致性、角色声线和当前目的、连续节拍或必要的镜头段、声音与画面约束。每一节拍有明确起止时间、说话者、原样台词、对方接收后的反应、机位与声音变化，且与 `timing` 的毫秒时间窗一致。不能为了套模板改变台词、角色身份或镜头顺序。目标格式和模型名称写在 `target`，但不能靠 `target` 文本自行选择格式。

当用户选用项目内的 Seedance 模型时，可按「全局场景与机位 → 每名角色的声音、目的与表演状态 → 连续时间段中的准确台词和对方反应 → 声画连续性约束」组织提示词。只为确有剧情动机的抢话写触发点和双方声音的短暂交叠；不把每句都写成机械轮流，也不替人物补完被打断的台词。画幅、时长、参考类型使用项目当前模型设置，不把来源示例的档位或计费规则写进提示词。

当节点 `targetFormat` 为 `h3` 且当前目标模型支持该格式时，依次使用 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 六个分区，再按该模型当前能力设置音乐与排除项。在 `detailed_description` 采用逐节拍行；每句台词单独成行，稳定说话人编号放在台词标签外，台词文本和标点保留在 `<d>…</d>` 内。动作另起行；被抢断处描述口型停留和声音减弱，不写已完整闭口后对方才开口。只有用户实际提供且项目请求支持的图片、音色参考才加对应引用，绝不虚构素材编号或声音输入。若当前模型契约不支持这些 H3 标签，返回 `needs_input`，不要擅自改为 `generic`。

有对白权限为「逐字保留」时，在所有版本中原样保留台词字符与标点。台词允许改写时，每处实际改动写进 `adaptationNotes`；只调整表演行不算改动台词。若用户要求第二格式，`alternatePrompt` 也必须完整自足，而不是引用第一版的段落。不同格式的时间、发言者、原词权限和结局应一致。

实际连接的图片、音频或视频可作为对应角色、场景或动作的参考。按本轮真实可用的名称或 `@` 引用描述，不发明素材编号、外部地址或上传顺序。看见的服饰、位置可用于视觉约束；静态帧不提供音色或对白事实。只有下游视频模型明确支持的参考类别才能声称会随请求使用；否则把内容写成文字描述并在适配说明中标明限制。

对白镜头至少说明机位相对人物的位置和朝向。镜头是否切换由用户与剧情决定；不要为了制造电影感加入无故运镜。背景人物、字幕、配乐、画面文字和语言选择服从用户要求及模型能力。提示词不得包含供创作者阅读的预算公式、验收打勾项、来源说明或推广信息，这些只放在报告字段。
