# 影视对白提示词接入合同

## 定位

这是「提示词生成与优化」节点的本地文本技能，适用于把剧本、小说片段或一句创意组织成对白视频提示词。它不调度视频任务、不执行脚本、不调用外部工具，也不自行代表用户批准工作流计划或成片。运行时只使用项目选定的文本模型；视频由用户现有的下游节点按当前启用模型的能力执行。技能资料随应用打包，文件位于 `src-tauri/skills/cinematic-dialogue/`。

## 输入和交付

节点继续使用现有多轮历史、当前手改稿与已连接参考素材。给模型的目标视频模型、格式和时长应来自当前用户决定与项目实际模型能力；没有足够信息时，技能用单轮合并问题澄清。锁定原台词与允许改写是两种不同权限。改写时必须留下逐句依据；保留时发现时长冲突必须请用户决定。

技能只返回 JSON。`needs_input` 含 `status`、`message`；`ready` 含 `status`、`videoPrompt`、`target`、`turnPlan`、`budget`、`reviewChecklist`、`adaptationNotes` 和整数毫秒的 `timing.beats`，用户要求另一格式时另有 `alternatePrompt`。节点中确认的目标时长、格式和锁定原台词是校验基准；返回的时间线必须从零连续覆盖目标时长，锁定台词必须与正文逐字对应。校验不通过时不写入输出，下游沿用前一份可用文本。节点对话展示报告；当前可编辑输出及下游文本连线只使用 `videoPrompt`，不能把预算、检查表或 JSON 包装送给视频模型。第二格式由用户明确选择后才能送往下游。

`turnPlan` 解释话轮因果；`budget` 给出时长估算和风险；`reviewChecklist` 是生成后由用户检查的清单。项目原生校验只证明输入文本与规划数据的一致性，不能验证实际视频质量；没有锁定原台词时会明确显示逐字保留未核验。第二格式显示在对话中；用户可在下一轮要求「将备选版设为主提示词」，此时新的 `videoPrompt` 才进入下游。用户修改锁定台词、时长或格式会清除旧输出，需重新生成；工作流既有执行计划和审批规则仍按各自节点执行。

## 本地化边界

内置资料是重新编写的表演与格式规则，仅包含创作所需的 Markdown。没有来源脚本、命令行校验器、固定供应商、计费口径、推广地址或作者标记。实际可用时长、多模态和声音能力以项目当前模型配置及生成请求结果为准，文本阶段不得预言生成质量。
