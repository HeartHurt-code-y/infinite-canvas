# 03 · 30 秒长视频：阶段法与时间戳

对应官方 SECTION02 2.2（用阶段和结束状态组织事件）。

---

## 核心原则

事件较多时，把故事拆成**连续阶段**。

- 每个阶段**只安排一个主要状态变化**
- 每个阶段都写清楚**该阶段结束时画面中可以直接看到的状态**

30 秒不是「多生成 15 秒」。模型需要在更长时间里同时维护人物外貌与服装一致性、场景空间关系、道具位置与状态、动作前后逻辑、镜头运动方向、对白与画面同步、情绪节奏。「结束时」这一行就是给模型的状态锚点。

---

## 长视频模板

```
【生成目标】
生成一段<视频类型>。核心主体是<主体>，主要事件是<故事概要>。

【阶段一】
开始时：<人物、道具和场景的初始状态>。
主要事件：<一个主要动作或事件>。
结束时：<人物位置、道具归属或画面状态>。

【阶段二】
承接上一阶段：<需要保持的状态>。
主要事件：<一个主要动作或事件>。
结束时：<可观察状态>。

【阶段三】
主要事件：<收束事件>。
结束时：<最终画面状态>。

【保持一致】
保持<人物身份、数量、服装、道具归属、空间方向和声音关系>稳定。
```

## 官方示例 · 花店订单包装流程

```
生成一段花店订单包装流程说明视频。<花艺师>和<店员>共同完成花束整理、包装和交付。

阶段一
开始时：<花艺师>站在工作台后，桌面放有散开的花枝、剪刀和包装纸。
主要事件：<花艺师>整理花枝并修剪长度。
结束时：花束握在<花艺师>左手，剪刀放回工作台右侧。

阶段二
承接上一阶段：两人保持相同身份和服装，花束仍由<花艺师>持有。
主要事件：<店员>展开包装纸，<花艺师>放入花束并系上绿色丝带。
结束时：包装完成的花束平放在工作台中央，丝带结朝向镜头。

阶段三
主要事件：<店员>拿起花束并放到取货架上。
结束时：花束只在取货架中央，两人站在工作台后方检查成品。

保持一致
保持<花艺师>和<店员>的身份、服装、工作台方向、剪刀位置和花束归属稳定。
```

注意「结束时」全都是**可以直接看到的物理状态**：花束在哪只手、剪刀放哪、丝带结朝哪、成品在架子中央。不是「气氛温馨」这类不可验证的描述。

## 时间戳：什么时候才用

**普通叙事优先使用「阶段」。** 只有关键交接、进出场、转场或明确节拍需要控制时，再使用以 1 秒为单位的时间表达。

| 写法       | 适用                   | 示例                                    |
| ---------- | ---------------------- | --------------------------------------- |
| 时间区间   | 分配剧情节奏           | `0-3秒……3-7秒……7-12秒……`                |
| 明确时间点 | 指定一次关键事件       | `第5秒，镜头快速向左横移并完成转场。`   |
| 相对时间   | 描述事件之间的等待关系 | `人物按下按钮3秒后，房间灯光逐渐熄灭。` |

### 官方示例 · 展示台换物

```
0-5秒：展示空置的木质展示台；一只手放下白色陶盘；结束时手已离开，展示台中央只有白色陶盘。
5-10秒：移走白色陶盘，再放下透明玻璃杯；结束时展示台中央只有透明玻璃杯。
10-15秒：移走透明玻璃杯，再放下绿色陶瓶；结束时展示台中央只有绿色陶瓶。
```

每段依然带「结束时……只有……」。**「只有」这个词很关键**，它同时排除了上一件物品残留。

### 使用规则（官方原文）

- 时间段应**连续、不重叠**。
- 时间段表示事件的**时间预算，不是精准剪辑点**，动作可能在边界附近提前或延后。
- 一个时间段中内容**过少**会增加模型的发挥空间，内容**过多**则可能造成过度切镜或剧情遗漏。
- ❌ **不要用时间戳控制「一秒完成三次动作」等频率。**

## 30 秒节奏参考

一个常用的四拍分配（作为规划工具，不是帧级承诺）：

| 拍子 | 时间     | 任务                       |
| ---- | -------- | -------------------------- |
| 建立 | 0–5 秒   | 立住主体，给出继续看的理由 |
| 发展 | 5–16 秒  | 主要动作或问题             |
| 转折 | 16–25 秒 | 结果、后果或情绪转向       |
| 收束 | 25–30 秒 | 干净的结尾画面或回扣       |
