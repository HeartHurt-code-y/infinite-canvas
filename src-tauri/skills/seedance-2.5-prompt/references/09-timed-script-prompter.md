# 09 · 精准计时提示词工作流（剧本 / 分镜 → 秒级时间戳）

> 本篇与 01–07 互补：**01–07 教你"按官方指南把模型要猜的地方写死"**（公式、符号、素材职责、长视频、编辑、白模、运镜、情绪、边界）；**本篇教你"拿到一段剧本/台词/分镜后，先逐秒测算，再落成带原生时间戳的 2.5 提示词"**。
>
> 适用信号：用户给的是剧本/台词/分镜而非现成提示词；或提到「算秒」「分镜脚本」「时间戳控制」「视频延长」「超长视频」。用户已给成型提示词要优化 → 走 SKILL.md 的诊断顺序（07）。

---

## 何时用本篇

| 信号                                             | 用本篇                        |
| ------------------------------------------------ | ----------------------------- |
| 用户给了剧本 / 台词 / 分镜，要视频提示词         | ✅                            |
| 提到"算秒""分镜脚本""时间戳控制""延长""超长视频" | ✅                            |
| 用户已给成型提示词要优化                         | 走 SKILL.md 诊断顺序（见 07） |

**核心哲学**：Seedance 2.5 原生支持秒级时间戳区间控制——你能用 `0-X秒` 区间把每一秒的剧情节奏分配清楚；算力宝贵，每一秒画面都要有不可替代的价值，不长不短、不多不少。**但时间戳是「时间预算」而非「帧级剪辑点」**（官方边界 01）：它用于分配事件节奏，不承诺动作在某毫秒精确发生，也**不要用来控制「一秒完成三次动作」这类频率**——这一点与 [03-long-video-timing](03-long-video-timing.md) 的使用规则完全一致。

> **权威对齐说明**：本篇的"任务类型与参数规则（单段≤30s / 延长比例锁定且时长可设 / 首尾帧用首帧比例）"均严格遵循官方《Seedance 2.5 提示词指南》2.2 / 2.3 / 2.5；官方指南**未设**"超长视频模式 / 180 秒 / 套娃延长 60 秒"。篇中的"台词字/秒速率、动作时长表、镜头数建议"为**经验性速查**（已在文中标注），非官方硬性规则，请按实际生成效果校准。

## Step 1 · 读剧本，抓核心

从用户输入提取：

1. **谁** —— 出场角色（1–2 人为宜，超过则考虑拆分）
2. **在哪** —— 场景（一个生成段一个主要场景）
3. **做什么** —— 核心动作链（2.5 长尾动作强，可写复杂动作序列）
4. **说什么** —— 台词原文（**逐字锁定**，不得修改；多语种台词保留原语言）
5. **情绪走向** —— 起点 → 终点
6. **素材** —— 用户是否提供了 @图片/@视频/@音频，各自参考什么（职责写法见 [02-assets-routing](02-assets-routing.md)）

---

## Step 2 · 选择生成模式

| 模式             | 适用                        | 参数规则（按官方指南 2.3 / 2.5）                                                                                 |
| ---------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 单段生成（默认） | 一个连续片段                | 最长 **30 秒**（官方单次直出上限，2.2）；短至数秒亦可，按内容需要。时长可在生成页/接口设置                       |
| 视频延长         | 用户已有 2.5 成片，想接着演 | **比例自动锁定原视频**（不支持另行设置）；**延长时长由用户设置**（官方 2.5）。向后延长承接尾帧、向前延长衔接首帧 |
| 首尾帧生视频     | 用户给了首帧/首尾帧图       | **比例自动用首帧图**（首尾需同画幅，否则尾帧可能拉伸）；**时长可设置**（官方 2.3）                               |

> 官方指南（SECTION01–05）**没有"超长视频模式 / 180 秒"这一独立任务类型**，也**没有"套娃延长 60 秒"的说法**。超过 30 秒的成片用**多次延长接力**完成：先生成首段（≤30s），再对成品做向后/向前延长，每段延长时长由用户设置、比例始终锁定原视频。剧本超过 30 秒 → 主动建议"首段 + 延长接力"，并先用 2.2 阶段法把全片剧情拆成连续不重叠的时间段。

用户没提模式 → 默认单段生成。

## Step 3 · 精准时间测算（核心步骤）

逐项测算、逐项展示、不跳步骤。下面是经验速查表（中文语境中值估算，非模型硬性规则）。

### 3.1 台词时间

| 台词类型                        | 语速标准       | 公式                        |
| ------------------------------- | -------------- | --------------------------- |
| 普通中文对白                    | 3–4 字/秒      | 字数 ÷ 3.5 = 秒数（取中值） |
| 情绪台词（哭腔/怒斥/颤抖/压抑） | 2–3 字/秒      | 字数 ÷ 2.5 = 秒数           |
| 古风台词/文言/诗词              | 2–3 字/秒      | 字数 ÷ 2.5 = 秒数           |
| 气声/耳语/低语                  | 1.5–2 字/秒    | 字数 ÷ 1.8 = 秒数           |
| 外语对白（英/日/韩等）          | 约 2.5–3 词/秒 | 词数 ÷ 2.8 = 秒数           |
| 停顿/迟疑/换气                  | —              | 每次 0.5–1 秒               |

> 一句台词如果 > 8 秒说不完 → 按自然停顿拆到多个时间戳区间，但**原文不改**。

### 3.2 动作时间

| 动作类型                             | 最短可看清时间 |
| ------------------------------------ | -------------- |
| 简单表情反应（抬眉/抿嘴/眨眼）       | 0.5–1 秒       |
| 关键眼神/对视                        | 1–2 秒         |
| 转头/回身                            | 1–2 秒         |
| 起身/坐下/蹲下                       | 1.5–3 秒       |
| 走位（一步）                         | 0.5 秒/步      |
| 走位（A→B，3–5 步）                  | 2–4 秒         |
| 拔剑/推门/掀帘/摔杯                  | 1–2 秒         |
| 单手交手一击                         | 1–2 秒         |
| 连续交手（2–3 回合）                 | 3–5 秒         |
| 复杂长尾动作（后空翻+拔剑+落地连招） | 4–8 秒         |
| 物品拿起/递交/特写                   | 1–2 秒         |
| 身体倒地/坠落                        | 1.5–3 秒       |

### 3.3 运镜与衔接时间

| 运镜类型                 | 时间           |
| ------------------------ | -------------- |
| 定场/环境建立            | 1–2 秒         |
| 推/拉镜头                | 1–3 秒         |
| 摇/移镜头                | 1–2 秒         |
| 跟拍                     | 与主体动作同步 |
| 硬切                     | 0–0.5 秒       |
| 淡入/淡出/叠化           | 1–2 秒         |
| 首帧承接（建立空间方位） | 1–2 秒         |
| 末帧钩子停留             | 1–2 秒         |

### 3.4 帧级精度（产品级能力，指南未详述）

> 帧级精度属 2.5 的产品级能力，**《Seedance 2.5 提示词指南》SECTION01–05 未详述其写法**。绝大多数需求用官方支持的三种时间表达即可覆盖（2.2）：
>
> - **时间区间**（如 `0-5秒`）：分配剧情节奏；
> - **时间点**（如 `第 8 秒`）：指定一次关键事件；
> - **相对时间**（如 `开始时 / 主要事件 / 结束时`）：描述事件间的等待或先后关系。
>
> 仅在确有卡音乐点/精确卡帧需求时，可尝试帧级双标注：`第 0-90 帧 (0s-3s)`（帧号 ≈ 秒 × 24，具体 fps 以生成页为准）。这属于产品能力延伸，**不作官方指南强制语法**。

### 3.5 时间测算表（必须输出）

```
┌─────────────────────────────────────┐
│         本段演出时长测算             │
├────────────────┬────────┬───────────┤
│ 项目            │ 详情    │ 测算时间   │
├────────────────┼────────┼───────────┤
│ 台词口播        │ ...    │ X.X 秒    │
│ 表情与表演      │ ...    │ X.X 秒    │
│ 身体动作/走位   │ ...    │ X.X 秒    │
│ 道具交互        │ ...    │ X.X 秒    │
│ 运镜与转场      │ ...    │ X.X 秒    │
│ 首帧承接        │ ...    │ X.X 秒    │
│ 末帧钩子停留    │ ...    │ X.X 秒    │
├────────────────┼────────┼───────────┤
│ 测算总时长      │        │ XX.X 秒   │
│ 规划时长        │        │ XX 秒     │
│ 结论            │ 通过/需调整 │         │
└────────────────┴────────┴───────────┘
```

**测算总时长 > 规划时长（单段上限 30 秒）→ 调整优先级：**

1. 先用满 30 秒上限（2.5 单次直出最长 30 秒，官方 2.2）
2. 仍不够 → 建议拆成"首段（≤30s）+ 延长接力"：对成品做向后/向前延长，每段延长时长由用户设置、比例始终锁定原视频（官方 2.5）
3. 减少次要动作/反应镜头
4. 删减**原创建议台词**（用户原文台词不可删）
5. 用户原文台词按自然停顿拆分到下一时间戳区间/下一段
6. 用户原文台词**绝不删改**

**测算总时长 < 规划时长 → 不要注水：** 不硬凑 30 秒，4–30 秒内任何值都可以；空余时间留给画面自然节奏，不是塞废话。

## Step 4 · 丰富完善成可执行的画面

把抽象内容转为摄影机可拍的物理画面（2.5 物理质感与长尾动作强，动作链可写更细）：

- "她很悲伤" → "眼眶泛红，一滴泪沿脸颊滑落，嘴唇微颤，原生皮肤质感，毛孔清晰可见"
- "两人对峙" → "男左女右，相距三步，风卷落叶从两人之间掠过"
- "剑光一闪" → "剑刃从左下方斜向上挥出，刃面反光划过画面中央，雨水顺着剑刃滑落"

**动作动词 + 具象物理细节 + 摄影机可见。** 情绪转可观察表现见 [06-camera-and-emotion](06-camera-and-emotion.md) 的 3.4；主体/动作/素材职责见 [01-core-formula](01-core-formula.md) 与 [02-assets-routing](02-assets-routing.md)。

## 核心规则（计时专属 + 与 01–07 衔接）

### 时间规则

1. 单段最长 **30 秒**（官方单次直出上限，2.2）；不强制拉满，按内容需要选 4–30 秒间的任意值。_（"4 秒"为经验下限，官方未规定最短时长）_
2. 时间戳区间必须**连续、不重叠**（官方 2.2：时间区间用于分配剧情节奏）。_（"每镜头 1–10 秒、30 秒内 ≤8 镜头"为经验建议，非官方硬性限制）_
3. 必须展示完整测算过程，不能只给结论。
4. 时间戳区间必须连续、不重叠、总时长与规划一致（脚本体检见 [scripts/validate_prompt.py](../scripts/validate_prompt.py)）。
5. 关键眼神、情绪停顿、动作余韵该留就留——精简但不破坏节奏。
6. 帧级标注仅在有卡音乐点需求时尝试，且属产品级能力、指南未详述（见 3.4）。

### 台词规则

8. 用户剧本中的台词**逐字锁定**。不得翻译、改写、润色、删减、合并。多语种台词保留原语言。
9. 台词在时间测算表和提示词中完全一致。
10. 用户没给台词时可生成"原创建议台词"并标注；需要口型同步时声明"嘴型与台词发音严格同步"。

### 画面规则

11. 只写摄影机可拍到的——动作、表情、物体、光线。禁止抽象"意境""高级感"，转成具体光线、颜色、动作、构图（见 01/06）。
12. 动作描写用「起点状态 → 过程 → 终点状态」完整链条。2.5 长尾动作强，复杂连招可完整写出。
13. 材质写具体名 + 颜色 + 质感；追求真实感时用"原生皮肤质感""毛发根根分明"等 2.5 敏感词。
14. 多镜头/多区间中角色必须重复面部、发型、服装锚点，保证切镜一致性。

### 2.5 专属规则

15. 时间戳用 `0-3s：` 或 `0-3秒：` 前缀格式，按时间顺序排列，validator 会自动校验区间连续、不重叠（见 [scripts/validate_prompt.py](../scripts/validate_prompt.py)）；帧级需求可选用 `第 0-72 帧 (0s-3s)` 双标注（属产品级能力、官方指南 SECTION01–05 未详述，非强制语法）。
16. @图片/@视频/@音频 引用必须声明用途（参考什么、不参考什么），例："@视频1仅参考运镜轨迹与动作节奏，不保留原画面质感"（写法见 02）。
17. 需要干净底片时显式写"纯净视频，全程无字幕、无背景音乐"；需要指定字幕/文字语言时显式声明"画面所有文字必须为[语言]，禁止出现其他语言文字"。
18. 需要去除参考素材 BGM 时写"去除@视频1中的背景音乐，仅保留人声"。
19. 负向约束**按需声明**（见 [10-pe-discipline](10-pe-discipline.md) 原则 8「不滥加约束」）：用户要纯净视频/防误读时放心写——禁止字幕/水印/logo/IP 角色/品牌元素，2.5 响应可靠。
20. 不生成资产库提示词（角色图/场景图/道具图/三视图）。
21. 白模任务使用 2.5 白模公式（见 [05-advanced-playbook](05-advanced-playbook.md)）——粗颗粒：【参考声明】+【对应关系映射】+【剧情详述】+【场景处理】+【整体收束】；细颗粒：【渲染指令】+【分段渲染描述】+【场景处理】+【整体收束】。

## 时长选择参考

| 剧本特征                               | 建议时长                 | 理由                                                                                               |
| -------------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------- |
| 一个眼神/一个反应/一个动作             | 4–6 秒                   | 短镜，不拖                                                                                         |
| 一句台词 + 一个动作                    | 6–8 秒                   | 刚好说完做完                                                                                       |
| 两句台词交替 + 反应                    | 8–12 秒                  | 对话节奏                                                                                           |
| 三句台词 + 走位 + 动作                 | 12–15 秒                 | 编排紧凑                                                                                           |
| 追逐/打斗/多人交互/复杂连招            | 15–30 秒                 | 2.5 支持 30 秒单次，动作密度高不必硬切（打斗细分建议见 [12-fight-combat](12-fight-combat.md) 4.3） |
| 古风台词（慢速）+ 情绪                 | 比现代语速 +2–3 秒       | 古风语速 2–3 字/秒                                                                                 |
| 完整短片/MV/预告（多镜头叙事，>30 秒） | 首段 ≤30 秒 + 延长接力   | 单段上限 30 秒，用延长接力接续，比例始终锁定原视频（官方 2.5）                                     |
| 已有成片想继续演                       | 延长段（时长由用户设置） | 比例锁定原视频，前/后延长衔接边界画面（官方 2.5）                                                  |

## 质量自检

输出前必须确认：

- [ ] 是否只输出视频提示词，没有角色/场景/道具资产库内容？
- [ ] 是否展示完整时间测算过程？
- [ ] 测算总时长是否 ≤ 规划时长？
- [ ] 台词是否逐字锁定、不被修改？多语种台词是否保留原语言？

- [ ] 时间戳区间是否连续、不重叠、按时间顺序？
- [ ] 是否给出了多模态版 + 纯文字版？
- [ ] @素材引用是否声明了"参考什么、不参考什么"（见 02）？

- [ ] 是否没有废话填充，每一秒都有不可替代的价值？
