# 13 · 题材动作簇库（T1–T7 节拍菜单）

> 生成【时间戳剧本分镜】前：先选题材 → 再选动作簇 → 从菜单中挑 4–6 个节拍。
> 动作簇是**可选节拍菜单**，不是固定流程。
> 每个动作簇附「时间戳示例」，展示如何把节拍钉死到秒（写法同 [12-fight-combat](12-fight-combat.md) 4.2）。
>
> **⚠️ 来源声明**：本库为**经验性方法论**（整合自作者自研技能，非官方指南），时间戳示例仅作节拍编排参考；已按官方口径校准——单段 ≤30 秒、参数不写进 Prompt、负向按需。单段标准打斗 4–6 个节拍（每节拍 2–6 秒）、20–30 秒可到 6–8 个，均为经验建议（同 [12-fight-combat](12-fight-combat.md) 4.2）。

## T1 现代街战

### T1-1 压迫近战型
**适用**: 一对一肉搏、强弱压迫、雨巷/车库/拳馆。

| 可选节拍 | 动作素材 | 环境反馈 | 镜头素材 |
|---------|---------|---------|---------|
| 冲刺压近 | 冲刺踏步 | 水洼炸开 | 低位贴地推近 |
| 顺手抄物掷出 | 抄起投掷 | 投掷物擦墙弹开 | 过肩压迫 |
| 低肩逼近 | 直拳/摆拳 | 墙面震灰 | 贴身跟拍 |
| 高护架压迫 | 肘击/顶膝 | 砖墙凹陷 | 投掷物擦过前景 |
| 直拳破防 | 肩撞 | 金属弯折 | 命中后贴身追出 |
| 肘膝短打 | 抱摔 | 玻璃震裂 | 轻震后继续跟随 |
| 逼入墙角 | 压臂/侧踢 | 鞋底拖痕 | 水花扑镜 |
| 终段重击 | 重拳/膝撞 | 卷帘门震裂 | 贴身拉回 |

**时间戳示例（15s）**:
```
0-2秒：起幅，雨巷对峙，水洼倒影
2-5秒：冲刺压近，水花扑镜
5-9秒：肘膝短打连续压制
9-13秒：逼入墙角，砖墙凹陷
13-15秒：终段重击，卷帘门震裂，对手贴墙滑落
```

禁用: 飞天/长滞空/法术光效/机甲金属

### T1-2 借物反制型
**适用**: 场景有单车、椅子、棍、车门、玻璃门。

| 可选节拍 | 动作素材 | 环境反馈 | 镜头素材 |
|---------|---------|---------|---------|
| 发现物件 | 横挡 | 金属弯折 | 手部特写 |
| 横挡防守 | 拍挡 | 玻璃蛛网裂 | 透过破洞看人 |
| 物件承受命中 | 抓腕 | 车门凹陷 | 急速推近 |
| 借物卡腕 | 反手扫 | 水花扑镜 | 碎片前景遮挡转场 |
| 借物反击 | 短膝/肘击 | 碎片擦过前景 | 贴身拉回 |
| 物件碎裂退场 | 低扫/夺械 | — | — |

规则: 物件完成格挡/破坏/封路后，节拍必须回到人物攻防，不让道具连续承担 3 个以上节拍。

### T1-3 速度短打型
**适用**: 主角灵活，以短促连击、闪避、低位步法制造节奏。

**时间戳示例（12s）**: 0-2秒：拍挡进身 → 2-5秒：低扫破重心+连续刺拳 → 5-8秒：肘击接转身 → 8-10秒：侧闪反击 → 10-12秒：后撤再弹回+终段侧踢

### T1-4 多敌围攻型
**适用**: 2-6 人围攻，写代表性节拍，不逐人流水账。

**时间戳示例（18s）**: 0-2秒：高位俯拍建立包围 → 2-5秒：代表性先手 → 5-9秒：借力摔倒一人 → 9-12秒：余波带倒同伴 → 12-15秒：侧翼补刀 → 15-18秒：破围换位+残敌退开
镜头: 高位俯拍建立包围 → 贴身跟拍 → 环绕半圈 → 拉远看散落态势

## T2 凡躯超英

### T2-1 强化肉搏型
**时间戳示例（15s）**: 0-2秒：冲刺显力 → 2-5秒：正面推进（顺手抄物掷出） → 5-8秒：借物格挡 → 8-11秒：强化重击 → 11-13秒：短促反制被硬吃 → 13-15秒：终段撞入环境
动作: 重拳/肩撞/短膝/压臂/抓拽/侧踢/低位冲撞
环境: 砖墙凹陷/金属车架穿透/水洼震荡/卷帘门凹陷
禁用: 科幻UI/持续能量盾/机甲装甲/玄幻灵气

### T2-2 科技武器分化型
**时间戳示例（20s）**: 0-3秒：武器展开 → 3-7秒：远程牵制 → 7-11秒：近身重击 → 11-14秒：装备短路+主角中招 → 14-17秒：识别真身 → 17-20秒：装备反噬+终段脉冲
动作: 等离子链刃鞭扫/液压锤砸地/EMP 扔出/全息分身侧击
环境: 电火花扇形喷溅/全息错位/无人机坠落/液压油喷出

### T2-3 装备短促爆发型
**时间戳示例（12s）**: 0-2秒：装备暗亮 → 2-4秒：被压制 → 4-6秒：短促充能 → 6-8秒：闪避或预判 → 8-10秒：单次爆发 → 10-12秒：过载熄灭+环境短路
动作: 预判闪避/掌心脉冲/强化肘击/电弧格挡/短距冲刺

## T3 低魔武侠

### T3-1 兵刃试探型
**时间戳示例（15s）**: 0-3秒：三步对峙+拔刀出鞘 → 3-6秒：斜劈试探 → 6-9秒：横剑挑开+手腕特写 → 9-12秒：刀风擦衣+后撤半步 → 12-15秒：灯笼轻晃+再对峙
动作: 斜劈/直刺/横扫/挑剑/刀背格挡/反手压剑
镜头: 低位积水缓推/手腕特写接步法/正反打/环绕半圈/刀锋擦镜接下一招

### T3-2 换位破招型
**时间戳示例（15s）**: 0-3秒：连刺逼线 → 3-6秒：刀背格挡 → 6-9秒：侧身让喉+肩撞破位 → 9-12秒：低位扫腿+反手压剑 → 12-15秒：外侧落位+双方收力

### T3-3 借物群战型
**时间戳示例（18s）**: 0-3秒：四面合围 → 3-6秒：长凳硬挡+木屑炸开 → 6-9秒：低扫带倒 → 9-12秒：反腕倒插 → 12-15秒：翻身斜劈 → 15-18秒：余波带倒+残敌退开
环境: 桌椅翻倒/酒壶摔碎/木屑爆裂/红灯笼摇晃/兵器钉横梁

### T3-4 收势入鞘型（终段专用）
**时间戳示例（10s）**: 0-3秒：最后一剑擦肩 → 3-5秒：刀锋掠过颈侧+同时收力 → 5-8秒：雨幕分开 → 8-10秒：反腕入鞘+灯笼倒影晃动
禁用: 大爆炸结尾/过度胜利姿态

## T4 玄幻仙侠

### T4-1 剑气对轰型
**时间戳示例（20s）**: 0-3秒：悬崖对峙+剑身蓄光 → 3-6秒：一方出剑气 → 6-9秒：双剑交叉迎接 → 9-13秒：接触点内陷+山石碎裂 → 13-17秒：侧滑破局 → 17-20秒：余波推进
注意: 上一拍残余剑气/雷弧必须进入下一拍，形成连锁而非闯关

### T4-2 御剑追击型
**时间戳示例（20s）**: 0-3秒：御剑起飞 → 3-7秒：云雾穿行 → 7-11秒：剑气擦身+空中换位 → 11-15秒：俯冲追击 → 15-18秒：剑阵封路 → 18-20秒：破云脱身

### T4-3 破阵破法型
**时间戳示例（22s）**: 0-4秒：法阵显形+光纹合围 → 4-8秒：主角寻找缝隙 → 8-12秒：一剑破点 → 12-16秒：光纹裂开+残弧反爬 → 16-19秒：折返夹击 → 19-22秒：阵纹熄灭
注意: 高位施法者少动作（指尖一点/袖袍一振），法术从平台裂缝、脚下阵纹、身后云雾同时合围

### T4-4 单人剑势演绎型（结构 C）
**时间戳示例（18s）**: 0-3秒：登场起势 → 3-6秒：环身斜劈 → 6-9秒：回剑反挑 → 9-12秒：低身侧旋+空中连刺 → 12-15秒：剑尖回收转向 → 15-18秒：凌空垂劈+余波中收剑
环境: 桃花瓣旋出/云雾被刺穿/阵纹亮起/水珠悬挂

## T5 机甲变身

### T5-1 装甲覆盖型（结构 B）
**时间戳示例（12s）**: 0-2秒：触发物开裂 → 2-4秒：粒子喷涌 → 4-6秒：鳞片翻转+胸甲闭合 → 6-8秒：面具覆盖 → 8-10秒：LED 亮起 → 10-12秒：战斗姿态接下一步

### T5-2 重装碾压型
**时间戳示例（20s）**: 0-3秒：装甲启动 → 3-6秒：推进器短喷 → 6-9秒：机甲重拳+装甲火花 → 9-13秒：敌人犁地 → 13-17秒：钢铁碎裂 → 17-20秒：终段按地
动作: 机甲直拳/液压肘击/顶膝/推进肩撞/按头砸地
镜头: 低位仰拍/Z 轴拖行/碎片擦镜转场/极端俯拍

### T5-3 终段地面破坏型
**时间戳示例（18s）**: 0-3秒：抓住目标 → 3-6秒：举向天空 → 6-9秒：下砸蓄力 → 9-12秒：接触地面 → 12-15秒：放射状裂开 → 15-18秒：碎片海啸+背影继续前压

## T6 邪典恐怖

### T6-1 追逃压迫型
**时间戳示例（15s）**: 0-3秒：顶灯短闪+怨灵显形 → 3-6秒：镜内转向+女主奔跑 → 6-9秒：墙面横爬 → 9-12秒：手臂抓来+低身滑过 → 12-15秒：逼到尽头

### T6-2 反生理扑击型
**时间戳示例（12s）**: 0-3秒：关节反折+头部缓转 → 3-6秒：天花倒挂 → 6-8秒：突然扑下 → 8-10秒：身体反向抽搐+黑雾喷散 → 10-12秒：顶灯爆闪

### T6-3 怨灵钉墙型（终段专用）
**时间戳示例（15s）**: 0-4秒：退无可退+水花遮挡 → 4-7秒：侧移到外侧 → 7-10秒：双手刺入 → 10-13秒：怨灵撞墙+墙体蛛网裂 → 13-15秒：贴墙喘息

## T7 极速者

### T7-1 瞬移截击型
**时间戳示例（15s）**: 0-2秒：雨滴拉线 → 2-5秒：残像入场+音障波纹 → 5-8秒：肩撞钉墙 → 8-10秒：低身扫腿 → 10-13秒：现身拦截+急刹水痕 → 13-15秒：残像沿路径退散

### T7-2 残像连击型
**时间戳示例（12s）**: 0-2秒：本体入画 → 2-4秒：残像分裂 → 4-6秒：第一击肩撞 → 6-8秒：第二击低扫 → 8-10秒：第三击横拳 → 10-12秒：残像掠过+本体回位

### T7-3 音障终击型（终段专用）
**时间戳示例（12s）**: 0-2秒：短促蓄势 → 2-4秒：雨滴拉线 → 4-6秒：拳头逼近 → 6-8秒：音障圆环 → 8-10秒：目标倒飞+地面水圈扩散 → 10-12秒：残像沿路径消散
