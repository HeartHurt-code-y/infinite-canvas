# 12 · 打斗 / 动作戏垂直工作流（题材化节拍设计）

> 本篇把「打斗 / 动作戏 / 变身 / 追逐 / 群战」这类强节拍场景从通用写法里抽出来，给一套**题材化设计引擎**：输入判断 → 结构判定 → 题材判定 → 压力曲线 → 连招编排 → 时间戳节拍 → 6 变量因果链 → 输出。
>
> 适用信号：用户输入是打斗、动作戏、武打、对决、变身、追逐、群战、怪物扑击；或提到「打斗分镜」「动作节点」「连击节奏」「压力曲线」。
>
> **与 01–11 的关系**：本篇不重复通用规则。素材职责（02）、长视频阶段（03）、编辑/延长（04）、白模（05）、运镜情绪（06）、边界（07）、纪律层（10）、API 参数（11）**全部沿用**；本篇只补「动作戏怎么选题材、怎么排节拍、怎么把命中写死」。

> **⚠️ 官方口径校准声明（必读）**：本篇整合自作者自研的 `seedance-2.5-fight-prompter` 技能（**非官方**），其动作簇库、压力曲线、节拍编排为**经验性方法论**，已逐条对照官方《Seedance 2.5 提示词指南》与官方 `sd25-pe` 技能校准：
> - 官方**没有**「超长视频模式 30-180s 一次生成」「套娃延长 60s」等说法。超过 30 秒的成片一律「单段（≤30s）+ 多次延长接力」（官方 2.2/2.5，见 [09-timed-script-prompter](09-timed-script-prompter.md)）。
> - 画幅、总时长、分辨率、帧率、声音开关**不写进提示词**（官方 sd25-pe 原则 7 / 参数分离，见 [11-api-compat](11-api-compat.md)）。原技能「默认 16:9」「全局参数强调分钟数/画幅/分辨率」等写法**已删除**。
> - 负向约束（不要字幕/不要BGM）**按需声明**，不自动强加（官方 sd25-pe 原则 8「不滥加约束」，见 [10-pe-discipline](10-pe-discipline.md)）。
> - 台词/动作/运镜时间表为**经验速查**（同 [09-timed-script-prompter](09-timed-script-prompter.md)），非官方硬性规则。

## 一、输入判断（四级）

| Level | 类型 | 示例 | 处理策略 |
|-------|------|------|----------|
| L1 创意 | 一句话想法 | "雨夜巷子里女主和黑衣人对打" | 补全题材、场景、角色、3–4 个核心动作节点 |
| L2 剧本 | 有角色+对抗设定 | "女侠被师门背叛，雨夜长街一人对战三名刀客，最后反杀" | 直接生成完整打斗 prompt，补全外观锚点、武器、场景、动作链和结尾 |
| L3 小说 | 长篇叙事中的打斗段落 | "[一段 300 字以上的小说打斗描写]" | 抽骨架、去修辞、建奇观（见下） |
| L4 锁定分镜 | 有时间码/动作链/镜头表 | "0s 落地 / 2s 挥刀 / 4s 格挡 / 6s 无人机…" | 剧情结果、动作顺序、视觉锚点是硬约束，只补衔接和物理反馈 |

### L3 小说输入三步（小说 ≠ 剧本）
1. **抽骨架**：这场打斗的胜负结果是什么？关键转折点是什么？
2. **去修辞**：删除"他感到一阵寒意""气势如虹""天地为之变色"等不可拍内容。
3. **建奇观**：选 2–3 个小说中最具视觉冲击力的画面作为动作节点锚点。

### L4 锁定分镜（内部锁定卡，不输出给用户）
| 锁定字段 | 内容 |
|----------|------|
| 场景容器 | 地点、空间结构、主要材质、光源 |
| 角色与能力 | 角色、武器、能力边界 |
| 锁定动作节点 | 4–6 个必须保留的动作结果和顺序 |
| 中段关键结果 | 最重要的局势变化 |
| 单元出口 | 本段结束时位置、姿态或转场 |
| 禁止新增 | 不可出现的角色、能力、奇观 |

> 锁定外内容只能作为微动作、环境余波、镜头遮挡或音效处理，**不得改变动作结果**（呼应 10 原则 1 意图优先）。

## 二、结构与题材判定

### 2.1 先判结构

| 结构 | 适用 | 核心写法 |
|------|------|----------|
| A 对打 | 两个或多个主体互相攻击 | 写 4–6 个连续攻防节点，每个命中点完整 6 变量因果链 |
| B 形态演化 | 变身/觉醒/异化/化神 | 起态 → 触发 → 分层覆盖 → 终态完成 |
| C 单人武学演绎 | 剑舞/拳路/无对手 | 起势 → 连续招式（用"——"分隔）→ 收势 |

### 2.2 再判题材 T1–T7（动作簇库见 [13-fight-clusters](13-fight-clusters.md)）

| 编号 | 题材 | 触发关键词 |
|------|------|-----------|
| T1 | 现代街战 | 拳脚、格斗、拳馆、街头、雨巷、搏击（力量夸张但无装备） |
| T2 | 凡躯超英 | 赛博、机能装、电磁刀、仿生肢体、EMP、全息分身、局部强化 |
| T3 | 低魔武侠 | 江湖、客栈、雨夜屋檐、刀剑、侠客、古装真功夫 |
| T4 | 玄幻仙侠 | 剑气、御空、法术、灵气、化神、雷法、渡劫 |
| T5 | 机甲变身 | 机甲、装甲、推进器、巨物、机械组装、粒子装甲 |
| T6 | 邪典恐怖 | 怨灵、无面人、鬼怪、反生理、旧楼追杀、异化 |
| T7 | 极速者 | 超音速、闪现、残影、音障、瞬移截击 |

判题规则：
- 人物能力 + 武器 + 场景 + 动作方式共同决定。
- T1/T2 边界：有明确装备/能量/仿生机制 → T2；只有物理夸张 → T1 强化街战。
- 混合题材以当前画面最强视觉元素为准。

## 三、动作设计引擎

### 3.1 压力曲线（选 1 条，决定这段打斗的"起伏呼吸"）

| 曲线 | 适用 | 局势变化 |
|------|------|----------|
| 压迫递增 | 强者逼弱者 | 还能躲 → 勉强挡 → 被逼退 → 空间封死 → 终段命中 |
| 反制失败 | 弱者有求生但力量差 | 被压制 → 短暂反击 → 对手硬吃 → 夺回 → 败退 |
| 诱敌反打 | 主角冷静技巧高 | 退让 → 暴露破绽 → 借位闪开 → 反打关键点 |
| 波峰波谷 | 双方实力接近 | A 压制 → B 反压 → A 改招 → B 受挫 → 终段定局 |
| 蓄力爆点 | 变身/大招 | 低压铺垫 → 层层蓄势 → 环境预兆 → 单次爆发 → 余波 |

### 3.2 连招编排四规则（写节拍前内部完成，不输出）

1. **连招方向链**：切入方向 → 折返方向 → 压进方向 → 横移/纵跃方向 → 终段方向。
2. **每拍动作因果**：方向变化 → 招式载体 → 命中位置 → 接触点物理 → 身体/环境后果 → 衔接。
3. **镜头贴附动作**：镜头贴住具体动作路径，说明被什么遮挡、如何接到下一招。
4. **装饰词物理化**：抽象强度词 → 具体载体 + 接触点物理现象 + 身体/环境后果。

### 3.3 镜头策略（选 1 个，形成重复视觉母题）

| 策略 | 适用 | 重复视觉母题 |
|------|------|-------------|
| 压迫贴身型 | 街战、追杀、弱者被压制 | 低位水面 / 对手拳头前景 / 墙面逼近 |
| 兵刃核心型 | 武侠、仙侠近战 | 刀锋 / 剑尖 / 火星 / 衣料浅痕 |
| 重量仰拍型 | 机甲、巨物、重击 | 脚掌 / 液压关节 / 地面裂纹 / 碎片前景 |
| 高速追踪型 | 极速者、追逐 | 雨滴拉线 / 残像路径 / 水痕 / 音障圆环 |
| 恐怖遮挡型 | 怨灵、旧楼 | 门缝 / 镜面 / 顶灯闪黑 / 水渍倒流 |
| 大场面调度型 | 仙侠对轰、群战 | 云海 / 阵纹 / 包围圈 / 高低层次 |

### 3.4 2.5 专属动作增强（节奏控制写法）

| 增强手段 | 用法 | 示例写法 |
|---------|------|---------|
| 慢镜局部 | 只慢关键命中帧，不慢全程 | "第 7 秒右勾拳命中瞬间，该帧以 40% 速度呈现 0.5 秒后恢复正常速度" |
| 多速度层次 | 快攻+慢镜+突停交替 | "连续快攻（正常速度）→ 重击瞬间（慢镜）→ 收势突停（静止 0.3 秒）" |
| 镜头速度变化 | 跟拍加速/急停 | "镜头随冲刺加速推进，命中前 0.2 秒骤停，震动感通过机位微晃呈现" |
| 环境余波链 | 前一拍破坏进入下一拍 | "上一拍碎裂的木屑未落地，卷入下一拍的拳风中" |
| 时间戳断点 | 2.5 精准控制动作起止 | "3-5秒：三次快速换位；5-7秒：贴身缠斗" |

## 四、节拍写法（时间戳剧本分镜）

### 4.1 6 变量因果链（每个命中点必写）

```
[打击者] 用 [载体: 拳脚/兵器/特效] 击中 [对手具体位置]
→ [受击反应]
→ [环境响应]
→ [镜头反馈]
→ [下一招衔接]
```

禁止写法：
- "两人激烈打斗" ← 没有具体动作
- "女主快速反击" ← 没有攻击部位和方式
- "敌人被击退" ← 没有击退方式和环境反馈

### 4.2 时间戳节拍（2.5 核心，每个攻防节点钉死秒数）

- 写法与 [09-timed-script-prompter](09-timed-script-prompter.md) 完全一致：`0-2秒：` / `0-3s：` 前缀，区间**连续、不重叠**，按时间顺序排列。
- 每个节拍内按「动作 → 对手反应 → 环境反馈 → 镜头反馈 → 衔接」写；**终段**补 `结束时：<可观察状态>` 收口（官方时间戳写法，如"结束时：三名刀客全部倒地，雨幕中只剩女主持刀而立"），可消除体检脚本的"结束时"WARN 提示。
- 单段 ≤30 秒：标准打斗 4–6 个节点（每个 2–6 秒）；30 秒可到 6–8 个。
- 每个镜头不少于 1 秒（特写/反应），不超过 8 秒。
- 空余时间**不要注水**：不硬凑 30 秒；关键眼神/情绪停顿/动作余韵该留就留。
- 精简优先：能 6 秒完成的不用 8 秒；能 20 秒完成的不用 30 秒。

示例（T3 武侠 · 雨夜长街 · 15s，A 对打）：
```
0-2秒：起幅。中景，雨夜长街，女主背对镜头立于画面左 1/3，三名刀客自画面右侧阴影缓步进入。镜头低位贴地缓推，水洼倒影中刀客逼近。
2-7秒：冲刺压近。女主俯身冲刺，镜头跟拍加速推进；首名刀客横刀格挡，刀刃相交迸出火星，水花扑镜。镜头以刀锋擦镜为遮挡，切至刀客侧后方。
7-12秒：换位破招。第二刀客自左侧斜劈，女主侧身让喉，肩撞破位；刀客后退撞翻酒坛，木屑爆裂。镜头环绕半圈跟拍。
12-15秒：终段。女主夺刀反腕倒插，刀客仰面倒地溅起水花；镜头高速后拉，三名刀客先后倒下，雨幕中只剩女主持刀而立。
```

### 4.3 打斗时长参考（经验值，非官方硬性规则）

| 打斗类型 | 建议时长 | 理由 |
|---------|---------|------|
| 单个杀招/一击制敌 | 4–6 秒 | 短镜不拖 |
| 单回合交手 + 反应 | 6–10 秒 | 看清一次完整攻防 |
| 标准打斗段（4–6 节点） | 12–20 秒 | 编排紧凑，动作密度高 |
| 长打斗（多节点+情绪递进） | 20–30 秒 | 2.5 单段上限 |
| 连场打斗/微短剧打斗 | 单段≤30s + 延长接力 | 官方无超长视频模式（见校准声明） |
| 打斗续接/结尾拉长 | 延长段（4–30s，用户设置） | 用「视频延长」 |

## 五、角色卡规范

角色卡不是外貌作文，而是告诉模型**动作偏好**：

```
- @图片1作为女主: 动作偏低扫、侧踢、快速步法、短促肘击，本段处于被压制后寻找脱身机会。
```

避免："她很美，眼神坚定，气质冷艳，身材修长。" ← 不服务动作（呼应 10 原则 10 素材只补充可观察属性）。

多人同框时**分别 @图片 锁定各自长相**，防长相趋同（双胞胎）：`<人物A>对应@图片1，<人物B>对应@图片2`（呼应 10 原则 11 主体基数匹配）。

## 六、输出（2.5 融合版结构）

> 完整可复制模板见 [../assets/templates.md](../assets/templates.md) J 节。结构上沿用官方三段式（素材描述 + 一句话概述 + 具体情节描述 + 全局补充），打斗版扩展为：

```
【整体风格】整体风格: <调性词1+2+3>, <特效/速度/力量>通过<具体物理现象>呈现, 不出现<跨题材污染词>。主体清晰可读优先于特效, 动作不断流, 命中不定格, 中段镜头稳定跟随, 高帧率流畅。
【素材描述】<每份素材逐条说明采用范围>：@图片1用于<主角>的<外貌、发型、服装>，不采用<图片背景>；@图片2用于<对手>的<外貌、服装>，不采用<图片背景>；@视频3用于<动作/白模参考>，不采用<视频中的人物身份和场景>；@音频4用于<角色音色/氛围音>，不采用<无关声音>（无则写「无」；多人同框分别 @图片 锁定）。
【一句话概述】<主体+地点+事件+题材/风格+特殊运镜>。（规划时长 X 秒：仅作元信息，由生成页/接口设置，不写进 Prompt 参数）
【时间戳剧本分镜】0-X秒：<起幅>… X-X秒：<过程节点>… X-X秒：<结尾（终段动作+结果爆发+空间位置，不写慢收势）>
【特效细节】[仅 T2/T4/T5/T6/T7 或特效较多时；能量只沿武器/碰撞点/攻击轨迹，粒子不遮主体]
【音效】<8-12 个本题材音效，逗号分隔>（数量为经验建议）
【全局补充】<机位+环境+整体声音/氛围+光影>；负向按需：<纯净视频/不要字幕/不要BGM，用户要求时写>
```

输出规范：
- **双版本**：多模态版（带 @素材）+ 纯文字版（@引用替换为文字描述）。
- 输出合同优先：默认只输出 Prompt 正文，不加 Markdown 包装（见 [10-pe-discipline](10-pe-discipline.md) 七）。
- HTML/TXT 发布件：仅用户要求"发布/分享"时生成，不作为默认。

## 七、打斗场景的编辑与续接扩展（配合 04/05）

用户要「改已生成的打斗视频」或「接续打斗」时，在 [04-edit-extend-keyframe](04-edit-extend-keyframe.md)（编辑/延长）与 [05-advanced-playbook](05-advanced-playbook.md)（转场）的通用模板之上，补两个打斗常用写法（整合自原 fight-prompter 模块 D/E，经验性）：

### 7.1 高级编辑（多标注工具）

- 标准智能编辑：`[具体修改对象] + [动作与变化描述] + [生效时序]`，例："在视频 3-8 秒，把女主的木棍替换为长剑"。
- 高级编辑（配合标注工具：框 / 线 / 箭头 / 文字 / 地标点 / 橡皮擦）：
  `[标注工具与方位] + [具体修改对象] + [动作与变化描述] + [生效时序]`
  - 标注方位写法：`红框内` / `沿红色箭头指向区域` / `地标点处` / `红线左侧`。
- 打斗常用：换武器、换服装、改攻击速度、去掉失误动作、改结尾。
- 编辑范围闭环、原视频唯一母版、"一次只改一个主要对象"等规则**不变**（见 04 / [10-pe-discipline](10-pe-discipline.md) 第五节）。

### 7.2 打斗续接转场类型库（7 种）

切镜设定 = `[转场类型指引] + [基础约束要求] + [切镜逻辑要求]`：

| 类型 | 适用 | 写法要点 |
|------|------|---------|
| 相似物转场 | 通用 | 前后镜头形状同构元素遮挡衔接（如伞面圆 → 天窗圆） |
| 动作转场 | 打斗/高速 | 镜头猛甩 + 运动模糊，动作惯性承接 |
| 动态接力转场 | 追逐/连续技 | 前段动作能量传递到后段主体 |
| 拉近/拉远转场 | 环境切换 | 快速变焦完成空间转换 |
| 水墨转场 | 武侠/仙侠 | 画面溶解为水墨笔触 |
| 自然镜头切换 | 通用 | 普通剪辑点，用动作/视线引导 |
| 遮罩转场 | 通用 | 前景物遮满画面后切出 |

> 转场写作顺序与"无缝转场"四要素（触发/过渡/到达/保持）见 [05-advanced-playbook](05-advanced-playbook.md)。

## 八、高危反例（自检清单）

1. **形容词堆叠**——"毁天灭地的力量撕裂虚空" → 改成具体：甲壳凹陷、金属弯折、对手倒退。
2. **跨题材污染**——T3 武侠出现"机甲撞击/警笛" → 只取本题材词库。
3. **特效遮主体**——"漫天光效铺满屏幕" → 粒子只沿武器/碰撞点，不遮身体轮廓。
4. **群战流水账**——逐个敌人分镜 → 合并群体，用代表性击倒 + 余波带倒。
5. **结尾太慢**——"慢慢收刀/光芒渐熄/镜头缓缓拉远" → 最后一击 + 结果爆发 + 空间位置。
6. **没有时间戳**——过程写得再好，没有 `X-X秒：` 分段 = 没用上 2.5 核心能力 → 每个攻防节点钉死秒数。
7. **漏负向约束**——用户要纯净视频却不写"不要字幕/不要BGM" → 按需声明，不自动强加。
8. **锁定结果被改**——L4 锁定分镜的胜负/顺序被"更炫"的写法替换 → 锁定动作卡是硬约束。
