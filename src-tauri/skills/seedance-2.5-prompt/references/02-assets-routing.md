# 02 · 素材职责映射与分场景调度

对应官方 SECTION01 1.2（先准备素材并明确职责）+ SECTION02 2.1（多素材创作）。

**这是 Seedance 2.5 相对 2.0 最大的能力变化，也是最容易写崩的地方。**

---

## 素材数量：上限 vs 稳定区

可以组合使用最多 **50 份**参考素材。

| 素材类型 | 输入范围（能力上限）                   | 推荐范围（稳定区）                              |
| -------- | -------------------------------------- | ----------------------------------------------- |
| 图片     | 最多 30 张，单张不超过 4K              | 主体图片以 1 至 8 个主体为宜                    |
| 视频     | 最多 10 段，全部视频总时长不超过 30 秒 | 主体音视频以 1 至 5 个主体、单段 5 至 10 秒为宜 |
| 音频     | 最多 10 段，全部音频总时长不超过 30 秒 | 保留与任务直接相关的台词、音色、环境声或音乐    |
| 视频编辑 | 可使用视频与参考图共同完成编辑         | 原视频 20 秒以内、参考图 1 至 5 张              |

**超过推荐范围仍可尝试**：主体图可扩展至 9–12 个主体，主体音视频可扩展至 6–10 个主体，视频编辑参考图可扩展至 6–8 张。素材越多，稳定性越容易下降。

### 多视角：拆图比拼图稳

主体图超过 5 个主体且仍需要多视角时，建议把不同视角拆成多张图片；多张独立视角图通常比把多个视角拼在一张图中更稳定。

```
@图片1定义同一盏折叠台灯的正面外观。
@图片2定义同一盏折叠台灯的左侧结构。
@图片3定义同一盏折叠台灯的右侧结构。
@图片4定义同一盏折叠台灯的背面结构。
四张图片共同定义同一盏折叠台灯，成片中始终只有一盏折叠台灯。
```

最后那句「成片中始终只有一盏」是防复制分裂的关键，别省。

### 支持的模态组合方式（官方企业实践指南）

Seedance 2.5 支持 7 种模态组合，可自由搭配图片 / 视频 / 音频：

| 类别   | 组合                                           |
| ------ | ---------------------------------------------- |
| 单模态 | 只参考图片、只参考视频、**【新增】只参考音频** |
| 双模态 | 图片 + 视频、音频 + 视频、图片 + 音频          |
| 三模态 | 图片 + 音频 + 视频                             |

> 来源：《【实践手册】Doubao-Seedance-2.5：企业级业务场景实践指南》（火山引擎官方，2026-08-04）。「只参考音频」为 2.5 新增能力。

## 逐份说明素材职责

上传参考素材后，需要说明每份素材具体提供什么。素材中的人物、背景或构图容易被误带入成片时，再写明不采用什么。

### 三条铁律

1. **素材映射关系必须写进提示词正文。**
2. **不要只依赖图片中的文字标注。**
3. **不要让模型自行判断多份素材分别对应哪个人物、道具或场景。**

「不采用」不必每份都写，只在素材里的人物、背景或构图容易被误带进成片时才写。

### 素材职责模板

```
@图片1用于<主体>的<外貌、服装、结构或材质>。
@视频1用于<动作、运镜或节奏>。
@音频1用于<角色或声音类型>的<音色、台词、环境声或音乐>。

<主体>在<场景>中完成<主要动作或事件>。
画面呈现<视觉风格>，镜头采用<镜头表达>。
```

### 官方示例 · 陶艺师素材版

```
@图片1用于<陶艺师>的五官、发型和深绿色围裙，不采用图片背景。
@图片2用于<陶艺工作室>的木质工作台、窗户位置和晨间光线，不采用图中人物。
@视频1用于双手拉坯、托起陶杯和放置陶杯的动作节奏，不采用视频中的人物身份、服装和场景。

<陶艺师>在清晨的<陶艺工作室>完成一只浅蓝色陶杯，将它从转盘上取下并放到木架中央。
镜头先以中景记录拉坯动作，再缓慢推近陶杯表面的纹理；保留转盘转动声、陶土摩擦声和室内环境声。
```

### 参考视频已经定死的东西，别复述

当参考视频已经准确给出动作、运镜和顺序时，提示词只需说明**继承哪些内容**，不必逐动作复述；重复描述可能与素材本身冲突。

白模视频主要提供运动和空间骨架，仍需要写清希望生成的主体、场景、动作和风格。

## 2.1 多素材创作：五步组织法

素材一多，提示词的重点就变成写清人物、道具、场景、动作和声音之间的对应关系。把全部素材塞进同一句话没有用。

```
逐份职责 → 主体映射 → 按类型分组 → 主体设定 → 分场景调用
```

**目标是让模型在当前场景中选择正确素材，不要求所有素材同时出现在画面中。**

### STEP 01 · 主体映射

给每个人物、商品、道具单独命名并绑定素材：

```
<人物A>对应@图片1，只采用外貌、发型和服装。
<人物B>对应@图片2，只采用外貌、发型和服装。
<道具A>对应@图片3，只采用结构、材质和颜色。
<场景A>参考@图片4，只采用空间布局、建筑和光线，不采用图中人物。
```

❌ 官方点名的反例：`@图片1至@图片4分别定义四名角色` —— 没有明确哪张图片对应哪个角色。

### STEP 02 · 按类型分组

素材多了按类型整理，人物、道具、场景、动作声音各归各组：

```
【人物】
<修复师>对应@图片1，只采用外貌、发型和服装。
<记录员>对应@图片2，只采用外貌、发型和服装。
<布展员>对应@图片3，只采用外貌、发型和服装。
<讲解员>对应@图片4，只采用外貌、发型和服装。
四人的外貌、服装、动作、站位和台词不互相交换。

【道具】
<样本盒>对应@图片5，只属于<修复师>。
<记录板>对应@图片6，只属于<记录员>。

【场景】
<修复室>参考@图片7，只采用空间、材质和光线。
<展厅>参考@图片8，只采用空间、材质和光线。

【动作与声音】
@视频1用于<修复师>打开样本盒的动作，不采用视频中的人物和场景。
@音频1用于<讲解员>的音色和指定台词。
```

「四人的外貌、服装、动作、站位和台词不互相交换」这句是**防串味**的，多人同场必写。

### STEP 03 · 主体设定（跨场景复用时）

当同一人物需要跨场景使用多份素材时，增加主体设定档案：

```
【主体设定：修复师】
外貌与服装：@图片1。
固定道具：@图片5中的<样本盒>。
出现地点：<修复室>和<展厅>。
动作参考：@视频1的开盒动作、@视频2的放置样本动作。
不采用：其他人物的服装，不持有<记录板>或讲解设备。
```

### STEP 04 · 分场景调用

每个场景只点名要用的素材，其余按下不表：

```
场景一｜修复室检查
使用：<修复师>、<样本盒>、<修复室>和@视频1的开盒动作。
事件：<修复师>在工作台前打开样本盒并检查内部样本。
结束时：<修复师>停在工作台内侧，样本盒始终位于<修复师>自身右手旁，也就是位于画面左侧。

场景二｜展厅登记
使用：<记录员>、<记录板>和<展厅>。
事件：<记录员>在展柜旁核对记录板上的编号。
结束时：记录板仍由<记录员>双手持有，其他人物不进入展柜区域。
```

注意「结束时」那句同时给了**自身方位**和**画面方位**（自身右手旁 = 画面左侧），这是防左右翻转最有效的写法。

## 素材分配参考（商业项目）

官方推荐范围内的一种典型分配思路：

| 素材     | 用途                         |
| -------- | ---------------------------- |
| 图片 1–3 | 主角多角度形象（一图一视角） |
| 图片 4–5 | 产品正面 / 细节              |
| 图片 6   | 场景与空间                   |
| 图片 7   | 灯光与色调风格               |
| 视频 1   | 人物动作节奏                 |
| 视频 2   | 运镜参考                     |
| 音频 1   | 人物音色                     |
| 音频 2   | 背景音乐                     |

**一份素材只承担一项职责。** 不要同时要求模型参考某段视频的角色、动作、场景、镜头、色彩和声音。
