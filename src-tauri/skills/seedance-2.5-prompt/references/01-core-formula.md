# 01 · 核心公式与声音文字符号

对应官方 SECTION01 基础撰写技法（1.1 文本指令的基础公式 / 1.3 声音与文字的特殊字符）。

---

## 1.1 文本指令的基础公式

```
主体 ＋ 动作或事件 ＋ 场景与环境（可选）＋ 视觉风格（可选）＋ 运镜或切镜（可选）＋ 声音（可选）
```

### 五个成分各自负责什么

| 成分 | 负责说明 | 必填 |
|---|---|---|
| 主体 ＋ 动作或事件 | 「谁或什么」正在「做什么」，视频内容的基础 | ✅ |
| 场景与环境 | 地点、时间、天气、空间关系和背景状态 | 可选 |
| 视觉风格 | 光线、色彩、材质、画面质感或整体氛围 | 可选 |
| 运镜或切镜 | 景别、机位、镜头运动、切换点 | 可选 |
| 声音 | 对白、环境声、音效、音乐 | 可选 |

**动作写法要点（官方原文）**：动作优先概括主要过程，只为关键动作写具体细节，避免重复描述同一动作。

**不写进提示词的东西**：时长、画幅比例、分辨率、帧率。这些在生成页面或 API 设置。

### 基础模板

```
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

### 官方示例 · 陶艺师

```
一名陶艺师在清晨的工作室里完成一只浅蓝色陶杯，将它从转盘上取下并放到木架中央。
窗外柔和晨光照入室内，湿润陶土呈现细腻光泽，工作台保持整洁。
镜头先以中景记录拉坯动作，再缓慢推近陶杯表面的纹理，最后切到木架正面。
保留转盘低沉转动声、陶土摩擦声和轻微室内环境声。
```

拆解对照：

| 句 | 对应成分 |
|---|---|
| 一名陶艺师……放到木架中央 | 主体 + 动作 |
| 窗外柔和晨光……工作台保持整洁 | 场景与环境 + 视觉风格 |
| 镜头先以中景……切到木架正面 | 运镜与切镜 |
| 保留转盘低沉转动声…… | 声音 |

## 1.3 声音与文字的特殊字符

提示词全程用自然语言就行。需要进一步区分音乐、音效、台词和字幕时，用这套符号：

| 内容 | 符号 | 示例 |
|------|------|------|
| 音乐 | `()` | `(背景播放舒缓节奏的钢琴乐)` |
| 音效 | `<>` | `<远处传来钟声>` |
| 台词 | `{}` | `{你好，欢迎回来}` |
| 字幕 | `【】` | `【第一章：启程】` |

> ⚠️ 冲突提醒：官方模板里的占位符也用 `<>`（如 `<主体>`、`<场景>`）。交付给模型的成品提示词中，占位符必须全部替换成实际内容，`<>` 只保留给音效。

### 直接控制声音与字幕

需要控制字幕或声音时，直接写明保留和不采用的声音类别。**画面内容仍优先使用正向描述。**

```
无背景音乐，只保留人物对白、环境声和动作音效。
不要字幕。
不要任何声音。
```

### 台词语言加固

台词用非中文时，先在台词前写明语言：

```
女孩用日语轻声说：{もう大丈夫です}
```

如果台词文本是英语、模型却说成了中文，或者需要控制地区口音，用这条加固公式：

```
台词语言 ＋ 地区变体或口音 ＋ 表达方式 ＋ 说话人 ＋ {台词内容}
```

官方示例：

```
台词语言：美式英语。女孩用自然、口语化的美式英语说：{I thought you weren't coming.}

台词语言：地道的洛杉矶美式英语。年轻男子用自然的洛杉矶口语说：{No way, you actually made it.}
```

> Seedance 2.5 原生支持 10 余种语言，可以直接用母语描述创意意图，不需要先翻译。

## 常见写崩点

| 症状 | 病因 | 修法 |
|---|---|---|
| 画面里动作乱、镜头切得碎 | 同一动作被重复描述了两三遍 | 只保留一次概括 + 关键细节 |
| 生成时长/比例不对 | 把「30 秒」「16:9」写进了提示词 | 移到生成页面/API 参数 |
| 台词说成了中文 | 没写台词语言 | 套台词语言强化公式 |
| 莫名其妙冒出字幕 | 没做排除声明 | 加 `不要字幕。` |
| 音效被念成台词 | 符号用错 | 音效用 `<>`，台词用 `{}` |

> **⚠️ 口径调和注记（与 10 原则 8 对齐）**：上表「加 `不要字幕。`」**不是默认建议**——字幕排除句仅用于以下三种场景：① 用户明确提出字幕/文字控制需求；② 画面必含文字元素（招牌、信件、标题等）需防误读或防生成可读文字；③ 生成结果已出现莫名字幕、需事后排除（即本表"写崩点"的修复语境）。**用户未提出字幕相关需求时，不自动添加字幕排除句**（见 [10-pe-discipline](10-pe-discipline.md) 原则 8「不滥加约束」）。
