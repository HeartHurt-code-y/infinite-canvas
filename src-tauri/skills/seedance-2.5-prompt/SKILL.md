三个高频句式贯穿全篇，学会它们等于学会一半：

| 句式                     | 用途                                       |
| ------------------------ | ------------------------------------------ |
| `只采用……不采用……`       | 素材职责边界，防止背景/人物/构图误带入成片 |
| `结束时……画面里能看到……` | 阶段收口，用可观察状态代替抽象描述         |
| `<X>对应@图片N`          | 主体与素材一一绑定，杜绝模型自行匹配       |

## 精准计时子工作流（剧本 / 分镜 → 秒级时间戳）

当用户输入的是**剧本、台词或分镜**而非现成提示词时，先用 [09-timed-script-prompter](references/09-timed-script-prompter.md) 走"读剧本 → 选模式 → 逐秒测算 → 抽象转可拍画面 → 双版本输出"五步。它与 01–07 的关系是：**01–07 管"写法的正确性"（公式/符号/素材/编辑/白模/运镜/情绪/边界），09 管"时长测算与节奏编排"**。两者叠加使用——09 算好每一秒、定好时间戳，01–07 确保每一秒里写死的东西模型不会猜错。

**打斗/动作戏类剧本 → 09 与 [12-fight-combat](references/12-fight-combat.md) 叠加**：09 负责总时长测算与台词锁定，12 负责题材判定、压力曲线、攻防节拍与动作簇选型（12 的 4.2 时间戳节拍写法与 09 完全一致）。纯打斗任务直接读 12 即可；含打斗的通用剧本先读 09 再按 12 排节拍。

## 核心速查

### 六段公式（实心必写，其余可选）

```
主体 ＋ 动作或事件 ＋ 场景与环境（可选）＋ 视觉风格（可选）＋ 运镜或切镜（可选）＋ 声音（可选）
```

```
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

- 只有**主体 + 动作**是必填，其余不需要就删掉。
- 动作**优先概括主要过程**，只为关键动作写细节，同一动作别重复描述。
- **时长、画幅比例不写进提示词**，由生成页面或 API 设置。

### 声音与文字四符号

| 内容 | 符号   | 示例                         |
| ---- | ------ | ---------------------------- |
| 音乐 | `()`   | `(背景播放舒缓节奏的钢琴乐)` |
| 音效 | `<>`   | `<远处传来钟声>`             |
| 台词 | `{}`   | `{你好，欢迎回来}`           |
| 字幕 | `【】` | `【第一章：启程】`           |

> 注意：`<>` 同时被官方用作模板占位符（如 `<主体>`）。写成品提示词时占位符要全部替换掉，`<>` 只留给音效。

排除式控制直接写：`无背景音乐，只保留人物对白、环境声和动作音效。` / `不要字幕。` / `不要任何声音。`

### 素材上限 vs 稳定区

| 素材类型 | 输入范围（能力上限）       | 推荐范围（稳定区）                           |
| -------- | -------------------------- | -------------------------------------------- |
| 图片     | 最多 30 张，单张 ≤ 4K      | 主体图片 1–8 个主体                          |
| 视频     | 最多 10 段，总时长 ≤ 30 秒 | 1–5 个主体，单段 5–10 秒                     |
| 音频     | 最多 10 段，总时长 ≤ 30 秒 | 只留与任务直接相关的台词、音色、环境声或音乐 |
| 视频编辑 | 视频 + 参考图共同完成      | 原视频 ≤ 20 秒，参考图 1–5 张                |

单次最多 50 份全模态素材。**上限是能力边界，推荐范围才是稳定区，素材越多稳定性越容易掉。**

### 三类任务的参数自动锁定（写提示词前必须确认）

| 任务类型            | 画幅比例                         | 时长                                                      |
| ------------------- | -------------------------------- | --------------------------------------------------------- |
| 视频编辑            | 自动继承输入视频，**不支持设置** | 自动继承输入视频，**不支持设置**，可能有最大约 0.3 秒差异 |
| 首帧 / 首尾帧生视频 | 自动使用**首帧图片**比例         | **支持设置**                                              |
| 视频延长            | 自动继承输入视频                 | **支持设置**（延长片段音量可能与原视频轻微差异）          |

首帧与尾帧必须**同画幅**，否则尾帧会被拉伸。

## 提示词撰写工作流

### Step 1 · 拆需求

问清楚（缺失就按最合理假设补齐并标注）：

1. 成片时长与画幅？（决定是否要用阶段法）
2. 有几张图 / 几段视频 / 几段音频？分别是什么？
3. 是新生成，还是改 / 接已有视频？
4. 有没有必须锁死的东西：人脸、产品结构、Logo、台词、品牌色？
5. 声音要不要？要不要字幕？

### Step 2 · 建素材台账

每份素材一行，写清**编号 → 归属 → 只采用什么 → 不采用什么**。

```
<人物A>对应@图片1，只采用外貌、发型和服装。
<道具A>对应@图片3，只采用结构、材质和颜色。
<场景A>参考@图片4，只采用空间布局、建筑和光线，不采用图中人物。
```

反例（官方点名）：`@图片1至@图片4分别定义四名角色` —— 没说清哪张对应谁，等于又让模型猜。

素材超过 8 份时按 `【人物】【道具】【场景】【动作与声音】` 分组，跨场景复用的主体再单独建【主体设定】档案。详见 [02-assets-routing](references/02-assets-routing.md)。

### Step 3 · 组织时间结构

- **普通叙事优先用「阶段」**，不要一上来就上时间戳。
- 每个阶段**只安排一个主要状态变化**，并写清「结束时」画面里能直接看到什么。
- 只有关键交接、进出场、转场、明确节拍才用以 1 秒为单位的时间表达。
- 时间段必须**连续、不重叠**；它是时间预算，不是精准剪辑点。

### Step 4 · 写成品

按任务类型套对应模板（[assets/templates.md](assets/templates.md)），补上运镜与声音，抽象情绪一律翻译成眼神、眉头、嘴角、呼吸、视线、手部动作等可观察表现。

### Step 5 · 体检后交付

跑一遍 [07-checklist-and-limits](references/07-checklist-and-limits.md) 的 14 条官方自查清单，或直接跑脚本：

```bash
python scripts/validate_prompt.py prompt.txt
```

## 优化已有提示词时的诊断顺序

用户拿来一条效果不好的提示词，按这个顺序找病灶：

1. **主体和主要动作是否一句话说得清？** 说不清 → 先重写主干，其余都是白搭。
2. **@素材有没有漏声明职责？** 有 @编号却没有对应的「用于……」行 → 补上。
3. **有没有让模型猜的地方？** 「分别定义」「等」「之类」「合适的」→ 全部替换成明确指认。
4. **阶段有没有写结束状态？** 只有动作没有「结束时」→ 补可观察收口。
5. **时间段是否重叠或跳空？** 修成连续区间。
6. **一次改了几个变量？** 编辑类任务一次只解决一个主要问题，变量越多模型越容易重画整段。
7. **要求是否超出能力边界？** 帧级对齐、逐像素一致、精确字幕/公式/参数 → 转后期，见边界九条。

## 不在范围内

- 生成参数（时长、分辨率、画幅、seed）→ 在生成页面或 API 设置，不写进提示词
- 精确字幕、公式、标牌、产品参数、帧级时间点 → 官方建议「前期合成素材 ＋ 视频生成 ＋ 后期制作」
- 剪辑、调色、音量标准化、版权音乐替换 → 交给后期软件
