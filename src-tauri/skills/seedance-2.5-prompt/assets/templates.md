# 可复制模板总表（Seedance 2.5）

模板按使用场景分组。**A–I 节**按官方原文收录；**J 节**为打斗/动作戏经验模板（整合自非官方技能，已标注并校准，见节首说明）。每条模板里的 `<>` 是占位符，写成品时全部替换为具体内容；`()` 音乐 / `<>` 音效 / `{}` 台词 / `【】` 字幕 是成品符号，只在音效符号处保留尖括号。

## A · 文生视频（基础六段公式）

### A1 基础模板
```
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```
> 只有「主体 + 动作」必写；其余不需要就删掉。时长/画幅不写进提示词。

### A2 四符号
```
音乐 ：(背景播放舒缓节奏的钢琴乐)
音效 ：<远处传来钟声>
台词 ：{你好，欢迎回来}
字幕 ：【第一章：启程】
```
排除式控制：`无背景音乐，只保留人物对白、环境声和动作音效。` / `不要字幕。` / `不要任何声音。`

### A3 台词语言加固
```
台词语言：美式英语。女孩用自然、口语化的美式英语说：{I thought you weren't coming.}
台词语言：地道的洛杉矶美式英语。年轻男子用自然的洛杉矶口语说：{No way, you actually made it.}
```

## B · 多素材创作（五步组织法）

### B1 素材职责（单份）
```
@图片1用于<主体>的<外貌、服装、结构或材质>，不采用图片背景。
@视频1用于<动作、运镜或节奏>，不采用视频中的人物身份、服装和场景。
@音频1用于<角色或声音类型>的<音色、台词、环境声或音乐>。
```
反例（禁止）：`@图片1至@图片4分别定义四名角色`

### B2 五步组织法（STEP01–04 全模板）
```
STEP 01 · 逐份命名
<人物A>对应@图片1，只采用外貌、发型和服装。
<人物B>对应@图片2，只采用外貌、发型和服装。
<道具A>对应@图片3，只采用结构、材质和颜色。
<场景A>参考@图片4，只采用空间布局、建筑和光线，不采用图中人物。

STEP 02 · 按类型分组
【人物】<修复师>对应@图片1…… <记录员>对应@图片2……
【道具】<样本盒>对应@图片5，只属于<修复师>。
【场景】<修复室>参考@图片7，只采用空间、材质和光线。
【动作与声音】@视频1用于<修复师>打开样本盒的动作…… @音频1用于<讲解员>的音色和指定台词。

STEP 03 · 主体设定（跨场景复用）
【主体设定：修复师】
外貌与服装：@图片1。固定道具：@图片5中的<样本盒>。
出现地点：<修复室>和<展厅>。动作参考：@视频1的开盒动作、@视频2的放置样本动作。
不采用：其他人物的服装，不持有<记录板>或讲解设备。

STEP 04 · 分场景调用
场景一｜修复室检查：使用<修复师>、<样本盒>、<修复室>和@视频1的开盒动作。
事件：<修复师>在工作台前打开样本盒并检查内部样本。
结束时：<修复师>停在工作台内侧，样本盒始终位于<修复师>自身右手旁，也就是画面左侧。
```

## C · 长视频（阶段 + 时间戳）

### C1 阶段模板
```
【生成目标】生成一段<视频类型>。核心主体是<主体>，主要事件是<故事概要>。
【阶段一】开始时：<初始状态>。主要事件：<一个主要动作或事件>。结束时：<可观察状态>。
【阶段二】承接上一阶段：<需要保持的状态>。主要事件：<一个主要动作或事件>。结束时：<可观察状态>。
【阶段三】主要事件：<收束事件>。结束时：<最终画面状态>。
【保持一致】保持<人物身份、数量、服装、道具归属、空间方向和声音关系>稳定。
```

### C2 时间戳写法
```
时间区间：0-5秒：展示空置木质展示台；一只手放下白色陶盘；结束时手已离开，展示台中央只有白色陶盘。
5-10秒：移走白色陶盘，再放下透明玻璃杯；结束时展示台中央只有透明玻璃杯。
明确时间点：第5秒，镜头快速向左横移并完成转场。
相对时间：人物按下按钮3秒后，房间灯光逐渐熄灭。
```
> 时间段连续、不重叠；是时间预算不是精准剪辑点；窗口 ≥3 秒更稳。

## D · 编辑 / 延长 / 首尾帧（参数锁定）

### D0 自动锁定规则
- 视频编辑：比例+时长均锁定（与输入视频一致，时长差 ≤0.3 秒）
- 首帧/首尾帧生视频：比例用首帧，尾帧须同画幅；时长可设
- 视频延长：比例锁定，时长可设；音量可能轻微差异

### D1 通用视频编辑
```
【编辑目标】编辑@视频1，在<全片或明确时间段>对<画面对象、区域或声音类别>进行<增加、移除、替换或调整>。
【原视频职责】@视频1是唯一编辑母版，负责<人物、场景、动作、构图、镜头、遮挡关系、声音和事件顺序>。
【目标素材职责】@图片1或@音频1用于<目标对象或声音的指定属性>。
【编辑范围】只处理<对象、区域、时间段或声音类别>。
【保持内容】保持@视频1中的<不应变化的画面、动作、声音和时间关系>。
```

### D2 主体替换 / 背景替换 / 声音
```
主体替换：【编辑目标】编辑@视频1，只把<原对象>修改为<目标对象>。【目标素材职责】@图片1用于<目标对象>的<外观、结构或材质>，不采用<无关背景、人物或构图>。【编辑对象与范围】只修改<明确对象和区域>。
背景替换：编辑@视频1，只替换<背景区域>的<场景、光线或氛围>，@图片2用于新背景的<空间、材质和光线>；保持<主体>身份、服装、动作和镜头。
声音：编辑@视频1，只把<原音色/音乐>替换为<目标>，@音频1用于<目标音色或音乐>；保持画面与对白不变。
```

### D3 视频延长（前 / 后）
```
前延长：延长@视频1，紧接上一帧继续生成<时长>视频。保持<人物身份、服装、场景、镜头、声音>稳定。后续：<接下来的动作或事件>。
后延长：延长@视频1，从最后一帧继续生成<时长>视频。保持<已有状态锚点>。后续：<新事件>。避免突然切换<天气、服装、车辆型号、画面风格>。
```

### D4 首尾帧 / 多关键帧
```
首帧生视频：@图片1是首帧，定义<主体、构图、风格>。生成<时长>视频，<主要动作或事件>，保持首帧中的<身份、服装、场景>。
多关键帧：@图片1是第一关键帧…… @图片N是末关键帧。视频依次经过各关键帧，每帧之间<动作或运镜>，保持<主体身份与风格>稳定。
```

## E · 进阶玩法（白模 / 分镜 / 成片 / 转场）

### E1 粗粒度白模
```
@视频1是粗粒度白模参考，仅提供<动作路径、站位、机位、运镜、切镜、光影或声音节奏>，不采用其中的白模外观、材质和场景。
@视频1中的<白模主体A>对应<主体A>。@视频1中的<几何道具>对应<关键道具>。
@图片1定义<主体A>的<外貌、服装或结构>。
<主体>在<场景>中完成<主要动作>。保持@视频1中的<动作路径、站位、运镜、切镜>。画面采用<风格>，声音包括<……>。
```

### E2 细粒度白模
```
@视频1是细粒度白模参考，保持<主体结构、动作、空间布局、机位、运镜和切镜>，不采用原有灰模材质和空白背景。
@图片1定义<主体>的<材质、颜色或表面细节>。@图片2定义<场景>的<空间、材质、光线或风格>。
将@视频1中的<主体>重渲染为<最终主体>，场景重渲染为<最终场景>。保持<结构、动作、镜头>。
```

### E3 宫格分镜
```
@图片1提供<N格宫格分镜>的镜头顺序和大致构图，按照<从左到右、从上到下>顺序读取；不采用图中的<线稿画风、文字标注或占位人物>。
@图片2定义<主体A>的<外貌与服装>。
镜头1：<景别、主体动作、场景状态>。镜头2：<景别、运镜或切换>。…… 镜头N：<结束动作和结束画面状态>。
最终画面采用<视觉风格>，声音包括<……>。
```

### E4 一键成片
```
【素材职责】@图片1用于<人物、商品、场景或开场画面>。…… @视频1仅用于<剪辑节奏、转场、字幕包装或音乐风格>，不采用其中的人物身份和场景。
【编排方式】图片按照<顺序>出现。<说明需要保持的人物、商品、地点和事件关系>。
【画面动态】每张图片采用<轻微Live动效、视差、推拉或局部动作>。保持<主体外观、商品结构>稳定。
【成片风格】采用<剪辑节奏、转场方式、字幕或图形包装、色彩风格>。
【声音】包括<对白、环境声、音效或音乐>。
```

### E5 无缝转场
```
@视频1是转场前片段，采用其<尾部主体、动作、构图、镜头方向和声音>。
@视频2是转场后片段，采用其<开头主体、构图、镜头方向和声音>。
保持两段原视频中的<人物身份、商品结构、场景和主要动作>稳定。
在@视频1尾部，<主体或前景物>通过<动作>触发转场。镜头<运动方向和速度变化>，画面中的<形状、材质、光线或空间>逐渐变化为@视频2开头的<对应元素>。
转场结束时自然到达@视频2的开头构图，并保持<主体位置、镜头方向和运动趋势>连续。声音从<前段声音>平滑过渡到<后段声音>。
```

## F · 镜头与情绪

### F1 七种热门运镜写法要点
一镜到底（连续经过的主体/空间/事件顺序）｜希区柯克变焦（主体大小不变+背景拉近推远）｜航拍视角（俯视高度+移动方向+环境范围）｜FPV（第一人称路径+速度+转向）｜子弹时间（冻结/放慢的动作+环绕方向）｜手持镜头（跟拍对象+晃动程度）｜回弹变速（加速/减速/回弹节点+最终停留）

### F2 小众术语公式
```
专业术语 ＋ 作用主体 ＋ 画面变化 ＋ 前景/背景关系 ＋ 方向或速度
移焦：焦点从前景树叶平滑转移到背景人物。树叶逐渐虚化，背景人物的面部由模糊变得清晰。
```

### F3 情绪默认写法
```
整体情绪从<起始情绪>转为<结束情绪>。发生<触发事件>后，<主体>先出现<即时可观察反应>。
随后，<眼神、眉头、嘴角、呼吸、视线或手部动作>逐渐发生<变化>。最终，<主体>以<克制或明确的外在表现>表达<目标情绪>。
```

### F4 情绪多阶段写法
```
听到或看到<第一个触发事件>时，<主体的第一个可观察反应>。
当<第二个触发事件>出现后，<主体的表情、视线或呼吸发生的变化>。
确认<关键信息>后，<主体试图克制或掩饰的情绪>通过<可观察表现>逐渐显现。
最终，<主体的最终动作、表情或说话方式>。
```

## H · 精准计时输出（剧本/分镜 → 秒级时间戳）

> 用于用户给的是剧本/台词/分镜、而非现成提示词时。时间测算速查与双版本/延长/接力格式见 [references/09-timed-script-prompter.md](../references/09-timed-script-prompter.md)。任务类型与参数规则严格遵循官方指南 2.2/2.3/2.5（单段≤30s；延长比例锁定、时长可设；首尾帧用首帧比例）。

### H1 时间测算速查（中值估算，非硬性规则）

```
台词：普通中文 3-4 字/秒（字数÷3.5）；情绪/古风 2-3 字/秒（÷2.5）；气声 1.5-2 字/秒（÷1.8）；外语 2.5-3 词/秒（词数÷2.8）；停顿/换气每次 0.5-1 秒。
动作：表情反应 0.5-1s｜眼神对视 1-2s｜转头回身 1-2s｜起身坐下 1.5-3s｜走位 0.5s/步｜拔剑推门 1-2s｜连击 3-5s｜复杂长尾 4-8s｜倒地坠落 1.5-3s。
运镜：定场 1-2s｜推拉 1-3s｜摇移 1-2s｜硬切 0-0.5s｜叠化 1-2s｜首帧承接 1-2s｜末帧停留 1-2s。
帧级：产品级能力、官方指南未详述；确有卡点需求时帧号 ≈ 秒×24（fps 以生成页为准）。双标注写法：第 0-90 帧 (0s-3s)。
```

### H2 双版本输出格式（多模态版 + 纯文字版）

```
## 剧本分析
- 出场角色: [CH01] [CH02]   场景: [SC01]   生成模式: [单段 X 秒 / 视频延长（向后/向前）/ 首尾帧生视频]
- 核心动作: [一句话]   情绪走向: [起点 → 终点]
- 台词锁定: | D01 | [角色] | "[台词原文]" | [字数]字 | [语速类型] |

## 精准时间测算
[逐项测算 + 测算表，结论：通过/需调整]

## 规划结论
- 建议时长: [X] 秒（共 X 帧 @24fps）  选择理由: [为何此长度]

--- 多模态版 ---
> 【全局约束】1.视觉风格[…]全片禁止偏移。2.字幕音频[纯净/用@音频1]。3.参考素材@图片1=[…]@视频1=[…]@音频1=[…]。本段规划 X 秒，测算 X.X 秒。
> 0-3s：[景别+运镜+动作+台词原文+光线+音画同步，跨区间重复面部/发型/服装锚点]
> 3-7s：…
> 负向约束：禁止[字幕/水印/无关BGM/IP]

--- 纯文字版 ---
[结构同上，@引用替换为完整文字描述，可直接复制]
```

### H3 延长段格式

```
> 接续上一段结尾：[复述上一段末帧状态，确保无缝承接]。延长 X 秒。
> 0-Xs（延长段内时间轴）：[新动作/新场景变化]
> [保持角色锚点；声明"画面风格、人物、场景与上一段保持一致"]
```

### H4 超过 30 秒成片：单段 + 延长接力格式

> 官方指南没有"超长视频模式 / 180 秒"独立任务类型。超过 30 秒的成片用「单段（≤30s）+ 多次延长」接力，每段按官方时间戳三法（0-X秒区间 / 第X秒 / 相对时间）书写：

```
> 【全局约束】（同上）
> 0-8s：[景别+运镜+人物动作+台词原文+光线氛围+音画同步，五维融合为连续段落]
> 8-15s：…（区间连续不重叠，与首段规划一致）
> …
> 末段如需继续：接续上一段结尾做向后延长（见 H3），保持人物/道具/背景/运动/声音连续。

## I · 提示词工程纪律模板（来自 references/10，官方 sd25-pe）

【未采用素材】
@图片5、@图片6未参与本任务，不用于人物、场景、道具、动作或镜头。
@音频2未参与本任务，不用于台词、音色、环境声、音效或音乐。

```text
