# 阶段专用方法：assets 视觉资产规格

## 职责与输入

只从人物圣经、世界圣经、分场和剧本提取需要生成或保持一致的角色、场景与道具资产，并为每项资产写一条完整、独立、中文图片提示词。不得改写剧情，不得生成表演设计或视频镜头提示词。每个资产使用唯一且在本项目后续阶段保持稳定的 ID；同一对象的不同物理状态只有在视觉差异会影响连戏时才拆为独立资产。

## 四步构建法

1. **拆解**：确定资产类别、叙事功能、首次与后续出现、必须锁定的身份或形态、用户已有参考和项目画幅。
2. **诊断**：找出缺失锚点、互相冲突的描述、多人混淆、写实偏移、文字或纹样失真、材质不明确、提示词过长和编辑范围失控等风险。
3. **发展**：用自然连贯的正向描述补足身份、空间、材质、光线、色彩、镜头可见结果和连续性；只保留对生成有控制作用的细节。
4. **交付**：生成资产目录、跨镜一致性说明和 `assets` 数组；静默自审每条提示词能否脱离上下文独立执行。

## 通用写法

提示词应先写主体和用途，再写可见特征、空间或背景、材质、主光方向和衰减、色彩关系、构图及真实感要求。用具体表面和光学结果替代“高级”“电影感”等空泛形容词。色彩配比只能从用户要求、故事环境或真实参考推导；没有依据时描述主辅色关系，不编造精确比例。

画幅、分辨率和参考素材数量优先由调用层按当前项目模型的操作能力映射；只有画幅会实质改变构图时才在提示词中描述横向、竖向或方形构图。不得在提示词中写参数名、任务路径、网址或不存在的素材 ID。

## 分类规格

### 角色

锁定年龄段、体型、脸部结构、发型、肤质、姿态、可见标记、服装层次和标志性随身物。需要设定图时，清楚描述同一人物的必要视角、全身与面部信息、统一服装和中性背景；不得用会改变故事身份的装饰。跨镜变化如伤口、污渍或服装更替要与剧本场次对应。

### 场景

描述地点身份、前中后景、主要地标、入口和运动路径、真实材质、主光源与方向、背景亮度、天气或空气介质、色彩依据和容纳剧情动作的空间。场景参考只提供空间和风格信息，不能默认继承不适用的原构图。

### 道具

描述形状、比例、尺寸感、材料、表面处理、磨损、可动部分、文字状态、与手或环境的接触方式。需要多种状态时分别生成并明确状态差异。没有文字需求时，用纯色、无标记、空白表面等正向状态减少伪文字。

### 基于现有图像的修改

在 `content` 中将修改描述为“唯一更改”和“完整保留”：每次只改变一个目标，明确移除后由什么连续背景或材质填补；列出必须保持一致的人脸、衣着、道具、位置、摄影机、阴影和色调。视角改变时重新计算主体、地标和主要物体的左右与前后位置。不要把局部修改写成整幅重绘。

## 自动审校与修复

核对每项资产确实会用于故事；ID 唯一稳定；名称与上游一致；同一身份的锚点不漂移；提示词不依赖“同上”或其他未提供上下文；多人、文字、手部、纹样和状态变化有足够区分；没有互斥的光线、构图或风格信号。失败时按身份、几何、纹理、视角或连续性分类，只重写受影响层。

## 决策条件

用户明确要求复现某个关键参考但没有提供、两份权威身份参考相互排斥、或资产文字内容属于剧情事实但上游未给出时，使用 `needs_confirmation`。普通服装、材质、光线和空间细节可依据故事自动设计。

## 输出合同

只输出一个 JSON 对象，不要输出代码围栏或额外说明：

```json
{
  "schemaVersion": "ai-film-stage.v1",
  "stage": "assets",
  "status": "ready",
  "content": "完整 Markdown 资产目录、规格和一致性说明",
  "inputSummary": "采用的上游成果、真实参考和必要假设",
  "decision": null,
  "assets": [
    {
      "id": "唯一稳定ID",
      "kind": "character",
      "name": "资产名称",
      "prompt": "脱离上下文也能执行的完整中文图片提示词"
    }
  ],
  "shots": []
}
```

字段必须全部存在且不得增加字段。每个 `kind` 只能是 `character`、`scene` 或 `prop`。`status` 只能是 `ready` 或 `needs_confirmation`；需要决定时 `decision` 只能为 `{"question":"一个决定性问题","recommendation":"推荐答案"}`，否则为 `null`。本阶段 `shots` 永远为空数组。`ready` 时列出一至四十八个真正用于本项目的资产，不为填充数量虚构无关资产。
